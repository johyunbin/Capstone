# 논문 분석 스킬

PDF 논문을 읽고 구조화된 분석 문서를 .md + .pdf + .docx 3종 세트로 생성한다.

## 출력 구조

```markdown
# [논문 제목] 총정리

> **범위**: [논문 범위 한 줄 요약]

---

### [1] 논문 개요 및 문제 정의
### [2] 제안 기법
### [3] 실험 설계 및 결과
### [4] 한계점 및 미해결 문제
### [5] Exqutor와의 연결고리
### [6] 핵심 용어 정리 (표)
```

## 파일 명명 규칙

- `[번호] 논문제목_키워드 총정리.md`
- 동일 이름으로 `.pdf`, `.docx` 생성
- Research/ 디렉토리에 저장

## PDF 생성 규칙

- fpdf2 + NanumSquareOTF (Regular + Bold)
- D2Coding for code blocks
- 테이블: 7pt, 셀 border 1px
- 페이지 여백: 기본 (10mm)
- **반드시 한글 폰트 임베딩 확인**

## 분석 스타일

- 서사적 한국어 학술 산문 (bullet 나열 지양)
- 배경 맥락 → 핵심 아이디어 → 번호 매긴 기법(O1, O2...) → 후속 질문
- 데이터셋, 하드웨어 스펙, baseline, 핵심 메트릭 포함 필수
- Exqutor 본 논문과의 관계 반드시 서술
