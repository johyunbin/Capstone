# 캡스톤 제출물 준비 스킬

캡스톤 디자인 제출물을 양식에 맞춰 작성한다.

## 제출물 종류 및 양식 위치

| 제출물 | 양식 | 예시 |
|--------|------|------|
| 연구지도확인서 | `Templates/양식/연구지도확인서.zip` | — |
| 연구제안서 | (사이트 확인) | `Templates/예시/` 참조 |
| 수행계획서 | (사이트 확인) | — |
| 자문내역서 | (사이트 확인) | — |
| 결과보고서 | `Templates/양식/결과보고서.zip` | — |
| 회의록 | `Templates/양식/회의록-양식.zip` | — |
| 중간발표 PPT | — | `Templates/예시/첨부8, 10` |
| 중간보고서 | — | `Templates/예시/첨부9, 11` |
| 최종보고서 | — | `Templates/예시/첨부14` |
| 포스터 (A0) | — | `Templates/예시/첨부13` |

## 워크플로

1. 해당 양식 zip을 해제하여 템플릿 확인
2. 프로젝트 맥락(CLAUDE.md, Research/ 분석문서)에서 내용 추출
3. 양식에 맞춰 작성
4. .docx로 생성 (제출용)
