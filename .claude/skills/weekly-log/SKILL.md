# Weekly Log — 주간 작업일지

매주 금요일 또는 요청 시 git 이력과 문서 변경을 종합하여 주간 보고서 자동 생성.

## 데이터 소스

1. **git log** — 이번 주 커밋 이력
2. **Research/** — 새로 추가/수정된 분석 문서
3. **Experiments/** — 새로 추가된 실험 로그
4. **미팅 노트** — 교수님/자문위원 미팅 기록

## 출력 형식

```markdown
# 주간 작업일지 (YYYY-MM-DD ~ YYYY-MM-DD)

## 이번 주 요약
- [한 줄 요약]

## 완료 작업
1. [작업 1]
2. [작업 2]

## 문서 변경
| 문서 | 변경 유형 | 내용 |
|------|----------|------|
| (13) 새문서.md | 신규 | 논문 X 분석 |
| CLAUDE.md | 수정 | 일정 업데이트 |

## 실험 진행
- [실험명]: [결과 요약]

## 다음 주 계획
1. [계획 1]
2. [계획 2]

## 이슈/블로커
- [있으면 기술]
```

## 저장 위치
- `Logs/주간보고_YYYY-MM-DD.md`
- 캡스톤 회의록 양식과 병행 가능
