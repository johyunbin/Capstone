# [80] Selectivity and Cost Estimation for Joins Based on Random Sampling

## 요약

Haas, Naughton, Seshadri, Swami의 JCSS 1996 논문으로, 조인 선택도(join selectivity) 추정을 위한 무작위 샘플링의 이론적 기초를 제시한 '고전' 논문이다. 이 논문은 데이터베이스 통계와 표본론을 결합하여 샘플링 기반 추정의 수학적 모델을 정립했다.

핵심 기여:
1. **이론적 프레임워크**: 조인 크기 추정의 통계 모델 개발
2. **신뢰도 분석**: 샘플 크기와 추정 오류의 관계 공식화
3. **점근 분포(Asymptotic Distribution)**: 표본 크기가 클 때의 분포 특성 증명
4. **실용적 가이드**: 필요한 샘플 크기 결정 방법 제시

본 논문은 이후 30년 가까이 샘플링 기반 카디널리티 추정 연구의 이론적 기반이 되었다. 특히 신뢰도 구간 계산, 적응적 샘플링, 그리고 비용 모델에 광범위하게 인용된다.

본 논문과의 관계: Exqutor의 적응적 샘플링 방식의 직접적인 이론적 토대다. 특히 선택도 추정의 신뢰도를 정량화하고 필요한 샘플 크기를 결정하는 방법론을 제공한다. Exqutor는 범위 필터와 벡터 검색의 결합 선택도 추정에 이 논문의 통계 이론을 적용할 수 있다.

## 상세분석

### 80.1 조인 선택도의 수학적 정의

**기본 정의:**

```
테이블 T1: N_1개 행
테이블 T2: N_2개 행

조인 조건 P에 대해:
조인 결과 = T1과 T2의 행 중 P를 만족하는 쌍의 집합

조인 카디널리티:
C = |{(t1, t2) : t1 ∈ T1, t2 ∈ T2, P(t1, t2) = true}|

조인 선택도:
σ = C / (N_1 × N_2)
```

**예시:**

```
T1: 고객 테이블 (10,000명)
T2: 주문 테이블 (100,000건)

조인 조건: 고객.id = 주문.고객_id

조인 결과: 90,000건 (평균 고객당 9개 주문)

카디널리티: C = 90,000
선택도: σ = 90,000 / (10,000 × 100,000) = 0.009 (0.9%)
```

### 80.2 샘플링 이론의 적용

**표본 선택도의 분포:**

T1에서 n_1개, T2에서 n_2개 행을 무작위로 샘플링할 때,
샘플 내 조인 결과를 c라 하면:

```
표본 선택도: σ_hat = c / (n_1 × n_2)

이 추정량의 분포:
```

**Case 1: 선택도가 고정되어 있고 n → ∞일 때**

```
중심극한정리(Central Limit Theorem):
√n × (σ_hat - σ) → N(0, σ(1-σ))

분포: σ_hat는 점근적으로 정규분포
     평균: σ
     표준편차: √(σ(1-σ) / n)
```

**Confidence Interval (95% 신뢰도):**

```
P(σ_hat - 1.96 × σ_SE < σ < σ_hat + 1.96 × σ_SE) = 0.95

여기서 σ_SE = √(σ_hat(1-σ_hat) / n)

정규 근사의 신뢰도를 높이려면 n이 충분해야 함:
n × σ_hat > 5 and n × (1-σ_hat) > 5
```

### 80.3 조인에 특정한 이슈

**독립성 가정:**

조인 조건이 두 테이블의 행을 독립적으로 선택할 때:

```
σ(T1, T2) = σ(T1) × σ(T2)

예:
T1에서 P_1을 만족할 확률: σ_1 = 0.2 (20%)
T2에서 P_2를 만족할 확률: σ_2 = 0.5 (50%)
조인 선택도: σ = 0.2 × 0.5 = 0.1 (10%)

(T1.A = T2.A인 등호 조인이 아닐 때 근사)
```

**등호 조인(Equi-join)의 특수성:**

```
T1.id = T2.id 형태의 조인

경우 1: 외래키 관계 있음
  └─ 모든 T2.id가 T1에 존재
     σ = N_2 / (N_1 × N_2) = 1 / N_1
     (매우 낮은 선택도 가능)

경우 2: 일반적인 등호 조인
  └─ σ = m / (N_1 × N_2)
     m = 두 테이블의 공통 키 개수
```

### 80.4 점근 성질(Asymptotic Properties)

**큰 n에서의 행동:**

```
샘플 크기 n이 클 때:

1. 일관성(Consistency):
   σ_hat → σ (거의 확실하게)
   샘플 크기가 증가하면 추정치가 참값으로 수렴

2. 정규 수렴(Normal Convergence):
   (σ_hat - σ) / √(σ(1-σ)/n) → N(0, 1)
   정규분포로 수렴 속도: O(1/√n)

3. 효율성(Efficiency):
   분산: Var(σ_hat) = σ(1-σ) / n
   가장 작은 분산을 가짐 (비편향 추정량 중)
```

### 80.5 신뢰도와 샘플 크기의 관계

**정밀도 요구사항:**

```
±ε 범위의 오류를 100(1-α)% 신뢰도로 원할 때:

필요한 샘플 크기:
n = z²_{1-α/2} × σ(1-σ) / ε²

여기서 z_{1-α/2}는 표준 정규분포의 상위 α/2 백분위수:
- 90% 신뢰도 (α=0.1): z = 1.645
- 95% 신뢰도 (α=0.05): z = 1.960
- 99% 신뢰도 (α=0.01): z = 2.576
```

**구체적 계산 예시:**

```
목표: 선택도 σ = 0.01 (1%)을 ±20% 상대 오류, 95% 신뢰도로 추정

절대 오류 ε = σ × 0.2 = 0.01 × 0.2 = 0.002

필요 샘플:
n = 1.96² × 0.01 × 0.99 / 0.002²
n = 3.84 × 0.0099 / 0.000004
n = 9,504

테이블이 1,000,000행이면: 샘플율 = 9,504 / 1,000,000 ≈ 1%
```

**선택도에 따른 샘플 크기:**

```
같은 조건 (±20% 오류, 95% 신뢰도)에서:

σ = 0.5 (50%):  n ≥ 2,401
σ = 0.1 (10%):  n ≥ 9,604
σ = 0.01 (1%):  n ≥ 9,504 (σ와 (1-σ)이 비슷해서 최대)
σ = 0.001 (0.1%): n ≥ 95,040
σ = 0.0001 (0.01%): n ≥ 950,399

선택도 감소에 따라 필요 샘플 선택도의 역함수에 비례
```

### 80.6 다중 조인에의 확장

**체인 조인(Chain Join):**

```
T1 JOIN T2 JOIN T3

각 조인의 선택도:
σ_1_2 = P(t1, t2 만족) = 0.1
σ_2₃ = P(t2, t3 만족) = 0.2

결합 선택도 (독립성 가정):
σ_total = σ_1_2 × σ_2₃ = 0.1 × 0.2 = 0.02 (2%)

문제: σ_total이 σ_1_2, σ_2₃보다 낮음
→ 최종 카디널리티 추정이 더 불안정
```

**스타 조인(Star Join):**

```
중앙 테이블 T1과 여러 dimension 테이블 T2, T3, T4 조인

T1과 T2의 선택도: σ_1_2 = 0.3
T1과 T3의 선택도: σ_1₃ = 0.4
T1과 T4의 선택도: σ_1₄ = 0.5

결합 선택도: σ_total = 0.3 × 0.4 × 0.5 = 0.06 (6%)

문제: 테이블이 많을수록 선택도는 더 낮아짐
```

### 80.7 비용 모델에의 적용

**조인 실행 비용 추정:**

```
조인 비용 = CPU_비용 + I/O_비용 + 메모리_비용

CPU 비용: 조인된 행 수 × 행당_처리비용
        = C × cost_per_row
        = N_1 × N_2 × σ × cost_per_row

I/O 비용: 접근해야 할 페이지 수
        = (N_1 × page_size_1) + (N_2 × page_size_2)
        (선택도가 낮으면 CPU 비용이 지배적)

정확한 σ 추정 → 정확한 비용 예측 → 최적 실행 계획
```

### 80.8 본 논문과의 관계

**Exqutor의 샘플링 기반 선택도 추정:**

Exqutor는 범위 필터와 벡터 검색의 결합 선택도를 추정하는데, 이 논문의 이론을 직접 적용할 수 있다:

**1단계: 이론적 기초 적용**

```
범위 필터: WHERE price ∈ [L, U]
벡터 검색: WHERE similarity(embedding) > θ

쿼리 선택도:
σ = P(가격 조건) × P(유사도 조건)

이는 논문의 곱셈 규칙(independent join selectivity)
과 동일한 형태
```

**2단계: 샘플 크기 결정**

```
목표 정확도: ±15% 상대 오류, 90% 신뢰도
추정된 σ = 0.12 (범위 필터 15% × 벡터 80%)

필요 샘플 크기:
ε = 0.12 × 0.15 = 0.018
z = 1.645 (90% 신뢰도)

n = 1.645² × 0.12 × 0.88 / 0.018²
n ≈ 250개 (전체 1% 미만)
```

**3단계: 신뢰도 검증**

```
수집한 샘플에서:
c = 범위 필터 AND 유사도 조건 만족하는 행 수

신뢰도 구간:
σ_hat ± 1.645 × √(σ_hat(1-σ_hat) / n)

이 구간이 충분히 좁으면 추정 사용
너무 넓으면 추가 샘플링
```

**논문 [80]의 핵심 가치:**

1. **이론적 정당성**: 샘플링 기반 추정의 수학적 기초 제공
2. **샘플 크기 결정**: n = z² × σ(1-σ) / ε² 공식
3. **신뢰도 계산**: 점근 정규분포를 이용한 신뢰도 구간 계산
4. **다중 조인 확장**: 곱셈 규칙을 통한 복합 선택도 추정
5. **실무 적용**: 이후 모든 샘플링 기반 옵티마이저의 기반
