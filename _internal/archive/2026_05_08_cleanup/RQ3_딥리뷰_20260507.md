## §1. Tier 1 — 알고리즘 충실도

### 1.1 통일 backend (`_measure_common.py`)

**핵심 가치**: 22 method 모두 동일 측정 골격 사용 → cross-method 비교의 confound 제거.

| 단계 | 함수 | 검증 |
|---|---|---|
| Vector fetch | `fetch_all_vectors_safe(ds)` | KM20 cluster 단위 fresh conn (PG vector::real[] cast leak 회피) ✓ |
| stratum 부여 | method-specific (각 wrapper) | KM20 sids 회수 후 method 의 algorithm 호출 |
| 캐시 | `cache_cluster_samples_inmem` | `cache_per_cluster=500`, RNG seed=42 고정 ✓ |
| HT estimator | `stratified_estimate` | weight = N_i / s_i (Horvitz-Thompson) ✓ |
| BERN baseline | `bernoulli_estimate` | concat'd cluster cache (≤10K) 에서 추출, HT weight = total_rows / s ⚠️ |

⚠️ **RQ1/RQ2 와 동일 caveat**: bernoulli_estimate 는 캐시에서 추출 (full population X). 절대 q-error 인용 시 명시.

✓ **장점**: 모든 method 가 동일 cache, 동일 query pool, 동일 RNG seed → method 간 ranking 의 신뢰성 강함.

### 1.3 검증된 핵심 method 알고리즘

#### KDE-pilot (`rq3/kde/kde_pilot.py`) ✓
- Silverman bandwidth: h = 1.06 × std × n^(-1/5) ✓
- KDE hit prob: p̂ = mean[Φ((D−d_j)/h)] (Gaussian kernel CDF) ✓
- Neyman main: n ∝ N × σ̂, sum to (budget − pilot_used) ✓
- Pilot/main disjoint: `avail = where(~used_masks)` ✓
- HT 결합: (pilot_hits + main_hits) × N / (pilot_n + main_n) ✓
- Edge case 처리: m<2 또는 sd<1e-9 시 empirical fallback ✓

#### Distance-Shell (`rq3/online_weight/distance_shell.py`) ✓
- Pilot: 50 uniform sample → distance d_j → 5 shells (quantile equal-frequency)
- Shell σ_i = sqrt(p × (1−p)) per shell
- Neyman alloc on shells: target_add ∝ N_i × σ_i
- Rejection-based main phase

#### Spectral (`rq3/spectral/spectral_clustering.py`) ⚠️
- ⚠️ **Limitation noted in code**: sklearn SpectralClustering 은 transductive (학습 sample 만 cluster id 부여)
- 본 구현: centroid = cluster mean → out-of-sample 에 nearest centroid 부여 (centroid-based approximation, NOT proper Nystrom 확장)
- 영향: non-convex cluster 의 핵심 강점 일부 손실 (Spectral 결과가 K-Means centroid 비슷해질 수 있음)

→ 본 limitation 은 narrative 에 "Spectral 는 centroid-based approximation 으로 in-sample 학습 + nearest assignment — true Nystrom 확장 X" 로 명시 권고.

#### Importance Sampling (NaN 18.88%) ⚠️
- `rq3_importance_sampling.parquet` 의 NaN 비율 19% — 다른 method 의 0–2% 대비 매우 높음
- 원인: importance weight (w_i = 1 / pdf(x_i)) 가 일부 query 에서 극단값 → est = 0 또는 발산
- 4 variants (p50_clip, p50_noclip, p200_clip, p200_noclip) 모두 비슷한 NaN 패턴
- 본 결과는 narrative 에 "Importance Sampling 은 1M/SIFT 1.5M 에서 BERN 대비 hurt — pdf 추정 noise 가 weight 에 amplified" 로 인용 가능

#### 핵심 통계 결론

1. **Cohen's d 표준 해석 (|d| ≤ 0.2 negligible / 0.5 small / 0.8 medium / >0.8 large)**:
   - **No method has |d| > 0.8 in either direction** = no large effect
   - **Top improve (hilbert) d=−0.156** = negligible 경계
   - **Top hurt (importance_sampling p200_clip) d=+0.704** = small-medium hurt

2. **Robust fraction (CI 0 제외 / 10 cell)**:
   - Hilbert/minibatch/hdbscan: 50% 만 robust → narrative 에 "절반 cell 에서 통계 robust improve"
   - Importance sampling 4 variant: 80–100% robust hurt → narrative 에 "IS 는 모든 condition 에서 BERN 대비 systematic hurt"
   - distance_shell: 80% robust hurt — online weight method 의 surprising negative result

3. **Practical significance vs statistical significance**:
   - paired Wilcoxon p-value 만 보면 sample size n=500 효과로 p<0.05 가 자주 나옴
   - effect size (Cohen's d) 는 sample size 무관 → **본 결과의 practical 신뢰도 정량**

### 3.2 Spectral 정정 사례 — recovery vs bootstrap 의 mathematical 차이

#### 두 metric 정의

**Recovery rate** (`recovery_rate.py`):
```
recovery = (method_q − random20_q) / (km20_q − random20_q)
```
- 분모: KM20 과 RANDOM20 의 q-error 격차 (oracle 의 잠재력)
- 분자: method 가 RANDOM20 대비 얼마나 oracle 방향으로 갔는지
- 1.0 = KM20 oracle 수준, 0.0 = RANDOM20 수준, **음수 = RANDOM20 보다 나쁨**

**Bootstrap delta_pct** (`rq3_bootstrap_effect_size.py`):
```
delta_pct = (median(method_qe) − median(bern_qe)) / median(bern_qe) × 100
```
- 분모: BERN q-error 의 median
- 분자: method 와 BERN 의 median 차이
- paired bootstrap (seed, query_id) 으로 robust uncertainty

#### Spectral DEEP s=0.01 검증

| Metric | 값 | 해석 |
|---|---|---|
| recovery_summary `recovery` | **−5.39%** | RANDOM20 보다 5.4 배 더 많이 oracle 반대 방향 |
| recovery_summary `method_minus_bern_pct` | **+22.49%** | spectral q-error 가 BERN 보다 22.5% 큼 (unpaired median) |
| bootstrap `delta_pct_mean` | **+16.71%** | paired bootstrap 의 median 차이 (16.71% 큼) |
| bootstrap `delta_pct_ci` | [−0.50, +20.87] | **CI 가 0 포함** → 통계 robust X |
| bootstrap `cohens_d` | +0.187 | negligible 경계 |
| bootstrap `direction` | hurt | small effect |

**Mathematical 차이 명확화**:
1. recovery 는 정규화된 metric (oracle gap 대비). 분모 (km20 − random20 = 1.597 − 1.663 = **−0.066**) 가 작아서 sensitive — 작은 분자 변화가 큰 metric 변화로 amplify.
2. bootstrap 은 BERN 직접 비교. paired 분석이라 개별 query 변동의 영향 적음.
3. 22.49% vs 16.71% 의 차이: unpaired (전체 median) vs paired bootstrap (sample-level). Paired 가 보수적.

#### 정정 narrative

- 만약 사전 narrative 에 "spectral 가 graph-Laplacian 으로 KMeans 보다 우수" 또는 "spectral 가 개선 method" 로 표현되었다면 → **본 결과는 그 narrative 가 wrong**
- 정확한 narrative: "Spectral (Nystrom centroid-based) 는 1M/SIFT 1.5M 에서 BERN 대비 small hurt (mean d=+0.123, 1/10 cells robust). 가장 좁은 sel (s=0.01) 에서 recovery rate −5.39% (RANDOM20 oracle 가치를 상실)."
- 본 결과는 narrative 에 "**KMeans 변형 (minibatch/birch) 와 그 외 cluster method (gmm/hdbscan) 가 비슷 수준 — graph-Laplacian 의 추가 가치 없음**" 으로 강화
