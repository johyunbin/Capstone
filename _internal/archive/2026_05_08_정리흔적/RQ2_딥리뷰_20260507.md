## §1. Tier 1 — 알고리즘 충실도

### 1.1 σ_i 사전 계산 (`rq2/compute_stratum_sigma.py`)

#### 정의
- σ_i² = mean_q[p_iq × (1 − p_iq)] (Bernoulli variance per query, average across query pool)
- p_iq = (cluster i 안에서 query q hit 한 row 수) / N_i
- 단일 σ_i across selectivity (sel=0.1 D_target 기준) — single-σ limitation은 코드 line 7 에 명시

#### 검증

| 항목 | 검증 | 결과 |
|---|---|---|
| 정의 | line 119-120 `bern_var = p_iq * (1-p_iq); sigma = sqrt(bern_var.mean(axis=0))` | ✓ 표준 |
| HNSW 우회 | line 102 `l2_distance(vec, vec)` 함수 호출 (KNN-plan 회피, hook 미트리거) | ✓ 의도적 |
| n_strata 동적 | line 78 `n_strata = max(N_dict.keys()) + 1` | ✓ 테이블 의존 |
| Storage | PG `vector_stratum_sigma` 테이블 (table_name, stratum_id, sigma, n_i, sel_used) | ✓ 캐시 |

#### 우려
- `single σ_i across all sels` 가정: σ_i (sel=0.1) 가 모든 sel 의 Neyman 에 사용됨. Sel-adaptive σ는 RQ3 영역으로 이관 (kde_pilot 의 query-aware σ 와 비교 가능 — Tier 4 참조).

### 1.2 5-mode allocation (`rq2/rq2_alloc_python.py`)

#### Allocation formulas

| Mode | w_j | 의미 |
|---|---|---|
| equal | 1.0 | budget/n_strata 균등 |
| proportional | N_j | N_j 비례 (uniform stratum 시 equal 과 등가) |
| neyman | N_j × σ_j | Neyman 1934, variance-optimal |
| anti_neyman | N_j / σ_j | Ablation, suboptimal (σ 작은 곳에 더 많이) |
| bernoulli | — | TABLESAMPLE BERNOULLI baseline |

코드 line 119-145 검증:
- `f = w / sum_w * budget` → 비례 분배
- `s = max(int(f), 1)` → 최소 1 보장
- 잔여 budget 분배: `np.argsort(-frac)[:extra]` → 큰 fractional part 우선 (Hamilton method, largest-remainder) ✓
- `extra < 0` 미처리 (over-allocation by min=1 effect) — comment 에 "무시" 명시. 20 strata × budget 385 환경에서는 base ≈19 이라 사실상 발생 X.

#### Stratified estimator (Horvitz-Thompson)

```python
# line 148-166
weight = sizes.get(sid, 0) / s_i  # N_i / s_i
est += hits * weight  # HT 표준
```
✓ 표준 Horvitz-Thompson estimator.

#### Bernoulli estimator 와 sampling-population

⚠️ **RQ1 와 동일 caveat**:
- `flat = concat([samples[sid] for sid in range(N_STRATA)])` — 캐시 (≤10K) 에서 추출
- HT weight `total_rows / s` = 1M / 385
- 실제 PG bernoulli (1M 전체 모집단) 와 sampling-population 차이

→ 절대 q-error 인용 시 caveat 필요, 상대 비교는 보존.

### 1.3 5-mode 단조성 (`local_analysis/rq2_5mode_monotonicity.py`)

#### Methodology
- Per (dataset, mode, sel, seed): median q_error → diff_pct = (method_med − bern_med) / bern_med × 100
- Per-seed Spearman ρ + 95% bootstrap CI (5,000 resample, rng=42)
- Pooled Mann-Kendall + Spearman on sel-mean

✓ RQ1 gradient_monotonicity 와 framework 동일 (consistent metric).

#### Sign convention 차이 (주의)
- RQ1: `(bern_med − strat_med) / bern_med × 100` → 양수 = STRAT 좋음
- RQ2: `(method_med − bern_med) / bern_med × 100` → **음수 = method 좋음**
- 따라서 RQ2 의 ρ > 0 monotonicity = "sel↑ → method 의 advantage (음수의 절대값) 감소" = RQ1 의 ρ < 0 와 같은 방향

→ 보고서 작성 시 부호 헷갈리지 않도록 주의.

### 1.4 Anti-Neyman cell analysis (`local_analysis/rq2_anti_neyman_cell_analysis.py`)

#### Methodology
- Per (dataset, sel) cell:
  - paired Wilcoxon (two-sided) on raw q_error_an vs q_error_pr
  - delta_pct = ratio-of-medians
  - Bootstrap CI 2,000 resample
  - Cohen's d (paired) = mean(diff) / std(diff, ddof=1)
- BH correction column: ⚠️ **mislabeled** — line 84 `out["p_BH_005"] = (out["p_wilcoxon"] * len(out) <= 0.05)` 는 사실 **Bonferroni** (p × n). BH 는 더 dynamic. 실용상 n=10 에서 둘이 비슷하지만 명칭 정정 권고.

#### 두 가지 통계 검정의 차이 (중요)

| 검정 | What | Interpretation |
|---|---|---|
| Bootstrap delta_pct CI | (median_an − median_pr) / median_pr × 100 의 분포 | 중심 경향의 차이 robustness |
| Wilcoxon paired | 개별 query 수준의 paired difference 부호 분포 | 개별 결과의 일관된 방향성 |

**격차 의미**: median 수준 차이는 robust 하지만 (CI 0 제외), 개별 query 수준에서는 일관 방향 X (p > 0.5, |d| < 0.1).

→ "**σ_i 신호가 너무 약해서** Anti-Neyman 의 median 손해는 통계 detect 가능하지만 개별 query 수준에서는 random noise 와 구별 X" 의 정직한 입증.

### 3.4 Wilcoxon vs CI 격차의 통계적 의미

s=0.01 에서:
- median 수준: AN > PR 고정 (CI 0 제외)
- 개별 query 수준: AN < PR vs AN > PR 가 거의 50:50 (n_better 값이 47-55 사이)
- → 분포의 *중심* 은 차이 있지만 *형태* 는 비슷한 noise

이는 σ_i 가 query 별로 다양 (i.e., query-adaptive σ_i 가 나음 — RQ3 의 KDE-pilot 영역) 이며, single σ_i 의 noise 가 너무 큼을 시사. **본 narrative 가 RQ2 → RQ3 motivation 으로 자연스럽게 연결**.
