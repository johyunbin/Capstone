## §2. Method 간 정보 직교성 종합

### 2.1 IID null distribution baseline

mean off-diagonal ARI = **0.015** (essentially 0). random 96-d data 에서는 어떤 method 도 의미 있는 partition 형성 X → ARI 0 baseline 확립.

→ 이후 DEEP-like 의 ARI 가 0.48, SIFT-like 0.37 인 것은 **data 의 cluster 구조에서 오는 공통 신호** 임을 입증.

### 2.2 DEEP-like clustered (mean 0.481) — **method 간 합의 강함**

20-cluster Gaussian mixture 에서 각 method 가 cluster boundary 회복 → ARI 높음. 하지만 **method 간 다양성** 도 분명히 존재:

#### Top redundant pairs (ARI ≥ 0.65)
| pair | DEEP-clust ARI | 해석 |
|---|---|---|
| minibatch ↔ minibatch_partial | 1.000 | partial_fit 가 완전 KMeans 회복 (DEEP-like 의 well-separated cluster) |
| spectral ↔ birch | 1.000 | 두 cluster 알고리즘이 동일 partition |
| hdbscan ↔ minibatch | 1.000 | density vs centroid 가 모두 동일 cluster |
| spectral ↔ minibatch | 0.667 | spectral 의 centroid-approximation 효과 |
| birch ↔ hdbscan | 0.667 | 모든 cluster method 수렴 |

→ **Cluster method 들은 DEEP-like 분포에서 정보 redundant** (RQ3 결과의 -0.13~-0.15 effect size 가 비슷한 이유 정량 입증).

#### Top orthogonal pairs (ARI ≤ 0.15)
| pair | DEEP-clust ARI | 해석 |
|---|---|---|
| sparse_rp ↔ random_proj | 0.125 | density 다른 RP (sparse vs dense) |
| sparse_rp ↔ minibatch | 0.216 | sparse_rp 가 cluster method 와 직교 |
| sparse_rp ↔ * | 모두 ~0.1–0.2 | sparse_rp 가 가장 직교 |

→ sparse_rp 가 cluster method 와 정보 직교 (90% orthogonal). 그러나 RQ3 effect size 는 d=−0.009 (negligible) — **다른 정보 capture 하지만 q-error 개선 없음**.

### 2.3 SIFT-like skewed (mean 0.373) — **다양성 더 큼**

#### Top redundant pairs
| pair | SIFT-skew ARI | 해석 |
|---|---|---|
| spectral ↔ birch | 0.888 | 여전히 매우 높음 |
| pq ↔ minibatch | 0.636 | PQ 가 KMeans 와 비슷 |
| minibatch ↔ minibatch_partial | 0.566 | DEEP 보다 낮아짐 (skew 에서 partial_fit 회복 부족) |

#### Top orthogonal pairs
| pair | SIFT-skew ARI | 해석 |
|---|---|---|
| sparse_rp ↔ random_proj | 0.076 | DEEP 보다 더 직교 |
| sparse_rp ↔ minibatch | 0.095 | 90% orthogonal |
| pca1d ↔ minibatch | 0.205 | PCA 의 단방향 vs cluster boundary 직교 |
| hilbert ↔ minibatch | 0.245 | curve 의 locality vs cluster centroid |

→ **Skew 에서 method 다양성 amplify**: sparse_rp / pca1d 의 직교성이 더 강해짐. 이것이 RQ3 의 SIFT 결과에서 effect size variance 가 큰 이유 정량 설명.

## §4. Cluster method 의 redundancy 가 RQ3 결과에 미친 영향

### 4.1 Effect size 비교

RQ3 딥리뷰 §3.1 의 mean Cohen's d:

| method | mean d | rank | 해석 |
|---|---|---|---|
| hilbert | −0.156 | 1st improve | 가장 강한 small effect |
| hybrid | −0.154 | 2nd | minibatch + hilbert |
| **minibatch** | **−0.151** | 3rd | cluster method 1 |
| **hdbscan** | **−0.136** | 4th | cluster method 2 |
| minibatch_partial | −0.119 | 5th | partial_fit |
| zorder | −0.119 | 6th | curve sibling |
| **pca1d** | **−0.101** | 7th | orthogonal method |
| **gmm** | −0.079 | 8th | cluster method 3 |
| kdtree | −0.071 | 9th | tree |
| kde_pilot | −0.049 | 10th | online weight |
| **birch** | −0.014 | 11th | cluster method 4 (negligible) |
| **sparse_rp** | −0.009 | 12th (negligible) | 가장 orthogonal |

### 4.2 ARI redundancy 와 effect size 의 관계

- **Cluster method 4종 (minibatch, hdbscan, gmm, birch)**: ARI 0.6+ (redundant) — effect size 비슷한 region (−0.02 ~ −0.15)
- **Curve method 2종 (hilbert, zorder)**: ARI 0.48 (sibling) — effect size −0.156 / −0.119
- **Hybrid (mb+hilbert)**: ARI 0.66 with mb, 0.37 with hilbert — effect size −0.154 (mb-dominant)
- **sparse_rp (orthogonal)**: ARI 0.12 — effect size −0.009 (negligible) → 다른 정보 capture 하지만 q-error 무관

**해석**: 
1. ARI 가 높은 method 들은 비슷한 partition → 비슷한 effect size (validation cross-method consistency)
2. 직교 method (sparse_rp) 도 effect size 작음 → "공간 인식 의 limit" narrative 강화 — 어떤 stratification 도 BERN 대비 negligible improvement

### 4.3 spectral 의 ARI 와 RQ3 결과 의 정합성

- Spectral ↔ birch ARI = 1.000 (DEEP-like) / 0.888 (SIFT) → **사실상 같은 partition**
- 그러나 RQ3 effect size: spectral d=+0.123 (hurt), birch d=−0.014 (negligible)
- **모순 아님**: spectral 의 hurt 는 Nystrom centroid-approximation 의 noise 에서 옴 (RQ3 딥리뷰 §1.3 참조). ARI 는 partition 만 보고, q-error 는 partition 활용 정확도까지 포함.

## §7. 검증 방법 (재현 가능)

```python
import pandas as pd
import numpy as np

# 5 CSV 로딩
ari_iid = pd.read_csv('experiments/results/rq3_agnostic/rq3_method_redundancy_ari_iid_96d.csv', index_col=0)
ari_clust = pd.read_csv('experiments/results/rq3_agnostic/rq3_method_redundancy_ari_deep_like_clustered_96d.csv', index_col=0)
ari_skew = pd.read_csv('experiments/results/rq3_agnostic/rq3_method_redundancy_ari_sift_like_skewed_128d.csv', index_col=0)
ari_full = pd.read_csv('experiments/results/rq3_agnostic/rq3_method_redundancy_ari.csv', index_col=0)

# avg(iid, clust, skew) 검증
print(np.allclose(ari_full.values, (ari_iid.values + ari_clust.values + ari_skew.values) / 3))  # True

# sparse_rp 직교성 검증
print(ari_full.loc['sparse_rp', 'random_proj'])  # 0.068
print(ari_full['sparse_rp'].drop('sparse_rp').mean())  # 종합 avg ARI

# Method orthogonality ranking
methods = list(ari_clust.columns)
ranks = sorted(
    [(m, ari_clust[m].drop(m).mean(), ari_skew[m].drop(m).mean()) for m in methods],
    key=lambda x: (x[1] + x[2]) / 2
)
for m, d, s in ranks:
    print(f'{m:<20} DEEP={d:.3f}  SIFT={s:.3f}  avg={(d+s)/2:.3f}')
```

→ 본 결과 모두 재현 가능.
