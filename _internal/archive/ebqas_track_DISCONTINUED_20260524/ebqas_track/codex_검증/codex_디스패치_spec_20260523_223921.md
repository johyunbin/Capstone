## 2. 검증축 6개

본 디스패치는 다음 6 축에서 적대적 검증을 요구한다. 각 축에서 (i) verdict ∈ {pass · concern · fail} (ii) 핵심 finding 3 이내 (iii) 정정 권고 1-3 항목 (iv) 신뢰도 0~1을 출력.

### 축 (a) — 수학 정확성

대상: 정본 anchor §5.5·§7·§11.3·§11.4 + 의사코드 §3.

검증 항목:
- Beta-Binomial conjugate posterior parameter — `p_g | s, n ~ Beta(α_g + s, β_g + n − s)` 유도 정확성.
- posterior mean의 가중평균 표현 — `p̂ = (κ_g/(κ_g+n)) · μ_g + (n/(κ_g+n)) · (s/n)`. prior mean과 sample proportion의 가중평균이지 두 독립 추정량의 평균이 아님을 식·산문 양쪽에서 명확히 진술하는지.
- B1 MSE — `MSE_B1 = p(1−p)/n` (대규모 N·n≪N 가정에서 binomial approximation).
- EB MSE — `MSE_EB = (n·p(1−p) + κ²(μ−p)²) / (n+κ)²` 유도.
- EB가 B1보다 좋아지는 조건 — `(μ−p)² < p(1−p)(1/n + 2/κ)` 의 유도 정확성.
- sample 수 감소 근사 — `n_EB ≈ n_B1 − κ` 가 어떤 가정 하에서 유효한지(posterior variance target 일치 + prior relevant 가정).

### 축 (b) — 안전장치 충분성

대상: 정본 anchor §10.2~5 + 의사코드 §4 + 실험 C(BCDE outline §2).

검증 항목:
- κ cap (κ_max 100 default·50~200 권장) 가 over-shrinkage를 충분히 방지하는지.
- decay ρ (0.95 default·0.90~0.98 권장) 가 workload drift 적응성을 충분히 제공하는지.
- mismatch reset (99% credible interval 밖이면 γ=0.5 감쇠) 의 trigger 조건이 안전한지 — false positive(정상이지만 prior credible interval 일시 벗어남) 시 과도한 reset 위험.
- fallback — 반복 mismatch 시 κ → 0에 수렴해 B1 수준으로 복귀하는 경로가 충분히 robust한지.
- group key 부적절 시 EB-QAS-safe가 “B1 수준 이상”을 보장하는지 vs “B1보다 악화 가능성”이 잔존하는지.

### 축 (c) — paired 비교 통제

대상: 실험 A spec §4·§5.3 + 정본 anchor §A.4.

검증 항목:
- 4-way matched(B1·CaseB·EB-QAS·EB-QAS-no-history) 동일 trial/query/seed 조건 보장 — 실험 A §5.3 의사코드의 `seed = base_seed + trial_idx` + `query_set = generate_queries(seed=seed)`가 4 mode에 일관 적용되는지.
- paired 통계량 3축(Wilcoxon + Cliff's δ + bootstrap CI) 일관성 확인 — 단일 better_ratio만으로 우위 단언 금지 룰이 명시되는지.
- subset paired 비교(plan_changed_vs_B1·low-selectivity·high-dimensional) 분할이 leakage 없이 수행되는지.

### 축 (d) — leakage 방지

대상: 정본 anchor §B.3 + 의사코드 §5.1·§5.2 + 실험 B(BCDE outline §1.4).

검증 항목:
- 현재 query t의 true cardinality는 query t+1 이후 prior에만 영향(query t의 likelihood에는 미사용) — `ebqas_estimate`와 `update_after_execution` 시점 분리.
- test query 결과를 train prior에 미사용 — 실험 B online protocol에서 query 순서대로 1~t−1 결과만 t 시점 prior에 반영.
- double counting 금지 — 현재 query sample을 prior update와 likelihood 양쪽에 사용 X.
- 전체 query set 평균 selectivity 사전 계산 후 prior 사용 X — “데이터 분포 사전 지식 가정 X” 룰 일관 적용.

### 축 (e) — 5/23 평결 4축 호환성

대상: 정본 anchor §본 문서 위상·환각 회피 룰 + README §3 + 실험 A spec §6 + 실험 BCDE outline §모든 환각 회피 carry.

검증 항목:
- CaseB식 산술평균 채택 X — EB-QAS는 posterior mean의 가중평균(prior + sample proportion)이지 두 독립 추정량 평균 X. 본 정의가 7 정본 전반에서 일관 적용되는지.
- 분포 사전 지식 가정 X — vector 분포·CDF·clustering·density map·histogram 미사용. group key 6-tuple만 사용.
- latency objective X — EB-QAS의 objective는 posterior Q-risk + sample budget. latency는 평가 지표·plan-sensitive subset 한정.
- method library 미의존 — posterior mean 한 줄 + Beta update — method paradigm(P1~P10) 무관.
