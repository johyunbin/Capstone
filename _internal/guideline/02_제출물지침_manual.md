1. "제출물 수동" 입력

### /clear vs /compact

| | /clear | /compact |
|---|---|---|
| 컨텍스트 | 100% 확보 | ~70% 확보 |
| 추천 용도 | **Phase 전환** (추천) | Phase 내부 보조 |

## 자주 하는 실수

| 실수 | 올바른 방법 |
|------|------------|
| hwp를 Claude에게 직접 편집 요청 | hwp는 수동 편집 — Claude는 내용만 제공 |
| 양식 없이 자유형식 작성 | 반드시 공식 양식 확인 후 작성 |
| 제출 후 일정 업데이트 누락 | 3곳(CLAUDE.md, 메모리, 노션) 동시 업데이트 |
| 샘플 확인 안 하고 바로 작성 | templates/samples/ 먼저 확인 |

## 관련 지침

| 지침 | 연동 관계 |
|------|----------|
| 문서생성지침 | 제출물 PDF 변환 위임 |
| 점검지침 | 마감 임박 시 알림, 일정 동기화 검증 |
| 발표지침 | 발표 자료도 제출물이지만 발표지침 담당 |
| 연구설계지침 | 설계안이 제출물 내용의 원본 |
