## 사용법

1. "발표 수동" 입력
2. Phase 0 실행 → 결과 보고 → **정지**
3. `/clear` 후 "Phase N 이어가줘"

### /clear vs /compact

| | /clear | /compact |
|---|---|---|
| 컨텍스트 | 100% 확보 | ~70% 확보 |
| 추천 용도 | **Phase 전환** (추천) | Phase 내부 보조 |

## Phase 체크리스트

> 상세 스크립트는 `05_발표지침_auto.md` 참조.

### Phase 0: 발표 유형 식별 + 샘플 확인 (3분)
- [ ] 발표 유형 (중간/최종/전시회)
- [ ] templates/samples/ 에서 해당 샘플 확인
- [ ] 분량/시간 기준 확인
- [ ] guideline/PHASE_STATE_05_발표.md 생성

✅ Phase 0 완료 → 결과 보고 → 정지
→ 사용자: `/clear` 후 "Phase 1 이어가줘"

### Phase 1: 슬라이드 구조 설계 (10분)
- [ ] 섹션 구성 (표지→배경→방법론→결과→향후계획)
- [ ] 슬라이드별 핵심 메시지 1개
- [ ] PHASE_STATE 업데이트

✅ Phase 1 완료 → 정지
→ 사용자: `/clear` 후 "Phase 2 이어가줘"

### Phase 2: 슬라이드 내용 작성 (20분)
- [ ] plans/ 설계안에서 방법론 추출
- [ ] reference/analysis/ 에서 관련 연구 추출
- [ ] 시각화 (차트/표/다이어그램) 우선
- [ ] PHASE_STATE 업데이트

✅ Phase 2 완료 → 정지
→ 사용자: `/clear` 후 "Phase 3 이어가줘"

### Phase 3: 발표 스크립트 (10분)
- [ ] 슬라이드별 대본 (30초~1.5분)
- [ ] 분량 검증 (한국어 300자/분)
- [ ] 강조 포인트 + 전환 멘트
- [ ] PHASE_STATE 업데이트

✅ Phase 3 완료 → 정지
→ 사용자: `/clear` 후 "Phase 4 이어가줘"

### Phase 4: 포스터/팜플렛 (전시회 시, 15분)
- [ ] A0/A1 크기
- [ ] 핵심 압축 (슬라이드 50% 이하)
- [ ] QR코드(GitHub) 포함
- [ ] PHASE_STATE 업데이트

✅ Phase 4 완료 → 정지
→ 사용자: `/clear` 후 "Phase 5 이어가줘"

### Phase 5: 리허설 체크리스트 + Q&A (5분)
- [ ] 시간 내 완료 가능한가?
- [ ] 예상 질문 10개+ 답변 초안
- [ ] 백업 슬라이드 준비
- [ ] 팀원 역할 분담 (발표자/보조/질의응답/타이머)
- [ ] PHASE_STATE 업데이트

✅ Phase 5 완료 → 정지
→ 사용자: `/clear` 후 "Phase 6 이어가줘"

### Phase 6: 종합 리포트 (2분)

## 자주 하는 실수

| 실수 | 올바른 방법 |
|------|------------|
| 텍스트 과다 슬라이드 | 핵심 1개 + 시각자료 |
| 시간 초과 | 대본 글자수로 사전 검증 |
| 실험 결과 없이 발표 | 예비 실험이라도 포함 |
| Q&A 준비 부족 | 예상 질문 10개+ |
| 포스터 인쇄 지연 | 최소 1주 전 발주 |

## 관련 지침

| 지침 | 연동 관계 |
|------|----------|
| 제출물지침 | 발표 자료도 제출물 |
| 실험지침 | 발표에 넣을 실험 결과 |
| 연구설계지침 | 방법론 슬라이드 소스 |
| 문서생성지침 | 스크립트 PDF 변환 |
