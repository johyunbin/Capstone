> 마지막 실행: —

## 사용법

1. "논문분석 수동" 입력
2. Phase 0 실행 → 결과 보고 → **정지**
3. `/clear` 후 "Phase N 이어가줘"

### /clear vs /compact

| | /clear | /compact |
|---|---|---|
| 컨텍스트 | 100% 확보 | ~70% 확보 |
| 추천 용도 | **Phase 전환** (추천) | Phase 내부 보조 |

## Phase 체크리스트

> 상세 스크립트는 `01_논문분석지침_auto.md` 참조.

### Phase 0: 인벤토리 + 번호 확인 (2분)
- [ ] summaries/ 현재 번호 범위 확인 (현재: [0]~[81])
- [ ] analysis/ 현재 번호 범위 확인 (현재: (01)~(12))
- [ ] papers/ 파일 수 확인
- [ ] guideline/PHASE_STATE_01_논문분석.md 생성

✅ Phase 0 완료 → 결과 보고 → 정지
→ 사용자: `/clear` 후 "Phase 1 이어가줘"

### Phase 1: 대상 논문 선택 + 읽기 (10분)
- [ ] 미분석 논문 식별
- [ ] 대상 논문 PDF 읽기
- [ ] 핵심 내용 파악
- [ ] PHASE_STATE 업데이트

✅ Phase 1 완료 → 정지
→ 사용자: `/clear` 후 "Phase 2 이어가줘"

### Phase 2: 총정리 md 작성 (15분)
- [ ] 한국어 학술 산문으로 작성
- [ ] 필수 포함: 배경, 기법, 실험설계, 정량결과, 한계, Exqutor 연결, 용어표
- [ ] 파일명: `[번호] 제목 총정리.md`
- [ ] PHASE_STATE 업데이트

✅ Phase 2 완료 → 정지
→ 사용자: `/clear` 후 "Phase 3 이어가줘"

### Phase 3: 시리즈 분석 (선택, 20분)
- [ ] 관련 논문 3편+ 모이면 시리즈 작성
- [ ] 파일명: `(번호) 제목.md`
- [ ] PHASE_STATE 업데이트

✅ Phase 3 완료 → 정지
→ 사용자: `/clear` 후 "Phase 4 이어가줘"

### Phase 4: 품질 체크 + PDF 변환 (3분)
- [ ] 필수 7개 항목 포함 여부 확인

- [ ] 2종 세트(md+pdf) 완성 확인
- [ ] PHASE_STATE 최종 업데이트

✅ **논문분석 완료**

## 자주 하는 실수

| 실수 | 올바른 방법 |
|------|------------|
| 번호 중복 부여 | 현재 최대번호+1 사용 |
| bullet 나열로 작성 | 한국어 학술 산문 (서사적 문단) |
| 실험 조건 생략 | 데이터셋/HW/baseline/메트릭 필수 |
| fpdf2로 PDF 생성 | scripts/md2pdf.py만 사용 |
| PDF 없이 md만 남겨둠 | 작성 직후 PDF 변환 |

## 관련 지침

| 지침 | 연동 관계 |
|------|----------|
| 문서생성지침 | md → PDF 변환 위임 |
| 점검지침 | 작성 후 2종 세트 + PDF 폰트 검증 |
| 미팅지침 | 총정리 기반 미팅용 심층분석 가공 |
| 실험지침 | 분석에서 도출한 실험 설계 전달 |
| 연구설계지침 | 분석 결과가 연구 방향에 반영 |
