## 1. paper §V-B 5 단계 알고리즘 (verbatim 인용 + 페이지)

### 1.1 §V-B 전체 framework 위치 + 적용 범위

> **paper p.5 좌단 §V (Exqutor) 첫 단락**:
> "We present Exqutor, a system designed to enhance the query optimization process for VAQs in generalized vector database systems by estimating the cardinality of vector range search... For VAQs with vector indexes, Exqutor employs Exact Cardinality Query Optimization (ECQO)... For VAQs without index, Exqutor uses a sampling-based approach to approximate selectivity (subsection V-B)."

§V-A (ECQO) vs §V-B (Adaptive Sampling) 의 분리:

| 영역 | paper 적용 범위 | 우리 연구 영역 |
|---|---|---|
| §V-A ECQO | HNSW 인덱스 있을 때 (range query 1-2ms) | **본 연구 적용 안 함** (paper main result 그대로 인정) |
| §V-B Adaptive Sampling | HNSW 인덱스 없을 때 ("specifically for KNN queries") | **본 연구 메인 영역** |

> **paper p.5 우단 §V-B 첫 단락 (verbatim)**:
> "When a VAQ lacks a vector index, the query optimizer must rely on either an index over structured attributes or perform a full sequential scan. In the case of a sequential scan, evaluating the similarity predicate requires computing distances between the query vector and all vectors in the dataset. This exhaustive KNN search is highly expensive, making it unsuitable for direct execution during query planning, unlike the approach used in ECQO. To address this, **Exqutor adopts a sampling-based cardinality estimation approach specifically for KNN queries**, where it approximates the number of qualifying tuples by evaluating similarity over a small subset of the data."

★ 중요 — paper 가 §V-B 의 적용 범위를 **"specifically for KNN queries"** 로 명시. 즉 single-table KNN 영역 한정. multi-table joint distribution 은 paper §V-B 의 적용 범위 밖. 이는 옵션 E 의 paper gap 식별 근거.

### 1.2 Eq 1 — sample budget N (초기 sample 수)

> **paper p.5 우단 + p.6 좌단 Eq (1) verbatim**:
> "To determine an appropriate sample size, Exqutor uses a statistical formula derived from classical sampling theory [67]. The required number of samples N is computed as:
>
> **N = ⌈z² · P̂ · (1 − P̂) / e²⌉ (1)**
>
> z critical value corresponding to the desired confidence level (e.g., z = 1.96 for 95% confidence).
> P̂ estimated proportion of data points expected to fall within the similarity threshold.
> e desired margin of error (e.g., e = 0.05 for 5% error)."

paper p.6 우단 §VI 도입부:
> "For sampling-based cardinality estimation, we initially compute the number of samples N using the sample size formula (Equation 1) for sample size estimation [67], given a 95% confidence level (z = 1.96), a proportion estimate P̂ = 0.5, and a 5% margin of error (e = 0.05). Applying the formula yields a fixed sample size of **N = 385**."

### 1.3 Eq 2 — Q-error metric (정확도 측정)

> **paper p.6 좌단 Eq (2) verbatim**:
> "The adjustment is guided by the Q-error [68]–[70], which measures the deviation between the estimated and true cardinality:
>
> **Q-error = max(Card_esti / Card_true, Card_true / Card_esti) (2)**"

Q-error 는 1.0 이 완벽 (=추정값 = 실제값). paper exact 우리 사용 metric.

### 1.4 Eq 3-5 — Adaptive sample size adjustment (momentum + lr decay)

> **paper p.6 좌단 Eq (3)(4)(5) verbatim**:
> "Using this metric, Exqutor tracks recent estimation accuracy and updates the sample size according to the following rule:
>
> **δ = α · (Q-error − β) − (100 − α) · sampling_ratio (3)**
> **V_t = m · V_{t-1} + η_t · δ (4)**
> **sampling_size_{t+1} = sampling_size_t + V_t (5)**
>
> Here, δ is the adjustment factor computed from estimation error and the current sampling ratio, which determines the direction and magnitude of sample updates. V_t is the momentum term at iteration t, m is the momentum coefficient, and η_t is the learning rate. α balances the contribution between Q-error and the sampling ratio, and β is a tunable threshold representing acceptable Q-error."

### 1.5 Eq 6 — lr decay (learning rate scheduler)

> **paper p.6 좌단 Eq (6) verbatim**:
> "The learning rate is decayed at each iteration using:
>
> **η_{t+1} = γ · η_t (6)**
>
> where γ is the decay factor (0 < γ < 1) that progressively reduces the adjustment magnitude."

### 1.6 Hyperparameter 7 종 (paper §VI 도입부 verbatim)

> **paper p.6 우단 §VI 첫 단락 (verbatim)**:
> "For adaptive sampling, we extend the optimizer with momentum-based feedback control. Parameter values are selected based on prior work on adaptive query estimation [22], [70]: we set **the momentum coefficient m = 0.9, initial learning rate η₀ = 0.1, weighting factor α = 50, and target Q-error β = 1.5**. These values balance Q-error minimization and sample size stability. **The learning rate decay factor γ = 0.99** gradually reduces adjustment magnitude to ensure convergence. **Sample size updates are triggered every 50 queries** (period P)."

| Hyperparameter | 값 | 의미 |
|---|---:|---|
| m | 0.9 | momentum |
| η₀ | 0.1 | initial learning rate |
| α | 50 | warmup period |
| β | 1.5 | target Q-error |
| γ | 0.99 | lr decay |
| P | 50 | update period (queries) |
| N₀ | 385 | initial sample size (Eq 1) |

우리 측정 portfolio 가 paper exact 로 동일 사용.

### 1.7 Algorithm 1 — 5 단계 + 우리가 건드린 영역

본 연구의 학술 부록 `_internal/scripts/...` 의 Algorithm 1 pseudo-code 에서 paper Eq 1-6 을 5 단계로 정리하면:

```
Step 1 (Eq 1)     S ← Bernoulli sample of size N₀=385 from T (unstratified)  ← ★ 우리가 건드린 단계
Step 2 (Eq 2)     μ̂₀ ← (1/|S|) Σ 1{d(q,x) ≤ τ}                              ← paper exact 유지
Step 3 (Eq 3-5)   while convergence not met: 
                    Δ_t (relative grad) 
                    V_t ← m·V_{t-1} + η_t·δ (momentum)
                    μ̂_t ← μ̂_{t-1} + η_t·V_t (update)                         ← paper exact 유지
Step 4 (Eq 6)     η_{t+1} ← γ·η_t (lr decay)                                  ← paper exact 유지
Step 5 (Eq 6 추가) sampling_size_{t+1} ← sampling_size_t + V_t (batch size)    ← paper exact 유지
                  ★ Step 11 (loop 안에서 n_inc 만큼 추가 sample) 도 paper 그대로
```

**우리 연구의 정확한 contribution scope**:
- Step 1 (Eq 1 N=385 의 Bernoulli) → stratified K-Means K=20 으로 대체 (CaseA 단독 모드) 또는 산술 평균 결합 (CaseB 결합 모드)
- Step 2 ~ Step 5 (Eq 2 ~ Eq 6) → 모두 paper exact 유지

이것이 본 회의 (5/14 18:00 ~ 19:00) 에서 "**5 단계 中 1 단계만 건드림**" 의 정확한 의미.

## 2. paper 자체 명시 한계 (verbatim 인용 + 페이지)

### 2.1 §VI-E Limitations (p.12 우단, paper 본인 명시)

> **paper §VI-E 전문 verbatim**:
> "While Exqutor demonstrates substantial performance improvements across diverse workloads, several limitations remain.
>
> 1. **In high-dimensional spaces, the overhead of sampling increases because of the higher cost of distance computations, which may reduce the efficiency of our adaptive sampling strategy.**
>
> 2. Moreover, our approach relies on cost models that fail to fully capture the performance characteristics of ANN indexes, so even with accurate cardinality estimates the optimizer may still choose suboptimal plans.
>
> 3. Addressing these issues through more efficient sampling in high dimensions and refined cost models for VAQ optimization remains an important direction for future work."

★ 우리 연구 의의가 정확히 1번 한계와 맞물린다.

> **paper p.6 우단 §VI 도입부 (verbatim)**:
> "**Impact of vector dimensionality and query characteristics.** With ECQO, the availability of accurate cardinality estimates for vector range search allows the optimizer to avoid unnecessary operations... Because the cost of HNSW search increases with vector dimensionality due to more expensive distance computations, we observe a corresponding rise in overall query time as the dimensionality grows."

> **paper §VI-B 우단 (Fig 5 다음 단락)**:
> "Adaptive sampling overcomes this limitation by modifying the sample size based on query feedback. It tracks Q-error over time and adjusts the number of sampled rows accordingly. When the error is high, indicating that the estimate diverges from observed cardinality, the sample size is increased to enhance accuracy. Conversely, when estimates stabilize, the sample size is reduced to conserve computation."

★ paper 가 명시: "adaptive sampling 의 본질은 **Q-error feedback 으로 sample size 동적 조정**" — 이는 우리가 안 건드린 Eq 3-6 영역. 즉 paper 의 진짜 contribution 영역.

### 2.2 §V-B 적용 범위 명시 (single-table KNN only)

> **paper p.5 우단 §V-B 첫 단락 (앞서 §1.1 인용)**:
> "**Exqutor adopts a sampling-based cardinality estimation approach specifically for KNN queries**"

★ paper 자체가 §V-B 영역을 single-table KNN 으로 제한. multi-table join 환경 (우리 A2-Fig7/8/9 측정) 은 paper §V-B 가 다루지 않은 영역.

### 2.3 §VII Related Work — 기존 sampling 의 한계 (paper 본인 명시)

> **paper p.12 우단 §VII Related Work (verbatim)**:
> "**One technique in query optimization for efficiently estimating selectivity and cost is sampling.** Early works introduced random sampling for join size estimation [79], [80], while later approaches refined these ideas with adaptive sampling strategies [81]. The method in [81] adjusts the sample size dynamically until a desired confidence level is reached, **but does not consider sampling overhead or optimize it dynamically based on query characteristics**."

★ paper 의 differentiation = "기존 sampling 은 query characteristics 기반 동적 조정 안 함" + "Exqutor 는 함" (Eq 3-6 동적 batch). 이게 paper §V-B 의 진짜 contribution. 우리가 안 건드림.

### 2.4 §VII Filtered Vector Search 의 한계 (multi-table 명시)

> **paper p.12 좌단 §VII Filtered Vector Search (verbatim)**:
> "However, these methods are **limited to filtering within a single relation or collection, making them less effective for large-scale analytical workloads that involve complex joins across multiple datasets**."

★ 기존 연구들이 single relation 한정인 것을 paper 자체가 비판. 그러나 paper 의 §V-B 도 결국 single-table KNN 한정 (위 §1.1 인용). 즉 multi-table joint distribution 영역은 paper 자체도 약하게 다룬 영역.

### 2.5 §VIII Conclusion 의 Future Work 시사

## 3. paper gap (paper 가 의도적으로 안 다룬 영역, 학술 가치)

paper 가 의도적으로 또는 묵시적으로 안 다룬 영역 5 가지. 우리 연구 방향 옵션의 후보 근거.

### 3.1 Gap 1 — Bernoulli step 의 distribution-aware augment

paper §V-B Algorithm 1 의 **Step 1 (Eq 1, initial Bernoulli sample of N₀=385)** 은 unstratified 무작위 추출이다. paper 가 distribution-aware stratification 을 검토하지 않은 영역.

학술 가치:
- **재현 + ablation** 측면 학술 가치 (보통). paper exact + 단일 axis (분포 정보) 추가의 정량 비교.
- 학부 캡스톤 / reviewer-grade reproducibility 측면 적합.
- **본 연구의 main contribution 영역 (옵션 A)** — 단독 best −10.17%, 결합 −7.37%.

### 3.2 Gap 2 — Eq 3-6 batch size scheduler 의 distribution-aware augment

paper §V-B Algorithm 1 의 **Step 11 (Eq 3-6, dynamic batch size adjustment)** 은 Q-error feedback 으로 sample size 만 조정. 분포 정보 (group boundary, sz_j, σ_j) 가 batch 분배에 반영 안 됨.

학술 가치:
- **paper framework 의 진짜 contribution 영역** (Eq 3-6). paper §VI-B 가 명시: "adaptive sampling 의 본질은 동적 batch".
- 분포 정보를 dynamic batch 분배에 inject 하면 paper 자체의 contribution 을 augmentation.
- **★ 강한 학술 가치** — paper 의 main mechanism 을 확장.
- **옵션 B** 의 근거.

### 3.3 Gap 3 — Neyman paradox 의 메커니즘 일반화

paper 가 K-means + Neyman allocation 결합을 시도하지 않았다. 우리 측정에서 발견한 "K-means (L2) + L2 query → σ_j narrow → Neyman 효과 없음" 메커니즘은 paper gap.

학술 가치:
- **★★ 매우 강한 학술 가치** — vector similarity range query 환경에서 classical statistical sampling theory (Neyman) 의 한계 메커니즘 발견.

paper §V-B 는 "데이터 모름 환경" 1 단계만 다룬다. 정보 수준에 따른 method spectrum 은 가지지 않음.

### 3.5 Gap 5 — Multi-table joint distribution (single-table KNN 제약 깨기)

paper §V-B 가 명시적으로 "specifically for KNN queries" (single-table). multi-table 영역은 paper §V-A ECQO 만 다룸. 그러나 ECQO 는 인덱스 있을 때 한정.
