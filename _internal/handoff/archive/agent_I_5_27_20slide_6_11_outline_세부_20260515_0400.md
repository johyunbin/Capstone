### Slide 8 — Form 1 Component D: Distribution-Aware Stratification (4 mode)

**8.1 title**: Component D — Distribution-Aware Stratification (Equal / Prop / Neyman / Anti-Neyman, Cochran 1977 + RQ2 paradox)

**8.2 bullet 5**:
- Equal: n_j = N/K (L2 정보 수준)
- Proportional: n_j ∝ N_j (L3 + N_j, 권장)
- Neyman: n_j ∝ N_j·σ_j (L4 + σ_j, paradox sel=0.01)
- Anti-Neyman: n_j ∝ N_j/σ_j (negative control)
- RQ2 발견: Anti < Prop < Neyman (sel=0.01 한정)

**8.3 시각 자료**: 4 mode allocation rule 의 mathematical formula 표 + RQ2 5-way 측정 결과 bar chart (DEEP sel=0.01: Anti 1.540 < Prop 1.580 < Neyman 1.595 paradox + DEEP sel=0.1: Neyman 1.108 최저 normal) + Cochran 1977 §5.5 quote ("the gain in accuracy from Neyman allocation compared to proportional allocation is pretty small...").

**8.4 speaker note**: Component D 는 분포 인지 axis 로 4 mode allocation rule 을 제공합니다. RQ2 batch axis 측정 결과 DEEP sel=0.01 paired n=455 에서 Anti-Neyman 1.540 < Proportional 1.580 < Neyman 1.595 의 paradox 가 발견되었고, sel=0.1 에서는 Neyman 1.108 이 최저로 paradox 가 역전됩니다. 본 paradox 는 σ_j range 1.3-1.6× narrow 라는 oracle interpretation 으로 설명 가능하며, Cochran 1977 §5.5 의 classical theory ("Neyman ≈ Proportional when σ uniform") 와 정합합니다. 본 Form 1 의 default 는 Proportional 권장입니다.

**8.5 transition**: Component D Distribution-aware stratification → (다음) 측정 1 (streaming workload simulation) — paper §VI-B "shifting workloads" 영역의 정량 측정.
