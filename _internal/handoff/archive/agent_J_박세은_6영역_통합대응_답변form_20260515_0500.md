### 영역 3 답변 ("분포 안다" 의 multi-layer 분리)

박세은님,

영역 3 자문 감사합니다. 이 영역은 본 연구 narrative 의 핵심 정정 영역 中 하나라 자세히 답변드립니다.

박세은님 지적의 핵심은 "이미 데이터셋이 어떤 형태인지 안다" 는 의미인데 왜 K-means 등의 추가 학습이 필요하냐는 것입니다. 본 연구가 이 영역을 충분히 분리해 설명하지 않은 것이 narrative 약점이었습니다.

본 연구는 "분포 안다" 를 **3 layer 로 분리** 해 사용해야 합니다:

- **L1 (global statistics, skew flag)**: HHI 지표, 데이터셋이 skewed 인지 normal 인지 정도의 메타 정보. 데이터 카탈로그에 미리 저장 가능, 별도 학습 비용 없음. 이 layer 만으로는 본 연구의 stratification 적용 불가.
- **L2 (cluster boundary 단순, K=20)**: 데이터를 K=20 으로 분할했을 때 각 cluster 경계 (centroid 위치). K-means K=20 학습 0.1-0.5 초로 cheap.
- **L3 (cluster boundary + σ_j 분산)**: L2 + 각 cluster 내 분산 σ_j (Neyman allocation 사용). σ_j 직접 측정은 본 연구가 oracle 가정으로 처리, 실제 산업 환경 측정 cost 는 추가 검증 영역.

박세은님 지적은 본 연구가 RQ2 영역에서 "분포 안다" 를 명확히 분리하지 않고 막연히 사용한 결과입니다. 정확한 narrative 정정은:

- **RQ2 영역** = L2 + L3 (실험 천장 가정, 학습 0 비용 + σ_j oracle)
- **RQ3 영역** = 실제 데이터셋에서 L2 학습 (0.1-0.5 초) + σ_j 측정

"K-means 추가 학습 왜 필요하냐" 의 답: **L1 정보 (skew flag) 만으로는 stratification 의 cluster boundary 가 부재**. L2 + L3 를 얻으려면 K-means 학습이 필수입니다. 본 연구는 그 학습 비용을 0.1-0.5 초 (sparse_rp 0.1 / chao_weighted 0.5 / neuram 0.5 / pca1d 0.5 / hilbert 0.5 / reservoir 0.1) 로 측정해 산업 적용 가능 영역에 두었습니다.

evidence: 회의 PDF v2 §3.4 line 540-556 (RQ3 method 사전 학습 framing), pareto analysis line 1-50 (학습 시간), Agent A 옵션 D § L1-L4 framework.

정직 disclosure: 본 연구가 L1 (skew flag only) 영역의 정량 측정은 안 했습니다. 단 이론적으로 L1 으로는 stratification 부재라 의미 없습니다. L3 의 σ_j 직접 측정 cost 는 oracle 가정 사용 → 실제 산업 환경 측정 cost 는 향후 검증 영역.

### 영역 4 답변 ★★★ (분포 알면 ECQO 적용? — 본 연구 방향 자체 보호)

박세은님,

영역 4 가 가장 critical 한 자문입니다. 본 연구 방향의 근본 의문이라 multi-layer 4 로 분리해 답변드립니다.

**(a) paper §V-B 영역 자체가 "without index" 가정**

본 연구는 paper Exqutor §V-B 의 후속 연구 form 입니다. paper §V-A (ECQO) 와 §V-B (Adaptive Sampling) 의 적용 범위는 paper 자체가 **상호 배타** 로 명시합니다 (paper p.5 좌단 §V 도입부):

> "For VAQs with vector indexes, Exqutor employs Exact Cardinality Query Optimization (ECQO)... **For VAQs without index**, Exqutor uses a sampling-based approach to approximate selectivity (subsection V-B)."

즉 paper 자체가 ECQO 영역 (인덱스 있을 때) 과 §V-B 영역 (인덱스 없을 때) 를 분리합니다. 본 연구는 §V-B 영역 (인덱스 없을 때) 만 다룹니다. ECQO 영역은 본 연구가 아예 다루지 않습니다 (paper main result 그대로 인정).

따라서 "분포 알면 ECQO" 라는 질문은 paper 의 분리 가정 안에서는 부적절합니다. **분포 안다 = vector index 있다, 가 아닙니다**.

**(b) 인덱스 cost 비교: HNSW O(n log n) vs K-means K=20 fit 0.1-0.5 초**

만약 ECQO 를 적용하려면 HNSW vector index 를 구축해야 합니다. HNSW 구축 비용은 paper [38] (Malkov-Yashunin 2018) 에 따르면 O(n log n) + memory 가 base table 의 1.x 배 + 매 insert 마다 maintain O(log n). DEEP/SIFT 1M vector 기준 수 분 ~ 수십 분, SF=100 (1억 vector) 기준 수 시간 ~ 수일. 게다가 paper §VI-A 의 ann index amplification factor 가 base table 보다 큼.

본 연구의 K-means K=20 stratification fit 비용은 **0.1-0.5 초** (sparse_rp 0.1 / chao_weighted 0.5). 비교 자체가 안 됩니다.

ECQO 를 적용할 수 있는 환경이라면 ECQO 가 답이 맞습니다. 하지만 ECQO 는 인덱스 구축 비용 + 메모리 amplification 이 큰 영역이라 모든 데이터셋이 ECQO 를 적용할 수 있는 것이 아닙니다. 본 연구의 stratification 은 **인덱스 구축이 비싸거나 ad-hoc query 환경 (인덱스 빌드 시간이 query 시간보다 비쌈)** 에서 의미가 있습니다.

**(c) ECQO + 본 연구 complementary**

paper §VI-B 에서 "shifting workloads" 영역 (data distribution 이 시간에 따라 변하는 환경) 을 다룹니다. shifting workload 에서는 HNSW index 가 stale 해지면 rebuild 비용이 매번 발생합니다. 본 연구의 stratification 은 K-means 재학습 0.1-0.5 초로 훨씬 cheap.

즉 **high-frequency stable workload** = ECQO 권장, **ad-hoc / shifting workload** = 본 연구 stratification 권장. 두 영역이 상호 배타가 아니라 **complementary** 입니다.

**(d) "분포 안다" 의 layer 분리**

영역 3 답변에서 분리한 L1/L2/L3 와 ECQO 인덱스 = data 자체 의 HNSW index 는 **layer 가 다릅니다**. L2/L3 = cluster 메타 정보 (centroid + σ_j) = **K × d 메모리만 필요** (K=20 × 768 ≈ 15KB). HNSW index = **데이터 전체의 graph** = 메모리 1.x 배 base table. 둘은 cost 차원이 완전히 다릅니다.

본 연구의 narrative 정정 form 은:

- "분포 안다 = HNSW index 있다" → ✗
- "분포 안다 = cluster boundary K=20 학습 0.1-0.5 초 메타 정보" → ✓
- "본 연구 = ECQO 영역 outside (paper §V-B 가정 = without index)" → ✓
- "본 연구 stratification cost ≪ HNSW index build cost" → ✓

evidence: paper [0] §V (p.5 좌단), §V-B (p.5 우단), §VI-A HNSW amplification (p.10 좌단), §VI-B shifting workloads (p.7 좌단), paper [38] HNSW build complexity, Agent A § 1.1 인덱스 X 가정 verbatim, pareto analysis line 14 0.1-0.5 초.

정직 disclosure: 본 연구가 ECQO 를 직접 measurement comparison 으로 다루지 않았습니다. ECQO 영역 outside 라는 narrative 가 본 연구의 정직 한계입니다. 박광현 5/15 미팅에서 ECQO vs 본 연구 직접 comparison 측정의 필요성을 자문 받을 가능성 있습니다 (이것이 reviewer-grade 자문 영역). 사전 답변 form: "본 연구 phase 1 = paper §V-B 영역 내 reproducibility + ablation, phase 2 = ECQO vs 본 연구 comparison (future work)".

### 영역 5 답변 (RQ3 method 사전 학습 framing)

박세은님,

영역 5 자문 감사합니다. 이 영역도 본 narrative 의 명시 영역 약점입니다.

박세은님 지적의 핵심은 "분포 모르는데 바로 쿼리를 처리해야 하는 상황에서 RQ3 method 를 사용한다고 했지만, 사실은 query 실행 전에 method 학습이 먼저 진행되어야 한다" 는 점입니다. 정확한 지적입니다.

본 연구 RQ3 의 measurement protocol 은 회의 PDF v2 §3.4 line 540-556 에 다음과 같이 명시되어 있습니다:

1. **데이터 도착** → method 학습 (예: K-means K=20 cluster 학습 0.1-0.5 초)
2. **K=20 stratum 으로 데이터 분할** → 각 cluster 크기 N_j 와 σ_j 계산
3. **Query 도착** → 각 stratum 별 sample 385 개 가중 처리

학습 (1, 2) 은 **사전 계산**, query 시점 (3) 은 **실시간** 처리입니다. 즉 본 연구의 RQ3 = 진짜 streaming 환경이 아니라 **사전 학습 완료된 baseline** 입니다.

이 framing 의 명시가 5/27 발표 / 6/11 보고서에 필요합니다. 정정된 narrative:

- **RQ3 batch axis** (현 1001 file measurement) = **사전 학습 완료된 baseline** axis. cold start 후 K-means K=20 학습 0.1-0.5 초 1 회, 이후 query 시점 sample 처리만.
- **streaming axis** (Form 1 의 진짜 contribution 영역) = online cluster maintenance + per-tuple update 영역. 1001 file 측정 portfolio 에 포함되지 않음.

따라서 본 연구 narrative 의 "**현 1001 file = 사전 학습 batch baseline**" 명시는 본 Form 1 (Streaming-aware Distribution-Conscious Cardinality Estimation) 의 존재 이유 자체를 강화합니다. 박세은님 지적이 사실 Form 1 narrative 의 motivation 입니다.

Form 1 의 핵심 design 은:

- **Stratified Reservoir Sampling** (Vitter 1985 + Al-Kateb-Lee-Wang SSDBM 2010) — single-pass O(1) memory per cluster
- **BIRCH CF-tree online cluster maintenance** (Zhang-Ramakrishnan-Livny 1996 SIGMOD) — sample stream 에서 (N_j, LS_j, SS_j) tuple online 유지
- **paper Eq 1-6 통합** — Eq 1 (Bernoulli) 대체 + Eq 2-6 (Q-error feedback + lr decay + period P=50) verbatim 유지 + Eq 5 group-aware n_inc 분배 augment

즉 박세은님 영역 5 지적이 Form 1 narrative 의 motivation 직접 강조 입니다. 5/27 발표 §1 problem framing 영역에 이 정정 명시 적용합니다.

evidence: 회의 PDF v2 §3.4 line 540-556 (RQ3 사전 계산 명시), Agent E Form 1 § 1.2.1 Component A stratified reservoir, Agent E § 1.2.2 BIRCH CF-tree, Agent E § 1.2.3 paper Eq 1-6 통합.

## 4. "분포 안다" L1/L2/L3 multi-layer 분리

### 4.1 L1 — Global skew flag (HHI 지표 등)

**의미**: 데이터셋 전체의 분포 형태 (normal / skewed). HHI (Herfindahl-Hirschman Index) 등 1 차원 메타 정보.

**얻는 방법**: 데이터 카탈로그 메타데이터 또는 1 회 full scan (n 개 sample 추출 후 entropy 계산). 비용 매우 cheap (full scan 의 일부).

**적용 가능 영역**: 다음 method 선택 자체 (skew → stratification 권장, normal → Bernoulli 충분).

**stratification 직접 사용 X**: cluster boundary 정보가 부재라 본 연구의 K=20 stratification 적용 불가.

**본 연구 측정 영역**: L1 단독 영역의 measurement 안 함. 회의 PDF v2 §6.4 line 1106 에 "skew flag 만으로 본 연구 method 적용 불가" 명시.

### 4.2 L2 — Cluster boundary (K-means K=20, centroid 위치)

**의미**: K-means K=20 학습 후 각 cluster 의 centroid 위치 + 각 row 의 cluster 소속. 데이터의 spatial structure 정보.

**얻는 방법**: K-means K=20 학습 (sparse_rp 0.1 / chao_weighted 0.5 / neuram 0.5 / pca1d 0.5 / hilbert 0.5 / reservoir 0.1 초). SF=1 한정.

**적용 가능 영역**: Equal allocation stratification (n_j = N/K, 각 cluster 별 sample 19-20 개). 기본 stratification.

**본 연구 측정 영역**: ★ main 측정 영역. RQ3 + CaseA + CaseB 1001 file portfolio 대부분.

### 4.3 L3 — Cluster boundary + σ_j 분산 (Neyman allocation)

**의미**: L2 + 각 cluster j 의 분산 σ_j² (within-cluster variability). Neyman allocation 의 axis.

**얻는 방법**: L2 K-means 학습 후 추가로 σ_j² 직접 측정 (각 cluster 의 1{d(q,x) ≤ τ} indicator 분산). 단 RQ2 영역에서는 **oracle 가정** (실제 측정 안 하고 alreadyknown 가정).

**적용 가능 영역**: Neyman allocation (n_j ∝ N_j × σ_j) 또는 Anti-Neyman (n_j ∝ N_j / σ_j). sel=0.01 영역에서 Neyman ≈ Prop 의 paradox 발생 (회의 PDF v2 §3.2 RQ2 결과 line 466).

**본 연구 측정 영역**: RQ2 5-way 측정 (Bernoulli / Equal / Proportional / Neyman / Anti-Neyman). RQ3 영역에서는 σ_j 직접 측정 안 함.

**정직 disclosure**: σ_j = oracle 한정. 실제 산업 환경에서 σ_j 측정 cost 는 추가 검증 영역.

### 4.4 L_index — HNSW vector index (data itself, ECQO 영역)

**의미**: 데이터의 vector graph index (HNSW). paper §V-A ECQO 의 base.

**얻는 방법**: HNSW build O(n log n) + memory 1.x ~ 2x base table. paper [38] Malkov-Yashunin 2018.

**적용 가능 영역**: paper §V-A ECQO (vector range query 1-2 ms). **본 연구 outside**.

**비용 비교**: L_index ≫ L2/L3 의 fit cost.

### 4.5 L1/L2/L3 vs L_index 의 핵심 분리

| Layer | 정보 의미 | 비용 | 본 연구 / paper 영역 |
|---|---|---|---|
| L1 | global flag | 0 (메타) | 미사용 (stratification 부재) |
| L2 | cluster centroid | 0.1-0.5 초 | 본 연구 RQ3 main ✓ |
| L3 | + σ_j | 0.5 초 + σ_j 측정 | 본 연구 RQ2 (oracle) ✓ |
| L_index | HNSW graph | O(n log n) + 메모리 | ECQO (paper §V-A) |

박세은님 영역 4 의 답변 핵심:
- "분포 안다" = L1/L2/L3 (메타 정보, 본 연구 영역)
- "vector index 있다" = L_index (HNSW, ECQO 영역)
- 두 layer **cost 차원이 완전히 다름**, paper 자체가 §V-A vs §V-B 분리
