## 3. ★ 핵심 결과 (정본)

### 3.1 latency 무개선 진단 (엔진 적용 검증, 56 cell)
- 측정 노이즈 바닥 = rep CV 중앙값 **17%**. B1↔CaseB latency 효과(condition 설명력 0.0008%)는 분해능 아래.
- **within-cell q-error↔latency 부분상관 r = −0.007** (naive pooled −0.286은 cell-mix 교란). → 추정 정확도와 실행시간 **완전 디커플**.
- latency 이득 = baseline(주입X)→주입(B1/CaseB/oracle)의 이진 전이(HashJoin·base-table SeqScan → NL+IndexScan). sel별 가속: 0.001 4.5×·0.01 1.8×·0.1 1.0×. **B1 가속 ≈ oracle 가속** — B1이 이미 가용 이득을 ~100% 추출.

### 3.2 ★ A1 — CaseB q-error 우위의 메커니즘 (Codex 검증)
측정 코드(`measure_3way`) 정독 — B1·CaseA·CaseB가 각자 독립 AdaptiveState(Eq 1-6), q_idx<50은 전 mode N=385 고정.

**고정 N=385 (q<50, 1,226 measurement) 깨끗한 비교:**
| 추정량 | 평균 q-error | B1 이긴 비율 |
|---|---|---|
| B1 (Bernoulli 단독) | 1.944 | — |
| CaseA (stratified 단독 = "우리 method") | 1.984 (B1보다 **나쁨**) | 44% |
| CaseB (Bern+strat)/2 — 연구 주장 | 1.477 | 99% |
| **CaseB′ (Bern+Bern)/2 — 통제군** | **1.459** | **100%** |

- **B1을 두 번째 Bernoulli와 평균낸 통제군(CaseB′)이 CaseB와 동등 이상.** CaseB가 CaseB′보다 나은 measurement 42%뿐. 부호 독립(반대 48%).
- Codex 적대검증: "결론 강하게 지지". 추가 — q<50서 B1 ~64% zero-hit, 평균이 그걸 구제하는 것도 일반 효과.
- **뉘앙스**: hilbert 계열 5종(hilbert_real·skilling_hilbert·pca1d·zorder_morton·ica_fastica)은 CaseA가 B1을 57~75% 이김 = **PCA/ICA 투영 기반 층화는 진짜로 Bernoulli보다 약간(~2%) 우수**. 나머지 8종(스케치/양자화)은 B1보다 나쁨.
- **평결**: 89.1%·−4.38% 수치는 진짜(조작 없음)이나 **"분포 인지 stratification 덕분"이라는 인과 귀속이 틀림.** ~95%가 평균(분산+zero-hit) 효과.

### 3.3 A2 1차 — method 구현 무결성 (`_get_method_strata`)
- **method 중복**: `neuram`·`cca1d`·`adaptive_bucket_probing` ≈ `pca1d`(PCA 1D→quantile bin). 코드 주석이 "단순화"·"Pseudo-AE"로 인정. 16/41종 다양성 상당 부분 허수.
- **명명 무결성**: `neurocard_lite`·`tucker`·`vinecopula`·`factor_join`는 발표 알고리즘 이름을 달았으나 구현은 조잡한 PCA+bin 대체물.
- **가짜 hilbert**: 구 `hilbert`는 진짜 곡선 아님(PCA2D+lex sort) — 코드가 "학술 fraud 회피"로 `pca2d_lex` 개명 명시. strong 13은 `hilbert_real` 사용(모듈 정독 미완).
- A1 설명: 신호 5종이 전부 PCA/ICA 투영 기반 — 주성분 구조를 잡아 층이 동질적 → 분산↓. 코드로 A1 결과가 설명됨.

### 3.4 전략 결론 (사용자에게 보고 완료)
- **q-error**: 개선 가능 — 추정량 평균 ~24%↓, PCA 층화 ~2%↓. 단 전자는 일반 효과(신규성 없음).
- **latency**: 사실상 개선 불가 — 구조적. B1이 이미 oracle 수준 plan 회복. Flow-Loss(VLDB'21)·Leis(VLDB'15) 문헌 일치(Gemini 대조 완료).
- **재측정 무용**: 측정 데이터는 멀쩡함(환각·조작 아님). 망가진 건 method 구현·해석·목표. → 재측정이 아니라 **정직한 재프레이밍**이 답.
