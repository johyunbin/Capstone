### 10.2 CaseC 정의 (정밀)

```
CaseC measurement = (B1 + B1') / 2 independent dual-Bernoulli ensemble:
- 한 trial 안에 두 개의 독립 AdaptiveState (state_a, state_b) 운영
- 두 개의 독립 rng (rng_a = seed * 13 + 7 · rng_b = seed * 13 + 7 + 1000000)
- 각 query 마다:
    est_a = bernoulli_estimate(samples_b1, sizes_b1, qvec, D, rng_a, budget=state_a.size)
    est_b = bernoulli_estimate(samples_b1, sizes_b1, qvec, D, rng_b, budget=state_b.size)
    est_final = (est_a + est_b) / 2.0
    q_err = q_error(est_final, true_card)
- 두 state 각자 update (같은 ensemble q_err 으로 update)
    state_a.update(q_err, state_a.size / total_rows)
    state_b.update(q_err, state_b.size / total_rows)
```

**audit 의 CaseB' 와의 차이**: audit = trial t 와 trial tj 의 estimate cross-pair (post-hoc 재구성). 실측 CaseC = 한 trial 안에 두 독립 sampler 동시 운영 (pre-registered). **표본 크기 = 2 × state.size (B1 의 2배)** — audit 의 CaseB' 와 동일한 inherent feature.
