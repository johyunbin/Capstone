### 3.1 slide 5 질문 답변 (Adaptive Sampling 정확 메커니즘)

★ **박세은 팀장님 후자 해석 (여러 쿼리에 대해 각 쿼리별 한 번씩만 샘플링) 이 정확함**. 추가로 — **50 쿼리 batch (UPDATE PERIOD) 마다 sample 크기 N 자체가 동적 조정**.

**상세 (reference/analysis/(01) Exqutor 상세분석.md verbatim §5)**:
- **한 쿼리** = N개 sample **한 번** 추출 → 무작위 베르누이로 카디널리티 추정 → Q-error = max(추정/실제, 실제/추정) 계산
- **50 쿼리 batch 마다**: 누적 Q-error 로 조정 인자 δ 계산 → **모멘텀 m=0.9** 적용 (급변동 방지) → 학습률 η 감쇠 → **다음 batch 의 N 갱신**
- 초기 N = 385 (식 1, 통계 신뢰도)
- DEEP·SimSearchNet++: 시간 지나며 N 감소 (안정적) · SIFT: 더 복잡한 분포 → N 증가

★ "한 쿼리 안에서 여러 번 추정하면서 sample 개수 조절" 은 **틀린 해석**. 한 쿼리는 한 번 sample. 쿼리들 전체에 걸친 N 조정. v17 slide 5 표현이 이 점을 모호하게 보여 의문 발생 → **v18 slide 5 에서 명확화** (50 쿼리 batch UPDATE PERIOD 도식 추가).
