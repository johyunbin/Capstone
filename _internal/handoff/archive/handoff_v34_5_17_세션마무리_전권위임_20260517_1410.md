## 1. 본 연구 framing — 논문 재현이 목적이 아니다 (가장 먼저 내재화)

다음 세션이 가장 먼저 흡수해야 하는 사실이다.

**본 연구의 목적은 Exqutor 논문 재현이 아니다.** 모든 임베딩 데이터셋(DEEP 96d / SIFT 128d / SSN 256d / WIKI 768d / YFCC 192d) + 우리가 직접 concat 한 다중 벡터 데이터셋(DEEP+SIFT 224d / DEEP+WIKI 864d / DEEP+YFCC 288d)에 대해, 조작 변인(selectivity 0.001/0.01/0.10, method 16종, single/multi-vector, scale factor 1/10/100, strata 수 K 10/20/30)을 빠짐없이 교차 확인하는 완전 실험이 목표다. paper Exqutor §V-B Adaptive Sampling 은 우리가 Q-error 를 측정하기 위한 측정 방법론의 출발점일 뿐이며, 비교 대상(대조군 B1)을 정의해 줄 뿐이다.

### 측정 3-way (이 세 모드의 구분이 본 연구의 뼈대)

| 모드 | 정의 | 측정 상태 |
|---|---|---|
| **B1 (대조군)** | paper §V-B 그대로의 Bernoulli random sampling N=385 → `est_b1`. AdaptiveState Eq 1-6 momentum 보정 포함. 비교 기준선. | **측정 완료** |
| **CaseB (실험군·결합/증강)** | `est_final = (est_b1 + est_method) / 2.0`. paper Bernoulli 추정값과 16 method 분포 인지 stratification 추정값의 산술 평균. | **측정 완료** |
| **CaseA (실험군·완전 대체)** | `est_final = est_method`. Bernoulli 없이 16 method stratification 추정값만 단독 사용. | ★ **미측정 — 다음 세션 핵심 신규 작업 (작업 C)** |

연구 narrative arc 는 이렇다 — 베르누이 → 16 method 완전 대체(CaseA) 시도 → 효과 적을 것으로 추정 → 대체 대신 결합(증강, CaseB)으로 전환. CaseB 측정이 다 끝났으므로, **CaseA 도 CaseB 와 동일한 portfolio 전 범위로 측정하면** 이 arc 를 B1 / CaseA / CaseB 3-way 실측 데이터로 완전히 뒷받침할 수 있다. 사용자 지시 원문 취지: "CaseB(결합) 측정이 다 끝났으니, CaseA(완전 대체)도 CaseB 측정한 전체 portfolio 와 똑같이 전체 측정하라. 시간 남으니까."

우리의 개입 지점은 오직 **sample selection 단계** 한 곳이다. cardinality 추정 알고리즘과 AdaptiveState Eq 1-6 은 paper 그대로 둔다.

## 5. ★ 미해결 — B1 2단계 subsampling (다음 세션 첫 작업)

**가장 중요한 미해결 사안.** §2 의 4번 K10 B1 fix 과정에서 드러난 사실이다.

기존 B1 측정 전체가 다음과 같은 **2단계 구조**였다 — 80M 전체 벡터 → strata 당 500개씩 약 10,000개를 캐시 → 그 캐시에서 385 sample. 즉 random sample 이 80M 직접이 아니라 10,000개 중간 캐시를 거쳤다.

수정본은 이 중간 캐시를 없애고 **80M 에서 직접 1단계** random sample 을 뽑는다. 두 방식을 K=20 에서 비교하면 SIFT 2.63% / SSN 0.78% 차이가 난다. 이 1~3% 차이가 **통계 노이즈인지 체계적 bias 인지 아직 검증되지 않았다.** 검증 에이전트를 띄우려던 차에 사용자가 세션 종료를 지시해 중단됐다.

**다음 세션의 첫 작업(작업 A)**: 이 B1 2단계 vs 1단계 동등성을 검증하고, 결론에 따라
- **노이즈 수준이면** → REPORT v12 수치(§3) 그대로 확정. K granularity 보강(작업 B)·CaseA(작업 C)만 수정본 B1 로 새로 측정하면 된다.
- **체계적 bias 면** → B1 전면 재측정이 필요할 수 있다. 이 경우 측정 portfolio 전체의 B1 을 다시 측정하고 paired Δ% 를 재계산해야 한다 — 작업량이 크므로, 메인 세션이 검증 결과를 직접 확인하고 사용자 복귀 전까지 가능한 범위를 판단해 진행한다.

검증 방법 권장: 동일 cell·K=20 에서 2단계 B1 과 1단계 B1 을 각각 trial 다수회 측정해, 두 분포의 평균 차이가 trial 간 inherent 분산(REPORT v12 §9 에서 B1 trial CV 약 6%) 안에 들어오는지 통계 검정(paired t-test 또는 Wilcoxon)으로 확인한다. measurement run 단위 systematic bias 가 ±10~25% 라는 REPORT v12 §9 (4)번 관찰도 함께 고려할 것 — run bias 가 큰 만큼, 같은 run 안에서 두 방식을 짝지어 측정해야 깨끗한 비교가 된다.

## 8. ★ 권장 작업 방식 — plan-first 병렬 에이전트 2단계

사용자 명시 지시다.

1. **1단계 — plan 작성**: 병렬 에이전트로 작업별(A~J) 상세 plan 을 매우 상세하게 작성한다. 각 에이전트가 한 작업의 ExitPlanMode 수준 상세 계획(어떤 파일, 어떤 명령, 어떤 검증)을 산출한다.
2. **취합**: 메인 세션이 병렬 에이전트 plan 산출물을 직접 읽고 취합한다. 작업 간 의존성(A → B/C/I)을 정리하고 순서를 확정한다.
3. **2단계 — implement**: 취합한 plan 을 토대로 다시 병렬 에이전트로 구현한다.
4. **검증**: 메인 세션이 에이전트 결과를 **반드시 직접 확인** 한다 — parquet 재계산, 파일 존재 확인, 로그 점검. 에이전트 산출물을 검증 없이 신뢰하지 않는다(trust but verify).

작업 순서 권장: A(B1 검증) 먼저 단독 → 결론에 따라 B·C launch(측정은 시간 오래 걸리므로 background 로 띄우고 D 로 모니터링) → 측정 도는 동안 E·F·G·H(정리 작업)를 병렬 진행 → 측정 완료 후 I(분석 재구성)·J(통계 보완).

## 9. 환각 회피 룰 (필독 — 직전 세션들에서 반복된 문제)

- **"영역" 필러 토큰 절대 금지** — 조사("의/에서/을/는")나 어미 자리에 "영역" 이라는 무의미 토큰을 반복 삽입하는 환각이 며칠간 반복됐다. 사용자가 5/16 직접 지적("며칠 전부터 계속 영역영역 이런 식의 환각 답변"). MEMORY `feedback_no_filler_token.md` 에 영구 등록. 모든 user-facing 텍스트와 에이전트 prompt 를 출력 전 점검 — "영역" 이 의미 없이 반복되면 정상 조사로 고친다. 한 문장에 "영역" 2번 이상이면 거의 확실히 환각이다.
- **모든 수치는 parquet 실측에서** — `paired_delta_v12.parquet` / `aggregated_v12_full.parquet` 에서 직접 확인. 이전 세션·문서의 수치를 그대로 신뢰하지 말 것. REPORT v12 §7.2 환각이 그 사례다(K10 +14.62% 주장 → 실측 −26.85%).
- **에이전트 산출물을 메인 세션이 직접 검증** — 직전 세션의 12개+ 에이전트 검증도 메인이 핵심 수치를 재확인했다. trust but verify.
- **K=10 수치 취급 주의** — K10 paired 는 B1 결함으로 신뢰 불가. headline 은 항상 K=10 제외 1240건.
- **비가역 작업 사전 dry-run** — mv·삭제·재측정 덮어쓰기 등은 dry-run 후 진행. 단, 전권 위임 범위 안에서는 사용자 사전 위임으로 간주하되 결과를 명확히 기록·보고한다.
