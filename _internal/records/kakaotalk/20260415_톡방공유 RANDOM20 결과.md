## 실험 결과

RANDOM20 = 데이터를 무작위로 20개 그룹으로 나눈 뒤 같은 stratified sampling 적용. KM20과의 차이 = "공간 구조를 아느냐 모르느냐".

| selectivity | KM20 (공간 인식) | RANDOM20 (무작위) | 차이 |
|---|---|---|---|
| 0.500 (넓은 범위) | +1.64% | +2.20% | 거의 같음 |
| 0.050 (중간 범위) | +1.85% | +0.79% | KM20 약간 우세 |
| **0.010 (좁은 범위)** | **+8.93%** | **-10.67%** | **KM20이 19.6%p 우세** |

### 핵심 발견

selectivity가 낮을수록 (= query가 찾는 데이터가 특정 영역에 집중될수록):
- KM20 (공간 구조를 아는 상태): **개선 폭이 커진다** (+1.6% → +8.9%)
- RANDOM20 (공간 구조를 모르는 상태): **오히려 나빠진다** (+2.2% → -10.7%)

### 교수님 프레이밍과의 연결

이 결과는 교수님이 말씀하신 "데이터가 쏠려있을 때 → 기존 방식이 나빠지고 → 개선된 sampling으로 해결"과 정확히 일치합니다.

구체적으로:
1. **데이터가 쏠려있다**: cluster 크기가 26K~81K (3배 차이)
2. **좁은 범위를 찾을 때 쏠림이 더 심하다**: s=0.010에서 true matches가 소수 cluster에 집중
3. **공간 구조를 아는 sampling만 개선**: KM20은 +8.93%, 무작위(RANDOM20)는 -10.67%

## 이게 뭘 의미하나

- **넓은 범위 query** (s=0.500): 어차피 데이터가 전체에 퍼져있어서, 아무렇게나 나눠도 비슷한 결과 → "공간 인식" 불필요
- **좁은 범위 query** (s=0.010): 찾는 데이터가 특정 영역에 몰려있어서, 그 영역을 정확히 알아야 제대로 추정 → "공간 인식" 필수

→ 교수님의 "쏠림 → 성능 저하 → 개선" 프레이밍이 실험적으로 확인됨.
