## 사유 — 왜 정정해야 하는가

raw 파일 [`experiments/results/rq1_motivation/random20_low_sel_summary.json`](../../experiments/results/rq1_motivation/random20_low_sel_summary.json) 에 5-seed × 100 query 측정이 모두 보존되어 있음:

```json
"s0.05.km20": {
  "mean": 1.8537%,
  "ci": [-0.22, +3.42],   // 5-seed t-based
  "per_seed": [+2.23%, +3.47%, +3.96%, -2.08%, +1.69%]
},
"s0.01.km20": {
  "mean": 8.9322%,
  "ci": [+6.59, +10.95],  // 5-seed t-based
  "per_seed": [+8.51%, +11.42%, +11.53%, +4.33%, +8.87%]
}
```

"(단일 seed)" 라고 표기하면 reviewer/심사위원이 *seed-to-seed 변동 미측정* 으로 오해. 실제로는 5-seed 측정·CI 산출 완료 → 자체 anchor 손실 위험. 5 분 정정으로 신뢰도 회복.
