[RQ2] 분포 아는 상황에서 어떤 방식이 최적인가?
═══════════════════════════════════════════

기준선: BERN (RQ1 의 row-level baseline)

비교 후보:
  (a) KM20 + Proportional Allocation
      - 현재까지 측정 완료
      - DEEP +1.6~8.9%, SIFT +3.0~4.4%
      - Two-Level Decomposition 으로 효과 분해
        (Level 1 = K 등분 / Level 2 = 공간 인식)

  (b) KM20 + Neyman Allocation  ★ 신규
      - n_i ∝ N_i × σ_i  (분산 비례)
      - variance-optimal (Neyman 1934)
      - 추가 +1~3% 기대

  (c) KM20 + Anti-Neyman  ★ 신규 (ablation)
      - n_i ∝ N_i / σ_i  (분산 반비례)
      - 분산 비례가 왜 옳은지 직관 그림
      - 예상: Proportional 보다 나쁨

    → 저비용 환경에서 KM20 효과 ↑ 메시지

K=20 채택 근거:
  Phase 6 Step 3' 에서 K=10 vs K=20 직접 비교,
  K=20 이 s=0.10 까지 추가 유의 신호 확보.
  K=50 이상은 sample_size=385 / K=50 = 7개/stratum 으로
  추정 분산 폭증.

═══════════════════════════════════════════

  Paradigm 1. Offline Partition (1회 사전 계산)

    B. KDE-pilot (Neyman + KDE)

  Paradigm 3. Weight-based (분할 X)
    H. Importance Sampling (2x2 factorial)

핵심 metric: Recovery Rate
  = (방법X − RANDOM20) / (KM20 − RANDOM20)
  - 1.0 → KM20 oracle 수준 회수
  - 0.0 → RANDOM20 (공간 인식 없음)
  - 음수 → 더 나쁨

가설 H3: distribution-agnostic 방법은 KM20 대비
        유의미한 비율을 회수하면서 사전 학습
        불필요/극소 비용 이점을 제공한다.

## §2. W1 sprint 작업 11 항목 (분담 카드)

**우선순위**:
- RQ1 (#1) — 확실히
- RQ2 (#2~4) — 확실히
- RQ3 (#5~11) — 가능한 선까지

**시간 예측 합계**: 8개 (RQ3 W1 까지) ≈ 20h / 11개 풀 ≈ 30h

### #1 — RQ1: SIFT × SYSTEM(block) baseline 측정 (~2h)

| 항목 | 내용 |
|---|---|
| **동기** | 박세은 "Normal vs Skew BERN baseline 직접 비교 부재" 의문. 4 cell 중 마지막 1 cell. |
| **확인** | H1: skew 데이터일수록 random sampling 의 q-error 가 악화되며 block > row 편향. |
| **예상** | SIFT SYSTEM > SIFT BERN > DEEP SYSTEM > DEEP BERN. SIFT 안 격차 > DEEP 안 격차. |
| **조건** | SIFT 1.5M / TABLESAMPLE SYSTEM / s∈{0.01, 0.05, 0.10, 0.30, 0.50} / 5 seed / 100 query / sample_size=385 |
| **기존자료** | DEEP 비교 `experiments/results/rq1_motivation/phase4_compare.json`, SIFT BERN `phase7_sift_bern.parquet` (s=0.5 만) |
| **현재 상태** | 조현빈 진행 중 (5/6 오전). D_target 보강 + BERN 재측정 + SYSTEM 측정 풀그리드. |

### #2 — RQ2: Neyman Allocation 구현 + 측정 (~4h)

| 항목 | 내용 |
|---|---|
| **동기** | KM20 의 Proportional 은 분산 정보 미활용. Neyman (variance-optimal, 1934) 도입 → 박세은 "한 가지 더 고안" 답. |
| **확인** | H2-N: Neyman 이 Proportional 위에서 추가 q-error 개선. |
| **예상** | DEEP/SIFT 양쪽에서 +1~3%. SIFT (분산 비균질 큼) 에서 효과 더 클 가능성. |
| **조건** | DEEP 1M + SIFT 1.5M / s 5점 / 5 seed / 100 query / sample_size=385 |
| **구현** | Python 사전 계산: cluster σ_i 측정 → vector.c sample 배분 weight 수정 (~50줄, weight = N_i × σ_i / Σ) → GUC `vector.allocation_method = 'proportional' | 'neyman'` 추가 |

### #3 — RQ2: Anti-Neyman ablation (~30min, #2 직후)

| 항목 | 내용 |
|---|---|
| **동기** | Neyman 정당성을 ablation 으로 입증. 박세은 "분산 반비례 방식도 테스트" 제안. |
| **확인** | H2-AN: Anti-Neyman 이 Proportional 보다 나쁨. |
| **예상** | 순서: Anti-Neyman < Proportional < Neyman. |
| **구현** | #2 코드에서 weight 부호만 반전. GUC `vector.allocation_method = 'anti_neyman'`. |

### #4 — RQ2: Sample size sensitivity (~3h)

| 항목 | 내용 |
|---|---|
| **동기** | 회의 "Exqutor 대비 효과 약함" 지적 → baseline 부정확한 (sample_size 작은) 환경에서 우리 방법의 가치 ↑ 확인. |
| **확인** | H2-S: sample_size 작을수록 KM20 효과 (vs BERN) 큼. |
| **예상** | sample_size 100 에서 +10%? / 3000 에서 가장 작음. 단조 감소 곡선. |
| **조건** | DEEP 1M / sample_size {100, 385, 1000, 3000} / s {0.01, 0.05, 0.50} / 5 seed / 100 query / BERN vs KM20-Proportional |

### #5 — RQ3: C. Random Projection (~2h)

| 항목 | 내용 |
|---|---|
| **동기** | 분포 모를 때 가장 단순 distribution-agnostic. Johnson-Lindenstrauss 정리 — 랜덤 단위벡터 사영이 거리 ε 이내 보존. 7-way 의 "최단순 하한선". |
| **확인** | H3-C: 1D 랜덤 사영으로 KM20 의 일부 (10~40%) 회수. |
| **예상** | recovery_rate ≈ 0.10~0.40. SIFT 에서 더 낮을 것 (skew 가 사영을 비균질하게 만듦). |
| **구현** | numpy 랜덤 normal vector 1개 → dot product → 20 등분 quantile bin → stratum_id. ~30 LOC. |

### #6 — RQ3: A. LSH (~4h)

| 항목 | 내용 |
|---|---|
| **동기** | 다차원 확률적 공간 포착. 해시 충돌 ∝ 거리 (이론 보장). |
| **확인** | H3-A: LSH 가 Random Projection 보다 우수. |
| **예상** | recovery_rate ≈ 0.30~0.60. |
| **구현** | k=10 hash function (random hyperplane) × L=4 hash table → 다중 bucket 결합. ~100 LOC. |

### #7 — RQ3: E. Hilbert Curve (~4h)

| 항목 | 내용 |
|---|---|
| **동기** | 결정론적 공간 포착. R-tree 30년 검증된 space-filling curve. 벡터 카디널리티에 최초 적용 (contribution 후보). |
| **확인** | H3-E: Hilbert Curve 가 결정론으로 LSH 보다 안정. |
| **예상** | recovery_rate ≈ 0.40~0.65. variance 가 LSH 보다 작음. |
| **구현** | 차원 축소 (PCA 16d) → Hilbert order → 20 등분. `hilbertcurve` 라이브러리 활용. |

### #8 — RQ3: F. MiniBatch K-means (~1h)

| 항목 | 내용 |
|---|---|
| **동기** | 박세은 "사전 계산 비용" 비판 직접 답 — full K-means 의 1/20~1/100 학습량으로 충분한가? |
| **확인** | H3-F: 1~5% sample 로 80%+ 회수. |
| **예상** | recovery_rate ≈ 0.70~0.90. 학습 시간 1.2초 → 0.05초. |
| **구현** | sklearn `MiniBatchKMeans(n_clusters=20, batch_size=1024)`. 기존 phase6_export_km20_strata.py 살짝 수정. |

### #9~11 — RQ3 후순위 (시간 부족 시 후속 연구로)

| # | 이름 | 시간 | 동기 |
