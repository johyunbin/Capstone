# 오프라인 실험 정당성 감사 — 종합 평결 (A1–A5)

> 검증: Codex(gpt-5.5, xhigh/high) 적대 교차검증 · A1 수치 재현 스크립트 재실행

## 핵심 한 줄

v13 오프라인 측정 데이터는 A3 점검상 **건전하며 신뢰 가능하다** — 재측정은 불필요하다. 그러나 *"분포 인지 층화라는 단일 개입이 Q-error를 89% 개선한다"* 는 **인과 귀속이 틀렸다**. 89% 우위는 분포 인지의 효과가 아니라 **독립 추정량 2개를 산술 평균한 앙상블(분산 감소) 효과**다 — 고정-N 통제군 `(Bernoulli+Bernoulli)/2`가 CaseB 우위의 대부분을 재현한다. latency는 측정한 56 cell 범위에서 B1→CaseB 무개선이며, B1이 이미 oracle 수준 plan을 회복하므로 추가 개선의 여지가 구조적으로 없다. **재측정이 아니라 정직한 재프레이밍이 해법.**

## 0. 감사 범위와 방법

엔진 적용 검증에서 B1→CaseB latency 무개선이 관측된 것이 감사의 발단이다. "측정이 틀렸나, 해석이 틀렸나, 목표가 틀렸나"를 가리기 위해 측정 코드·데이터·결과를 다섯 항목으로 점검하였다.

| 항목 | 질문 | 평결 |
|---|---|---|
| A1 | CaseB의 Q-error 89% 우위는 '분포 인지' 효과인가, 일반 통계 효과인가 | **앙상블 평균 효과** |
| A2 | 16종 method 구현이 표방한 알고리즘대로 작동하는가 | **상당수 명명·구현 결함** |
| A3 | v13 측정 데이터 자체에 조작·손상이 있는가 | **없음 — 데이터는 건전** |
| A4 | 엔진 적용 검증의 latency 무개선은 진짜인가 | **진짜 — 구조적 한계** |
| A5 | 종합 평결과 제출물 함의 | 본 문서 §5–§6 |

framing(불변): 본 연구 = Exqutor 논문 §V-B 적응적 표본 추출의 **표본 선택 단계 하나**(무작위 Bernoulli → 분포 인지 층화) 개입의 효과 검증. 3-way matched — B1(대조군, 논문 그대로)·CaseA(완전 대체 = method 단독, 음성 대조군)·CaseB(결합 `(est_b1+est_method)/2`).

## 1. A1 — Q-error 89% 우위의 메커니즘

### 1.1 판정용 통제군

측정 코드(`measure_3way`, measure_paper_exact.py:1312–1333) 정독 결과 — B1·CaseA·CaseB는 각자 독립 AdaptiveState로 표본 크기가 발산하나, `q_idx < update_period(50)` 구간은 전 mode 표본 N=385 고정이라 깨끗한 추정량 비교가 가능하다. 여기에 통제군을 하나 더 둔다.

- **CaseB** = `(est_Bernoulli + est_method) / 2` ← 연구 주장 (논문 방식 + 분포 인지 방식)
- **CaseB′** = `(est_Bernoulli + est_Bernoulli) / 2` ← 통제군. method 자리에 또 다른 독립 Bernoulli draw.

CaseB ≈ CaseB′ 이면 우위의 정체는 '평균' 그 자체다.

### 1.2 고정 N=385 (q<50, 1,226 measurement, strong-13)

| 추정량 | 평균 Q-error | B1 이긴 비율 |
|---|--:|--:|
| B1 (Bernoulli 단독) | 1.944 | — |
| CaseA (분포 인지 층화 단독 = "우리 method") | **1.984** (B1보다 **나쁨**) | 44% |
| CaseB (Bernoulli+method)/2 — 연구 주장 | 1.477 | 99% |
| **CaseB′ (Bernoulli+Bernoulli)/2 — 통제군** | **1.459** | 100% |

**CaseB′(1.459)가 CaseB(1.477)와 동등하거나 오히려 낫다.** CaseB가 통제군 CaseB′를 이기는 measurement는 42%뿐 — 절반 미만. 즉 method 자리에 분포와 무관한 두 번째 Bernoulli를 넣어도 같은 89%대 우위가 나온다. B1↔stratified 추정량의 부호 구조도 반대 부호 48.1% ≈ 50%로, 두 추정량은 **사실상 독립** — 독립 오차를 평균하면 분산이 줄어드는 교과서적 효과다.

### 1.3 연구 데이터 안의 결정적 증거 — hyperloglog

`hyperloglog` method는 벡터를 md5 해시해 버킷에 넣는 **무작위 해시 분할**로, 데이터 분포와 아무 관계가 없다. v13 수치:

- CaseA(분포 인지 층화 단독으로 hyperloglog 사용): mean Δ% **+2.57%** — B1보다 **나쁨**, better 16.8%.
- CaseB(hyperloglog를 Bernoulli와 평균): median Δ% **−4.58%**, better 100%.

**분포와 무관한 무작위 해시조차 평균에 넣기만 하면 −4.58% "개선"으로 둔갑한다.** hyperloglog의 CaseB 우위(median −4.58%)는 전체 CaseB 우위(median −4.38%)·강한 13종 범위(median −2.7%~−6.5%) 안에 그대로 들어간다 — 분포 인지 method든 무작위 해시든 CaseB 우위 크기가 비슷하다는 것이, 우위의 원천이 method 품질이 아니라 평균임을 연구 자신의 데이터로 보여 준다. (인용 축 유의: CaseA는 mean Δ%, CaseB는 median Δ%.)

### 1.4 A1 평결

- v13 정본 수치(CaseB better **89.1%** 1,344/1,508, median Δ% **−4.38%**)는 **진짜다** — A3 데이터 무결성 점검에서 손상·결측 없음.
- 그러나 *"분포 인지 층화 덕분"* 이라는 **인과 귀속은 틀렸다.** 고정-N(q<50, 1,226건) 통제군 비교에서 평균 효과만으로 CaseB 우위의 대부분이 재현된다 — CaseB 우위는 분포 인지가 아니라 독립 추정량 평균에 따른 분산·zero-hit 감소라는 일반 통계 효과로 설명되며 신규성이 없다. ("95%" 같은 전수 인과분해 수치로 단정하지 않는다 — 통제군은 고정-N 슬라이스다.)
- 분포 인지 층화로 Bernoulli를 **완전 대체**(CaseA)하는 것은 portfolio 전체로 보면 **순효과 0이 아니라 오히려 악화**다 — v13 전수에서 CaseA better 35.2%·평균 Δ% +12.90%, 고정-N에서도 CaseA 1.984 > B1 1.944. 신호 5종(§2.1)만 근소한 우위~중립(full-adaptive 평균 Δ% −0.42%~+0.58%)일 뿐, 분포 인지 층화가 Bernoulli를 대체할 만한 순이득은 어디에도 없다.
- Codex 적대 검증: A1 결론 "강하게 지지"(직전 세션). 본 세션 `audit_a1_mechanism.py` 재실행으로 수치 일치 확인.

## 2. A2 — method 구현 무결성

A1이 남긴 잔여 물음 — "CaseA가 B1을 이기는 소수 method(신호 5종: `hilbert_real`·`skilling_hilbert`·`pca1d`·`zorder_morton`·`ica_fastica`)는 진짜 분포 인지 구현인가?" — 을 위해 회수한 서버 측정 모듈을 정독하고 Codex로 교차검증하였다.

### 2.1 신호 5종 — 실제 변별 신호는 PCA/ICA 투영

| method | 표방 | 실제 구현 | 변별 신호 |
|---|---|---|---|
| `hilbert_real` | 진짜 Hilbert 곡선 | PCA(2) → 진짜 Wikipedia xy2d Hilbert 곡선 → quantile bin | **PCA(2)** |
| `skilling_hilbert` | "Skilling 2004 진짜 고차원 Hilbert" | PCA(4) → 코드가 직접 `"Skip exact swap for simplicity (approximation)"` 명시 → Morton식 비트 인터리브 → quantile bin | **PCA(4)** (Hilbert 아님) |
| `pca1d` | PCA 1D | PCA(1) → quantile bin | **PCA(1)** |
| `zorder_morton` | Z-order Morton | PCA(2) → 진짜 Morton 비트 인터리브 → quantile bin | **PCA(2)** |
| `ica_fastica` | FastICA | sklearn FastICA(1) → quantile bin | **ICA(1)** |

다섯 method 모두 `PCA/ICA(k) 투영 → [공간 채움 곡선] → quantile bin` 구조다. 곡선·인터리브는 이미 차원 축소된 공간을 1D로 재배열할 뿐, 층을 가르는 변별 신호는 PCA/ICA 투영이다. 4종이 PCA, 1종이 ICA로 환원된다 — 신호 5종의 미미한 우위(§1.4)는 "분포 인지 공간 채움 곡선"이 아니라 **일반적 차원 축소 + quantile 층화**(교과서적 분산 감소 기법)다.

### 2.2 명명 결함 (Codex 확인)

- **`skilling_hilbert` — 명명 부정확.** docstring은 "Skilling 2004 true high-D Hilbert curve, algorithm 137" 표방하나, 코드가 핵심 좌표 교환 단계를 스스로 *"단순화를 위해 건너뛴다"* 고 주석에 명시. 진짜 Hilbert 곡선이 아니다. 구 `hilbert`→`pca2d_lex` 개명("학술 fraud 회피")과 **동일 부류이며 개명에서 누락**됐다.
- **`kmeans_neyman` — Neyman 미적용.** docstring은 "Neyman σ-aware re-bin" 표방, σ를 계산하나(465–472줄) 실제 `return labels`(raw KMeans id). 주석도 "For minimal change, return cluster id" 자인 — σ 계산은 dead code.
- **`lavallee_hidiroglou` — Neyman 미적용.** docstring "Neyman σ_h allocation" 표방, 실제는 PCA1D → take-all → cum-√f만.
- `_neyman_allocation_assign` 함수 — 정의만 있고 호출 0건 (dead code).
- 3-way 측정은 method strata에 **`equal_alloc`(균등 배분)** 사용(measure_paper_exact.py:1320–1330) — method의 "Neyman" 명칭은 측정에서 어차피 발동하지 않는다.

### 2.3 보고서 §4.7 method 명칭 정직성 노트가 거꾸로

현 6/11 보고서 §4.7은 *"hilbert_real은 PCA 2D 사전식 정렬 alias이며 진정한 Hilbert curve 정렬은 별도의 skilling_hilbert가 담당"* 이라 적었다. **두 진술 모두 사실과 반대다** — `hilbert_real`이 진짜 Hilbert 곡선이고, `skilling_hilbert`가 가짜다. 정직성 노트 자체가 부정확하다.

### 2.4 A2 평결

신호 5종이 CaseA에서 B1을 근소하게 이기는 것은 PCA/ICA 차원 축소의 일반 효과이며, "분포 인지 공간 채움 곡선"의 신규 기여가 아니다. method 레지스트리는 표방한 알고리즘 이름과 실제 구현이 여러 곳에서 어긋난다(`skilling_hilbert` 가짜 Hilbert, `kmeans_neyman`·`lavallee_hidiroglou` Neyman 미적용). A1의 평결을 강화한다 — CaseB 우위는 method 정체와 무관한 평균 효과다.

## 4. A4 — 엔진 적용 검증 (latency)

56 cell(phase2/3/4_extension) 측정 JSON을 진단 스크립트(`diagnose_latency_nullresult.py`, Codex P1 3건 반영)로 정량화.

- **0a 노이즈 바닥**: 같은 variant 15 rep 반복의 변동계수 중앙값 **17%**(p90 33%). 측정 분해능 한계.
- **0b q-error↔latency 디커플**: cell 고정효과 제거 후 within-cell 부분상관 **r = −0.007** (naive pooled −0.286은 cell-mix 교란). 한 cell 안에서 추정값을 정확히 해도 실행시간이 따라오지 않는다. (zero-hit `injected_card=0` 4건은 q-error 무한대라 상관서 제외 — 정직 보고)
- **0c plan 전이**: latency 이득의 정체 = base 테이블 SeqScan+HashJoin → NL+IndexScan의 이진 전이(24 cell). sel별 가속 — 0.001: 4.5×, 0.01: 1.8×, 0.1: 1.0×. **B1 가속(4.43×) ≈ oracle 가속(4.54×)** — B1이 이미 가용 이득을 거의 100% 추출.
- **0d B1↔CaseB paired latency (직접 대조)**: 728 pair / 56 cell. paired Δ% 중앙값 **+0.13%**(CaseB가 오히려 미세하게 느림), 평균 +1.62%. CaseB 빠름 349 · 느림 379 ≈ 50:50. **|중앙값 0.13%| ≪ 노이즈 바닥 17% → latency 차이를 측정으로 분리 불가.**

보고서 §5.5는 이미 variance decomposition에서 condition % SS가 0.00%(p=0.866)임을 정직하게 보고했다 — A4는 이를 paired 직접 대조로 재확인한다.

**A4 평결: 측정한 56 cell 범위에서 B1→CaseB의 latency 개선은 부재한다.** B1이 이미 oracle 수준 plan을 회복(B1 가속 ≈ oracle 가속)하므로 CaseB가 추가로 끌어낼 latency 이득의 여지가 구조적으로 없고, q-error와 latency가 디커플돼 있어 추정 정확도를 더 높여도 실행시간은 따라오지 않는다. 단 latency sweep은 미실행 — 전 selectivity·전 엔진에 걸친 보편적 단언은 보류하며 "cliff까지 검증"이라는 표현도 쓰지 않는다.

## 5. 종합 평결

| 무엇이 | 평결 |
|---|---|
| v13 오프라인 측정 데이터(1,508건) | **건전·신뢰 가능** — A3 직접 점검(구조 매칭·결측 0·K 결함 해소) |
| 엔진 적용 검증 측정(2,880회) | 측정은 실제 수행됨 — 단 pgvector 패치 자체의 코드 감사는 본 감사 범위 밖 |
| 89.1% / −4.38% 같은 수치 | **진짜** — A1·A3 점검상 조작·손상 없음 |
| "89% 우위 = 분포 인지 층화 개입의 효과" 인과 귀속 | **틀림** — 앙상블 평균 효과 (A1) |
| "16종 method가 7 paradigm을 대표" 구현 무결성 | **부분적 허위** — 명명·구현 결함 다수 (A2, Codex 확인) |
| "분포 인지 층화가 Bernoulli를 대체 가능" | **틀림** — 완전 대체(CaseA)는 portfolio 전체로 악화 (A1) |
| latency도 개선됐다는 함의 | **틀림** — 측정 56 cell 범위 무개선·구조적 headroom 부재 (A4) |

q-error는 결합(CaseB)으로 개선된다 — 단 그 개선은 추정량 평균이라는 일반 통계 효과이고, 분포 인지 층화로 Bernoulli를 대체하는 것 자체는 portfolio 전체로 보면 이득이 없거나 오히려 손해다. latency는 측정 범위에서 개선되지 않으며 구조적 여지도 없다. v13 측정 데이터는 건전하다. 망가진 것은 **일부 method 구현·결과의 인과 해석·연구 목표 설정**이다. 따라서 **재측정은 무용하며, 해법은 정직한 재프레이밍**이다.
