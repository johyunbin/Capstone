## 1. n=10 paired Wilcoxon — discrete p-value 분포

**핵심 한계**: n=10 paired Wilcoxon → exact test의 p-value 가 discrete.

- 가능한 two-sided p-value (no ties, lowest 20):
  ```
  ['0.0020', '0.0039', '0.0059', '0.0098', '0.0137', '0.0195', '0.0273', '0.0371', '0.0488', '0.0645', '0.0840', '0.1055', '0.1309', '0.1602', '0.1934']
  ```
- 결과: p < 0.05 통과하려면 **W ≤ 8 또는 W ≥ 47** (10개 trial 중 거의 모두 same direction)
- p < 0.01 통과: W ≤ 5 또는 W ≥ 50
- 단일 -10% 효과크기로는 n=10 with noise → power 부족 가능 (특히 std 큰 cell)

## 2. Wilcoxon 재계산 (per cell × method × mode)

**검증**: analyze_paper_exact.py wilcoxon → method='auto' (n=10 시 exact).

**alternative 비교**:
- two-sided (메인 사용): CaseA ≠ B1 (방향 무관)
- greater (제안): B1 > CaseA → CaseA-better one-sided test, power ↑

- 총 paired tests: 300 (CaseA 197, CaseB 103)

## 3. BH-FDR adjusted p-value 재계산

**method 비교**:
- (A) analyze_paper_exact.py 자체 구현 (rank-based, monotonic correction)
- (B) statsmodels `multipletests('fdr_bh')` (cross-check)

- max abs diff: **1.110223e-16**
- mean abs diff: **8.187895e-18**
→ **PASS**: 메인 BH-FDR 구현 statsmodels와 정확히 일치.

## 4. one-sided vs two-sided 통계 power 비교

**가설**: 우리는 'CaseA가 B1보다 작은 q_error' (CaseA-better) 검증 — 방향성 명확하므로 one-sided test 적합. two-sided는 over-conservative.

- two-sided p_adj < 0.05: **109건** / 300
- one-sided (greater, CaseA-better) p_adj < 0.05: **61건** / 300
- 차이: **-48건** (one-sided − two-sided)
  - two-sided 109건은 'CaseA ≠ B1 (양방향)' — outliers (lsh/RP/sobol in A1-SSN/A2-Fig7 등) 가 worse 방향으로 signif 일부 포함
  - one-sided 61건만 'CaseA가 진짜 better' 신뢰 가능
  - 109 - 61 = **48건은 method가 worse 방향으로 signif** (narrative caveat 필요)
