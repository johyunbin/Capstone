## 사용법

각 실험은 **2 단계**로 진행:

1. **시작 프롬프트** (실험 진행 전에 복붙)
   - Claude 에게 컨텍스트 + 측정 항목 + 기대 결과를 알려줌
   - 그러면 Claude 가 스크립트 작성 / 측정 가이드 / 예상 결과 안내

2. **완료 프롬프트** (실험 끝난 후 복붙)
   - 측정 결과 (raw json 경로) + 핵심 수치를 알려줌
   - 그러면 Claude 가 **간단 브리핑 + 상세 설명** 출력 (보고서/발표용)

```

  - ...

다음 형식으로 정리해줘:

1. 한 줄 요약 (트윗 길이 — 누가 봐도 결과를 알 수 있게)

2. 간단 브리핑 (3~5줄)
   - 무엇을 측정했는가
   - 왜 측정했는가 (RQ 와의 연결)
   - 핵심 결과

3. 상세 설명 (처음 보는 사람도 이해 가능 — 친절한 학술 산문 톤)

   - 결과 (수치 + 통계적 유의성 + 비교 표)
   - 의의 (이 결과가 RQ 와 어떻게 연결되며, 다음 단계로 어떻게 이어지나)

4. 발표/보고서 narrative 보강 포인트
   - 이 결과를 발표 슬라이드 / 보고서에 어떻게 녹일 것인가
   - 박세은님 의문 (Normal vs Skew / Exqutor 인과 chain / 인덱스 비판 / 사전 계산 비용 / iff→필요조건) 중 어느 것을 강화하나

5. 다음 실험 연결 (선택)
   - 이 결과를 받아서 다음 실험은 무엇을 보강해야 하나
```

### #2 — RQ2: Neyman Allocation 구현 + 측정 (~4h)

```
RQ2 보강 실험 — Neyman Allocation 구현 + 측정 진행.

목표:
- 기존 KM20 = Proportional Allocation (n_i ∝ N_i, cluster 크기 비례)
- Neyman Allocation = n_i ∝ N_i × σ_i (크기 × 분산, variance-optimal)
- 통계학 정통 (Neyman 1934 정리)
- 추가 +1~3% 기대

구현 단계:
1. Python 사전 계산: 각 cluster (KM20) 안에서 거리 또는 indicator 의 분산 σ_i 측정
2. vector.c 의 sample 배분 weight 수정:
   - 기존: 비례 weight = N_i / N
   - 신규: Neyman weight = (N_i × σ_i) / Σ(N_j × σ_j)
3. GUC 추가: vector.allocation_method = 'proportional' | 'neyman'

측정 조건:
- 데이터셋: DEEP 1M, SIFT 1.5M (양쪽 다)
- selectivity: 1%, 5%, 10%, 30%, 50%
- seed: 5
- query: 100
- 비교: BERN baseline → KM20 Proportional → KM20 Neyman

기존 자료:
- KM20 Proportional 측정: experiments/results/rq1_motivation/phase6_strat_km20_native.parquet
- KM20 학습 코드: experiments/code/rq1/ (numpy mini-batch k-means)
- vector.c 수정 이력: memory/reference_server.md

기대 결과:
- KM20 Proportional 위에서 추가 +1~3% (DEEP), +1~3% (SIFT)
- SIFT (cluster 분산 더 비균질) 에서 효과 더 클 가능성

세부 결정 (Claude 권한):
- σ_i 정의: 거리 D 의 분산 / indicator 의 분산 / hook_est 의 분산 중 어느 것?
  → 추천: indicator 분산 (binary success 0/1) 이 가장 직관적

측정 시작 도와줘.
```

### #3 — RQ2: Anti-Neyman ablation (Neyman 과 묶음, 추가 ~30분)

```
RQ2 ablation — Anti-Neyman 측정 (#2 직후 진행).

목표:
- Anti-Neyman = n_i ∝ N_i / σ_i (분산 반비례)
- variance-suboptimal — 분산 비례의 정당성을 ablation 으로 입증
- 예상: Proportional 보다 나쁨

구현:
- Neyman 코드 (#2) 에서 weight 부호만 반전
- GUC: vector.allocation_method = 'anti_neyman' 추가

측정 조건: #2 와 동일 (DEEP/SIFT × selectivity 5점 × 5seed × 100 query)

비교 표:
- BERN vs KM20-Proportional vs KM20-Neyman vs KM20-Anti-Neyman
- 4-way ablation

기대 결과:
- Proportional > Anti-Neyman (분산 비례가 옳다는 직관 그림)

측정 시작 도와줘.
```

### #5 — RQ3: C. Random Projection (~2h)

```
RQ3 — C. Random Projection 구현 + 측정 진행.

목표 (가장 단순한 distribution-agnostic 방법):
- Johnson-Lindenstrauss lemma 기반
- 랜덤 단위벡터 r 생성 → 각 vector v 의 사영값 v·r 계산 → K=20 등분
- "최단순 하한선" 역할

구현:
1. Python 으로 stratum_id 할당 (~50줄):
   - r = np.random.randn(d), r /= np.linalg.norm(r)
   - 각 행에 대해 v · r 계산
   - K=20 quantile 로 stratum_id 할당
2. DB UPDATE: SET stratum_id = 새 값
3. 기존 KM20 측정 파이프라인 재활용

측정 조건:
- 데이터셋: DEEP 1M, SIFT 1.5M
- selectivity 5점 × 5seed × 100query
- 비교: RANDOM20 ≤ C ≤ KM20 예상

기대 결과:
- recovery_rate 10~40%
- 1D 사영으로는 다차원 구조 포착 한계 → RANDOM20 과 큰 차이 없을 수도

측정 시작 도와줘.
```

### #6 — RQ3: A. LSH (~4h)

```
RQ3 — A. LSH (Locality-Sensitive Hashing) 구현 + 측정 진행.

목표:
- 해시 충돌 확률이 거리에 반비례 → 가까운 vector 가 같은 버킷
- 랜덤 하이퍼플레인 p 개 → 2^p 버킷

구현:
1. p = 5 정도로 설정 → 32 버킷 (KM20 과 비교 가능 수준)
2. Python: 랜덤 하이퍼플레인 H (p × d) 생성
3. 각 vector v 에 대해 sign(v · H) 계산 → p-bit 버킷 ID
4. 버킷 → stratum_id 매핑 (32 → 20 으로 줄이려면 작은 버킷 merge)

측정 조건: #5 와 동일

기대 결과:
- recovery_rate 30~60%
- C(RandProj) 보다 강함 (다차원 구조 포착)

측정 시작 도와줘.
```

```
★ 2x2 factorial (필수):
다른 방법은 allocation 만 바꾸고 estimator (hook_est) 는 동일.
H 만 estimator 도 바꾸므로, allocation × estimator 교락 분리 필수.

| | Uniform estimator | IS estimator |
| KM20 allocation | 기존 RQ2 결과 | KM20-IS (신규) |
| H allocation | H-uniform (신규) | H-IS (default) |

→ 4 조합 모두 측정 → 신규 측정 3 개 (KM20-IS, H-uniform, H-IS)

기대 결과:
- recovery_rate 30~70%
- factorial 분해로 allocation 효과 vs estimator 효과 분리

측정 시작 도와줘.
```
