## 1. RQ1 — random sampling이 skew 데이터에서 얼마나 부정확?

### (a) 동기

벡터 DB는 쿼리 실행 전 "이 조건에 맞는 행이 대략 몇 개?"를 추정. 이 추정이 정확해야 좋은 실행 계획. Exqutor는 이 추정을 위해 **데이터 일부 무작위 sampling**.

문제는 **데이터가 한쪽에 쏠려 있을 때 (skew) random sampling이 제대로 작동하는가?**

### (b) 가설

- **H1**: 데이터가 더 skew일수록 random sampling의 q_error가 더 부정확
- **H2**: selectivity가 낮을수록 (rare query) 더 부정확

### (c) 실험

- **비교**: BERN (random) vs KM20 (분포 아는 oracle)
- **데이터**: DEEP 1M (Normal) + SIFT 1.5M (Skew)
- **selectivity 5단계**: 0.01 / 0.05 / 0.10 / 0.30 / 0.50

### (d) 실제 결과 — 가설 모두 적중 ✓

**KM20 vs RANDOM20 (DEEP 1M)** — 공간 구조를 아는 것의 가치

| sel | KM20 개선 | RANDOM20 개선 | 격차 |
|---|---|---|---|
| 0.50 (50%) | +1.31% | +2.20% | ~0 |
| 0.30 | +2.62% | +0.26% | 2.4%p |
| 0.10 | +4.19% | +1.74% | 2.5%p |
| 0.05 | +1.85% | +0.79% | 1.1%p |
| **0.01 (1%)** | **+8.93%** | **−10.67%** | **19.6%p** |

→ 좁은 쿼리 (s=1%)에서 격차 19.6%p. **쿼리 범위가 좁아질수록 "공간 구조를 아는 것"이 점점 더 중요**.

**단조성 통계 검정** (per-seed Spearman ρ, n=25):

- DEEP-KM20: ρ = **−0.680**, 95% CI **[−0.800, −0.440]** → 0 제외, **단조 감소 확정**
- DEEP-RAND: ρ = +0.560, CI [+0.320, +0.840] → 0 제외, reverse-monotonic 확정

### (e) 결론

✓ **Selectivity Gradient 단조성 입증** — gradient 19.6%p (KM20 +8.93% vs RANDOM20 −10.67%, s=0.01)
✓ **H1, H2 모두 정량 확인**

## 3. RQ2 — 분포 알 때 어떤 allocation이 최적?

### (a) 동기

KM20 (K-means K=20) oracle 가정. **5가지 방식 중 어느 게 가장 좋을까?**

| 방식 | 의미 |
|---|---|
| BERN | random (baseline) |
| Equal | 클러스터마다 같은 수 |
| Proportional | 클러스터 크기 비례 |
| Neyman | 분산 σ_i 비례 (이론상 최적) |
| Anti-Neyman | σ_i 반대 (negative control) |

### (b) 가설

- KM20 oracle은 모든 stratified > BERN
- Neyman > Proportional (분산 활용 가치)
- Anti-Neyman 가장 나쁨

### (c) 실험

- **데이터**: DEEP 1M / SIFT 1.5M
- 5 mode × 5 sel × 5 seed × 100 query = **25,000 cell**
- 추가: sample size 4단계 sensitivity (40 cell), 8M cross-scale 검증

### (d) 실제 결과

✓ **모든 stratified > BERN** (DEEP −1.3~−7.0%, SIFT −3.7~−10.5%)
✓ **KM20 sample-size robust — 40/40 cell 일관**

⚠️ **Neyman vs Equal**: 거의 차이 X (σ_i 신호 약함)
⚠️ **Anti-Neyman vs Proportional**: 좁은 sel만 systematic hurt
- DEEP s=0.01 +5.21%, SIFT s=0.01 +9.49% (CI 0 제외)
- 그러나 paired Wilcoxon p > 0.5, Cohen's d < 0.1 — 개별 query 수준은 random과 동치

✓ **8M cross-scale**: 1M와 일관 방향 재현 (Anti-Neyman s=0.1 Δ=+1.28% CI 0 제외)

### (e) 결론 — σ_i 신호 약함 honest 입증

- ✓ **KM20 oracle은 sample-size robust** (단점: 학습 ~30분)
- σ_i 신호는 **median 수준에서만 detect 가능, 개별 query는 random과 동치**
- → "분포 분산을 활용하는 것"의 한계, 분포의 "위치"만 알아도 충분
- → **RQ3 distribution-agnostic 추구의 motivation chain**

## 4. RQ3 — 분포 모를 때 어떤 방식이 KM20 oracle을 대체?

### (a) 동기

학습 X, 결정론으로도 KM20 수준 회수 가능?

### (b) 실험

- 22 method × DEEP 1M + SIFT 1.5M × 5 sel × 5 seed × 100 query
- 5/5 회의 초기 7-way → W1 16-method → **5/7 새벽 22-method 완성**

### (c) 22 method 분류 (5 paradigm)

| Paradigm | Method | 특징 |
|---|---|---|
| **Cluster (Offline)** | KM20 (oracle) / MiniBatch / **partial_fit** / **HDBSCAN** / GMM / BIRCH / Spectral | K-means 기반, 학습 필요 |
| **Locality** | **Hilbert** / Z-order / **Hybrid** | Space-filling curve |
| **Projection** | Random Proj / Sparse RP / PCA-1D | 차원 축소 |
| **Tree** | KD-tree / PQ | 분할 indexing |
| **Online weight** | KDE-pilot / Distance-Shell / IS variants 4종 | 분할 X, 가중치만 |

### (d) 결과 — 4강 ★ (paired bootstrap CI 0 제외 5/10 cell robust)

| 순위 | Method | 수치 | 핵심 |
|---|---|---|---|
| **★1** | **Hilbert** (PCA 2D + 결정론 quantile) | mean Cohen's d = **−0.156** | 학습 X, 결정론, ~수초 fit |
| **★2** | **MiniBatch K-means partial_fit** | ARI = **1.000** (batch 동등) | OLTP 적용 가능, 4 cell paired CI 0 제외 |
| **★3** | **HDBSCAN** (5/7 NEW, density-based) | SIFT s=0.10 **−3.99%** [−5.34, −2.12] | 모든 22 method 중 mid-sel best |
| **★4** | **Hybrid** (KMeans + Hilbert) (5/7 NEW) | SIFT 평균 rank **5.83** (Hilbert 5.85 보다 약간 우수) | SIFT s=0.10 −3.10% [−4.61, −1.19] |

### (e) Negative Control — cluster 분할 자체의 가치 정량 증명

| Method | 수치 | 해석 |
|---|---|---|
| **PQ** | DEEP s=0.01 **+23.64%** [+15.91, +31.80] | massive failure (분할 paradigm 미스매치) |
| **Sobol** | SIFT s=0.01 **+33.62%** | 가장 큰 hurt (quasi-random 사용 불가) |
| **IS variants** | d = +0.5~+0.7 | medium hurt (분할 X 한계) |
| **Distance-Shell** | d = +0.49 | cluster X 한계 (online weight 만) |

→ 4 negative control 모두 CI 0 제외 hurt → **"cluster 분할 자체"가 결정적 가치**

### (f) Hilbert mechanism 정량 분리 (5/7 W1-C 분석)

| Metric | Hilbert | Z-order | 해석 |
|---|---|---|---|
| Inverse Manhattan | **1.000** (perfect) | 1.992 (50% jumps) | 1D-2D continuity 보존도 |
| Stratum compactness | 4.77 | 12.12 | Hilbert가 **2.54× 더 compact** |
| ARI orthogonality avg | 0.316 (curve sibling) | 0.314 | Z-order와 정보 공유 |

→ **Hilbert의 강한 결과는 PCA 효과가 아닌 curve 자체의 locality**

### (g) Method orthogonality ranking (5 ARI CSV 통합 분석)

직교성 ranking (avg ARI, 낮을수록 정보 직교):
- 1위 **sparse_rp** (0.122) — 가장 직교
- 2위 pca1d (0.277)
- 3위 curve sibling Hilbert/Z-order (0.31)
- 4위 tree (0.331)
- 5위 cluster method 4종 (0.55+) — 정보 redundant

→ 본 연구의 22 method가 **정보적으로 5 region cover** → ablation 학술 정당성 ✓

### (h) Cross-scale 1M ↔ 8M 검증

- 18 method × 2 sel = 36 cell
- **method ranking 1M/8M 동일** (외적 타당성 강화)
- 8M에서 sampling 자연 안정화 (random_proj −3.34% 가장 개선)
- kde_pilot 만 +5.27% deviation (adaptive estimator scale 한계)

### (i) 결론

✓ **Hilbert + MiniBatch partial_fit** = production replacement (학습 X / OLTP 가능)
✓ **HDBSCAN** = SIFT skew 환경 추가 가치
✓ **Hybrid** = 양 paradigm 결합 (5/7 NEW)
✓ **모든 method |d| < 0.8** → "공간 인식의 limit" honest 명시

## 5. RQ2 vs RQ3 종합 비교 — 분포 알 때 vs 분포 모를 때

### (a) 핵심 차이

| 구분 | RQ2 (분포 알 때) | RQ3 (분포 모를 때) |
|---|---|---|
| baseline | KM20 oracle, 모든 40 cell BERN 우위 | 4강 (Hilbert / partial / HDBSCAN / Hybrid) |
| effect size | sample-size robust | KM20과 같은 region (d ≈ −0.15) |
| 학습 비용 | KM20 ~30분 | Hilbert ~수초 / partial_fit OLTP |
| production 적합 | 학습 가능 시 | 학습 X 또는 OLTP 환경 |

### (b) 상황별 권장

| 상황 | 권장 방식 | 이유 |
|---|---|---|
| 분포 정확히 안다 + 학습 시간 OK | **KM20 oracle** | 40/40 cell 일관 |
| 분포 안다 + OLTP 환경 (학습 시간 X) | **MiniBatch partial_fit** | ARI 1.000 batch 동등, streaming 지원 |
| 분포 모름 + 학습 X | **Hilbert curve** | ~수초 fit, 결정론, inverse Manhattan 1.000 |
| 분포 모름 + SIFT 같은 skew 환경 | **HDBSCAN** | mid-sel best −3.99%, density-based |

### (c) 핵심 insight

> 분포 모르는 상황에서도 **Hilbert / HDBSCAN이 KM20과 같은 region 진입 가능**.
>
> "**공간 인식 자체가 가치**" — 정확한 분포 모르더라도 그 공간 내 어디에 있는지만 알면 OK.
>
> = production deployment 가능 (학습 부담 없이).
