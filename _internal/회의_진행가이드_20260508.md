## 예상 질문 + 답변 (Q&A)

### Q1: KM20 oracle 은 production 불가능 아닌가?
**A**: 예, oracle baseline. 그래서 4강 production-ready method 가 KM20 oracle 의 70~100% 회복 (Recovery Rate). 특히 **MiniBatch_partial** 은 partial_fit 으로 OLTP friendly — pre-computed cluster 없이 stream learning.

### Q2: SSN++ 만 hurt direction 인 이유?
**A**: cluster_ratio 1.29 + intrinsic_dim 0.88 = **분포 균형** (uniform-like). BERN baseline 자체가 이미 낮음 (ceiling effect). 본 연구의 **outer boundary** 를 정의 — Sweet Spot 의 정량 경계.

### Q3: 4강 선정의 근거?
**A**:
1. **HDBSCAN**: avg -8.04% (1위) + SIFT_sf1 -34.17% 최강 1위 → strongest narrative (oracle 영역)
2. **MB_partial**: CI 9/10 + online learning 유일 → OLTP friendly (production sweet spot)
3. **Hilbert**: 가장 가벼움 (수 초) + CI 9/10 → production candidate
4. **Hybrid (MB+Hilbert)**: ablation → mechanism narrative (clustering vs ordering 분리)

### Q4: PDX 와의 차이?
**A**: **Complementary contribution**. PDX = compute layer (data layout for fast similarity). 본 연구 = pre-process layer (sampling/clustering for accurate cardinality). 같은 thesis 다른 영역.

### Q5: Tier 1 17종 spread 1.21%p 는 무엇을 의미?
**A**: HDBSCAN (-8.04) ~ kdtree (-6.83) 까지 모든 method 가 작은 차이. 즉 "method choice" 보다 **"분포 정보 인지 자체"** 가 결정적. 어느 method 든 Tier 1 이면 OK, 4강 = 대표.

### Q6: Multi 결과는? (5/8 17:?? STAGE 1+2 완료 반영)
**A** — 핵심 narrative 1줄: **"단일 정확성은 multi 정확성의 *필요조건*만 성립, 충분조건은 X"**

**측정 결과**:
- multi-vector 2 cell (partsupp_deep_sift_10, partsupp_deep_wiki_10) × 4강 ✅ 측정 완료
- multi-table join (partsupp_deep_10 ⨝ part_wiki_10) × 4강 = STAGE 3 측정 진행 중 (회의 후 추가 보강)

**핵심 정량**:
- 단일 sweet spot 4강 평균 \|Δ%\| = **17.13%** (SIFT_sf1 / WIKI_sf1 / YFCC_sf1)
- multi-vector 4강 평균 \|Δ%\| = **0.67%**
- → **25.4× 약화** (magnitude shrinkage)
- 부호 일관성 (sel=0.10): 3/8 negative · 5/8 positive boundary (\|Δ\| 모두 < 1.5%)

**해석**: multi 환경에서 4강 method 의 ranking 도 노이즈 수준으로 와해. multi-relation 일반화는 **joint-aware clustering** 또는 **multi-vector decomposition** 별도 설계 필요 → future work.

**자료**: PPT slide 11 + master_v6 §multi-2 (line 690~720) + S11 차트 (4강 × 2 multi-vector cell + 단일 -17.13% reference + STAGE 3 measuring 표기)
