# 03_selectivity_sweep — 선택도 민감도

쿼리 필터 **선택도(selectivity) 를 0.001 과 0.10 으로** 바꿔 본 16-method 측정.
본실험 기본 sel=0.01 (트랙 02) 의 양 끝 점이다. 선택도가 매우 낮거나(0.001) 높을 때
(0.10) 결합 효과가 유지되는지 본다.

- file 680개 (cell × sel{0.001, 0.10} × 16 method + B1)
- 구조: `{데이터셋}_{sf}[_K{n}]/sel{0.001|0.10}/{mode}/{파일}.json`
- 일부 SIFT/SSN cell 은 K10 / K30 변종도 포함 (`SIFT_sf100_K10/` 등)
- 출처: server 측정 `v9_sel_sweep_0530`

> sel=0.01 본실험과 sel{0.001,0.10} 을 함께 보면 선택도-결합효과 곡선이 그려진다.
