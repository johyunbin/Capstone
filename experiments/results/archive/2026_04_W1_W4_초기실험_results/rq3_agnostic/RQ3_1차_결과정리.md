## 4. 발견의 의의 — 3 contributions

### 4-1. Hilbert Curve — **본 연구의 핵심 발견 1순위** ★

- PCA 2D + Hilbert curve + quantile 분할 = 학습 0 + 결정론
- **MiniBatch (1% 학습) 와 동등 또는 SIFT 에서 우수** (-2.9% vs -2.5%)
- **Mechanism 분석** (서버 측 fit log 추출):
  - PCA 2D explained variance: SIFT 22.0% > DEEP 12.3% — SIFT 의 cluster 구조가 2D 로 더 잘 압축
  - Hilbert bucket max/min ratio 1.16~1.18 (매우 균질, quantile 분할 효과)
  - vs MiniBatch 자연 cluster 비율 2.45~4.77 — Hilbert 가 훨씬 균질
- 5/27 발표의 contribution 4번째 (Recovery Rate Framework) 의 가장 강력한 사례
- **"learning-free stratification 도 oracle 수준 가능"** narrative 확립

### 4-2. MiniBatch K-means — production-ready 솔루션 ★

- 1% 학습 (10K row, ~수초) + KM oracle 의 효과 회수
- 모든 cell -0.4~-4.2%, 통계 유의 8/10
- RQ재정립 plan 의 Limitation 1 (KM20 = oracle, production X) 해소

### 4-3. Cluster 분할의 결정적 가치 — 부정적 control 정량 증명 ★

본 연구의 **negative control 로서 가장 강한 결과**:

- **Distance-Shell** (+8~+17%): cluster 분할 (KM) 대신 distance shell → 매우 나쁨
  - cluster 정보가 sigma 추정의 핵심
  - shell quantile 만으론 spatial 정보 보존 불가
- **Importance Sampling** (best -17%, worst +866%): cluster/shell 분할 X, weight 만 → massive failure
  - 분할 자체가 KM oracle 효과의 본질
  - weight clip 도 일부 cell 만 도움
- **LSH/Random Projection** (+0.6~+45%): 단순 hash/projection → 일관되게 worse
  - distribution-agnostic 의 단순 분할 한계

**3가지 negative control 의 일관된 패턴** = "stratification 의 가치는 cluster-aware 분할에서 온다" 의 정량 증명.

### 4-4. 분모 붕괴 caveat

- KM20 oracle 과 RANDOM20 의 q_error 격차 0.26~3.98%
- recovery_rate.py 의 fall-back 동작 — primary metric 을 절대 개선 %로 변경
- 향후 sample_size 작은 환경 (sensitivity) 에서 격차 회복 검증
