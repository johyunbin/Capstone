## 4. 발견의 의의

### 4-1. Hilbert Curve — **본 연구의 핵심 발견 후보** ★

- PCA 2D + Hilbert curve + quantile 분할 = 학습 0 + 결정론
- 그럼에도 **MiniBatch (1% 학습) 과 동등 또는 SIFT 에서 더 우수**
- 5/27 발표의 contribution 4번째 (Recovery Rate Framework) 의 가장 강력한 사례
- **"learning-free stratification 도 oracle 수준 가능"** narrative

### 4-2. MiniBatch K-means — production solution

- 1% 학습 (10K rows, ~수초) + KM oracle 의 효과 회수
- RQ재정립 plan 의 Limitation 1 (KM20 = oracle, production X) 해소
- 단 Hilbert 가 동등하다면 "MiniBatch vs Hilbert" 의 trade-off 가 새로운 비교축

### 4-3. LSH / Random Projection — 부정적 control

- 두 distribution-agnostic baseline 이 RANDOM20 보다 일관되게 나쁨
- 좁은 sel (s=0.01) 에서 SIFT Random Projection +45.14% (매우 나쁨)
- **"단순 hash/projection 만으로는 분포 정보 회수 불가"** 의 정량적 증명
- 가설 H3-A "LSH 가 RandProj 보다 우수" 도 refute (둘 다 fail)

### 4-4. 분모 붕괴 caveat

- KM20 oracle 과 RANDOM20 의 격차 0.26~3.98%
- 이는 cache_per_cluster=500 / sample_size=385 환경에서 cluster-aware vs random 차이가 작다는 뜻
- recovery_rate.py 의 fall-back 동작 — primary metric 을 절대 개선 %로 변경
