# 논문분석지침 (MANUAL)

> 사람이 직접 수행하거나 Claude에게 개별 요청할 때 참조

## 언제 실행하나?

- **새 논문을 분석할 때** — "이 논문 분석해줘", "총정리 만들어줘"
- **여러 논문을 비교 분석할 때** — "시리즈 분석 만들어줘"
- **미분석 논문을 확인하고 싶을 때** — "아직 안 읽은 논문 뭐 있어?"
- **기존 총정리를 업데이트할 때** — "이 총정리에 실험 결과 추가해줘"

## 단계별 가이드

### Step 1: 현황 파악

현재 분석 현황 확인:
```bash
cd ~/Capstone
echo "papers: $(ls research/papers/*.pdf | wc -l)"       # 69편
echo "summaries: $(ls research/summaries/*.md | wc -l)"   # 82편
echo "analysis: $(ls research/analysis/*.md | wc -l)"     # 12편
```

- summaries 번호: [0]~[81] (82편)
- analysis 번호: (01)~(12) (12편)
- papers보다 summaries가 많은 이유: 일부 논문은 PDF 없이 웹/arXiv에서 직접 분석

### Step 2: 대상 논문 선택

Claude에게 요청:
> "research/papers/에서 아직 총정리 안 된 논문 목록 보여줘"

또는 직접 지정:
> "[논문제목].pdf 총정리 만들어줘"
> "research/papers/[파일명].pdf 분석해줘"

### Step 3: 총정리 작성 요청

Claude에게 요청할 때 핵심 포인트:
> "이 논문 총정리 만들어줘. 한국어 학술 산문으로, 실험 조건과 한계까지 포함."

**파일명 규칙**:
- summaries: `[번호] 논문제목_키워드 총정리.md` → 다음 번호 [82]
- analysis: `(번호) 제목.md` → 다음 번호 (13)

**저장 위치**:
- 총정리: `research/summaries/`
- 시리즈: `research/analysis/`

### Step 4: 시리즈 분석 (선택)

관련 논문 3편 이상 모이면 시리즈 분석을 요청:
> "[번호1], [번호2], [번호3] 논문을 비교 분석하는 시리즈 만들어줘"

기존 시리즈 유형 참고:
- `(01)~(08)`: Exqutor 관련 상세분석/통합요약 (쌍으로 구성)
- `(09)~(11)`: 개별 논문 미팅용 심층분석
- `(12)`: 복수 논문 통합요약

### Step 5: 품질 확인

총정리에 반드시 포함되어야 하는 것:
1. 연구 배경/문제 정의
2. 제안 기법 (번호 매겨서)
3. 실험 설계 (데이터셋, HW, baseline, 메트릭)
4. 정량적 결과
5. 한계점/미해결 문제
6. Exqutor와의 연결고리
7. 핵심 용어 표

빠진 항목이 있으면:
> "이 총정리에 실험 설계 섹션이 빠졌어. 추가해줘."

### Step 6: PDF 변환

총정리 md 완성 후 PDF 변환:
```bash
python3 scripts/md2pdf.py research/summaries/[파일명].md
# → 같은 디렉토리에 .pdf 생성
```

또는 Claude에게:
> "방금 만든 총정리 PDF로 변환해줘"

**주의**: Chrome CDP 방식만 사용 (scripts/md2pdf.py). fpdf2 사용 금지.

## 자주 하는 실수

| 실수 | 올바른 방법 |
|------|------------|
| 번호 중복 부여 | 반드시 현재 최대번호+1 사용 |
| bullet 나열로 작성 | 한국어 학술 산문 (서사적 문단) |
| 실험 조건 생략 | 데이터셋/HW/baseline/메트릭 필수 |
| Exqutor 연결고리 누락 | 반드시 포함 (우리 연구와의 관계) |
| fpdf2로 PDF 생성 | scripts/md2pdf.py만 사용 |
| summaries와 analysis 혼동 | summaries=[번호], analysis=(번호) |
| PDF 없이 md만 남겨둠 | 작성 직후 PDF 변환 |

## 관련 지침

| 지침 | 연동 관계 |
|------|----------|
| 문서생성지침 | md → PDF 변환 위임 (scripts/md2pdf.py) |
| 점검지침 | 작성 후 2종 세트 완성도 + PDF 폰트 검증 |
| 미팅지침 | 총정리 기반 미팅용 심층분석 가공 |
| 실험지침 | 분석에서 도출한 실험 설계를 실험지침에 전달 |
| 연구설계지침 | 논문 분석 결과가 연구 방향 설계에 반영 |
