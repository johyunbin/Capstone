# [06] 미팅지침 (MANUAL)

> 대상: Capstone 프로젝트 | 모드: 수동 (Phase별 정지, 사용자 확인 후 진행)
> 마지막 실행: —

## 사용법

1. "미팅 수동" 입력
2. Phase 0 실행 → 결과 보고 → **정지**
3. `/clear` 후 "Phase N 이어가줘"

### /clear vs /compact

| | /clear | /compact |
|---|---|---|
| 컨텍스트 | 100% 확보 | ~70% 확보 |
| 추천 용도 | **Phase 전환** (추천) | Phase 내부 보조 |

## Phase 체크리스트

> 상세 스크립트는 `06_미팅지침_auto.md` 참조.

### Phase 0: 미팅 유형 파악 + 인벤토리 (1분)
- [ ] 미팅 유형 확인 (교수님/자문위원/팀내부)
- [ ] 미팅 전/후 확인
- [ ] 기존 회의록/브리핑 확인
- [ ] guideline/PHASE_STATE_06_미팅.md 생성

✅ Phase 0 완료 → 결과 보고 → 정지
→ 사용자: `/clear` 후 "Phase 1 이어가줘"

### Phase 1-A: 미팅 전 — 브리핑 제작 (15분)
- [ ] 최근 git 활동 + 문서 현황 수집
- [ ] 최신 설계안 핵심 요약
- [ ] 논의 안건 + 질문 목록 초안
- [ ] `records/meetings/YYYYMMDD_미팅브리핑_대상.md` 저장
- [ ] PHASE_STATE 업데이트

### Phase 1-B: 미팅 전 — 심층분석 (선택, 20분)
- [ ] 특정 논문 발표 요청 시 심층분석 작성
- [ ] 기존 (09)~(12) 패턴 참조
- [ ] PHASE_STATE 업데이트

✅ Phase 1 완료 → 정지
→ 사용자: `/clear` 후 "Phase 2 이어가줘"

### Phase 2: 미팅 후 — 회의록 작성 (10분)
- [ ] 카톡 대화 → 구조화된 회의록 변환
- [ ] 또는 구두 회의 메모 정리
- [ ] `records/meetings/YYYYMMDD_제목.md` 저장
- [ ] PHASE_STATE 업데이트

✅ Phase 2 완료 → 정지
→ 사용자: `/clear` 후 "Phase 3 이어가줘"

### Phase 3: 후속 과제 추출 및 추적 (3분)
- [ ] ACTION ITEM 추출
- [ ] 담당자 + 마감일 배정
- [ ] 노션 업데이트 안내
- [ ] PHASE_STATE 업데이트

✅ Phase 3 완료 → 정지
→ 사용자: `/clear` 후 "Phase 4 이어가줘"

### Phase 4: 종합 확인 (1분)
- [ ] 파일 저장 위치 확인
- [ ] PHASE_STATE 최종 업데이트

✅ **미팅 완료**

## 자주 하는 실수

| 실수 | 올바른 방법 |
|------|------------|
| 회의록을 루트에 저장 | `records/meetings/`에 저장 |
| 카톡 원문 그대로 저장 | 구조화된 형식으로 변환 |
| 후속 과제 미추출 | 반드시 ACTION ITEM 추출 |
| 자문내역서를 여기서 작성 | 자문내역서는 제출물지침 담당 |

## 관련 지침

| 지침 | 연동 관계 |
|------|----------|
| 논문분석지침 | 심층분석의 원천 |
| 제출물지침 | 자문내역서·연구지도확인서 담당 |
| 주간보고지침 | 회의록을 주간보고에서 참조 |
| 연구설계지침 | 설계안이 브리핑 소스 |
