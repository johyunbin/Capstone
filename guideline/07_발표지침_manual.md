# 발표지침 (MANUAL)

> 사람이 직접 수행하거나 Claude에게 개별 요청할 때 참조

## 언제 실행하나?

- 중간발표(5월) 또는 최종발표(6월) **2~3주 전**부터 준비 시작
- 전시회 포스터는 **3~4주 전**부터 (인쇄 리드타임 고려)
- 교수님/자문위원 미팅 전 발표 연습이 필요할 때
- "발표", "PPT", "슬라이드", "포스터", "대본" 키워드로 Claude에게 요청

## 단계별 가이드

### Step 1: 샘플 확인

발표 유형에 맞는 샘플을 먼저 확인한다.

- 중간발표: `templates/samples/중간발표1/`, `중간발표2/`
- PPT 크기: `templates/samples/ppt-크기-수정/`
- 포스터: `templates/samples/포스터/`
- 팜플렛: `templates/samples/팜플렛-크기-확인/`

### Step 2: 슬라이드 구조 잡기

샘플의 섹션 구성을 참고해서 우리 발표에 맞게 조정한다.

**중간발표 기본 흐름:**
1. 표지 → 2. 배경 → 3. 관련연구 → 4. 본논문 → 5. 우리방법론 → 6. 실험설계 → 7. 진행상황 → 8-9. 결과 → 10. 향후계획 → 11. 참고문헌 → 12. Q&A

**최종발표는 중간 + 추가:**
- 전체 실험 결과 3~5장
- 결론 + 기여 1장
- 한계 + 향후 연구 1장

### Step 3: 내용 채우기

각 슬라이드의 핵심 메시지를 1개로 정한다.

내용 소스:
- 연구 방법론: `plans/연구_설계안_*.md`
- 관련 연구: `research/analysis/` 시리즈 분석
- 실험 결과: 실험 산출물 (실험지침 참조)

규칙:
- 텍스트 5줄 이하/슬라이드
- 차트·표·다이어그램으로 시각화 우선
- 전문용어 첫 등장 시 한영 병기

### Step 4: 발표 스크립트 작성

슬라이드별 대본을 30초~1.5분 분량으로 작성한다.

- 분량 검증: 한국어 기준 분당 약 300자
- 10분 발표 = 약 3,000자 대본
- 강조 포인트와 전환 멘트를 명시

### Step 5: 리허설

발표 전 반드시 확인할 항목:
- 시간 내 완료 가능한가?
- 슬라이드 전환이 자연스러운가?
- 차트가 먼 거리에서도 보이는가?
- Q&A 예상 질문에 답변할 수 있는가?
- 백업 슬라이드(상세 데이터)를 준비했는가?

### Step 6: 포스터 (전시회 시)

- 크기: A0(841×1189mm) 또는 A1(594×841mm)
- 핵심만 압축 (슬라이드 내용의 50% 이하)
- 인쇄 최소 1주일 전 발주
- QR코드(GitHub 링크) 포함

## 자주 하는 실수

| 실수 | 해결 |
|------|------|
| 텍스트가 너무 많은 슬라이드 | 핵심 메시지 1개 + 시각 자료 위주 |
| 시간 초과 | 대본 글자수로 사전 검증 (300자/분) |
| 관련 연구를 너무 길게 설명 | 핵심 차별점만 1~2문장 |
| 실험 결과 없이 발표 | 예비 실험이라도 포함, "현재 진행 중" 명시 |
| 포스터 인쇄 지연 | 최소 1주 전 파일 확정 + 인쇄 발주 |
| Q&A 준비 부족 | 예상 질문 10개 이상 + 답변 초안 |
| PPT 크기 불일치 | templates/samples/ppt-크기-수정/ 참고 |

## 팀원 역할 분담 예시

| 역할 | 담당 | 내용 |
|------|------|------|
| 발표자 | (지정) | 메인 발표, 스크립트 숙지 |
| 보조 발표 | (지정) | 실험 결과 부분 또는 시연 |
| 질의응답 | (지정) | Q&A 주도, 기술적 질문 대응 |
| 타이머 | (지정) | 시간 관리, 신호 |

## 관련 지침

- **제출물지침**: 발표 자료도 제출물 — 마감·양식 관리는 제출물지침 담당
- **실험지침**: 발표에 넣을 실험 결과는 실험지침에서 생성
- **연구설계지침**: 방법론 슬라이드 내용의 소스
- **문서생성지침**: 스크립트·구조 문서를 PDF로 변환할 때
- **점검지침**: 발표 자료 파일 무결성 검증
