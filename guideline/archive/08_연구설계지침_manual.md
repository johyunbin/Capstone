1. "설계 수동" 입력
2. Phase 0 실행 → 결과 보고 → **정지**

### /clear vs /compact

| | /clear | /compact |
|---|---|---|
| 컨텍스트 | 100% 확보 | ~70% 확보 |
| 추천 용도 | **Phase 전환** (추천) | Phase 내부 보조 |

## 자주 하는 실수

| 실수 | 올바른 방법 |
|------|------------|
| RQ가 너무 광범위 | 변수를 한정 (선택도·데이터셋·시스템) |
| 대조군 미설정 | vanilla pgvector baseline 필수 |
| HW 스펙 누락 | 재현 불가 = 무의미 |
| 성공 기준 없는 단계 | "이 단계는 언제 끝나는가?" |
| 설계만 하고 전환 안 함 | 확정 후 실험지침 연동 |

## 관련 지침

| 지침 | 연동 관계 |
|------|----------|
| 실험지침 | 설계 확정 후 실험 실행 |
| 논문분석지침 | 설계 근거가 되는 논문 분석 |
| 문서생성지침 | 설계안 PDF 변환 |
| 제출물지침 | 연구제안서에 설계 내용 반영 |
