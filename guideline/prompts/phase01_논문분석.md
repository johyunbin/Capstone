# Phase 1: 논문분석지침 제작 프롬프트

## 지침 개요

**논문분석 = 원논문 PDF → 구조화된 분석 문서 생성.** 총정리(개별 논문)와 시리즈 분석(그룹)
두 유형을 다룬다. md 원본 작성까지만 담당하고, PDF 변환은 문서생성지침에 위임.

## IS / IS NOT

**IS:**
- research/papers/ 원논문 읽고 총정리 md 작성 (summaries/)
- 시리즈 분석 md 작성 (analysis/)
- 논문 번호 부여 규칙 관리 ([0]~[N])
- 시리즈 번호 부여 규칙 관리 ((01)~(NN))
- 분석 품질 체크리스트 (배경/기법/실험/한계 모두 포함 여부)
- 논문 간 관계 매핑 (인용/대조/확장)

**IS NOT:**
- md → PDF 변환 → 문서생성지침
- PDF 폰트 검증 → 점검지침
- 실험 재현/벤치마크 → 실험지침
- 미팅용 심층분석 → 미팅지침 (단, 논문분석 결과를 기반으로 미팅지침에서 가공)

## 읽어야 할 프로젝트 파일

1. `CLAUDE.md` — 문서 작성 규칙, 번호 체계
2. `.claude/skills/paper-analysis/` — 기존 스킬 (흡수 대상)
3. `research/summaries/` — 기존 총정리 파일 (포맷 참조)
4. `research/analysis/` — 기존 시리즈 분석 (포맷 참조)
5. `research/papers/` — 원논문 목록

## Phase 구성 가이드

### Phase 0: 인벤토리 + 번호 확인 (2분)
- papers/ 원논문 수 vs summaries/ 총정리 수 비교
- 다음 할당 번호 확인 ([N+1])
- analysis/ 시리즈 번호 확인 ((NN+1))

### Phase 1: 논문 선택 + 읽기 (10분)
- 대상 논문 선택 (사용자 지정 또는 미분석 논문 중 우선순위)
- PDF 읽기 → 핵심 구조 파악

### Phase 2: 총정리 md 작성 (15분)
- 구조: 논문 개요 → 문제 정의 → 제안 기법 → 실험 설계 → 결과 → 한계/후속
- 한국어 학술 산문 스타일 (CLAUDE.md 규칙)
- 데이터셋/하드웨어/baseline/메트릭 반드시 포함
- 파일명: `[번호] 제목 총정리.md`
- 저장: `research/summaries/`

### Phase 3: 시리즈 분석 작성 (선택, 그룹 분석 시) (20분)
- 여러 총정리를 종합한 비교/통합 분석
- 파일명: `(번호) 제목.md`
- 저장: `research/analysis/`

### Phase 4: 품질 체크 + PDF 변환 요청 (3분)
- 체크리스트: 배경O, 기법O, 실험O, 한계O, 데이터셋O, 메트릭O
- 문서생성지침 호출 (md → PDF 변환)

## 완료 조건
- 총정리 md 작성 완료 (summaries/ 저장)
- 품질 체크리스트 전항목 통과
- PDF 변환 요청 또는 직접 변환 완료
