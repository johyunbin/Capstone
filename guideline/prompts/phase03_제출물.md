# Phase 3: 제출물지침 제작 프롬프트

## 지침 개요

**제출물 = 캡스톤 공식 제출 서류 작성 + 마감 관리.** 양식에 맞춰 작성하고,
마감일을 추적하며, 일정 변경 시 3곳(CLAUDE.md/메모리/노션)을 동시 업데이트한다.

## IS / IS NOT

**IS:**
- 연구제안서, 수행계획서, 중간/최종 보고서 작성
- 연구지도확인서, 자문내역서 작성
- 물품구매/회의비 양식 작성
- templates/forms/ 양식 확인 및 적용
- 마감 D-day 계산 및 알림
- 일정 3곳 동기화 (CLAUDE.md 일정표 + 메모리 + 노션 일정 DB)
- 캡스톤 사이트 제출 페이지 확인

**IS NOT:**
- 중간/최종 발표 PPT → 발표지침
- 논문 분석 문서 → 논문분석지침
- 서류 PDF 변환 → 문서생성지침
- 사이트 공지 모니터링 → 점검지침 (제출물은 마감 추적만)

## 읽어야 할 프로젝트 파일

1. `CLAUDE.md` — 핵심 일정표, 현재 단계
2. `.claude/skills/submission-prep/` — 기존 스킬 (흡수 대상)
3. `templates/forms/` — 양식 디렉토리 전체
4. `templates/samples/` — 예시 디렉토리 (보고서 샘플)
5. `submission/` — 기존 제출물 (포맷 참조)

## Phase 구성 가이드

### Phase 0: 일정 확인 + 다음 마감 식별 (2분)
- CLAUDE.md 일정표 파싱
- 오늘 날짜 기준 다음 미완료(⬜) 마감 확인
- D-day 계산

### Phase 1: 양식 확인 (3분)
- 해당 제출물의 양식이 templates/forms/에 있는지
- 없으면 캡스톤 사이트(capstone.cs.yonsei.ac.kr/?page_id=27)에서 확인
- 양식 요구사항 파악 (hwp/docx/pdf, 필수 항목)

### Phase 2: 제출물 작성 (20분+)
- 양식에 맞춰 내용 작성
- 기존 연구 결과(research/), 실험 결과, 설계안(plans/) 참조
- 한국어 학술 산문 스타일

### Phase 3: 검증 + 제출 준비 (5분)
- 필수 항목 누락 체크
- 파일 형식 확인 (hwp 필요 시 안내)
- submission/ 폴더에 최종본 저장

### Phase 4: 일정 동기화 (2분)
- 제출 완료 시 CLAUDE.md 일정표 상태 → ✅ 업데이트
- 메모리(project_capstone.md) 업데이트
- 노션 일정 DB 업데이트 안내

## 완료 조건
- 제출물 파일 submission/에 저장
- 양식 필수 항목 전부 충족
- 일정 3곳 동기화 완료
