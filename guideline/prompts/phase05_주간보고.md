# Phase 5: 주간보고지침 제작 프롬프트

## 지침 개요

**주간보고 = git 이력 + 문서 변경 + 실험 진행을 종합한 주간 리포트.**
노션 동기화와 팀원 진행 추적도 이 지침에서 담당.

## IS / IS NOT

**IS:**
- git log 기반 이번 주 작업 요약
- research/ 새 분석 문서 추가/수정 파악
- 실험 진행 상황 반영
- 노션 DB 동기화 (Study Archive, 일정 DB)
- 팀원 업무 분배 현황 정리
- 다음 주 계획 수립

**IS NOT:**
- 미팅 회의록 작성 → 미팅지침 (주간보고는 회의록을 "참조"만)
- 제출물 마감 관리 → 제출물지침
- 문서 작성/변환 → 논문분석지침, 문서생성지침

## 읽어야 할 프로젝트 파일

1. `CLAUDE.md` — 핵심 일정, 현재 단계
2. `.claude/skills/weekly-log/` — 기존 스킬 (흡수 대상)
3. `.claude/skills/progress-brief/` — 기존 스킬 (흡수 대상)
4. `records/meetings/` — 이번 주 회의록 (있으면 참조)

## Phase 구성 가이드

### Phase 0: 데이터 수집 (3분)
- `git log --since="1 week ago" --oneline` 실행
- research/ 내 최근 수정 파일 목록
- records/meetings/ 이번 주 회의록 확인

### Phase 1: 주간 요약 작성 (10분)
- 이번 주 완료 사항 (커밋 기반)
- 분석 문서 추가/수정 현황
- 실험 진행 현황
- 미팅 요약 (회의록 참조)

### Phase 2: 노션 동기화 (5분)
- Study Archive DB: 새 분석 문서 반영 여부 확인
- 일정 DB: 마감 상태 업데이트
- 팀 페이지: 진행 현황 업데이트 안내

### Phase 3: 다음 주 계획 (3분)
- CLAUDE.md 일정 기준 다음 마감 확인
- 우선순위 작업 목록
- 팀원 역할 분담

### Phase 4: 리포트 출력 (2분)
```markdown
# 주간 작업일지 (YYYY-MM-DD ~ YYYY-MM-DD)

## 이번 주 완료
- ...

## 논문 분석 현황
- 총정리: N/82편
- 시리즈: N편

## 실험 진행
- ...

## 다음 주 계획
- ...
```

## 완료 조건
- 주간 리포트 출력 완료
- 노션 동기화 확인 (또는 안내)
- 다음 주 계획 수립
