# Phase 6: 미팅지침 제작 프롬프트

## 지침 개요

**미팅 = 미팅 전 브리핑 제작 + 미팅 중/후 회의록 + 후속 과제 추적.**
교수님 미팅, 자문위원 미팅, 팀 내부 토의 세 유형을 다룬다.

## IS / IS NOT

**IS:**
- 미팅 전 브리핑 자료 제작 (연구 진행 현황 + 논의 안건 + 질문 목록)
- 미팅용 심층분석 문서 작성 (기존 (09)~(12) 패턴)
- 카카오톡 대화 → 구조화된 회의록 변환
- 회의록 저장: `records/meetings/YYYYMMDD_제목.md`
- 후속 과제 추출 및 담당자 배정
- 후속 과제 → 노션 반영 안내

**IS NOT:**
- 논문 총정리/시리즈 분석 → 논문분석지침 (미팅지침은 논문분석 "결과"를 브리핑에 가공)
- 자문내역서 작성 → 제출물지침
- 주간 종합 보고 → 주간보고지침 (회의록은 주간보고에서 "참조")
- 연구 방향 설계 → 연구설계지침

## 읽어야 할 프로젝트 파일

1. `CLAUDE.md` — 카카오톡 처리 규칙 (글로벌 CLAUDE.md), 현재 단계
2. `records/meetings/` — 기존 회의록 (포맷 참조)
3. `research/analysis/(09)~(12)` — 미팅준비 심층분석 패턴 참조
4. `plans/` — 최신 설계안 (브리핑 소스)

## Phase 구성 가이드

### Phase 0: 미팅 유형 파악 (1분)
- 교수님 미팅 / 자문위원 미팅 / 팀 내부 토의 중 어떤 유형인지 확인
- 미팅 날짜, 참석자 확인

### Phase 1-A: 미팅 전 — 브리핑 제작 (15분)
**교수님/자문위원 미팅 시:**
- 최신 진행 현황 요약 (git log + 문서 현황)
- 논의 안건 목록
- 질문/결정 필요 사항
- 연구 설계안 요약 (plans/ 참조)

**팀 내부 토의 시:**
- 각자 진행 상황
- 결정할 사항 목록

### Phase 1-B: 미팅 전 — 심층분석 (선택) (20분)
- 특정 논문/기술을 미팅에서 발표해야 할 때
- 기존 (09)~(12) 패턴으로 심층분석 md 작성
- research/analysis/에 저장

### Phase 2: 미팅 후 — 회의록 작성 (10분)
**카톡 대화가 입력된 경우:**
- 원문 파싱 → 구조화
- 형식: 날짜, 참석자, 주요 논의, 결정사항, 후속 과제
- 저장: `records/meetings/YYYYMMDD_제목.md`

**구두 회의 메모가 입력된 경우:**
- 같은 형식으로 구조화

### Phase 3: 후속 과제 추출 (3분)
- 회의록에서 ACTION ITEM 추출
- 담당자 + 마감일 배정
- 노션 반영 안내

## 완료 조건
- 브리핑 또는 회의록 파일 저장 완료
- 후속 과제 목록 정리
- records/meetings/에 회의록 존재
