# Phase 7: 발표지침 제작 프롬프트

## 지침 개요

**발표 = 중간/최종 발표 PPT + 전시회 포스터 + 발표 스크립트.** 시각적 프레젠테이션
자료를 제작하고, 발표 준비(스크립트, 리허설)까지 담당한다.

## IS / IS NOT

**IS:**
- 중간발표 PPT 제작 (5월)
- 최종발표 PPT 제작 (6월)
- 전시회 포스터/팜플렛 제작
- 발표 스크립트 (슬라이드별 대본)
- 시간 배분 계획
- 리허설 체크리스트
- templates/samples/ 예시 참조하여 구조 설계

**IS NOT:**
- 중간/최종 "보고서" (서면) → 제출물지침
- 실험 결과 생성 → 실험지침 (발표는 결과를 "시각화해서 슬라이드에 배치")
- 연구 설계/방법론 설명 문서 → 연구설계지침

## 읽어야 할 프로젝트 파일

1. `CLAUDE.md` — 일정 (중간발표 5월, 최종발표 6월, 전시회)
2. `templates/samples/중간발표1/`, `중간발표2/` — 발표 샘플
3. `templates/samples/포스터/`, `팜플렛-크기-확인/` — 포스터 샘플
4. `templates/samples/ppt-크기-수정/` — PPT 크기 참고
5. `plans/` — 최신 연구 설계안 (발표 내용 소스)
6. `research/analysis/` — 시리즈 분석 (발표 내용 소스)

## Phase 구성 가이드

### Phase 0: 발표 유형 + 샘플 확인 (3분)
- 중간 / 최종 / 전시회 중 어떤 발표인지
- templates/samples/에서 해당 샘플 읽기
- 발표 시간 확인 (보통 10~15분)

### Phase 1: 슬라이드 구조 설계 (10분)
**중간발표 기준 (예시):**
1. 표지 (팀명, 주제, 팀원)
2. 연구 배경 + 문제 정의
3. 관련 연구 (Exqutor 포함)
4. 연구 방법론 (Cascade Decomposition)
5. 실험 설계 (데이터셋, 지표, 비교축)
6. 현재까지 결과 (있으면)
7. 향후 계획
8. Q&A

### Phase 2: 슬라이드 내용 작성 (20분)
- 각 슬라이드별 핵심 메시지 1개
- 실험 결과 차트/표 배치 계획
- 다이어그램 필요 부분 식별

### Phase 3: 발표 스크립트 (10분)
- 슬라이드별 대본 (30초~1분 분량)
- 전체 발표 시간 계산
- 강조 포인트 표시

### Phase 4: 포스터/팜플렛 (전시회 시) (15분)
- 포스터 레이아웃 설계
- A0/A1 크기 기준
- 핵심 내용만 압축

### Phase 5: 리허설 체크리스트 (3분)
- [ ] 발표 시간 맞는지
- [ ] 슬라이드 전환 자연스러운지
- [ ] 백업 슬라이드 준비
- [ ] Q&A 예상 질문 + 답변

## 완료 조건
- PPT 구조 + 내용 초안 완성
- 발표 스크립트 작성
- 리허설 체크리스트 준비
