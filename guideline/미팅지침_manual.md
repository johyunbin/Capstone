# 미팅지침 (MANUAL)

> 사람이 직접 수행하거나 Claude에게 개별 요청할 때 참조

## 언제 실행하나?

**미팅 전:**
- 교수님·자문위원 미팅 1~2일 전 → 브리핑 자료 준비
- 팀 내부 토의 전 → 안건 정리

**미팅 후:**
- 카카오톡 대화를 Claude에게 붙여넣기 → 자동으로 회의록 생성
- 구두 회의 메모 정리 요청

**트리거 키워드:** "미팅", "회의", "브리핑", "카톡", "회의록"

---

## 단계별 가이드

### Step 1: 미팅 유형 확인

미팅은 3가지 유형으로 분류된다:

| 유형 | 대상 | 빈도 | 주요 산출물 |
|------|------|------|-------------|
| 교수님 미팅 | 지도교수 | 격주~월 1회 | 브리핑 + 회의록 |
| 자문위원 미팅 | 박성원 자문위원 | 학기 2~3회 | 브리핑 + 자문내역서(→ 제출물지침) |
| 팀 내부 토의 | 4인 팀원 | 주 1회+ | 회의록 |

### Step 2: 미팅 전 — 브리핑 준비

**Claude에게 요청 예시:**
```
교수님 미팅 브리핑 만들어줘 (4/2 미팅)
```

Claude가 자동으로:
1. 최근 git 활동 + 문서 현황 수집
2. 최신 설계안(plans/) 핵심 요약
3. 논의 안건 + 질문 목록 초안 작성
4. `records/meetings/YYYYMMDD_미팅브리핑_대상.md` 저장

**직접 하려면:**
1. plans/ 에서 최신 설계안 열기
2. git log로 최근 진행 확인
3. 안건 3~5개 + 질문 정리
4. records/meetings/ 에 브리핑 파일 저장

### Step 3: 미팅 전 — 심층분석 (선택)

교수님이 특정 논문을 발표하라고 하면:

```
[1] AnalyticDB-V 미팅준비 심층분석 만들어줘
```

기존 패턴 (09)~(12) 참조:
- (09)~(11): 개별 논문 심층분석 (`[번호] 논문명_미팅준비_심층분석.md`)
- (12): 복수 논문 통합 요약 + 미팅 대본

### Step 4: 미팅 후 — 회의록

**카톡 대화 방식 (가장 빈번):**
1. 카톡 대화방에서 대화 전체 복사
2. Claude에게 붙여넣기 — 자동으로 구조화된 회의록 생성
3. 결과 파일: `records/meetings/YYYYMMDD_제목.md`

**구두 회의 방식:**
```
오늘 교수님 미팅 정리:
- DB 환경은 박세은이 교수님께 요청
- 실험 범위는 SIFT1M으로 시작
- 다음 주까지 환경 구축 완료
```

### Step 5: 후속 과제 관리

회의록 작성 후 Claude가 자동으로:
1. ACTION ITEM 추출
2. 담당자 + 마감일 배정
3. 노션 업데이트 안내

**직접 관리:**
- 회의록 하단 `후속 과제` 테이블에서 진행 상태 관리
- 완료된 과제는 노션에서도 체크

## 파일 위치 규칙

| 파일 유형 | 저장 위치 | 파일명 패턴 |
|-----------|-----------|-------------|
| 브리핑 | records/meetings/ | `YYYYMMDD_미팅브리핑_대상.md` |
| 회의록 | records/meetings/ | `YYYYMMDD_제목.md` |
| 심층분석 | research/analysis/ | `(번호) [논문번호] 제목_미팅준비_심층분석.md` |

---

## 자주 하는 실수

| 실수 | 올바른 방법 |
|------|-------------|
| 회의록을 프로젝트 루트에 저장 | 반드시 `records/meetings/`에 저장 |
| 카톡 원문을 그대로 저장 | 구조화된 형식으로 변환 후 저장 |
| 후속 과제 미추출 | 회의록 작성 후 반드시 ACTION ITEM 추출 |
| 자문위원 미팅 후 자문내역서 여기서 작성 | 자문내역서는 제출물지침 담당 |
| 브리핑에 논문 분석을 처음부터 작성 | 기존 분석 결과를 요약·가공만 (신규 분석은 논문분석지침) |

## 관련 지침

| 지침 | 연동 관계 |
|------|-----------|
| 논문분석지침 | 미팅 심층분석의 원천 (미팅지침은 결과를 가공) |
| 제출물지침 | 자문내역서·연구지도확인서는 제출물지침이 담당 |
| 주간보고지침 | 회의록은 주간보고에서 참조 |
| 연구설계지침 | 설계안이 브리핑 소스로 사용 |
| 문서생성지침 | 브리핑/심층분석 PDF 변환 위임 |
