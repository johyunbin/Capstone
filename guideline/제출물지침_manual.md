# 제출물지침 (MANUAL)

> 사람이 직접 수행하거나 Claude에게 개별 요청할 때 참조

## 언제 실행하나?

- **마감 1주일 전** — 양식 확보 + 초안 작성 시작
- **마감 2~3일 전** — 내용 완성 + 검증 + 최종본 저장
- **새 마감이 추가되었을 때** — 캡스톤 사이트 공지 또는 교수님 안내
- **제출 완료 직후** — 일정 상태 업데이트

## 단계별 가이드

### Step 1: 다음 마감 확인

CLAUDE.md의 `핵심 일정` 테이블에서 ⬜ 항목을 확인한다:

```bash
cd ~/Capstone && grep "⬜" CLAUDE.md
```

캡스톤 사이트 일정도 교차 확인:
- https://capstone.cs.yonsei.ac.kr/capstone/?page_id=370

Claude에게 요청할 경우:
> "다음 마감 확인해줘" 또는 "D-day 계산해줘"

### Step 2: 양식 확보

1. **templates/forms/** 확인 — 해당 양식이 있는지

```bash
ls ~/Capstone/templates/forms/
```

2. 없으면 **캡스톤 사이트**에서 다운로드:
   - https://capstone.cs.yonsei.ac.kr/capstone/?page_id=27

3. 양식 형식 확인:
   - `.hwp` → LibreOffice 또는 한글에서 직접 편집
   - `.docx` → Claude에게 작성 요청 가능
   - `.pdf` → 내용 작성 후 PDF 변환 (문서생성지침 참조)

### Step 3: 예시 참조

기존 샘플로 포맷과 분량을 파악한다:

```bash
ls ~/Capstone/templates/samples/
# 2분반_Reward_연구제안서.pdf — 연구제안서 샘플
# 람다람쥐_자문내역서-수정본.pdf — 자문내역서 샘플
```

기존 제출물도 참조:
```bash
ls ~/Capstone/submission/
# 속도는벡터_연구지도확인서1~4.pdf
# 1차 자문내역서(연세대학교 팀_속도는벡터).pdf
# 산학협력프로젝트수행계획서(벡터DB).hwp
```

### Step 4: 내용 작성

Claude에게 요청할 경우:
> "연구제안서 작성해줘" — 자동으로 양식 확인 + 프로젝트 자료 수집 + 작성

직접 작성할 경우:
1. 양식 필수 항목을 먼저 리스트업
2. plans/ 설계안에서 연구 방법론 추출
3. research/ 분석 문서에서 배경 및 선행 연구 추출
4. 팀 정보: CLAUDE.md `팀 운영` 섹션 참조

작성 주의사항:
- 팀명: `속도는벡터` (일관 표기)
- 지도교수: CLAUDE.md 참조
- 한국어 학술 산문 스타일
- 분량은 예시 샘플 수준에 맞춤

### Step 5: 검증 + 저장

- 필수 항목 누락 없는지 체크
- 파일을 submission/ 폴더에 저장:

```bash
ls ~/Capstone/submission/
# 새 파일: 속도는벡터_{제출물명}.{확장자}
```

### Step 6: 일정 업데이트

제출 완료 후 **반드시 3곳을 동시 업데이트**:

1. **CLAUDE.md** — 일정 테이블에서 ⬜ → ✅

2. **메모리** — project_capstone.md 상태 반영

3. **노션** — 캡스톤 일정 DB에 완료 표시

Claude에게 요청할 경우:
> "제출 완료 — 일정 업데이트해줘"

## 자주 하는 실수

| 실수 | 올바른 방법 |
|------|------------|
| hwp 양식을 Claude에게 직접 편집 요청 | hwp는 수동 편집 — Claude는 내용만 제공 |
| 양식 없이 자유형식으로 작성 | 반드시 공식 양식 확인 후 작성 |
| 제출 후 일정 업데이트 누락 | 3곳(CLAUDE.md, 메모리, 노션) 동시 업데이트 |
| 팀명 표기 불일치 | `속도는벡터` 일관 사용 |
| 기존 제출물 스타일 무시 | submission/ 기존 파일 포맷 참조 |
| PDF 변환을 이 지침에서 시도 | PDF 변환 → 문서생성지침 위임 |
| 샘플 확인 안 하고 바로 작성 | templates/samples/ 먼저 확인 |

## 관련 지침

| 지침 | 연동 관계 |
|------|----------|
| 문서생성지침 | 제출물 PDF 변환 위임 |
| 점검지침 | 마감 임박 시 알림, 일정 동기화 검증 |
| 발표지침 | 중간/최종 발표 PPT도 제출물이지만 발표지침이 담당 |
| 미팅지침 | 교수님 미팅 후 연구지도확인서 작성 연계 |
| 연구설계지침 | 설계안/기획안이 제출물 내용의 원본 |
