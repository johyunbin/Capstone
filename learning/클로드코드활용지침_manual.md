# [10] Claude Code 활용 지침 (MANUAL)

> 대상: 모든 프로젝트 | 모드: 수동 실행 (Phase별 승인)
> 목적: Claude Code를 최대 효율로 활용하여 개발 생산성을 극대화
> 출처: 25개 한국어 + 31개 영문 영상 트랜스크립트 전문 분석

## 실행 방법

"활용 수동" 입력 → CLAUDE.md 트리거 → 이 파일 자동 로드 → Phase별 정지+승인

---

## Phase 구성

### Phase 0: 현재 상태 진단 (3분) ⏸ 결과 보고 후 대기

1. CLAUDE.md 품질 평가 (길이/구조/검증루프/규칙/Lazy Loading)
2. 메모리 파일 감사 (인덱스 정합성, 오래된/중복)
3. 스킬/에이전트 목록 확인
4. MCP 서버 점검

→ **결과 보고 후 사용자 승인 대기**

---

### Phase 1: CLAUDE.md 최적화 (5분) ⏸ 변경 계획 승인

1. Progressive Disclosure (Lazy Loading) 적용 계획
2. 검증 루프 강화 방안
3. 봉리 학습 메커니즘 확인
4. 폴더별 CLAUDE.md 분리 제안
5. 불필요 내용 제거 목록

→ **변경 계획 제시 후 사용자 승인 대기**

---

### Phase 2: 컨텍스트 전략 점검 (5분) ⏸ 분석 결과 보고

1. `/context` 토큰 분석
2. MCP 과다 소비 식별 + CLI 대안 검토
3. 세션 전략 검토 (한 세션 = 한 기능)
4. 스킬 메타데이터 최적화 제안
5. 스크립트 오프로드 상태

→ **분석 결과 보고 후 사용자 승인 대기**

---

### Phase 3: 워크플로우 자동화 점검 (5분) ⏸ 제안 승인

1. 반복 패턴 식별 (커맨드/스킬 후보)
2. Hooks 활용도 점검 (포맷/린트/알림)
3. 병렬 개발 환경 점검 (Worktree/Sub-agent)
4. 개선 제안 (스킬 3, 훅 2, 커맨드 3 이내)

→ **제안 목록 제시 후 사용자 선택 대기**

---

### Phase 4: 구현 (10분) ⏸ 각 변경 전 확인

1. CLAUDE.md 수정 (diff 표시 후 승인)
2. 스킬 생성 (내용 확인 후 승인)
3. 훅 설정 (설정값 확인 후 승인)
4. MCP 정리 (제거 대상 확인 후 승인)
5. 커맨드 생성 (내용 확인 후 승인)

→ **각 변경마다 사용자 확인 대기**

---

### Phase 5: 검증 + 기록 (3분) ⏸ 최종 보고

1. CLAUDE.md 로딩 테스트
2. 스킬 트리거 테스트
3. 훅 동작 확인
4. 결과 기록

→ **최종 보고 후 커밋 여부 사용자 결정**
