## 2. Ch.1 연구 주제·목표 및 개요 (~1.5-2p, 박세은)

**scope**: 본 연구가 무엇을 하는 연구인지 — 연구 주제, 목표, 그리고 결과 개요 — 를 한 장에 압축한다. 본 연구는 Exqutor 논문의 재현이 아니라, cardinality 추정 파이프라인에서 sample selection 단계 하나의 개입이 추정 오차에 미치는 영향을 전 데이터셋·전 조작 변인에서 검증한 완전 실험임을 첫 장에서 명확히 한다.

- **§1.1 연구 주제** — 벡터 증강 분석 쿼리(VAQ)의 cardinality 추정에서 sample selection 방식(무작위 Bernoulli sampling → 분포 인지 stratification)의 효과 검증.
- **§1.2 연구 목표** — sample selection 단일 개입 지점을 통제 변인으로 삼아, 다섯 데이터셋·다섯 조작 변인(selectivity·method·구조·scale·strata 수)에 걸쳐 그 효과를 정량 측정. 학부 캡스톤에 맞게 새 알고리즘 제안이 아니라 한 변인을 끝까지 통제하는 검증 연구.
- **§1.3 연구 개요** — 1508건 3-way matched 측정. 핵심 결과 한 문단: 결합 방식(CaseB)이 대조군 대비 89.1%에서 Q-error 개선. 보고서 구성(Ch.2~7) 안내.

narrative source: §0, §1.3 / figure: 연구 개요 다이어그램(신규 필요) / 핵심 수치: 89.1%, 1508건.

## 3. Ch.2 연구의 필요성 (기존 연구 + 필요성) (~2-3p, 이동욱)

**scope**: 본 연구가 왜 필요한지를 기존 연구를 딛고 제시한다. 벡터 데이터베이스의 분석 쿼리에서 cardinality 추정이 왜 중요한지, 기존 방식의 한계가 무엇인지, 그리고 본 연구가 출발점으로 삼은 Exqutor 논문 §V-B Adaptive Sampling을 소개한 뒤, 그 방식의 unstratified Bernoulli sampling에 개선 여지가 있음을 짚는다.

- **§2.1 기존 연구** — 벡터 데이터베이스와 분석 쿼리, cardinality 추정과 쿼리 옵티마이저. 고정 비율 추정의 부정확성(pgvector 33% · DuckDB 100%) → 잘못된 실행 계획. *(중간보고서 §1·§2 배경 재활용)*
- **§2.2 Exqutor 논문 — 측정 방법론의 출발점** — §V-A ECQO(인덱스 있을 때 HNSW range query, 본 연구 대상 아님) + §V-B Adaptive Sampling(인덱스 없을 때 Bernoulli sample N=385 + momentum 식). 식 1-6, hyperparam 7종 verbatim.
- **§2.3 연구의 필요성** — 논문 §V-B의 sample selection은 unstratified Bernoulli random sampling. 데이터 분포를 인지해 계층(stratum)으로 나눠 뽑으면 표본 분산이 줄어 추정이 개선될 여지가 있다 — 이 여지를 전 변인에서 검증할 필요.

narrative source: §2 + 중간보고서 §1·§2 / figure: Exqutor 추정 파이프라인 그림(신규 검토) / 수치: N=385, 고정 비율 33%·100%.

## 4. Ch.3 연구 내용·방법 (~3-4p, 강재현)

**scope**: 본 연구가 실제로 한 일 — 무엇을 바꾸고 무엇을 그대로 두는지, sample selection 방식의 세 단계, 세 측정 mode, 데이터셋 Type 분류, 직접 만든 다중 벡터 데이터셋, 측정 설계 — 를 기술한다.

- **§3.1 framing — 무엇을 바꾸고 무엇을 그대로 두는가** — 개입 지점은 sample selection 단계 하나뿐. §V-A·§V-B AdaptiveState 식 1-6·cardinality 추정 알고리즘은 변경 없음. framing 표(그대로 두는 부분 / 바꾸는 부분).
- **§3.2 sample selection 세 단계 흐름** — 1단계 분포 인지 stratification(offline, K=20 stratum) / 2단계 표본 추출(online, 균등 배분 N/K) / 3단계 결합(online, est_final=(est_b1+est_method)/2.0 산술 평균). minimal augmentation — 식 1-6 위반 없음.
- **§3.3 세 측정 mode** — B1(대조군, 논문 그대로) / CaseA(완전 대체) / CaseB(결합). 3 mode ↔ 3 단계 대응 표. 한 측정이 세 mode를 같은 조건에서 동시 산출(matched).
- **§3.4 데이터셋 Type 분류** — 규모×구조×차원 5 Type. Type 1 소규모 단일 sf=1(272건) / Type 2 중규모 sf=10(224) / Type 3 대규모 sf=100 저~중차원(464) / Type 4a 다중 192~288d(368) / Type 4b 다중 864d↑(180).
- **§3.5 우리가 만든 다중 벡터(concat) 데이터셋** — 측정 공간의 능동적 확장. DEEP+SIFT 224d·DEEP+YFCC 288d·DEEP+WIKI 864d 직접 연결.
- **§3.6 측정 설계** — 1508건 3-way matched(4524 row). 5 조작 변인(데이터셋 9종·sf 1/10/100·sel 0.001/0.01/0.10·K 10/20/30·method 16종). 16 method = 7 paradigm 대표.

## 5. Ch.4 분석·실험 결과 (~4-5p, 조현빈) — 후속 세션

**scope**: 3-way 측정 portfolio가 보여주는 결과를 정량 제시한다. 본 보고서의 핵심 evidence 장.

- **§4.1 대표 수치 — 결합(CaseB) vs 대조군(B1)** — better 89.1%(1344/1508) · 중앙값 Δ% −4.38% · 평균 −3.06%(이상치 2건 제외 −4.09%) · 유의 65.3% · 효과크기 large 72.1%. v12→v13 baseline 정정(B1 1단계 측정으로 더 엄정해져 headline이 92.2%→89.1%로 약화된 경위) 정직 기술.
- **§4.2 negative control — 완전 대체(CaseA)** — CaseA better 35.2%·평균 +12.90%(불안정). CaseB가 CaseA를 96.5% 우월. 개선의 원천이 method 단독이 아니라 결합에 있음을 negative control이 거꾸로 입증.
- **§4.3 method·paradigm 분석** — 강한 13 method / 클러스터링 계열 3 제외(gmm·minibatch_partial·faiss_ivf). 상위 chao_weighted −6.22%·hilbert_real −5.91%·skilling_hilbert −5.75%. paradigm 중앙값 P3 −6.22%~P1 −1.40%.
- **§4.4 selectivity 효과** — better% 단조 증가: sel 0.001/0.01/0.10 = 83.3/87.6/97.5%.
