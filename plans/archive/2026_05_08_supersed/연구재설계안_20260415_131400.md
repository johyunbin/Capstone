# 연구 재설계안 — "쏠림 → 성능 저하 → 샘플링 개선"

**작성일**: 2026-04-15 13:12 KST
**목적**: 교수님의 핵심 프레이밍 "데이터가 쏠려있을 때 Exqutor의 uniform sampling이 나빠지고, 개선된 sampling으로 이를 해결" 에 정확히 정합하는 연구/실험 재설계
**기반**: 확인서 1~6, 카톡 회의록, 4/14~15 실험 데이터

---

## I. 교수님 프레이밍과 우리 연구의 연결

### 교수님의 핵심 질문

> "데이터가 **일반적**(정규분포 같은 균일한 형태)일 때와 **한쪽으로 쏠려있는** 경우 사이의 성능 차이.
> Exqutor는 쏠린 상황에서도 기존과 **똑같은** uniform sampling을 사용하니, 그런 케이스에서 **성능이 떨어지고**,
> 따라서 **샘플링 개선**을 통해서 이를 해결하자."

### 3단계 실증 구조

```
Step 1: 데이터가 "쏠려있다"는 것을 보여준다
Step 2: 쏠려있을 때 uniform sampling이 실제로 더 나빠지는 것을 보여준다
Step 3: 개선된 sampling이 이를 해결하는 것을 보여준다
```

## II. RQ 재정의

### RQ1 — 벡터 데이터의 공간 밀도 비균일성과 Exqutor uniform sampling의 편향

**질문**: 벡터 데이터의 공간 밀도가 비균일(skewed)할 때, Exqutor의 uniform sampling은 카디널리티 추정에서 편향이 발생하는가?

**하위 질문**:
- (a) 실제 벡터 데이터(DEEP 96d)의 공간 밀도가 비균일한가?
- (b) 이 비균일성이 query의 selectivity에 따라 uniform sampling의 Q-error에 어떤 영향을 미치는가?
- (c) Exqutor의 설계가 이 비균일성을 고려하지 않는 구조적 이유는 무엇인가?

### RQ2 — Distribution-Aware stratified sampling에 의한 편향 교정

**질문**: 데이터의 공간 구조를 사전 학습(k-means partition)한 층화 샘플링이, uniform sampling의 밀도 편향을 교정하여 카디널리티 추정 정확도를 유의미하게 개선하는가?

**핵심 비교**: "쏠린 데이터 + uniform" vs "쏠린 데이터 + stratified" → 교수님의 "성능 저하 → 개선"

### RQ3 — Distribution-Agnostic 경량 대안

**질문**: 사전 학습 없이도 (KDE-pilot, LSH-bucket) 유사한 편향 교정이 가능한가?

## III. 핵심 실험 설계 — "쏠림이 원인임을 증명"

### 실험 A: 데이터 밀도 비균일성 정량화

**목적**: Step 1 — "데이터가 쏠려있다"

**방법**:
1. DEEP 96d 1M에 KM20 적용 → cluster size 분포 측정
2. Gini 계수, 엔트로피, size ratio (max/min) 로 비균일도 정량화
3. 같은 분석을 SIFT 128d에도 적용 → 다른 데이터에서도 비균일성 존재 확인

**기존 결과 활용**: KM20 cluster sizes: min=26,343, max=81,233, ratio=3.1× → 이미 확인됨

### 실험 B: "쏠림 → uniform 성능 저하" 직접 증명 (핵심 실험)

**목적**: Step 2 — 쏠린 데이터에서 uniform이 더 나쁘다

**방법 — Control Experiment (가장 직접적인 증거)**:

두 가지 partition을 비교한다:

| 조건 | partition 방식 | 의미 |
|------|---------------|------|
| **KM20 (의미 있는 partition)** | k-means로 공간 구조 반영 | "쏠린 데이터" 인지 상태 |
| **RANDOM20 (무작위 partition)** | 20개 라벨 랜덤 배정 | "균일 데이터" 시뮬레이션 |

같은 stratified sampling 코드를 KM20과 RANDOM20 위에서 각각 실행:
- KM20 stratified: 공간 구조 반영 → **개선 있음** (기존 +1.64%)
- RANDOM20 stratified: 공간 구조 무시 → **개선 없음 (또는 미미)**

**이 차이가 의미하는 것**: 개선의 원인이 "데이터의 공간적 쏠림 (비균일 밀도)" 임을 직접 증명.
→ 쏠림이 없는 (random partition) 상태에서는 stratified도 도움이 안 됨
→ 쏠림이 있는 (KM20 partition) 상태에서만 stratified가 도움이 됨
→ **"쏠림 → 성능 저하 → 개선"** 인과 관계 확립

**구현**: 
- 1M subset에 `random_stratum_id` 컬럼 추가: `UPDATE ... SET random_stratum_id = floor(random() * 20)`
- 기존 stratified sampling 코드에서 `stratum_id` → `random_stratum_id`로 교체하여 재측정
- 같은 100 query × 6 selectivity × 5 seed

### 실험 C: selectivity별 "쏠림 강도" 변화 분석

**목적**: 왜 특정 selectivity에서 더 개선되는지 설명

**방법**:
- 각 selectivity (0.001 ~ 0.500)에서 true matches의 cluster 집중도 (HHI) 계산
- selectivity가 낮을수록 (matches가 적을수록) 집중도가 높아지는지 확인
- 집중도와 stratified 개선 폭의 관계 분석

**예상**: 
```
s=0.500: HHI ≈ 0.067 (거의 균일) → 개선 작음 → allocation 효과만
s=0.050: HHI ↑ → 개선 큼 (+5.62%)
s=0.010: HHI ↑↑ → 개선 가능하나 cnt-clamp 영향
s=0.001: cnt-clamp fallback → 개선 불가
```

### 실험 D: Pivot A — block sampling bias 제거 (기존 유지)

**목적**: uniform sampling 내에서도 SYSTEM (block) vs BERNOULLI (row) 차이
- SYSTEM: block 단위로 sampling → 같은 block의 행이 함께 선택 → spatial bias 추가
- BERNOULLI: 행 단위 독립 sampling → spatial bias 없음
- Pivot A의 개선 (+3.8~9.6%)도 "쏠림 → 성능 저하"의 한 변형

### 실험 E: 외적 타당성 — 다른 dataset

**목적**: DEEP 96d만의 특성이 아님을 확인

**방법**:
- 8M DEEP: D_target 재계산 완료 (actual_sel=0.5001), 이제 측정만
- SIFT 128d: 같은 방식으로 D_target 재계산 + 측정
- 가능하면 Wiki 768d (최종발표)

## V. 핵심 신규 실험 (RANDOM20 control)

**이것이 연구의 가장 강력한 증거가 될 수 있음.**

```
KM20 stratified vs BERN:  +1.64% (p=4.01e-05) → 개선 있음
RANDOM20 stratified vs BERN:  ≈ 0% (예상) → 개선 없음
                                    ↓
          차이의 원인 = KM20이 공간 구조(쏠림)를 반영하기 때문
```

**구현 난이도**: 낮음 (SQL 1줄 + 기존 코드 재사용)
**소요 시간**: 약 1시간 (1M subset 100 query × 6 sel × 2 mode)
**Impact**: "쏠림이 원인이다"의 직접적 인과 증거
