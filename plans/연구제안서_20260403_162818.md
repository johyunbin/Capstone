## 1. Background

### 1.1. Vector-Augmented Analytical Queries (VAQ)

벡터 증강 분석 쿼리(Vector-Augmented Analytical Query, VAQ)는 전통적인 관계형 분석 쿼리에 벡터 유사도 검색을 결합한 새로운 유형의 쿼리이다. RAG(Retrieval-Augmented Generation) 파이프라인, 추천 시스템, 멀티모달 검색 등 다양한 응용에서 "벡터 유사도 조건 + 관계형 필터 + 집계/조인"이 결합된 쿼리가 광범위하게 활용되고 있다.

예를 들어, 전자상거래에서 "쿼리 벡터와 유사한 상품 중 특정 가격대와 카테고리에 해당하는 것의 주문 건수와 평균 금액을 집계"하는 쿼리는 다음과 같다:

```sql
SELECT p.category, COUNT(*), AVG(o.amount)
FROM products p JOIN orders o ON p.id = o.product_id
WHERE p.embedding <-> :query < :D
  AND p.category = 'electronics'
  AND p.price BETWEEN 100 AND 500
GROUP BY p.category;
```

이러한 VAQ에서 핵심 문제는 **벡터 유사도 조건의 카디널리티(결과 건수)를 쿼리 옵티마이저가 정확히 추정하지 못한다**는 것이다. pgvector는 벡터 조건의 선택도를 33.3%로 고정 추정하고, VBASE는 50%, DuckDB는 100%로 추정한다 [1]. 실제 선택도는 0.001%에서 90%까지 극도로 다양하므로, 옵티마이저가 잘못된 실행 계획(예: 불필요한 Sequential Scan, 잘못된 조인 순서)을 선택하여 성능이 크게 저하된다.

### 1.2. Exqutor: Cardinality Estimation for VAQ

Exqutor [1]는 이 카디널리티 오추정 문제를 두 가지 방법으로 해결한다.

**ECQO (Exact Cardinality Query Optimization)**: HNSW 인덱스가 존재할 때, range query를 인덱스 위에서 실행하여 1~2ms 안에 정확한 카디널리티를 획득한다. 이 정확한 카디널리티를 옵티마이저에 전달하면 올바른 실행 계획을 선택하게 된다.

**Adaptive Sampling**: 인덱스가 없을 때, 모멘텀 기반 동적 샘플링으로 카디널리티를 근사한다. 초기 소규모 샘플에서 시작해, 추정값의 변화가 수렴할 때까지 샘플 크기를 점진적으로 늘리는 방식이다. 이 접근은 Lipton et al. [2]의 적응적 샘플링 이론에 기반한다.

그 결과 pgvector에서 최대 1,000배, VBASE에서 10,000배, DuckDB에서 1.5~37배의 성능 향상을 달성했다. 그러나 Exqutor의 Adaptive Sampling에는 다음과 같은 미검증 영역이 존재한다:

### 1.3. Sampling Theory for Selectivity Estimation

샘플링 기반 선택도 추정의 이론적 기초는 Haas et al. [3]이 정립했다. 핵심 공식 `n = z² × σ(1-σ) / ε²`에서 선택도 σ를 모르는 상황이 실무의 근본 문제이며, Lipton et al. [2]는 초기 샘플로 σ를 대략 추정한 후 필요한 추가 샘플 크기를 결정하는 적응적 방법론을 제시했다.

그러나 이 이론들은 **무작위 샘플이 전체 데이터를 대표한다는 암묵적 가정** 위에 서있다. 데이터의 거리 분포가 균일하거나 대칭이면 이 가정이 성립하지만, 분포가 치우쳐 있으면(skewed) 무작위 샘플이 밀도가 높은 영역에 편중되어 tail 영역의 카디널리티를 잘못 추정하게 된다. 통계학에서 이 문제를 해결하기 위해 **층화 샘플링(Stratified Sampling)**이 개발되었으며, Neyman allocation [4]은 구간 내 분산에 비례하여 샘플을 배분함으로써 전체 추정의 분산을 최소화한다.

## 2. Problem Description

본 연구가 다루는 문제는 다음과 같다.

Exqutor의 Adaptive Sampling은 전체 데이터에서 무작위로 샘플을 추출한 뒤, 벡터 거리 조건을 만족하는 비율로 카디널리티를 추정한다. 이 방식은 거리 분포가 고른(uniform 또는 symmetric) 데이터에서는 효과적이다. 그러나 **벡터 거리 분포가 skewed인 환경** — 예를 들어 대다수의 데이터가 query 벡터와 먼 거리에 몰려있고 소수만 가까운 경우(left-skewed), 또는 그 반대(right-skewed) — 에서는 무작위 샘플이 밀도가 높은 영역에 편중된다.

이 편중은 카디널리티 추정의 정확도를 저하시킨다:

- **Left-skewed 분포** (대다수가 멀고, 소수만 가까움): 엄격한 조건(`dist < D`, D가 작은 값)의 카디널리티를 과소추정. 가까운 벡터가 샘플에 충분히 포함되지 않아 "조건 만족 비율"이 실제보다 낮게 측정된다.
- **Right-skewed 분포** (대다수가 가깝고, 소수만 멂): 느슨한 조건(`dist < D`, D가 큰 값)에서는 정확하지만, 먼 영역의 밀도를 과소추정하여 tail 정보가 누락된다.

실제 벡터 데이터셋에서 query에 따라 거리 분포의 skewness가 크게 달라지며, 이 변동성이 Exqutor의 adaptive sampling 정확도에 직접적으로 영향을 미치는지는 실험적으로 검증되지 않았다. 본 연구는 이 gap을 실증하고, **분포 특성을 고려한 층화 샘플링(Stratified Sampling)** 으로 skewed 환경에서의 카디널리티 추정 정확도를 개선하는 방법을 제안한다.

## 3. Research Plan

본 연구는 세 개의 연구 질문(RQ)에 대응하는 3단계 실험으로 구성된다. 실험 데이터셋은 석사 연구원이 제공하는 Exqutor 실험 데이터(skewed 거리 분포 포함)를 사용하며, 연구실 서버에서 수행한다.

### RQ1: Exqutor의 adaptive sampling은 거리 분포의 skewness에 따라 추정 정확도가 얼마나 달라지는가?

**1단계 — Motivation 실험**

Exqutor의 adaptive sampling이 skewed 분포에서 실제로 정확도가 떨어지는지를 정량적으로 확인한다.

- **거리 분포 프로파일링**: 데이터셋에서 query vector를 50~100개 무작위 추출. 각 query에 대해 전체 데이터와의 거리 분포를 계산하고, Fisher's skewness coefficient(γ)를 측정하여 query들을 skewness 구간(|γ| < 0.5, 0.5~1, 1~2, 2+)으로 그룹핑한다.
- **카디널리티 추정 비교**: 동일 query에 대해 Exqutor 방식(무작위 adaptive sampling)으로 카디널리티를 추정하고, 실제 카디널리티(full scan)와 비교하여 Q-error [5]를 산출한다. 선택도 구간(0.1%, 1%, 5%, 10%, 30%, 50%)별로 분리 측정한다.
- **핵심 산출물**: (1) Skewness vs Q-error 산점도 — skew와 추정 오차의 상관 시각화, (2) 분포 유형별 Q-error 박스플롯, (3) Skewness × 선택도 Q-error 히트맵

**판단 기준**: |γ| > 1인 query 그룹의 평균 Q-error가 |γ| < 0.5인 그룹 대비 2배 이상이면 RQ2, RQ3 진행. 차이가 미미하면 skew 정의를 재조정하거나, 특정 선택도 구간에 집중하여 취약 구간을 탐색한다.

### RQ2: 거리 분포를 알고 있을 때, 층화 샘플링이 무작위 adaptive sampling보다 카디널리티 추정 정확도를 얼마나 개선하는가?

**2단계 — Distribution-Aware Stratified Sampling**

분포를 안다는 가정 하에, 최적 층화 전략으로 얼마나 개선 가능한지 이론적 상한(upper bound)을 측정한다.

거리 공간을 K개 구간(strata)으로 나누고, 각 구간에서 독립적으로 샘플링하여 구간별 카디널리티를 추정한 뒤 합산한다. 세 가지 strata 설정 전략을 비교한다:

K(strata 수)를 3, 5, 10, 20으로 변화시키며 최적 K를 탐색한다. 비교 baseline은 Exqutor의 무작위 adaptive sampling(Random)이며, Oracle(full scan 기반 정확한 카디널리티)을 상한으로 설정한다.

측정 지표: (1) Q-error(주 지표), (2) 동일 정확도 달성에 필요한 최소 샘플 수(샘플 효율), (3) 선택도 구간별 개선 폭.

### RQ3: 거리 분포를 모르는 상황에서, pilot sample 기반 자동 층화가 무작위 adaptive sampling보다 정확한가?

**3단계 — Distribution-Agnostic KDE-Pilot Stratification**

현실에서는 거리 분포를 사전에 알 수 없으므로, 소규모 pilot sample로 분포를 추정한 뒤 층화하는 방법을 제안한다.

알고리즘은 다음과 같다: (1) 전체의 1~5%를 pilot으로 무작위 추출, (2) pilot에서 거리값을 계산하여 KDE(Kernel Density Estimation)로 분포를 추정, (3) 추정된 분포 기반으로 strata 경계를 자동 결정, (4) 나머지 샘플을 strata별로 할당하여 추출, (5) 카디널리티 추정.

pilot 비율(0.5%, 1%, 2%, 5%)에 따른 sensitivity 분석을 수행하여 오버헤드와 정확도의 트레이드오프를 확인한다. 핵심 비교는 (1) KDE-Pilot vs Random(Exqutor) — agnostic 환경에서의 개선 폭, (2) KDE-Pilot vs Stratified-Neyman(2단계 Oracle 분포) — 이론적 상한 대비 도달률이다. pilot 오버헤드를 포함한 총 샘플링 비용(pilot + main 샘플 수)도 분석하여 비용-정확도 효율 곡선을 제시한다.

## 4. Expected Contribution

본 연구의 기여는 다음과 같다.

첫째(RQ1), **Exqutor adaptive sampling의 skew 취약점을 실증**한다. 벡터 거리 분포의 skewness와 카디널리티 추정 Q-error 간의 정량적 관계를 최초로 분석한다. 이는 기존 연구에서 미검증된 영역이며, VAQ 옵티마이저 설계 시 분포 특성을 고려해야 함을 보여주는 근거 데이터를 제공한다.

둘째(RQ2), **Distribution-aware stratified sampling의 효과를 입증**한다. Skewed 환경에서 세 가지 층화 전략(equal-width, equal-frequency, Neyman allocation)의 개선 폭을 비교하여 최적 전략을 제시한다. 이는 "분포를 알 때 얼마나 좋아질 수 있는가"라는 이론적 상한을 확립한다.

셋째(RQ3), **Distribution-agnostic KDE-pilot 기법을 제안하고 검증**한다. 사전 정보 없이도 소규모 pilot sample로 분포를 추정하여 skew-robust한 카디널리티 추정이 가능함을 실험적으로 보인다. pilot 오버헤드를 포함한 비용-정확도 트레이드오프 분석을 통해 실무 적용 가능성을 평가한다.
