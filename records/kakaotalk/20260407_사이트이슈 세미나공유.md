### 피싱 페이지 분석 (조현빈 제공)

공격 방식은 최근 유행하는 **ClickFix / Fake CAPTCHA** 소셜 엔지니어링 수법. 정상 Cloudflare 인증은 체크박스 클릭만으로 끝나지만, 해당 페이지는 사용자에게 다음을 유도함:

1. Win+R로 실행 창 열기
2. "Verification Code"로 위장한 PowerShell/cmd 명령어 붙여넣기 (Ctrl+V)
3. 실행 → 악성코드 다운로드 및 실행

**핵심 판단 기준**: Cloudflare 인증 과정에서 명령어 실행을 요구하는 것은 100% 악성. 실행하지 않았다면 페이지만 닫으면 되고, 실행했다면 즉시 네트워크 차단 + 바이러스 검사 필요.

Real-time systems와 machine learning의 교차 영역 탐구. 두 방향:

1. **RT for ML**: CPU/GPU 스케줄링, split-and-merge execution 등 real-time 기법이 safety-critical 환경에서 예측 가능하고 정확한 딥러닝 추론을 가능하게 하는 방법
2. **ML for RT**: 우선순위 할당, task inference 등에서 데이터 기반 방법이 휴리스틱을 능가하는 사례

양방향의 상호 이익과 timing-aware 신경망 설계, 확장 가능한 스케줄링 프레임워크 등 열린 과제 제시.
