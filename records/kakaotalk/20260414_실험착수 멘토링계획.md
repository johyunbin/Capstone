| # | 블로커 | 원인 | 해결 |
|---|--------|------|------|
| 1 | `FATAL: data directory has wrong ownership` | `vanilla_sf100` 소유자 `chaerim`, 실행자 `capstone2026` 불일치 | 임채림 조교에게 메일 요청 → `chown -R capstone2026:hddgroup` + `chmod -R u=rwX,g=rX,o=` 즉시 수행받음 |

| 3 | `vector.so: undefined symbol: set_baserel_rows_estimate_hook` | `apply_patch.sh`의 `dir=$(dirname "$0")`가 상대 경로 `.`로 시작 → 두 번째 `cd "$dir"`에서 원위치 복귀 실패 → **postgres 패치 누락** | 수동으로 `pgvector_Postgres.patch` 적용(`costsize.c`, `cost.h` 2파일) → incremental make 3.5초 + install 5.3초 → 심볼 export 확인 |

**실측 검증**

```
EXPLAIN ANALYZE
SELECT c_custkey FROM customer_sift_10
ORDER BY c_embedding <-> (SELECT c_embedding FROM customer_sift_10 WHERE c_custkey=1)
LIMIT 10;
→ Index Scan using customer_sift_hnsw (actual 5073ms, cold cache)

-- Hybrid VAQ
EXPLAIN ANALYZE
SELECT c_custkey, c_name FROM customer_sift_10
WHERE c_nationkey = 5
ORDER BY c_embedding <-> (...)
LIMIT 10;
→ Index Scan + Filter (actual 205ms, warm)
  추정 rows=59254 vs 실제 rows=0 — 카디널리티 과대추정 이미 관찰됨 (우리 연구 대상)
```
