## 주요 논의

### 1. 실험 DB 환경

- SAP 연구실 DB는 사용 불가 (기존 프로젝트 소유)
- 박세은: 교수님이 테스트용 PostgreSQL+pgvector 환경 보유 → 요청하면 받을 수 있을 것 같음, 확인 예정
- 강재현: 연구실 서버 없으면 벡터 데이터 + RDB 스키마 직접 구축 필요 (상당한 공수)

### 2. 연구 방향 확정

**방향:** 기존 Exqutor 연구를 확장하는 방식으로 진행 (신규 주제 서칭 종료)

### 3. 핵심 아이디어 (강재현)

**배경:** 관계형 필터링 + 벡터 검색이 혼합된 VAQ에서 플래닝이 오래 걸리는 이유 → 벡터 검색 카디널리티를 모르기 때문

**아이디어:** 벡터 유사도 조건을 두 단계로 분리

- 1단계: 유사도 임계값 낮게 → 카디널리티 높음 (넓게 검색)
- 2단계: 유사도 임계값 높게 → 카디널리티 낮음 (1단계 결과에서 정밀 검색)
- 1단계 결과에 인덱스를 미리 잡아두면 2단계 검색 가속 가능
- → 플래닝 시간 단축 + 검색 2회 비용 일부 상쇄 가능성

**강재현 메모:** "직관이라 더 찾아봐야 함 — 효용성 검토하려면 먼저 플래닝 메커니즘 조사 필요"
