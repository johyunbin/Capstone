## 3. 치명 4건 — 상세 + per-slide 수정 지침

### F1 · slide 20 "방법별 정확도" — "14가지/2제외" → "13가지/3제외"
- **현재 deck**: 제목 "16가지 방법 중 **14가지**가 기존 방식을 안정적으로 이긴다", 거대 수치 "**14/16**", 좌측 설명 "클러스터링 계열 **둘만** 약해 권장에서 제외". 막대 차트 16개 중 가우시안 혼합 모델(+2.7)만 회색(제외), 미니배치 K-means(−3.6)·IVF 클러스터링(−2.7)은 우월 색.
- **정본**: narrative §6.4 — "16 method 중 클러스터링 계열 **3개**(가우시안 혼합 모델·미니배치 K-means·IVF 클러스터링)를 제외한 **13개**가 견고하게 우월". 환각 회피 룰이 "14강/2제외"를 명시적으로 금지.
- **수정**: 제목·거대 수치를 "**13가지**"·"**13/16**"으로. 좌측 설명을 "클러스터링 계열 **3가지**(가우시안 혼합 모델·미니배치 K-means·IVF 클러스터링)는 측정에서 불안정해 권장 제외". 막대 차트에서 미니배치 K-means·IVF 클러스터링 막대를 가우시안 혼합 모델과 같은 **제외 색**으로. 범례 "권장 13 / 제외 3" 추가. (막대 16개의 수치 −6.2…+2.7 자체는 정확 — 그대로 둔다.)
- ※ deck 발표 멘트는 이미 "권장에서 제외한 것은 세 가지"라 화면-멘트가 충돌하던 상태였다.

### F2 · slide 23 "계층 수" — K granularity 6-cell 구수치 → 8-cell 정본
- **현재 deck**: "10개 계층 83.3% / 20개 계층 89.6% / 30개 계층 85.4%".
- **정본**: v13_summary §5 · narrative §8.3 — 작업 3에서 K granularity가 6-cell → **8-cell**로 전환됨. 현행 값은 "10개 **83.6%** / 20개 **89.8%** / 30개 **85.9%**" (K=20 최강). 구 6-cell 값 83.3/89.6/85.4는 폐기.
- **원인**: v16 prompt가 5/18 18~19시 작성 → 작업 3(19:34~20:27)의 8-cell 전환 이전. prompt가 구수치를 보유했고 deck이 충실히 재현. **prompt·deck 양쪽이 stale.**
- **수정**: deck "83.6 / 89.8 / 85.9"로 교체. (prompt는 본 작업에서 이미 수정됨 — §7.) 본문 "20개가 균형점·논문 기본값과 일치"는 유지(불변).

### F3 · slide 7 "측정 설계" — 데이터셋 "8종·96~864" → "9종·96~1024"
- **현재 deck**: 측정 설계 5축 표의 데이터셋 행 "8종 · 96~864 차원".
- **정본**: prompt slide 7이 "9종 (96~1024차원)" 명시. narrative §6.0 "데이터셋 아홉 종", §4.6 Type 4b "864~1024차원". 환각 회피 룰이 "8종/864차원 상한"을 금지.
- **수정**: 데이터셋 행을 "**9종 · 96~1024차원**"으로.

### F4 · slide 8 "측정한 데이터셋" — DEEP+CC3M(1024) 누락
- **현재 deck**: 다중 벡터 데이터셋이 DEEP+SIFT(224)·DEEP+YFCC(288)·DEEP+WIKI(864) **3종만**. 캡션 "96차원부터 **864차원**까지".
- **정본**: prompt slide 8이 다중 4종 — 위 3종 + **DEEP+CC3M(1024)** 명시. narrative §4.6 Type 4b가 DEEP+CC3M 1024차원 cell 포함.
- **수정**: 다중 벡터에 4번째 막대 **DEEP+CC3M(1024)** 추가. 캡션을 "96차원부터 **1024차원**까지"로. (단일 5종 DEEP 96·SIFT 128·YFCC 192·SimSearchNet++ 256·WIKI 768은 정확 — 그대로.)

### F5 · slide 4 "연구가 걸어온 길" — "분포를 알 때/모를 때" 이분법 [중]
- **현재 deck**: STAGE 2 박스 "분포를 알 때 / 최적 방식 한 가지", STAGE 3 박스 "분포를 모를 때 / 16가지 방법·세 방식 비교", 하단 라벨 "한 방법 · 분포 알 때".
- **정본**: narrative 부록 A-5 — "'분포를 안다/모른다' 이분법은 부정확하므로 폐기". prompt slide 4는 이 이분법 없이 "한 가지 분포 인지 방법으로 개선 확인" / "16가지 방법·세 방식·전 조건 검증"으로 명시했고, claude.ai/design이 요약하며 이분법을 재도입.
- **수정**: STAGE 2 → "한 가지 분포 인지 방법으로 개선 확인", STAGE 3 → "16가지 방법·세 방식·전 조건 검증". 하단 라벨에서 "분포 알 때/모를 때" 제거 — 단계는 측정 범위로만.

### F6 · slide 19 "완전 대체는 불안정" — 96.5% 보조 수치 누락 [중]
- **현재 deck**: 완전 대체 35.2% / 결합 89.1% 두 막대는 정확하나, prompt가 지정한 "결합 vs 완전 대체 직접 비교 — 결합이 96.5%에서 우월" 보조 수치 한 줄이 없음.
- **정본**: narrative §6.2 — "CaseB가 완전 대체를 96.5%에서 이긴다". prompt slide 19가 이 한 줄을 명시.
- **수정**: 두 막대 아래 작은 보조 수치 한 줄 "결합 vs 완전 대체 직접 비교 — 결합이 96.5%에서 우월" 추가.

### F7 · slide 5 "세 단계" — STEP 3 결합 도식의 영문 수식 [중]
- **현재 deck**: STEP 3 결합의 navy "평균" 박스 안에 "(estimate₁ + estimate₂) ÷ 2" 영문 수식이 들어가 박스와 겹쳐 글자가 가려짐.
- **정본**: prompt slide 5는 "두 추정값이 하나로 합쳐지는 그림"만 지정 — 수식 없음. prompt 규칙 4·5가 수식·코드 용어를 발표 슬라이드에서 금지.
- **수정**: 영문 수식 제거. "논문 추정 + 우리 추정 → 평균"을 자연어 라벨·도식으로만. 라벨이 박스·도형과 겹치지 않게.

### F8 · slide 10 "16가지 방법, 7가지 접근" — 8번째 카드 [경]
- **현재 deck**: 7개 접근 카드 + 8번째 navy "16 / 총 측정 방법" 카드 = 8칸.
