## 1. 본 연구의 핵심 질문 한 줄

**인덱스가 없는 상황에서 Exqutor 논문의 적응적 표본 추출(§V-B) 의 "표본 선택 단계" 를 무작위 베르누이에서 분포 인지 층화로 바꾸면, 카디널리티 추정이 더 정확해지는가?**

## 3. Exqutor 베이스라인 (B1) 측정 결과

### 3.1 카디널리티 추정 정확도

- 1,508 측정 × 베이스라인 mode 의 Q-error trim mean = **1.4582**
- median 1.5616 · std 0.1925 · range [1.15, 1.66]

(Q-error 정의: 식 2 verbatim — q = max(C_est/C_true, C_true/C_est), 1.0 이 완벽, 작을수록 정확)

### 3.2 실제 엔진 응답 시간 (DEEP sf=10, 12 셀 × 15 회 반복)

| 조건 | 응답 시간 (median, 12 셀 평균) | 가속 배수 |
|---|--:|--:|
| 기본 pgvector (카디널리티 미주입) | **5,677 ms** | 1.0× (기준) |
| **Exqutor 베이스라인 inject** | **978 ms** | **5.77×** |
| 정답 카디널리티 inject (oracle) | 992 ms | 5.65× |

본 연구의 12 셀 측정에서 베이스라인이 기본 pgvector 대비 **평균 5.77 배 가속** 을 달성한다 (보고서 §5.2 trim mean 기준 12 셀 oracle 가속 평균 5.67×, 범위 2.93×~7.40×).

### 3.3 정답 plan 회복

- 12 셀 중 베이스라인이 정답 plan 으로 회복한 수: **7/12 = 58.3%** (셀 단위)
- qid 별: qid 0 = 0/4 · qid 1 = 4/4 · qid 2 = 3/4
- 회복 실패 cell 은 sel=0.001 의 결정 경계 cell (베르누이 적중 0 회 시 측정 harness 가 MIN_INJECT=1.0 으로 강제 보정, 클램프된 1.0 이 planner 결정 경계 가까이 떨어져 plan 이 갈림 — 이는 §V-B 베르누이가 극단 selectivity 에서 마주치는 실패 모드의 정직한 노출이다).

### 3.4 통계 검정 — 베이스라인 가속의 견고성

- paired Wilcoxon 부호 순위 검정 + Holm-Bonferroni 보정 (anchor=기본 pgvector, 180 비교): **180/180 = 100% 유의** + 100% large effect (Hedges' g ≥ 0.8)
- 베이스라인 가속은 통계적으로 압도적·견고하게 확정된다.

## 4. 우리가 시도한 16 방법 중 가장 정확한 method

### 4.1 정확도 ranking 상위 5 (paired vs 베이스라인 기준)

| Method (정정 후 명칭) | 알고리즘 한 줄 설명 | paired better% | median Δ% (개선 폭) |
|---|---|--:|--:|
| **chao_weighted** | Chao 1982 가중 우선순위 sampling: 각 벡터에 norm·PCA·iDistance 가중치 w 부여 후 priority u^(1/w) 의 quantile 분할 | **100.0%** | **−6.22%** |
| **pca2d_hilbert_xy2d** | PCA 로 2 차원 환원 후 Wikipedia 표준 xy2d Hilbert curve algorithm 으로 1D 순서 분할 | 98.9% | −5.91% |
| **pca4_skilling_hilbert_approx** | PCA 로 4 차원 환원 후 Skilling 2004 알고리즘 근사 (4-axis × 8-bit Hilbert key, exact swap 일부 생략) | 100.0% | −5.75% |
| **ica_fastica** | Hyvärinen 1999 FastICA 의 독립 성분 분석 1D 투영 후 quantile 분할 | 100.0% | −5.69% |
| **pca1d** | Pearson 1901 PCA 의 첫 주성분 1D 투영 후 quantile 분할 | 97.9% | −5.55% |

### ★ 본 연구의 최저 Q-error method = `chao_weighted` (Chao 1982)

알고리즘 본질: 각 벡터에 가중치 w_i (L2 norm·PCA 1D 절대값·KMeans iDistance 중 하나) 를 부여하고, 균등 무작위값 u_i 의 1/w_i 제곱을 priority 로 두어 quantile 로 K=20 stratum 에 분할한다 (Chao 1982 의 "weighted reservoir" 기법, 큰 가중치를 가진 벡터가 우선순위 상위에 놓이는 핵심 trick). 본 method 는 paradigm P3 Streaming (스트리밍) 에 속하며, PCA 환원 없이 원본 차원에서 직접 동작하므로 다른 상위 method (Hilbert·Skilling) 와 달리 학술 정직성 측면에서 명칭과 실제 알고리즘이 완전 일치한다.

### 4.2 chao_weighted 의 정확도 절대값

- 베이스라인 평균 Q-error = 1.4582 → chao_weighted 결합 mode 평균 Q-error ≈ **1.37** (paired median Δ% −6.22% 기준)
- 분포 파악 1 회 cost (fit_time) = **11.03 초** (다른 상위 method 중 sparse_rp 가 가장 빠른 2.91 초, pca4_skilling_hilbert_approx 가 가장 느린 53.92 초)
- **Pareto frontier 1순위** — 정확도와 분포 파악 속도의 균형이 가장 좋다.

## 5. chao_weighted 의 실제 엔진 응답 시간·plan 회복

### 5.1 응답 시간

- Exqutor 베이스라인 inject 와 paired 비교: paired Δ% **mean +0.30%**, median **+0.11%** (4-way 확장 측정 5/24, 12 셀 × 18 variant × 15 회 = 3,240 측정)
- 통계적으로 **사실상 동등** (paired Wilcoxon p_holm < 0.05 = **7.7%** 만 유의, **86.9% small effect**, 17 inject variant 모두 |Δ%| ≤ 1.12% 안에 모임)
- 즉 **추정 정확도의 6.22% 향상이 엔진 응답 시간 추가 가속으로 직결되지 않는다**.

### 5.2 plan 회복 robustness (결합 13 method 평균)

- 12 셀 × 13 결합 method = 156 measurement 중 **148/156 = 94.9%** 가 정답 plan 으로 회복
- 베이스라인 7/12 = 58.3% 대비 **plan 회복 robustness 크게 향상**
- 회복 실패 8 건은 모두 Q3 (가장 풍부한 join space 가진 쿼리) 에서 발생

### 5.3 변동 분해 (실제 엔진 응답 시간)

- log(exec_ms) ~ C(query) + C(qid) + C(sel) + C(condition: B1·CaseB·oracle) + 교호작용 의 분산 분해 (3 평면 통합 2,250 obs, R²=0.83)
- 조건 (B1·결합·oracle) % SS = **0.00%** · p = **0.945**
- 즉 어느 추정값을 주입했는지가 응답 시간 변동에 사실상 기여하지 않는다.

### 5.4 종합 — chao_weighted 의 가치

본 연구의 최저 Q-error method 인 chao_weighted (그리고 결합 13 method 전체) 의 실제 엔진 가치는 **추가 latency 가속이 아니라 plan 회복의 robustness** 에 있다. 베이스라인은 결정 경계 가까운 cell 에서 fragile 하게 다른 plan 으로 미끄러질 수 있는 반면, 결합 13 method 는 같은 cell 에서도 정답 plan 을 안정적으로 회복한다.

## 6. 메커니즘 규명 — 사전 등록 통제 측정

### 6.1 통제 측정의 필요성

"분포 인지 method 가 베이스라인의 베르누이보다 정확하다" 는 결과 (89.1% 우위) 가 정말 **분포 인지의 효과인지**, 아니면 **두 독립 추정량을 평균하는 일반 통계 효과인지** 를 구분하기 위해 method 자리에 또 다른 무작위 베르누이를 둔 **이중 베르누이 ensemble** 통제군 (이하 CaseC) 측정.

CaseC 의 두 베르누이 표본은 같은 카디널리티 추정 알고리즘 (식 1-6) 위에서 서로 독립 seed 로 작동하며, 두 추정값을 산술 평균한다. 따라서 분포 인지 정보는 사용되지 않고, 두 독립 표본의 평균에 따른 분산 감소 효과만 작동한다.

### 6.2 통제 측정 결과 (95 측정 cell 전수)

본 측정은 25 셀 × 3 selectivity × 3 K 평면의 95 (cell × sel × K) 조합 전수에 대해 수행했다.

| 비교 | better% | median Δ% |
|---|--:|--:|
| **CaseC vs 베이스라인** | **95/95 = 100%** | **−11.32%** |
| **CaseC vs 결합 (CaseB)** | **95/95 = 100%** | **−5.98%** |

- CaseC 평균 Q-error = **1.3060** (베이스라인 1.4595 · 결합 1.4022 대비 모두 더 정확)
- 95 측정 전수에서 통제군이 결합 방식 (분포 인지 method) 보다 더 정확하다.

### 6.3 결론 — 89% 우위의 진짜 메커니즘

본 연구의 89.1% 결합 우위 메커니즘은 다음과 같이 분해된다:

1. **두 독립 추정량 평균에 따른 분산 감소 효과** (일반 앙상블 효과, 베이스라인 단일 표본 대비 표본 용량 2배 효과) — 지배적 원인
2. **분포 인지 method 의 추가 효과** — CaseC 와 결합의 비교에서 분포 인지가 양의 효과를 더하지 못함 (오히려 미세 음의 잡음)

→ **결합의 우위는 분포 인지 자체가 아니라 두 독립 추정량 평균의 분산 감소 효과** 가 지배적이다. 본 연구의 핵심 **negative · methodological 결과** 이며, "분포 인지 method 가 베르누이보다 우월하다" 라는 단순 인과로 결과를 해석해선 안 된다.

## 7. 학술 정직성 명시 — method 명칭 정정 (5/24 3-multi-AI audit)

본 연구의 16 method 중 8 method 가 명칭과 실제 구현 사이에 부분 불일치가 있어 학술 정직성 차원에서 정정한다. Claude (자체 raw 직접 분석)·Codex (적대 코드 read)·Gemini (학술 reference 검증) 3 모델의 통합 권고 결과이다.

| 이전 명칭 | 정정 후 명칭 | 정정 사유 |
|---|---|---|
| `hilbert_real` | **`pca2d_hilbert_xy2d`** | PCA 2D 환원 후 Wikipedia xy2d Hilbert curve 적용 — 고차원 Hilbert curve (Faloutsos 1989) 가 아니다 |
| `skilling_hilbert` | **`pca4_skilling_hilbert_approx`** | PCA 4D 환원 + Skilling 알고리즘 근사 (exact swap 일부 생략) |
| `zorder_morton` | **`pca2d_zorder_morton`** | PCA 2D 환원 후 Morton bit-interleave (Morton 1966 의 native multidim 아님) |
| `mhist2` | **`pca2d_equi_depth_grid`** | PCA 2D + equi-depth grid (Poosala 1997 MHIST-2 의 MaxDiff 미사용) |
| `hyperloglog` | **`md5_prefix_hash_bucket`** | md5 hash leading prefix bits 로 partition (Flajolet 2007 HyperLogLog 의 카디널리티 estimator 미사용) |
| `lavallee_hidiroglou` | **`takeall_cumsqrtf`** | take-all + cum-√f 만 적용 (Lavallée-Hidiroglou 1988 의 Neyman σ_h allocation 미적용) |
| `rabitq_strat` | **`rabitq_1bit_bucket`** | 1-bit sign partition only (Gao-Lin 2024 의 full RaBitQ codebook 아님) |
| `sparse_rp` (carry) | 명칭 유지 · reference 정정 | 1/√D 희소 무작위 투영의 정본 출처: Li-Hastie-Church 2006 (이전 Achlioptas 2003 표명 정정) |

★ 본 정정의 핵심: **§4.1 정확도 ranking 상위의 pca2d_hilbert_xy2d (구 hilbert_real, 2위) 와 pca4_skilling_hilbert_approx (구 skilling_hilbert, 3위) 의 우위는 고차원 공간 곡선의 효과가 아니라 PCA 분산 요약 + 공간 채움 곡선 hybrid 의 효과** 로 해석해야 한다. 1 위 chao_weighted 만 PCA 환원 없이 원본 차원에서 동작하며 명칭과 알고리즘이 완전 일치한다.

paradigm 분류도 정정 반영:
- 구 P9 InfoTheoretic 폐지·P5b Hashing 신설 (md5_prefix_hash_bucket 이동)
- 구 P5 QMC → P5 Classical Stratification (cum_sqrtf·takeall_cumsqrtf 의 Cochran 1977 표본 이론 본질 명시)
- P2 Spatial 의 PCA-reduced 부분 명시 (pca2d/pca4 prefix 로 명명)

## 8. 측정 한계 (honest limitation)

### 8.1 측정 평면 한계

- **A2-Fig8 (DEEP+CC3M sf=10, 1024d)**: 16 method 중 4 method 만 측정 (희소 cell, 단독 finding 인용 안 함)
- **WIKI sf=10 실제 엔진 측정**: 768d SeqScan 이 statement_timeout (180 초) 초과 — 측정 불가 (honest exception)
- **scale factor 1·100 실제 엔진 측정**: sf=1 은 작은 테이블이라 IndexScan 경로 선택 → 카디널리티 주입 미발동 (plan-invariant), sf=100 은 carry 미진행 (Future Work)
- **타 엔진 (VBASE·DuckDB-vss·Milvus)**: 미측정 (Future Work)
- 측정 portfolio = **41.9%** (1,508 / 의도 max 3,600), 완전 요인 설계 아닌 구조화 portfolio — K=20·sel=0.01 중심으로 측정 밀도 집중

### 8.2 측정의 통계 검정 floor

- trial 10 회로 한쪽 꼬리 Wilcoxon 최소 p값 1/1024 ≈ 0.001 에 몰림
- method·paradigm 우열은 p값보다 Δ%·효과 크기 (Hedges' g · Cliff's δ) 로 판단

### 8.3 sf=10 한정 일반화

본 연구의 실제 엔진 측정은 모두 **sf=10 (DEEP·SIFT·SSN·YFCC 4 데이터셋) 환경 기준** 이다. sf=1 (in-memory fit) 과 sf=100 (Disk I/O bound) 환경에서는 plan 변경 시 latency 증감 폭이 다를 수 있다.

### 8.4 method 명칭 정직성 한계 (§7 carry)
