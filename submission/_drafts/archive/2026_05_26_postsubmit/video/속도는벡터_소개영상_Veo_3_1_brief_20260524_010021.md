## Veo 3.1 clip 1 — 인트로 hero (0-5초)

**위치**: 영상 시작 (0:00-0:05)

**Veo 3.1 prompt** (Gemini 웹앱·Flow 복붙):
```text
A cinematic 5-second hero shot for a research presentation intro.

Visual:
- Opening: Empty navy background (#1E3A5F)
- 0-2s: "VAQ" Korean characters "벡터 증강 분석 쿼리" emerge in cyan-to-navy gradient (left-to-right reveal). Apple SD Gothic Neo style.
- 2-4s: Below the title, smaller text fades in: "한 SQL 안에 벡터 + SQL 분석" + small vector dots + SQL syntax icon.
- 4-5s: Camera slow zoom toward the text, navy background subtly shifting to slight cyan gradient.
- 5s end: Hold the final frame for cross-fade to next slide.

Audio (Veo 3.1 native sync):
- 0-1s: subtle whoosh ambient sound (low pitch)
- 1-4s: clean korean narration: "안녕하세요, 속도는벡터 팀입니다." (학술 톤, 중간 속도, 명확)
- 4-5s: ambient fade

Style:
- Cinematic, academic, calm
- Navy + cyan only (no other colors)
- No human characters
- Apple SD Gothic Neo Korean text rendering MUST be sharp (Veo 3.1 + Nano Banana Pro 텍스트 1위 강점 활용)
- 1920 × 1080 (16:9, 1080p)
- 30 fps

Do NOT include:
- English text in the foreground
- Logo flashes or visual gimmicks
- High-frequency noise or stingers
- Photorealistic faces
```

**검증**:
- [ ] 한국어 "VAQ — 벡터 증강 분석 쿼리" 텍스트 sharp
- [ ] navy → cyan 그라데이션 일관
- [ ] narration "안녕하세요, 속도는벡터 팀입니다." 동기화
- [ ] 1920×1080 30fps · MP4 export 가능
- [ ] 5초 정확

**Fallback**: 정적 PNG (deck v2 슬라이드 1 표지) + 별도 TTS narration. cinematic 손실 있지만 작동.

## Veo 3.1 clip 2 — 슬라이드 4 무게중심 transition (100-105초)

**위치**: 영상 중반, 슬라이드 3 (89.1% 우위 관측) → 슬라이드 4 (5행 표 무게중심) transition (1:40-1:45)

**Veo 3.1 prompt**:
```text
A cinematic 5-second reveal animation for a critical research result transition.

Visual:
- Opening: Hero "89.1%" text in navy-to-cyan gradient (carrying over from previous slide).
- 0-1s: "89.1%" text slightly shrinks and moves to top-left.
- 1-3s: A 5-row table materializes in the center (rows appear one-by-one):
  Row 1: "베이스라인 (무작위 단독) | 1.944 | —" (slight gray)
  Row 2: "단독 대체 (분포 인지 단독) | 1.984 | 44%" (coral hint)
  Row 3: "결합 방식 (두 추정의 평균) | 1.477 | 99%" (navy)
  Row 4: "평균 비교군 | 1.459 | 100%" (cyan tint background)
  Row 5: "사전 등록 통제 측정 | 1.373 | 100%" (cyan tint background, slight emphasis)
- 3-5s: Row 4 and Row 5 highlighted with subtle cyan glow. Below the table, a callout box (navy bold) reveals: "89% 우위는 분포 인지가 아닌 앙상블 평균 효과".

Audio (Veo 3.1 native sync):
- 0-1s: subtle "page turn" or "data reveal" ambient sound
- 1-3s: each row appearing with a soft "tick" (5 ticks total)
- 3-5s: a final "reveal chime" matching the callout reveal
- Narration: NONE (이건 transition 이라 narration 없음, 본 narration 은 105초부터 시작)

Style:
- Academic data visualization, cinematic but minimal
- Navy + cyan + subtle coral
- Apple SD Gothic Neo
- 1920 × 1080 30fps
- White background, table centered

Korean text in table MUST be sharp (Veo 3.1 + Nano Banana Pro 텍스트 1위 강점).
```

**검증**:
- [ ] 5 행 표 row-by-row 등장 (0.5초씩)
- [ ] row 4·5 cyan 틴트 + glow 강조
- [ ] navy 굵게 callout "앙상블 평균 효과" 정확 렌더링
- [ ] audio 동기화 (tick × 5 + reveal chime)
- [ ] 5초 정확

**Fallback**: 정적 표 PNG + cross-fade. animation 손실.

## narration TTS 옵션 (Veo 3.1 native vs 분리 TTS)

| 옵션 | 장점 | 단점 |
|---|---|---|
| **Veo 3.1 native audio** (위 prompt 안 narration 포함) | 동기화 완벽 · 한 번에 합성 | Veo 한도 빨리 소진 · audio 톤 제어 약함 |
| **ElevenLabs 한국어 TTS** (분리 합성) | voice 자연 · 한국어 학술 톤 풍부 | 슬라이드별 별도 합성 + sync 수작업 |
| **Google TTS** (분리 합성) | 무료 · 빠름 | voice 톤 평이 |
| **사용자 직접 녹음** (박세은) | 최고 자연 · 학술 발표 톤 | 시간 소요 |

**권장**: Veo 3.1 clip 3 개 (15 초) 는 native audio 활용 + 나머지 슬라이드 narration 은 ElevenLabs 또는 사용자 녹음.
