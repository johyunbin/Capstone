## ★ Step 3: FFmpeg 한국어 자막 burn-in (자동 명령, 1-2분)

자막 SRT 파일: `submission/_drafts/속도는벡터_소개영상_한국어자막_SRT_20260528.srt`

**ffmpeg 설치 확인** (macmini Terminal):
```bash
which ffmpeg
# 없으면: brew install ffmpeg
```

**burn-in 명령** (한국어 폰트 Apple SD Gothic Neo · 흰 텍스트 + navy `#1E3A5F` 그림자 · 하단 중앙):

```bash
cd ~/Downloads  # 또는 mp4 위치

ffmpeg -i 속도는벡터_소개영상_원본.mp4 \
  -vf "subtitles=/Users/hyunbin/Capstone/submission/_drafts/속도는벡터_소개영상_한국어자막_SRT_20260528.srt:force_style='Fontname=Apple SD Gothic Neo,Fontsize=36,PrimaryColour=&HFFFFFF&,OutlineColour=&H3A1E1E&,BorderStyle=1,Outline=2,Shadow=1,Alignment=2,MarginV=40,Bold=1'" \
  -c:a copy -c:v libx264 -preset slow -crf 18 \
  속도는벡터_소개영상_자막burnin_FINAL.mp4
```

→ `속도는벡터_소개영상_자막burnin_FINAL.mp4` 생성 (자막 burn-in 완료, 약 1-2분 소요).

**옵션 — 자막 색·크기 조정**:
- 폰트 크기: `Fontsize=36` (기본) · 더 크게 = 40-44
- 색: `PrimaryColour=&HFFFFFF&` (흰) · `OutlineColour=&H3A1E1E&` (navy `#1E3A5F` 의 BGR 변환)
- 하단 margin: `MarginV=40` · 더 위로 = 60-80

## ★ Trouble Shooting

**Q1: Veo prompt 또 깨진 경우?**
- 동일 prompt 3-4번 재시도. Veo 가 매번 다른 결과 generation.
- 또 깨지면 segment 텍스트 더 단순화 (예: "Engine Speed" → "Speed" 1단어로)
- 그래도 안 되면 영상 안 텍스트 X, 자막 SRT 만 의존

**Q2: Flow Storyboard 합성 실패?**
- Fallback: 26 segment mp4 개별 다운로드 → iMovie (macOS 기본) 에서 timeline 배치 → fade transition → export

**Q3: FFmpeg subtitles 한글 안 보임?**
- 한국어 폰트 path 명시: `Fontname=AppleSDGothicNeo-Bold` 또는 시스템 폰트 경로
- 또는 SRT → ASS 변환 후 burn-in

**Q4: 자막 timing 안 맞음?**
- SRT 파일의 timing 직접 편집 (Sublime Text 또는 VS Code)
- segment 별 실제 narration 길이 측정 후 조정
