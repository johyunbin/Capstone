### 1. W4 sprint 핵심 결과

본 연구는 Exqutor (BDAI-Research, arXiv:2512.09695v2) 의 ECQO + Adaptive Sampling 영역의 **단일 테이블 비인덱스 영역 보완**으로, 분포 인지 stratification (KM20 oracle) 가치 정량화 + 분포 모를 때 production-ready 대안 (4-강 method) 입증을 목표로 합니다.

- **5 dataset × 2 scale = 10 cell + YFCC_DL (다운로드 build) + 3 multi = 15 cell** 매트릭스 측정 완료 (5/7~5/8)
- **Exqutor 본 논문과 dataset 1:1 매칭** (DEEP / SIFT / SimSearchNet++ / WIKI / YFCC)
- **25 method per cell** (16 base + 9 NEW8+spectral)

### 2. 4-강 method narrative 요약

paired bootstrap 95% CI 0 제외 + Cohen's d medium~large effect 가 5 cell 일관:

- **Hilbert curve** = learning-free + 결정론, inverse Manhattan 1.000
- **MiniBatch K-means partial_fit** = OLTP production-ready (ARI=1.000)
- **Hybrid** = KMeans + Hilbert 결합
- **HDBSCAN** = density-based skew 환경 우위

**효과 size by distribution shape**:
- Normal (DEEP): -1~-2% (small)
- Skew (SIFT): **-10%** (large)
- 768d (WIKI): **-7~-10%** (large)
- PCA reduced (YFCC): **-5~-7%** (medium)

### 3. 자문 요청 사항

1. **5/27 발표 narrative 흐름**: motivation → RQ1 (Selectivity Gradient 단조성) → RQ2 (KM20 oracle + Anti-Neyman hurt) → RQ3 (4-강 method 5 cell 일관) → multi-vector + multi-join → YFCC 분포 검증 → limitation. 이 구조 적합한지 검토 부탁드립니다.
