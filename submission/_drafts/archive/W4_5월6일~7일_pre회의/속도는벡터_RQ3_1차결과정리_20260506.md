## 1. RQ3 가 묻는 질문

> **"분포를 모르는 환경에서 어떤 stratification 알고리즘이 RANDOM 보다 나은 sampling 효과를 내는가?"**

기존 KM20 oracle 은 사전에 K-means 학습이 필요해 production 환경에서 매번 학습이 부담. RQ3 는 7가지 후보를 비교해 **(a) production-ready 솔루션** 과 **(b) 학습 없는 결정론 솔루션** 을 찾는 것이 목표.

---

## 2. 평가 기준 (5/5 회의 §RQ3)

이론 metric:

```
recovery_rate = (방법X − RANDOM20) / (KM20 − RANDOM20)
  1.0 → KM20 oracle 수준 회수
  0.0 → RANDOM20 (분포 인식 X) 수준
  음수 → RANDOM20 보다 나쁨
```

**그러나 측정 결과 KM20 vs RANDOM20 격차가 0.26~3.98% 로 너무 작음** (분모 붕괴) → 사전 등록한 fall-back 적용:

**`method_minus_random_pct` = (방법 q_error − RANDOM20 q_error) / RANDOM20 × 100 (%)** 를 primary metric 으로 사용.
음수일수록 좋음 (방법이 RANDOM20 보다 q_error 낮음).

## 6. 핵심 발견 — 3 contributions

### 6-1. Hilbert Curve — **본 연구 핵심 contribution 1순위** ★

학습 0 + 결정론적 알고리즘이 1% 학습 솔루션과 동등한 성능. SIFT 에서 더 강함.

**Mechanism 분석** (서버 측 학습 단계 log 추출):
- **PCA 2D explained variance**: SIFT 22% > DEEP 12% — SIFT 의 cluster 구조가 2D 로 더 잘 압축
- **Bucket 분포**: max/min ratio 1.16~1.18 (매우 균질, quantile 분할 효과)
- **vs MiniBatch**: max/min ratio 2.45~4.77 (자연 cluster, 비균질)
- → 좁은 sel 에서 균질 분할이 sample efficiency 의 가치 발휘 (RQ2 의 Anti-Neyman 효과와 유사)

5/27 발표의 핵심 differentiator: **"learning-free stratification 도 oracle 수준 가능"**.

### 6-2. MiniBatch K-means — Production-ready 솔루션 ★

- 1% 학습 (10K row, ~수초) 으로 KM20 oracle 효과 회수
- DEEP 에선 -0.4~-4.2%, SIFT 에선 -1.4~-3.7%, 통계 유의 8/10
- RQ재정립 plan 의 Limitation 1 (KM20 = oracle, production X) 해소

### 6-3. Cluster 분할의 결정적 가치 — 부정적 control 3종 ★

본 연구의 **negative control 로서 가장 강한 결과**:

- **LSH/Random Projection** (+0.6~+45%): 단순 hash/projection 만으로는 cluster 정보 회수 불가
- **Distance-Shell** (+1.4~+17%): cluster 분할 (KM) 대신 distance shell 만으로는 매우 나쁨 — **cluster 의 spatial 정보가 결정적**
- **Importance Sampling** (+5~+866%): cluster/shell 분할 X, weight 만으로는 한계 — **분할 자체가 핵심 mechanism**

→ "stratification 의 가치는 cluster-aware 분할에서 온다" 의 정량 증명.

### 6-4. 분모 붕괴 caveat

- KM20 oracle 과 RANDOM20 의 q_error 격차 0.26~3.98% — recovery_rate 분모가 약함
- → **primary metric 을 method_minus_random_pct 로 변경** (사전 등록한 fall-back 활성)
- 향후 sample_size 더 작은 환경 (예: 100, 50) 에서 격차 회복 검증 필요 (sensitivity)

## 7. 5/8 회의 핵심 메시지

> **RQ3 7-way 측정 (offline 4 + online 2 + 비분할 1) 완료. 3개 contribution 발견.**
>
> **Best 2 — confirm 강 / 격상**:
> - **MiniBatch K-means** (#8): H3-F confirm — 1% 학습으로 KM oracle 수준, 통계 유의 8/10.
> - **Hilbert Curve** (#7): H3-E **refute 강 in 좋은 방향** — MiniBatch 와 동등, SIFT 에서 우수. 학습 0 + 결정론으로 oracle 수준 회수. **본 연구 contribution 1순위 격상**.
>
> **Negative controls — cluster 분할의 가치 정량 증명**:
> - **Distance-Shell** (#9): cluster 정보 X 의 shell 분할 → +14% (매우 나쁨)
> - **Importance Sampling** (#11): 분할 X 의 weight 만 → 최대 +866% (massive 나쁨)
> - **LSH/RandProj** (#5/#6): 단순 hash/projection → +5~+45% (나쁨)
>
> **Online 보조 결과**:
> - **KDE-pilot** (#10): SIFT mid-sel 에서만 효과 (-3.28%) — pilot noise 한계.
>
> **Caveat**: KM20 vs RANDOM20 격차 0.3~4% → recovery rate 분모 붕괴. method_minus_random_pct 를 primary metric.
