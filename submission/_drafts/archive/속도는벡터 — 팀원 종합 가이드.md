## 1. 우리가 푸는 문제 — 벡터 검색의 부정확한 카디널리티 추정

요즘 LLM 과 추천 시스템은 텍스트나 이미지를 **벡터** (수백 ~ 수천 차원의 숫자 배열) 로 변환해 데이터베이스에 저장합니다. 사용자가 어떤 텍스트로 검색하면 시스템은 그 텍스트도 벡터로 변환한 다음 데이터베이스 안에서 **유사한 벡터들을 빠르게 찾아** 응답합니다. 이런 데이터베이스를 벡터 데이터베이스라 부르고, 대표적인 오픈소스가 pgvector, VBASE, DuckDB 의 vector extension 등입니다.

문제는 검색 쿼리를 실행하기 전에 데이터베이스가 "이 검색 조건에 매칭될 데이터가 전체의 몇 퍼센트일까" 를 추정해야 한다는 점입니다. 매칭 비율 (selectivity) 에 따라 어떤 인덱스를 쓸지, 어떤 join 순서를 쓸지 결정되기 때문입니다. 그런데 pgvector 는 매칭 비율을 항상 33.3 퍼센트로, VBASE 는 50 퍼센트로, DuckDB 는 100 퍼센트로 가정합니다. 실제 매칭 비율은 0.001 퍼센트부터 90 퍼센트까지 큰 폭으로 변동하므로 이 고정값 가정은 자주 틀립니다. 틀린 추정은 잘못된 실행 계획으로 이어지고, 결과적으로 쿼리가 느려집니다.

본 연구의 기반 논문인 Exqutor (arXiv:2512.09695v2) 는 이 문제에 두 갈래로 접근합니다. 인덱스가 있을 때는 HNSW 범위 쿼리로 1-2 밀리초 안에 정확한 카디널리티를 얻고 (ECQO 영역), 인덱스가 없을 때는 무작위 sampling 으로 매칭 비율을 추정합니다 (Adaptive Sampling 영역). 두 영역 중 본 연구가 다루는 것은 후자 — Adaptive Sampling 입니다. 이 영역에서 원 논문이 사용한 sampling 방식은 **Bernoulli 무작위 sampling** 입니다.

## 2. 원 논문이 자체적으로 명시한 한계

Exqutor 논문은 자체 §V-B 절에서 Adaptive Sampling 의 한계를 명시하고 있습니다. 무작위 sampling 은 **데이터 분포에 의존적** 이라는 한계가 있습니다. 즉 데이터가 균등하게 분포되어 있을 때는 잘 작동하지만, 클러스터가 편향되어 있거나 일부 영역에 데이터가 집중되어 있을 때 추정값이 불안정해집니다.

본 연구는 이 한계를 출발점으로 잡았습니다. **데이터 분포를 인지하는 보조 추정 방식을 활용하면 sampling 의 정확도를 개선할 수 있을 것** 이라는 가설입니다. 이 가설을 검증하기 위해 다음 세 단계의 연구 질문을 단계적으로 풀었습니다.

## 3. 세 단계 연구 질문 (RQ1 / RQ2 / RQ3)

### 3.1 RQ1 — 무작위 sampling 이 실제로 얼마나 부정확한가

먼저 baseline 으로서 무작위 sampling 의 부정확함을 정량 측정했습니다. paper 정의 그대로 재현한 측정에서, DEEP / SIFT 데이터셋 sf=100 (scale factor 100) × selectivity 0.01 와 0.10 의 4 cells × 5 trials 결과를 보면 다음과 같습니다.

| 데이터셋 | selectivity | 무작위 sampling 평균 오차 | 분포 인지 평균 오차 | 격차 |
|---|---:|---:|---:|---:|
| SIFT | 0.10 | 1.230 | 1.123 | **−8.64% (1.095×)** |
| DEEP | 0.01 | 1.748 | 1.637 | −6.35% (1.068×) |
| DEEP | 0.10 | 1.161 | 1.117 | −3.78% |
| SIFT | 0.01 | 1.690 | 1.657 | −1.90% |
| **4 cells 평균** | | | | **−5.17%** |

가장 극단적 case 인 SIFT sel=0.10 에서 무작위 sampling 의 오차가 분포 인지 방식보다 8.64 퍼센트 더 큽니다. 무작위 sampling 의 부정확성이 selectivity 와 데이터셋에 따라 변동되며, 이는 분포 인지 접근의 출발점을 제공합니다.

### 3.2 RQ2 — 분포를 알 때 어떤 분배 방식이 최적인가

분포 정보를 알고 있다고 가정했을 때 sample 을 어떻게 분배하는 것이 최적인지 비교했습니다. K-means 클러스터링으로 데이터를 20 개 그룹 (stratum) 으로 분할한 다음, 각 stratum 에 sample 을 어떻게 분배할지 다섯 가지 방식 — Bernoulli 무작위 / 균등 분배 / 비례 분배 (stratum 크기 비례) / Neyman 분배 (크기 × stratum 내 표준편차) / Anti-Neyman (역방향) — 을 비교했습니다.

| 분배 방식 | 평균 오차 |
|---|---:|
| Bernoulli (baseline) | 1.748 |
| 균등 | 1.644 |
| **비례 (Proportional)** | **1.580** |
| Neyman | 1.595 |
| Anti-Neyman | 1.540 |

비례 분배가 baseline 대비 -9.53 퍼센트로 가장 안정적입니다. 이론적으로 Neyman 분배가 최적이어야 하지만 본 측정에서는 비례 분배가 Neyman 보다 약간 더 안정적이고, Anti-Neyman 이 가장 낮은 값을 보이는 paradox 가 발생했습니다. 원인은 본 측정 환경에서 stratum 별 표준편차의 변동이 1.3-1.6 배로 좁은 범위에 있고, stratum 크기 자체가 균등 분포 (변동계수 0) 이기 때문입니다. 표준편차 신호가 약하면 Neyman 분배의 효과가 비례 분배와 통계적으로 동등해집니다. 즉 분포를 알 때는 비례 분배가 답이며, 표준편차 신호가 큰 환경에서는 Neyman 이 더 유리할 수 있다는 의미입니다.

### 3.3 RQ3 — 분포를 모를 때 어떤 알고리즘이 최적인가

실제 환경에서는 데이터 분포를 미리 알 수 없습니다. 따라서 분포를 추정해주는 알고리즘이 필요합니다. 분포 추정 가능한 통계 paradigm 8 가지에서 56 개 알고리즘을 폭넓게 비교 측정했습니다. 결과는 §5 에서 자세히 다룹니다.

## 4. 알고리즘 portfolio — 8 paradigm × 56 method

본 연구가 비교한 8 paradigm 과 각 paradigm 의 대표 알고리즘은 다음과 같습니다.

| Paradigm | 대표 알고리즘 | 작동 가정 |
|---|---|---|
| 밀도 추정 (Density) | Parzen KDE (Parzen 1962) | 데이터 점 주변에 kernel 함수를 배치해 부드러운 확률 밀도 추정 |
| 정보 이론 (InfoTheoretic) | HyperLogLog (Flajolet 2007) | hash 의 leading-zero 분포로 distinct count 근사 |
| 스트리밍 (Streaming) | Chao 1982 weighted reservoir | stream 환경에서 분포 비례 sampling |
| 차원 축소 (DimReduction) | Sparse Random Projection (Li 2006) | 고차원을 저차원으로 압축하면서 거리 정보 보존 |
| 공간 분할 (Spatial) | Hilbert curve + Z-order (Morton 1966) | space-filling curve 로 고차원 공간 → 1차원 매핑 + 인접성 보존 |
| 균등 격자 (QMC) | Halton / Sobol / Hammersley / LHS | low-discrepancy quasi-Monte Carlo sequence |
| 클러스터 (Cluster) | k-means / MiniBatch | cluster 단위 sample 분배 |
| 양자화 (Quantization) | Product Quantization (Jegou 2011) | codebook 으로 벡터 압축 + 메모리 효율 |

각 paradigm 은 작동 가정이 서로 다릅니다. 예컨대 밀도 추정은 kernel 함수의 부드러움을, 정보 이론은 hash 함수의 균등성을 가정합니다. 본 연구는 어떤 가정이 본 sampling 시나리오에 가장 잘 맞는지를 측정으로 비교하는 접근입니다.

총 56 개 알고리즘을 9 개 측정 단위 (cell) 와 2 가지 적용 방식에 대해 paper 정의 그대로 측정했고, 산출 파일 1001 개를 확보했습니다.

## 5. 실험 framework — 대체 (CaseA) vs 증강 (CaseB)

본 연구의 핵심 framework 는 우리 method 를 paper Bernoulli baseline 에 **어떻게 적용할 것인가** 입니다. 두 가지 방식을 비교했습니다.

**대체 (CaseA · replace)**: paper 의 Bernoulli baseline 을 우리 method 로 단독 교체합니다. 수식으로는 `est_final = est_method` 입니다.

**증강 (CaseB · augment)**: paper 의 Bernoulli baseline 과 우리 method 의 추정값을 산술 평균합니다. 수식으로는 `est_final = (est_b1 + est_method) / 2` 입니다. 비유하자면 두 의사가 같은 환자를 진단했을 때 두 진단의 평균을 사용하는 방식입니다.

두 방식 모두 sample budget 은 paper 정의대로 N=385 를 유지하며, sample size 동적 조정 식 (paper Eq 1-6) 도 그대로 보존합니다. 차이는 최종 추정값을 어떻게 계산하느냐에만 있습니다.

## 7. 핵심 결과 — 대체는 무효, 증강만 유효

### 7.1 paradigm 단위 결과

8 paradigm 의 증강 (CaseB) 효과를 baseline 추정 오차 1.748 대비 정렬하면 다음과 같습니다.

| Paradigm | baseline → 증강 후 | 절감율 | 정확도 향상 배수 |
|---|---|---:|---:|
| 밀도 추정 (Parzen KDE) | 1.748 → 1.540 | -11.93% | **1.135×** |
| 정보 이론 (HyperLogLog) | 1.748 → 1.615 | -7.60% | **1.082×** |
| 스트리밍 (Chao 1982) | 1.748 → 1.632 | -6.63% | **1.071×** |
| 차원 축소 (Sparse RP) | 1.748 → 1.642 | -6.03% | **1.064×** |
| 공간 분할 (Hilbert + Z-order) | 1.748 → 1.651 | -5.57% | **1.059×** |
| 균등 격자 (QMC) | 1.748 → 1.774 | +1.47% | — |
| 클러스터 (k-means) | 1.748 → 1.784 | +2.04% | — |
| 양자화 (Product Quantization) | 1.748 → 1.896 | +8.44% | — |

다섯 paradigm 이 baseline 대비 통계적으로 압도하며, 추정 오차 6 ~ 14 퍼센트 절감, 정확도 1.06 배 ~ 1.14 배 향상 효과가 일관되게 나타납니다. 단일 알고리즘의 우연한 효과가 아니라 paradigm 차원에서 robust 한 개선임을 시사합니다.

### 7.2 결정적 비교 — 대체 vs 증강

본 연구의 핵심 발견은 **대체와 증강의 결과 차이** 입니다.

대체 (CaseA) — paper 의 Bernoulli baseline 을 우리 method 로 **단독 교체** 한 경우 493 cells 중 paper baseline 보다 우위인 cell 은 **0 cell, 즉 0 퍼센트** 입니다. 반대로 large worsening (효과 크기 large 수준의 악화) 은 37.1 퍼센트입니다. 즉 단독 대체는 통계적으로 무효입니다.

증강 (CaseB) — paper Bernoulli 와 우리 method 를 **산술 평균 결합** 한 경우 492 cells 중 paper baseline 보다 우위인 cell 은 **455 cell, 즉 92.5 퍼센트** 입니다 (p < 10⁻⁴⁵). 효과 크기로 보아도 Cliff's δ 가 large 수준인 비율이 63.0 퍼센트, Hedges' g 가 large 수준인 비율이 55.7 퍼센트로, 다양한 비모수 / 모수 통계 지표가 동일 방향을 가리킵니다.

이 negative control 결과가 본 연구의 결론을 명확히 합니다. **단독 대체는 무효이며, 증강 결합만 유효합니다.**

## 8. 왜 대체는 안 되고 증강만 되는가

세 가지 측면에서 분석됩니다.

첫째, **sample budget 의 분배 문제** 입니다. paper N=385 sample budget 을 stratified 추정 단독으로 사용하면 20 개 stratum 평균 19 sample 씩 분배됩니다. stratum 마다 19 개의 sample 로는 stratum 내부 변동을 신뢰성 있게 추정하기 어렵습니다. 반면 결합 방식에서는 paper Bernoulli 가 budget 전체를 사용하면서 stratified 가 보조 추정값을 제공하므로 budget 활용이 효율적입니다.

둘째, **통계적 가정의 충돌** 입니다. paper 의 sample size 동적 조정 식 (Eq 1-6) 은 무작위 sampling 의 i.i.d. 와 asymptotic normal 분포 가정 위에 설계되어 있습니다. stratified 추정값은 부분 분포 (cluster 별) 정보를 활용하므로 통계 분포 자체가 다르고, 따라서 단독으로 paper Eq 1-6 에 넣으면 가정이 위반됩니다. 결합 방식에서는 Bernoulli 추정이 가정을 충족하면서 stratified 가 정보를 보강하는 구조라 충돌이 없습니다.

셋째, **실험적 입증** 입니다. negative control 결과 (493 cells 중 0 cell outperform) 가 두 방식의 본질적 차이를 실증합니다. 단순 비교가 아니라 paper review-grade evidence 로 입증됩니다.

결합 방식의 본질은 **무작위 sampling 의 bias=0 특성과 분포 인지 sampling 의 variance 안정성** 을 산술 평균으로 결합하는 것입니다. 한 쪽이 fail 해도 다른 쪽이 보완하는 robust 구조입니다.

## 9. 한계와 향후 영역

본 연구가 측정하지 않은 영역을 정직하게 명시합니다.

첫째, **paper §V-A 의 multi-table 영역** 은 본 연구 §V-B sampling 영역과 별개로 paper main result 그대로 인정합니다. 측정한 multi-table cell (A2-Fig7, A2-Fig9) 의 stratification 학습 방식은 single table 에서 학습한 KM20 cluster 를 join 후 carry-over 하는 방식이며, 두 테이블 join 후 별도 stratification 학습은 본 연구의 scope 외입니다.

둘째, **ensemble augment 의 비용 overhead** — latency 와 memory — 는 본 측정에 포함되지 않았습니다. paper §V-B 재현 scope 에 정확도 측정만 포함되어 있어 추후 측정 영역 (cost-quality tradeoff) 으로 한계를 명시합니다.

셋째, **paper N=385 budget 위반 알고리즘** 9 가지 (균등 격자 paradigm 의 Halton/Sobol/LHS/Hammersley + 일부 다른 paradigm 알고리즘) 는 발표 자료에서 폐기했습니다. paper sample budget 정의 위반으로 정합성을 보장할 수 없기 때문입니다.
