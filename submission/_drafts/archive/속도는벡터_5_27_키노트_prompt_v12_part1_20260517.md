## 0. ★ v11 → v12 핵심 변경 (5건)

v11 대비 5건만 정정한다. framing 골격과 slide 구성은 그대로 유지한다.

### 0.1 "영역" 필러 토큰 전면 제거
v11 speaker notes는 "sample selection 영역", "paper 영역", "Q-error 영역" 처럼 조사 자리에 "영역"이 무의미하게 514회 삽입되어 거의 읽히지 않았다. v12는 speaker notes를 모두 정상 한국어 문장으로 다시 쓴다. "영역"은 단어 본래 뜻으로 필요한 경우(예: "차원 공간")가 아니면 일절 쓰지 않는다.

### 0.2 측정 portfolio 수치 정정 (slide 6)
- 이전(v11): "약 2039 file"
- 정정(v12): **통합 측정 1444건** (B1 대조군 80 + CaseB 실험군 1364)
- paired 비교는 1360건, 그중 K=10 결함 측정 120건을 제외한 **신뢰 가능 비교 1240건**이 분석 근거다.

### 0.3 정확도 evidence 수치·표현 정정 (slide 18)
- 이전(v11): "짝지은 Q-error 변화율(paired Δ%) 92.5%" + "paired CaseB < CaseA"
- 정정(v12): **CaseB(실험군)가 B1(대조군) 대비 Q-error를 낮춘 비율 92.2%** (1143/1240, K=10 제외), mean Δ% **−6.25%**
- CaseA(단독 대체) 계열은 본 narrative에 부합하지 않아 폐기되었으므로 "CaseB < CaseA" 표현 자체가 틀렸다. 비교 대상은 **CaseB vs B1** 한 쌍뿐이다.

### 0.4 selectivity slide를 단조 증가 메시지로 (slide 20)
- 이전(v11): selectivity-dependent "paradox" 중심
- 정정(v12): selectivity가 낮을수록 본질적(inherent) Q-error가 크지만, **selectivity가 높을수록 실험군 우월 비율이 단조 증가**한다는 것이 핵심 메시지다. better 비율 sel 0.001/0.01/0.10 = **84.4 / 92.4 / 99.2%**. "paradox" 표현은 쓰지 않는다.

### 0.5 concat 능동 확장 강조 + K granularity 과장 금지
- **concat 강조**: 우리는 DEEP/SIFT/SSN/WIKI/YFCC 등 공개 데이터셋을 직접 차원 방향으로 concat하여 multi-vector 측정 공간을 능동적으로 확장했다. 이 점을 slide 7에서 분명히 드러낸다.
- **K granularity 과장 금지**: K=10 측정에 대조군 B1의 구조적 결함이 확인되어(REPORT v12 §7) K granularity는 강한 finding이 아니다. 발표에서 K granularity를 본문 finding으로 내세우지 않으며, 별도 slide도 두지 않는다. 언급이 필요하면 honest limitation 수준으로만 다룬다.

|---|---|---|
| **paper 그대로 유지** | (a) §V-A ECQO HNSW range query (b) §V-B Adaptive Sampling Eq 1-6 momentum 보정 (c) cardinality 추정 알고리즘 자체 (Bernoulli estimator) | 간단 소개 — paper Exqutor의 contribution으로 인정 (slide 4) |

## 5. ★ slide 4 paper § 흐름 (간단 소개)

### Layout
- 좌측 §V-A ECQO 박스 (1 line: "HNSW range query → 정확 cardinality (1-2ms)")
- 우측 §V-B Adaptive Sampling 박스 (Eq 1-6 verbatim)
- 두 박스 연결 화살표 + 한 줄: "paper가 그대로 둔 cardinality 추정 mechanism"

### paper §V-B Eq 1-6 (verbatim, 박스 내부)
```
Eq 1: N = ⌈z²·P̂(1-P̂)/e²⌉ = 385   (sample budget, z=1.96 / P̂=0.5 / e=0.05)
Eq 2: Ĉ = Σ (matching rows) × (1 − sampling_ratio)   (estimator)
Eq 3: δ = max(true_Q-err, 1/true_Q-err)   (Q-error)
Eq 4: η ← m·η + (1−m)·δ/α   (momentum update, m=0.9 / α=50)
Eq 5: N_t+1 ← N_t × (1 + η·β·sign(...))   (sample size update, β=1.5)
Eq 6: η ← η · γ   (learning rate decay, γ=0.99)
```
period P=50 query마다 Eq 4-6 update.

### speaker note
> "paper Exqutor는 두 갈래로 cardinality를 추정합니다. §V-A ECQO는 인덱스가 있을 때 HNSW range query로 1-2ms 안에 정확한 cardinality를 얻습니다. §V-B Adaptive Sampling은 인덱스가 없을 때 Bernoulli random 표본 N=385개로 추정하고, Eq 1-6 momentum으로 표본 크기를 동적 보정합니다. 이 둘은 모두 paper 본인의 contribution이고, 본 발표에서는 그대로 인정하고 소개만 합니다. 저희가 개선한 부분은 아닙니다."

## 6. ★ slide 5 본 연구 3 phase 흐름

### Phase 1: 분포 인지 stratification (본 연구 개입)
- 데이터셋 적재 시 1회 (offline)
- ① Type 판별 (행 수 / structure / 차원)
- ② Type별 권장 method 선택 (dynamic 할당, slide 17 상세)
- ③ K=20 stratum으로 분할 (16 method 중 선택, slide 8-16 상세)
- 결과: 각 row → stratum_id 0..K-1

### Phase 2: 표본 추출 (본 연구 개입)
- 쿼리 진입 시 매 query (online)
- ① sample budget N=385 (Eq 1, paper verbatim 그대로)
- ② 각 stratum에서 비례 추출 (proportional allocation, K=20)
- ③ 추출 표본으로 est_method 계산

### Phase 3: 결합 minimal (산술 평균)
- ① est_b1 = paper Bernoulli random 표본 추정 (paper 그대로)
- ② est_method = 본 연구 method 추정
- ③ **est_final = (est_b1 + est_method) / 2.0** — 산술 평균
- ④ 이후 paper Eq 2-6 momentum 보정 (그대로 유지)

### Layout (3 박스 + 화살표)
```
┌────────────┐    ┌────────────┐    ┌────────────┐
│ Phase 1    │ →  │ Phase 2    │ →  │ Phase 3    │
│ 분포 인지  │    │ 표본 추출  │    │ 결합       │
│ stratifi-  │    │            │    │ minimal    │
│ cation     │    │            │    │            │
│ (offline)  │    │ (online)   │    │ (online)   │
│ ★ 개입     │    │ ★ 개입     │    │ minimal    │
└────────────┘    └────────────┘    └────────────┘
                                            ↓
                          [paper Adaptive Eq 1-6 보정 (그대로)]
```

### speaker note
> "본 연구의 흐름은 3 phase입니다. Phase 1과 Phase 2가 핵심 개입 지점입니다. Phase 1에서는 데이터셋을 적재할 때 한 번, 분포를 보고 K=20개 stratum으로 나눕니다. 어떤 method로 나눌지는 데이터셋 Type에 따라 자동으로 선택합니다. Phase 2에서는 쿼리가 들어올 때마다 각 stratum에서 비례적으로 표본을 뽑습니다. sample budget N=385는 paper Eq 1을 그대로 씁니다. Phase 3는 결합인데, paper Bernoulli 추정값과 저희 method 추정값을 단순 산술 평균합니다. 이 결합은 minimal합니다 — paper의 Adaptive Eq 1-6 momentum 보정은 그대로 둡니다."
