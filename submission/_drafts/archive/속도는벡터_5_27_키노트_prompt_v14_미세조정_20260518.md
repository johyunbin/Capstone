## 수정 1 — slide 7 "측정한 데이터셋": 제작·출처 서사 제거

현재 slide 7은 제목이 "공개 데이터셋에 더해, 다중 벡터 데이터를 직접 만들었다"이고, "우리가 직접 만든 다중 벡터 데이터", "두 데이터셋의 벡터를 차원 방향으로 이어 붙여 새로 만든다", "측정 범위를 넓혔다" 같은 **제작 과정·출처 서사**가 들어 있다. 청중에게는 데이터가 어디서 왔는지가 아니라 무엇을 측정했는지가 중요하다. 데이터셋을 담백하게 소개하는 슬라이드로 다시 만든다.

**수정 후 slide 7 화면:**
- 제목: "측정한 데이터셋"
- 데이터셋을 두 그룹으로, 이름과 차원만 담백하게:
  - 단일 벡터 데이터셋 — SIFT · DEEP · SimSearchNet++ · WIKI · YFCC
  - 다중 벡터 데이터셋 — DEEP+SIFT (224차원) · DEEP+YFCC (288차원) · DEEP+WIKI (864차원)
- 하단 한 줄: "96차원부터 864차원까지, 단일 벡터와 다중 벡터를 아우른다"
- **삭제할 것**: "직접 만들었다", "우리가 새로 만든", "공개 데이터셋에 더해", "측정 공간을 넓혔다", "측정 범위를 넓혔다" 등 제작·출처 서사 일체. 좌/우 박스로 "원래 있던 것 vs 우리가 만든 것"을 대비하던 구도도 없앤다 — 두 그룹은 단지 단일/다중 벡터 구분일 뿐이다.

## 수정 2 — slide 11 "완전 대체는 불안정": 박스 잘림 수정

현재 slide 11은 "완전 대체 35.2%"와 "결합 89.1%" 두 수치 박스를 **세로로 쌓아** 배치했는데, 아래쪽 "결합 89.1%" 박스가 슬라이드 하단 경계 밖으로 잘려 있다.

**수정 후 slide 11:**
- "완전 대체 35.2%"와 "결합 89.1%" 두 수치 박스를 **좌우로 나란히** 배치한다 (세로 쌓기 금지).
- 두 박스 모두 슬라이드 세로 범위 안에 완전히 들어오게 한다 — 어느 박스도 잘리지 않게.
- 결합 쪽을 강조 색으로. 우측 또는 하단 설명 텍스트는 그대로 둔다.

## 수정 3 — slide 12 막대 그래프: "나머지 6가지" → 16개 모두 표시

현재 slide 12 막대 그래프는 상위 방법 8개와 가우시안 혼합 모델을 개별 표시하고 중간을 "…나머지 6가지 방법"으로 묶었는데, **그 개수가 틀렸다 — 7가지가 맞다** (16개 − 개별 표시 9개 = 7개).

**수정 후 slide 12 막대 그래프:**
- 16가지 방법을 **모두 개별 막대로** 표시한다. "…나머지 N가지"로 묶지 않는다.
- 막대 값(개선폭 중앙값, 음수가 개선, 큰 개선이 위쪽):

  | 방법 | 개선폭 |
  |---|---|
  | 가중 표본 추출 | −6.2 |
  | Hilbert 곡선 | −5.9 |
  | 고차원 Hilbert 곡선 | −5.8 |
  | 독립성분 분석 | −5.7 |
  | 주성분 분석 | −5.6 |
  | Z-order 곡선 | −4.9 |
  | HyperLogLog | −4.6 |
  | 누적 제곱근 층화 | −4.5 |
  | Lavallée–Hidiroglou 층화 | −4.4 |
  | 희소 랜덤 투영 | −4.4 |
  | 랜덤 SVD | −4.1 |
  | 미니배치 K-means | −3.6 |
  | RaBitQ 양자화 | −3.6 |
  | 다차원 히스토그램 | −3.4 |
  | IVF 클러스터링 | −2.7 |
  | 가우시안 혼합 모델 | +2.7 |

- 가우시안 혼합 모델 1개만 양수(반대 방향) — 색을 다르게.
- 좌측 "14 / 16" 큰 수치와 설명은 유지하되, 설명을 "클러스터링 계열 둘(가우시안 혼합 모델·미니배치 K-means)만 약해 권장에서 제외"로 둔다.

## 수정 4 — slide 14 "데이터 구조": 세 박스 → 두 박스, "직접 연결한" 표현 제거

현재 slide 14는 "단일 벡터 89.1% / 다중 벡터 89.6% / 직접 연결한 다중 벡터 89.0%" 세 박스다. "직접 연결한"이라는 제작 서사 표현을 없애고, 데이터 구조를 단일·다중 **두 갈래**로 단순화한다.

**수정 후 slide 14:**
- 제목: "단일 벡터와 다중 벡터 모두에서 일관되게 우월"
- 큰 수치 두 개:
  - 단일 벡터 **89.1%**
  - 다중 벡터 **89.2%**
- 하단 한 줄: "데이터 구조가 달라져도 우월 비율이 거의 같다"
- (다중 벡터 89.2% = 기존 89.6%·89.0%로 나뉘어 있던 다중 벡터 측정을 하나로 합산한 값이다.)
