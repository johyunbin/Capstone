### slide 15 — 세 방식 비교: 완전 대체는 불안정, 결합이 답

**화면**
- 제목: "완전 대체는 불안정하다 — 결합이 답이다"
- 중앙에 막대 그래프로 두 수치를 **좌우 나란히** 대비 (세로로 쌓지 말 것 — 잘림 방지):
  - 완전 대체 — 기존 방식보다 나은 경우 35.2% (짧은 막대)
  - 결합 — 기존 방식보다 나은 경우 89.1% (긴 막대, 강조 색)
- 우측/하단 짧은 설명: 표본을 통째 바꾸면 우리 방법이 강할 때만 좋고 약할 때 크게 나빠진다 / 두 추정값을 결합하면 논문 방식이 안전망이 되어 안정적으로 개선
- 두 막대·텍스트 모두 슬라이드 안에 완전히 들어오게

**발표 멘트**
- "무작위 표본을 우리 표본으로 통째 바꾸면 어떨까요? 그렇게 한 완전 대체는 기존 방식보다 나은 경우가 35%뿐이었습니다. 우리 방법이 강할 때는 좋지만 약할 때는 오히려 크게 나빠집니다."
- "반면 두 추정값을 결합하면 89%에서 개선됩니다. 논문 방식이 안전망 역할을 하기 때문입니다. 그래서 통째 교체가 아니라 결합이 답입니다."

### slide 16 — 방법별 정확도: 16가지 중 14가지 우월

**화면**
- 제목: "16가지 방법 중 14가지가 기존 방식을 안정적으로 이긴다"
- 가운데~우측: 16가지 방법을 추정 오차 개선폭 순으로 **16개 모두 개별 가로 막대**로 표시 (묶지 않는다). 음수가 개선, 큰 개선이 위쪽:

  | 방법 | 개선폭 |
  |---|---|
  | 가중 표본 추출 | −6.2 |
  | Hilbert 곡선 | −5.9 |
  | 고차원 Hilbert 곡선 | −5.8 |
  | 독립성분 분석 | −5.7 |
  | 주성분 분석 | −5.6 |
  | Z-order 곡선 | −4.9 |
  | HyperLogLog | −4.6 |
  | 누적 제곱근 층화 | −4.5 |
  | Lavallée–Hidiroglou 층화 | −4.4 |
  | 희소 랜덤 투영 | −4.4 |
  | 랜덤 SVD | −4.1 |
  | 미니배치 K-means | −3.6 |
  | RaBitQ 양자화 | −3.6 |
  | 다차원 히스토그램 | −3.4 |
  | IVF 클러스터링 | −2.7 |
  | 가우시안 혼합 모델 | +2.7 |

  - 가우시안 혼합 모델 1개만 양수(반대 방향) — 색을 다르게
- 좌측: "14 / 16" 큰 수치 + "공간 곡선·차원 축소·층화 계열이 안정적. 클러스터링 계열 둘(가우시안 혼합 모델·미니배치 K-means)만 약해 권장에서 제외"

**발표 멘트**
- "열여섯 가지 방법을 정확도 순으로 줄 세운 결과입니다. 열네 가지는 모든 측정 조건에서 안정적으로 기존 방식을 이겼습니다. 공간 곡선과 차원 축소 계열이 특히 좋았습니다."
- "약한 것은 클러스터링 계열 둘입니다. 가우시안 혼합 모델은 기존 방식보다 못했고, 미니배치 K-means는 가장 큰 데이터에서 불안정했습니다. 그래서 클러스터링 계열은 권장에서 제외했습니다."

### slide 17 — 선택도: 높을수록 더 우월

**화면**
- 제목: "선택도가 높을수록 더 안정적으로 개선된다"
- 중앙 막대 그래프 세 개 (우상향이 한눈에 보이게):
  - 선택도 낮음(0.1%) → 83.3%
  - 선택도 중간(1%) → 87.6%
  - 선택도 높음(10%) → 97.5%
- 작은 라벨: 선택도 = 전체 데이터 중 조건을 만족하는 비율 / 조건에 맞는 데이터가 많을수록 분포 반영의 이점이 더 분명

**발표 멘트**
- "선택도는 전체 데이터 중 쿼리 조건을 만족하는 비율입니다. 선택도가 낮을 때, 중간일 때, 높을 때로 나눠 보면 결합 방식이 기존 방식을 이기는 비율이 83%, 88%, 98%로 꾸준히 올라갑니다."
- "조건에 맞는 데이터가 많을수록 분포를 반영한 표본의 이점이 더 분명하게 드러납니다."

### slide 18 — 데이터 구조: 단일·다중 모두 일관

**화면**
- 제목: "단일 벡터와 다중 벡터 모두에서 일관되게 우월"
- 중앙 막대(또는 큰 수치) 두 개를 나란히:
  - 단일 벡터 — 89.1%
  - 다중 벡터 — 89.2%
- 두 막대 높이가 거의 같음을 한눈에 보이게
- 한 줄: 데이터 구조가 달라져도 우월 비율이 거의 같다

**발표 멘트**
- "데이터 구조를 단일 벡터와 다중 벡터로 나눠 비교했습니다. 두 경우 모두 결합 방식이 기존 방식을 이기는 비율이 89%로 거의 같았습니다."
- "한 행에 벡터가 하나든 여럿이든, 효과가 흔들리지 않는다는 뜻입니다."

### slide 19 — 계층 수: 20개가 최적

**화면**
- 제목: "데이터를 20개 계층으로 나눌 때가 가장 좋다"
- 중앙 막대 그래프 세 개 (20개가 가장 높은 봉우리로 보이게):
  - 10개 계층 → 83.3%
  - 20개 계층 → 89.6% (강조)
  - 30개 계층 → 85.4%
- 우측 짧은 설명: 계층이 너무 적으면 쏠린 분포를 충분히 못 나누고, 너무 많으면 계층마다 표본이 얇아진다 / 20개가 균형점, 논문 기본값과도 일치

**발표 멘트**
- "데이터를 몇 개의 계층으로 나눌지도 실험했습니다. 열 개, 스무 개, 서른 개로 나눠 보니 스무 개일 때가 가장 좋았습니다."
- "계층이 너무 적으면 쏠린 분포를 충분히 못 나누고, 너무 많으면 계층마다 표본이 얇아집니다. 스무 개가 균형점이고, 논문이 기본값으로 쓴 값과도 일치합니다."

### slide 20 — 자원 효율: 정확도와 분포 파악 시간

**화면**
- 제목: "정확도와 분포 파악 시간의 균형"
- 중앙 점 그래프: 가로축 = 분포 파악에 걸리는 시간, 세로축 = 정확도 개선폭 (음수가 개선)
  - 점: 희소 랜덤 투영(2.9초·−4.4%) · 가중 표본 추출(11초·−6.2%) · HyperLogLog(12초·−4.6%) · 주성분 분석(23초·−5.6%) · Hilbert 곡선(41초·−5.9%) · 가우시안 혼합 모델(30초·+2.7%)
  - 각 점 라벨이 축 눈금·다른 라벨과 겹치지 않게 배치
- 우측 짧게: 균형 — 가중 표본 추출 / 가장 빠름 — 희소 랜덤 투영 / 최고 정확도 — Hilbert 곡선

**발표 멘트**
- "방법을 고를 때는 정확도뿐 아니라 데이터가 들어올 때 분포를 파악하는 시간도 봐야 합니다. 이 그래프는 두 축을 함께 보여 줍니다."
- "분포 파악이 빨라야 하면 희소 랜덤 투영, 정확도가 최우선이면 Hilbert 곡선, 둘의 균형이 필요하면 가중 표본 추출을 고르면 됩니다."

### slide 21 — 자동 선택: 데이터 유형을 보고 방법을 고른다

**화면**
- 제목: "데이터 유형을 보고 표본 선택 방법을 자동으로 고른다"
- 세로 흐름도 4단계:
  1. 데이터가 들어온다
  2. 데이터 유형 판별 (크기 · 구조 · 차원)
  3. 유형에 맞는 표본 선택 방법 자동 선택
  4. 결합 방식으로 카디널리티 추정
- 우측 한 줄: 사람이 매번 고르지 않고, 데이터 유형에 따라 자동으로 / 추정 알고리즘은 그대로

**발표 멘트**
- "측정 결과를 종합해, 데이터 유형에 따라 표본 선택 방법을 자동으로 고르는 방식을 제안합니다."
- "데이터가 들어오면 크기·구조·차원을 보고 유형을 판별하고, 그 유형에 맞는 방법을 골라 결합 방식으로 추정합니다. 사람이 매번 방법을 고르지 않아도 됩니다."

### slide 22 — 결론

**화면**
- 제목: "결론"
- 핵심 결과 네 가지를 카드로, **각 카드에 미니 시각 요소**를 함께:
  1. 분포를 반영한 표본 선택이 추정 오차를 89.1%에서 줄였다 — 89.1% 미니 막대/도넛
  2. 통째 교체는 불안정, 두 추정값의 결합이 답이다 — 35% vs 89% 미니 막대
  3. 선택도·데이터 구조·계층 수 모든 조건에서 일관 — 우상향 미니 그래프
  4. 데이터 유형에 따라 방법을 자동으로 고르는 방식을 제안 — 미니 흐름 아이콘
- 하단 띠: 추정 알고리즘은 그대로 두고, 표본을 뽑는 방식만 바꾸는 것만으로 추정이 더 정확해진다

**발표 멘트**
- "정리하겠습니다. 첫째, 무작위 대신 분포를 반영해 표본을 뽑으면 추정이 89%에서 더 정확해졌습니다. 둘째, 통째 교체는 불안정하고 두 추정값의 결합이 답이었습니다."
- "셋째, 이 효과는 선택도·데이터 구조·계층 수 어느 조건에서도 일관됐습니다. 넷째, 데이터 유형에 따라 방법을 자동으로 고르는 방식을 제안했습니다. 추정 알고리즘은 그대로 두고 표본 뽑는 방식만 바꾼 결과입니다."
