## 상황 (왜 이 신설이 필요한가)

본 팜플렛(223845, 4페이지)은 5월 28일 전시 배포본 정본이다. p3 "핵심 결과"가 본 연구의 추정 정확도 검증(1,508건 3-way 오프라인 측정)을 89.1% hero로 보여 주고, p4가 그 결과의 결론 4항목과 다음 단계로 닫는다. 그러나 그 사이에 본 연구가 지난 한 주에 걸쳐 새로 완료한 핵심 결과 — **검증된 추정치를 실제 PostgreSQL 엔진에 주입한 엔진 적용 검증 (12 구간 × 16 변형 × 15회 반복 = 2,880회 측정)** — 가 통째로 빠져 있다. 이 결과는 본 연구가 "추정 정확도 → 실행 계획 → end-to-end 시간" 의 인과 사슬을 직접 측정으로 닫아낸 closing the loop 카드이며, 관람객이 팜플렛을 손에 쥐고 결과 페이지를 넘기는 그 순간 "오프라인 검증이 실제 엔진에서도 같은 효과를 낸다"는 한 방을 전달해야 한다.

본 수정은 p3 "핵심 결과" 구역 내부에 새 결과 카드 한 장(이하 **결과 카드 5번**)을 끼워 넣어 — p3 결과 패널이 [기존 89.1% hero + 완전 대체 차트 + 조건별 3패널] 의 3 블록에서 [기존 3 블록 + 신설 1 블록] 의 4 블록으로 확장된다. 다른 5개 구역(p1 표지·p2 연구 배경·p2 우리 방법·p4 결론 4항목·p4 다음 단계+QR)은 한 자도 건드리지 않는다.

## 절대 규칙 (수정 시 동결)

이 9가지를 신설 결과 카드에서도 어김없이 지킨다 — 기존 4페이지의 규칙과 동일.

1. **코드명 노출 금지**: B1·CaseA·CaseB·oracle·baseline 같은 영문 코드명을 팜플렛 본문·표·도식에 노출하지 않는다. 한국어 라벨로 — "기본 엔진" / "베이스라인 방식" / "정답" / "결합 방식" 으로 통일.
2. **"영역" 필러 금지**: "검증 영역" / "결과 영역" / "분석 영역" 같은 무의미 토큰을 본문·라벨·헤더 어디에도 쓰지 않는다. "구간" / "단계" / 의미 있는 명사로.
3. **수식 노출 금지**: est_final = (est_b1 + est_method) / 2.0 식의 코드 수식을 본문에 노출하지 않는다. "두 추정값을 평균" 같은 한국어 표현으로.
4. **영문 메타 라벨 금지**: "Phase 2 results" / "Engine result" 같은 영문 메타 라벨을 헤더·소제목에 쓰지 않는다. "엔진 적용 검증" 같은 한국어 헤더.
5. **이분법 강조 금지**: "B1 vs CaseB" 식 두 대립 항목만 강조하는 이분법 표현 금지. 결합 방식이 robustness 면에서 베이스라인보다 견고하다는 한쪽 메시지로.
6. **별표(★) 금지**: 강조 표식으로 ★를 팜플렛에 쓰지 않는다.
7. **텍스트 잘림/겹침 금지**: 모든 글자가 박스·그라데이션·다른 텍스트와 겹치지 않게. 인쇄 안전 여백 12~15mm 유지.
8. **design system 동결**: navy `#1E3A5F` 앵커 + 악센트 4색(청록 `#0EA5E9`·코랄 `#F97316`·그린 `#10B981`·바이올렛 `#8B5CF6`) + 개념색(기존 방식 그레이 `#94A3B8`·완전 대체 코랄 `#F97316`·결합 청록 `#0EA5E9`) + Apple SD Gothic Neo·Inter + 흰 배경. 컬러풀 디자인을 되돌리지 않는다.
9. **한국어 학술 산문 톤**: bullet 나열·텍스트 박스만 늘어선 카드를 만들지 않는다. 팜플렛은 deck·포스터보다 더 압축 — 한 카드 안에서 한 문장으로 요지를 전달한다.

## 신설 결과 카드 정의

### p3 결과 카드 5번 — 엔진 적용 검증: 모든 구간 3-7배 가속, 결합 방식이 94.9% 견고하게 정답 계획을 회복한다

위치: p3 "핵심 결과" 구역의 마지막 블록 (89.1% hero · 완전 대체 vs 결합 차트 · 조건별 3패널 다음, p4 결론 페이지로 넘어가기 직전). 결과 카드 5번은 검증 카드(89.1%)에서 엔진 적용 결과 카드로의 badge 전이를 시각적으로 보여 준다 — 89.1% 가 오프라인 정확도라면, 이 카드는 실제 엔진에서의 효과다.

배경 색조: 옅은 청록 틴트 또는 그린 틴트(결과 국면 표식). 카드 좌상단에 작은 한국어 표식 "엔진 적용 검증" + 그린 점.

hero 숫자 쌍 (좌·우 또는 위·아래 — 카드 가로 폭에 따라):

- **3-7×** — navy → 청록 그라데이션. 작은 캡션 "12 구간 모두 가속".
- **94.9%** — navy → 청록 그라데이션. 작은 캡션 "결합 방식이 정답 계획을 회복한 비율".

구성 (한 카드 안 압축):

1. 카드 헤더 (좌상단 그린 점 + 한국어 표식 "엔진 적용 검증") + 카드 제목 "검증된 추정치를 실제 엔진에 넣었더니, 모든 구간이 3-7배 빨라졌고 정답 계획을 더 견고하게 회복했다"
2. hero 숫자 쌍 — "3-7×" (좌) / "94.9%" (우). 각 hero 아래 한 줄 캡션.
3. 핵심 메시지 한 문장 (hero 쌍 아래 중앙): "베이스라인은 정답 계획을 12 구간 중 7개에서만 회복하지만, 결합 방식 13종은 평균 148/156 = 94.9%를 회복한다 — 질의 벡터에 흔들리지 않는 견고함."
4. 통계 검증 한 줄 (카드 하단, 작게): "총 측정 12 구간 · 16 변형 · 15회 반복 · 2,880회. 기본 엔진 대비 짝지은 통계 검정 180건 100% 유의."
