## 절대 규칙 (모든 STEP 코드블록이 준수 · 일탈 시 자가검증에서 잡는다)

- **코드명 금지** — B1·CaseA·CaseB·qe_trim 같은 표기를 어디에도 쓰지 않는다. 세 방식은 **"기존 방식 / 완전 대체 / 결합"**으로만 부른다.
- **알고리즘은 한국어 이름으로** — Hilbert·PCA·GMM 같은 영문/코드 표기 대신 한국어 이름. 포스터에 알고리즘 개별 이름이 거의 나오지 않지만, 제외 3가지는 "가우시안 혼합 모델·미니배치 K-means·IVF 클러스터링"으로 적는다.
- **수식·코드 용어 금지** — Q-error·est_b1·Eq 1~6·stratum_id 같은 표기 금지. "추정 오차"·"계층"·"선택도" 같은 한국어로.
- **이분법·필러 금지** — "분포를 안다 / 모른다" 식 이분법 표현, "영역"이라는 무의미 필러 단어를 쓰지 않는다.
- **영어 메타 라벨·"★" 금지** — BASE PAPER·STEP·FINAL 같은 영어 메타 표기, "★" 기호를 포스터 화면에 넣지 않는다. 페이지 번호도 없다.
- **모든 섹션은 그림으로 말한다** — 텍스트 박스만 나열된 섹션을 만들지 않는다. 비교는 도식으로, 수치는 차트로, 과정은 흐름도로.
- **내용·구조·수치 동결** — 현행 포스터의 5섹션+헤더 콘텐츠·구조·수치는 그대로. 바꾸는 것은 **비주얼(색·폰트·차트 스타일·패널 처리)뿐**이다.

## 공유 디자인 시스템 (4종 발표물 공통 · 코드블록에 그대로 명시됨)

deck·포스터·소개영상·학교 표지 4종이 같은 시각 언어를 쓴다. 포스터도 이 시스템을 따른다.

- **배경**: 흰색 기조. 포스터는 면적이 커, 섹션 본문을 묶는 패널·카드에 옅은 틴트(navy 5~8% 또는 섹션 악센트 5~8%)를 허용해 섹션 경계를 만든다.
- **폰트**: 한글 Apple SD Gothic Neo · 라틴·숫자 Inter. 고정.
- **앵커색 navy `#1E3A5F`** — 지배색. 제목·섹션 번호 원·본문 강조어·워드마크 "벡터"·구조선에 쓴다.
- **악센트 4색** — 청록 `#0EA5E9` · 코랄 `#F97316` · 그린 `#10B981` · 바이올렛 `#8B5CF6`. 섹션 badge·아이콘·구분선에 분배한다.
- **개념색 3색 (전 발표물 일관)** — 기존 방식 → 그레이 `#94A3B8` · 완전 대체 → 코랄 `#F97316` · 결합 → 청록 `#0EA5E9`. 세 방식을 보여주는 모든 데이터 시각화에서 이 색을 쓴다.
- **hero 거대 수치** — navy→청록 그라데이션. 포스터에서 단 한 곳(④ 89.1%)만.
- **절제** — 한 섹션에 악센트는 2~3색까지. navy가 지배색. 그라데이션은 hero 한 곳만. 다크 배경·매거진 레이아웃 금지.

```text
  · ② 우리 방법 → 바이올렛
  · ③ 측정 설계 → 그린
  · ④ 핵심 결과 → 코랄

- ④ 핵심 결과: 결합이 기존 방식보다 정확한 비율 89.1%. 완전 대체는 불안정. 조건이 달라져도 일관되게 우월.
- ⑤ 결론: 핵심 결론 네 가지 + 다음 단계 + 소개 영상 QR.

[절대 규칙]
```

## STEP 1 — 헤더 + ①②③ 생성

claude.ai/design에 아래 코드블록을 복붙한다.

```text
좋아, 이제 그린다. STEP 1 — 헤더와 ① 연구 배경 · ② 우리 방법 · ③ 측정 설계, 이렇게 헤더와 세 섹션을 생성해줘. ④⑤는 다음 STEP에서 이어서 만든다.

세로 1단으로, 위에서 아래로 헤더 → ① → ② → ③ 순으로 쌓는다. 각 섹션 사이에는 흰 여백과 navy 가는 가로 구분선을 둔다. 각 섹션의 핵심 데이터 묶음은 옅은 틴트(투명도 5~8%)의 라운드 패널로 감싼다.

[헤더]
- 배경은 흰색(틴트 없음).
- 좌상단에 거대한 워드마크 "속도는벡터" — "속도는"은 navy, "벡터"는 청록(#0EA5E9)으로 칠해 두 색을 잇는다.
- 워드마크 바로 위에 짧은 청록 액센트 바를 둔다.
- 우상단에 "연세대학교 / 2026 캡스톤 디자인"을 navy로 작게, 오른쪽 정렬.
- 워드마크 아래에 부제를 navy 굵게: "벡터 분석 쿼리의 카디널리티 추정을 위한 분포 인지 표본 선택".
- 부제 아래 팀원 줄을 옅은 회색 작은 글씨로: "박세은 · 강재현 · 조현빈 · 이동욱 · 지도교수 박광현 교수".
- 헤더 하단에 navy 가는 가로 구분선.

[① 연구 배경]
- 섹션 헤더: 청록 채움 번호 원 "①" + navy 굵은 제목 "연구 배경". 제목 왼쪽에 청록 굵은 세로 구분바. 제목 아래 리드문 한 줄: "데이터베이스는 쿼리를 실행하기 전, 조건을 만족하는 행이 몇 개일지 — 카디널리티 — 를 추정한다. 이 추정이 틀리면 잘못된 실행 계획으로 쿼리가 느려진다."
- 레이아웃: 왼쪽 60%에 쿼리 실행 흐름도, 오른쪽 40%에 고정 비율 카드 두 개. 전체를 청록 5% 틴트 라운드 패널로 감싼다.
- 쿼리 실행 흐름도(왼쪽): 가로로 "쿼리 → [카디널리티 추정] → 실행 계획 → 갈림길". 갈림길은 위로 "빠른 쿼리", 아래로 "느린 쿼리"로 갈라진다. 각 박스는 흰 배경에 navy 테두리. 단 [카디널리티 추정] 박스만 청록으로 채운다. "빠른 쿼리"는 그린 톤, "느린 쿼리"는 코랄 톤으로 표시한다.
```
