## Slide 9 — ★ P1 Cluster method 알고리즘

### Layout (2 column, 각 column = 1 method)

**Column 1: minibatch_partial** (Sculley 2010)
- 알고리즘: MiniBatchKMeans + `partial_fit` (sub-batch 단계별 학습)
- step diagram:
  ```
  input → batch 1 → partial_fit → centers
       → batch 2 → partial_fit → centers (update)
       → ... → final centers → 표본 → stratum_id
  ```
- 시간 복잡도: O(batch × K × d) per batch
- reference: "Sculley 2010 (KDD)"

**Column 2: gmm** (Dempster-Laird-Rubin 1977 EM)
- 알고리즘: Gaussian Mixture Model with EM
- step diagram:
  ```
  input → initial μ_k, Σ_k, π_k
       → E-step: P(z=k | x)
       → M-step: μ_k, Σ_k, π_k update
       → 수렴까지 iter → 표본 → stratum_id
  ```
- 본 측정: `covariance_type='diag'` + `reg_covar=1e-2` (SIFT 128d / SSN 256d cholesky fail 회피)
- reference: "Dempster-Laird-Rubin 1977 (JRSS)"

- 우상단 라벨 (navy): "표본을 cluster center에 매핑 → stratum_id"

### speaker note
> "P1 Cluster paradigm은 두 method입니다. minibatch_partial은 Sculley 2010의 partial_fit으로 미니배치 K-means를 단계별로 학습합니다. gmm은 Dempster-Laird-Rubin 1977의 EM 알고리즘으로 Gaussian Mixture를 적합합니다. 둘 다 표본을 cluster center에 매핑해 stratum_id를 부여하는 방식입니다. 뒤에서 보겠지만 이 클러스터링 계열은 본 측정에서 다소 불안정합니다."

## Slide 10 — ★ P2 Spatial method 알고리즘

### Layout (4 column, 각 column = 1 method)

**Column 1: hilbert_real** (Faloutsos 1989)
- 알고리즘: Hilbert curve indexing — 고차원 벡터를 1D scalar로 매핑
- step diagram:
  ```
  벡터 → PCA 2D/3D → Hilbert curve → 1D scalar
       → quantile 분할 K=20 → stratum_id
  ```
- 본 측정: raw Wikipedia Hilbert curve 표준 구현 (정직하게 명명된 구현 사용)
- reference: "Faloutsos 1989 (PODS)"

**Column 2: zorder_morton** (Morton 1966)
- 알고리즘: Z-order space-filling curve — bit interleaving
- step diagram:
  ```
  벡터 → PCA 저차원 → 각 dim binary
       → bit interleaving → quantile 분할 → stratum_id
  ```
- reference: "Morton 1966 (IBM)"

**Column 3: skilling_hilbert** (Skilling 2004)
- 알고리즘: state-machine 기반 true 고차원 Hilbert curve
- step diagram:
  ```
  벡터 → unit cube 정규화 → state-machine 고차원 Hilbert
       → 1D scalar → quantile 분할 → stratum_id
  ```
- reference: "Skilling 2004 (AIP Conf Proc 707:381-387)"

**Column 4: faiss_ivf** (Johnson-Douze-Jégou 2017)
- 알고리즘: IVF (Inverted File Index) — coarse quantizer로 벡터를 cluster에 매핑
- step diagram:
  ```
  벡터 → coarse quantizer (K-means K=20)
       → cluster 매핑 → stratum_id = cluster id
  ```
- reference: "Johnson-Douze-Jégou 2017 (FAISS, IEEE)"

- 우상단 라벨: "공간 구조 기반 stratum 부여 (space-filling curve · IVF)"

### speaker note
> "P2 Spatial paradigm은 네 method입니다. hilbert_real은 Faloutsos 1989의 Hilbert curve로 고차원 벡터를 1차원 스칼라로 매핑합니다. zorder_morton은 Morton 1966의 Z-order curve로 비트 인터리빙을 합니다. skilling_hilbert는 Skilling 2004의 state-machine 알고리즘으로 진짜 고차원 Hilbert curve를 계산합니다. faiss_ivf는 Johnson 외 2017의 IVF로 벡터를 가장 가까운 cluster에 매핑합니다. 앞의 세 method는 space-filling curve로 1차원 스칼라를 만든 뒤 quantile로 나누고, faiss_ivf는 IVF 클러스터로 stratum_id를 부여합니다."

## Slide 11 — ★ P3 Streaming method 알고리즘

### Layout (1 method 상세, full slide)

**Method: chao_weighted** (Chao 1982 *Biometrika*)
- 알고리즘: Weighted reservoir sampling (priority queue 기반)
- step diagram (큰 박스, 좌→우):
  ```
  input 벡터
     → weight 부여 (예: norm 또는 anomaly score)
     → priority queue (size K=20)
     → weighted random 표본
     → K stratum 분포 인지 부여 → stratum_id
  ```
- 시간 복잡도: O(n × log K) priority queue insert/pop
- 메모리: O(K) priority queue — 매우 compact
- 본 측정: 단일 pass로 데이터셋 streaming 처리
- reference: "Chao 1982 — A general purpose unequal probability sampling plan (*Biometrika*)"

- 우측 칼럼 (navy 박스):
  - 제목: "정확도 상위 method"
  - bullet: "메모리 O(K)로 compact"
  - bullet: "단일 pass streaming 친화"
  - bullet: "16 method 중 정확도 상위권 (median Δ% −6.22%, better 100%)"

### speaker note
> "P3 Streaming paradigm은 chao_weighted 한 method입니다. Chao 1982 Biometrika의 weighted reservoir sampling으로, priority queue를 기반으로 합니다. 각 벡터에 weight를 부여하고, 크기 K=20의 priority queue에서 weighted random 표본을 뽑아 stratum을 부여합니다. 시간은 O(n log K), 메모리는 O(K)로 매우 compact합니다. 단일 pass로 streaming 처리가 가능하고, 16개 method 중 median Δ% −6.22%로 정확도 상위권이며 측정한 모든 cell에서 대조군을 이깁니다."

## Slide 12 — ★ P4 DimReduction method 알고리즘

### Layout (4 column, 각 column = 1 method)

**Column 1: sparse_rp** (Li-Hastie-Church 2006)
- 알고리즘: Very Sparse Random Projection
- step diagram:
  ```
  벡터 → sparse matrix (density ~1/√d)
       → random projection → projected 벡터
       → quantile 분할 K=20 → stratum_id
  ```
- 시간 복잡도: O(n × k × d × density)
- reference: "Li-Hastie-Church 2006 (KDD)"

**Column 2: pca1d** (Pearson 1901)
- 알고리즘: PCA → 1D projection
- step diagram:
  ```
  벡터 → covariance matrix SVD
       → 1st principal component projection (1D scalar)
       → quantile 분할 K=20 → stratum_id
  ```
- 시간 복잡도: O(n × d²) covariance + O(d³) SVD
- reference: "Pearson 1901 (Phil. Mag.)"

**Column 3: rsvd** (Halko-Martinsson-Tropp 2011)
- 알고리즘: Randomized SVD — 대규모 PCA
- step diagram:
  ```
  벡터 → random sketch (Gaussian)
       → low-rank approximation → power iter
       → truncated SVD → 1D projection → stratum_id
  ```
- reference: "Halko-Martinsson-Tropp 2011 (SIAM Rev.)"

**Column 4: ica_fastica** (Hyvärinen 1999)
- 알고리즘: FastICA — non-Gaussian 독립성
- step diagram:
  ```
  벡터 → centering + whitening
       → fixed-point iter → non-Gaussianity max
       → independent component → 1D projection → stratum_id
  ```
- 시간 복잡도: O(n × d²) iteration
- reference: "Hyvärinen 1999 (IEEE TNN)"

- 우상단 라벨: "저차원 projection → quantile 분할 → stratum_id"

### speaker note
> "P4 DimReduction paradigm은 네 method입니다. sparse_rp는 Li-Hastie-Church 2006의 very sparse random projection입니다. pca1d는 Pearson 1901의 PCA로 첫 주성분에 1차원 투영합니다. rsvd는 Halko-Martinsson-Tropp 2011의 randomized SVD로 대규모 PCA를 다룹니다. ica_fastica는 Hyvärinen 1999의 FastICA로 non-Gaussian 독립 성분을 찾습니다. 넷 다 저차원으로 투영한 뒤 quantile로 나눠 stratum_id를 부여합니다."

## Slide 13 — ★ P5 QMC method 알고리즘

### Layout (2 column, 각 column = 1 method)

**Column 1: cum_sqrtf** (Dalenius-Hodges 1959)
- 알고리즘: Minimum Variance Stratification (cumulative √f)
- step diagram:
  ```
  벡터 → 1D projection (예: PCA 1st PC)
       → cumulative √frequency 계산
       → K=20 등간격 분할 → stratum_id
  ```
- 본 측정: classical stratification 정통 (JASA 1959 verbatim)
- reference: "Dalenius-Hodges 1959 (JASA)"

**Column 2: lavallee_hidiroglou** (Lavallée-Hidiroglou 1988)
- 알고리즘: take-all stratum + Neyman allocation
- step diagram:
  ```
  벡터 → magnitude 정렬 (내림차순)
       → top-N take-all stratum (큰 값 전수)
       → 나머지 → Neyman allocation → stratum 분할 → stratum_id
  ```
- 본 측정: skew long-tail 데이터셋 효과 (Survey Methodology 1988 verbatim)
- reference: "Lavallée-Hidiroglou 1988 (Survey Methodology)"

- 우상단 라벨: "classical stratification mechanism"

### speaker note
> "P5 QMC paradigm은 두 method입니다. cum_sqrtf는 Dalenius-Hodges 1959의 cumulative √f 방식으로, 최소 분산 stratification의 정통 기법입니다. lavallee_hidiroglou는 Lavallée-Hidiroglou 1988의 take-all stratum과 Neyman allocation을 결합한 방식으로, 큰 값을 전수 조사하는 stratum을 따로 두어 skew된 long-tail 데이터셋에 효과적입니다. 둘 다 분포를 stratum으로 나누는 classical stratification mechanism입니다."

## Slide 14 — ★ P6 Quantization method 알고리즘

### Layout (2 column, 각 column = 1 method)

**Column 1: rabitq_strat** (Gao-Lin 2024 VLDB Best Paper)
- 알고리즘: RaBitQ — sign 기반 quantization
- step diagram:
  ```
  벡터 → random projection (Gaussian)
       → sign per dim (>0 → 1 / ≤0 → 0)
       → binary code → K=20 quantile 분할 → stratum_id
  ```
- reference: "Gao-Lin 2024 (VLDB Best Paper)"

**Column 2: mhist2** (Poosala 1997 VLDB)
- 알고리즘: MHIST — 다차원 histogram
- step diagram:
  ```
  벡터 → d차원 multi-dim histogram bucket
       → max variance split iter
       → bucket id → stratum_id
  ```
- reference: "Poosala 1997 (VLDB)"

- 우상단 라벨: "quantization 기반 stratum 부여"

### speaker note
> "P6 Quantization paradigm은 두 method입니다. rabitq_strat은 Gao-Lin 2024 VLDB Best Paper의 RaBitQ로, 차원마다 부호를 보고 binary code를 만들어 quantization합니다. mhist2는 Poosala 1997 VLDB의 MHIST로 다차원 histogram bucket을 분산이 최대인 방향으로 분할합니다. 둘 다 quantization 결과를 stratum_id로 부여합니다."

## Slide 15 — ★ P9 InfoTheoretic method 알고리즘

### Layout (1 method 상세, full slide)

**Method: hyperloglog** (Flajolet-Fusy-Gandouet-Meunier 2007 AofA)
- 알고리즘: HyperLogLog — cardinality estimation sketch (본 연구는 이 sketch를 stratum 부여에 활용)
- step diagram (큰 박스, 좌→우):
  ```
  벡터 → hash function → uniform random bit
       → leading zero count
       → register (m buckets) max update
       → harmonic mean → stratum 부여 → stratum_id
  ```
- 메모리: O(m × log log n) — 매우 compact
- reference: "Flajolet-Fusy-Gandouet-Meunier 2007 (AofA)"

- 우측 칼럼 (navy 박스):
  - 제목: "정확도 상위 method"
  - bullet: "메모리 O(m × log log n)로 매우 compact"
  - bullet: "sketch 기법 정통"
  - bullet: "16 method 중 정확도 상위권 (median Δ% −4.58%, better 100%)"

### ★ 주의 (speaker note에서 강조)
> "주의할 점이 하나 있습니다. HyperLogLog는 원래 cardinality를 추정하는 sketch 알고리즘으로 잘 알려져 있습니다. 하지만 본 연구에서는 그 sketch의 결과를 cardinality 추정값으로 쓰는 것이 아니라, 표본을 stratum으로 나누는 입력으로 활용합니다. 즉 HyperLogLog는 본 연구에서 sample selection 단계의 도구이지, cardinality 추정 알고리즘이 아닙니다."

### speaker note
> "P9 InfoTheoretic paradigm은 hyperloglog 한 method입니다. Flajolet 외 2007 AofA의 HyperLogLog로, 해시값의 leading zero를 세고 register를 갱신한 뒤 조화 평균을 냅니다. 한 가지 주의할 점은, HyperLogLog는 원래 cardinality 추정 sketch로 알려진 알고리즘이라는 것입니다. 본 연구에서는 그 결과를 cardinality 추정값으로 쓰지 않고, 표본을 stratum으로 나누는 입력으로만 활용합니다. 메모리가 O(m log log n)로 매우 compact하고, median Δ% −4.58%로 정확도 상위권입니다."

## Slide 17 — ★ dynamic 할당 mechanism flow

### Layout (큰 flow diagram, 세로)

```
┌────────────────────────────────┐
│ [데이터셋 진입]                │
└────────────────────────────────┘
         ↓
┌────────────────────────────────┐
│ Step 1: dataset profile         │
│ (행 수 / structure / 차원)      │
└────────────────────────────────┘
         ↓
┌────────────────────────────────┐
│ Step 2: Type 판별               │
│ (Type 1/2/3/4a/4b 중 하나)      │
└────────────────────────────────┘
         ↓
┌────────────────────────────────────────────┐
│ Step 3: Type별 권장 sample selection method │
│ (정확도 상위 method 중 데이터 특성에 맞춰)  │
└────────────────────────────────────────────┘
         ↓
┌────────────────────────────────┐
│ Step 4: CaseB ensemble         │
│ est_final = (est_b1 + est_method) / 2 │
└────────────────────────────────┘
         ↓
┌────────────────────────────────┐
│ [paper §V-B Adaptive Eq 1-6     │
│  보정 (그대로 유지)]            │
└────────────────────────────────┘
```

- 우상단 navy 박스: "★ sample selection 단계만 dynamic"
- 우하단 회색 박스: "paper Adaptive Eq 1-6은 dynamic이 아님 — 그대로 유지"

### speaker note
> "본 연구가 제안하는 dynamic 할당 흐름입니다. 데이터셋이 들어오면 먼저 행 수, 구조, 차원으로 profile을 만들고, 다섯 Type 중 어디에 속하는지 판별합니다. 그다음 그 Type의 데이터 특성에 맞는 표본 선택 method를 정확도 상위 method 중에서 선택합니다. 선택한 method로 CaseB ensemble을 구성하고, 이후 paper의 Adaptive Eq 1-6 momentum 보정을 그대로 적용합니다. 분명히 할 점은, dynamic하게 바뀌는 것은 표본 선택 단계 하나라는 것입니다. paper의 Adaptive Eq 1-6은 dynamic이 아니라 그대로 유지됩니다."
