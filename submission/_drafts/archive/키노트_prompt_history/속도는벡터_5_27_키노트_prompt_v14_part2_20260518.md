## 슬라이드 상세 (slide 11~20)

### slide 11 — 세 방식 비교: 완전 대체는 불안정, 결합이 답

**화면**
- 상단 제목: "완전 대체는 불안정하다 — 결합이 답이다"
- 두 수치를 **좌우로 나란히** 배치한다 (세로로 쌓지 말 것 — 세로로 쌓으면 아래 박스가 슬라이드 밖으로 잘린다):
  - 왼쪽: 완전 대체 — 기존 방식보다 나은 경우 **35.2%**
  - 오른쪽: 결합 — 기존 방식보다 나은 경우 **89.1%** (강조 색)
- 두 박스 모두 슬라이드 세로 범위 안에 완전히 들어오게 한다
- 하단 한 줄: 표본을 통째로 바꾸면 우리 방법이 강할 때만 좋고 약할 때 크게 나빠진다 — 두 추정값을 결합하면 안정적으로 개선된다

**발표 멘트**
- "그렇다면 무작위 표본을 우리 표본으로 통째 바꾸면 어떨까요? 그렇게 한 것이 완전 대체인데, 기존 방식보다 나은 경우가 35%뿐이었습니다. 우리 방법이 강할 때는 좋지만, 약할 때는 오히려 크게 나빠집니다."
- "반면 두 추정값을 결합하면 89%에서 개선됩니다. 논문 방식이 일종의 안전망 역할을 하기 때문입니다. 그래서 통째 교체가 아니라 결합이 답이라는 결론에 이르렀습니다. 효과가 없을 수 있는 완전 대체를 일부러 측정해, 개선의 원천이 결합 자체에 있음을 확인한 것입니다."

### slide 12 — 방법별 정확도: 16가지 중 14가지가 안정적으로 우월

**화면**
- 상단 제목: "16가지 방법 중 14가지가 기존 방식을 안정적으로 이긴다"
- 가운데~우측 가로 막대 그래프: 16가지 방법을 추정 오차 개선폭 순으로 **16개 모두 개별 막대로** 표시한다. "…나머지 N가지"처럼 묶지 않는다 (묶으면 개수를 틀리기 쉽다). 막대 값(개선폭 중앙값, 음수가 개선):

  | 방법 | 개선폭 |
  |---|---|
  | 가중 표본 추출 | −6.2 |
  | Hilbert 곡선 | −5.9 |
  | 고차원 Hilbert 곡선 | −5.8 |
  | 독립성분 분석 | −5.7 |
  | 주성분 분석 | −5.6 |
  | Z-order 곡선 | −4.9 |
  | HyperLogLog | −4.6 |
  | 누적 제곱근 층화 | −4.5 |
  | Lavallée–Hidiroglou 층화 | −4.4 |
  | 희소 랜덤 투영 | −4.4 |
  | 랜덤 SVD | −4.1 |
  | 미니배치 K-means | −3.6 |
  | RaBitQ 양자화 | −3.6 |
  | 다차원 히스토그램 | −3.4 |
  | IVF 클러스터링 | −2.7 |
  | 가우시안 혼합 모델 | +2.7 |

  - 가우시안 혼합 모델 1개만 양수(반대 방향) — 색을 다르게
- 좌측: "14 / 16" 큰 수치 + "공간 곡선·차원 축소·층화 계열이 안정적. 클러스터링 계열 둘(가우시안 혼합 모델·미니배치 K-means)만 약해 권장에서 제외"
- 한 줄: 음수가 개선 — 16개 중 14개가 모든 조건에서 안정적으로 우월

**발표 멘트**
- "열여섯 가지 방법을 정확도 순으로 줄 세운 결과입니다. 열네 가지는 모든 측정 조건에서 안정적으로 기존 방식을 이겼습니다. 공간 곡선과 차원 축소 계열이 특히 좋았습니다."
- "약한 것은 클러스터링 계열 둘입니다. 가우시안 혼합 모델은 기존 방식보다 못했고, 미니배치 K-means는 가장 큰 데이터에서 불안정했습니다. 그래서 클러스터링 계열은 권장 방법에서 제외했습니다."

### slide 13 — 선택도 효과: 단조 증가

**화면**
- 상단 제목: "선택도가 높을수록 더 안정적으로 개선된다"
- 가운데 막대 그래프 세 개:
  - 선택도 낮음 → 83.3%
  - 선택도 중간 → 87.6%
  - 선택도 높음 → 97.5%
- 한 줄: 선택도 = 전체 데이터 중 조건을 만족하는 비율 · 높을수록 우월 비율이 꾸준히 커진다

**발표 멘트**
- "선택도는 전체 데이터 중 쿼리 조건을 만족하는 비율을 말합니다. 선택도가 낮을 때, 중간일 때, 높을 때로 나눠 보면, 결합 방식이 기존 방식을 이기는 비율이 83%, 88%, 98%로 꾸준히 올라갑니다."
- "조건에 맞는 데이터가 많을수록 분포를 반영한 표본의 이점이 더 분명하게 드러나는 것입니다."

### slide 14 — 데이터 구조: 단일·다중 모두 일관

**화면**
- 상단 제목: "단일 벡터와 다중 벡터 모두에서 일관되게 우월"
- 가운데 큰 수치 두 개:
  - 단일 벡터 89.1%
  - 다중 벡터 89.2%
- 한 줄: 데이터 구조가 달라져도 우월 비율이 거의 같다

**발표 멘트**
- "데이터 구조를 단일 벡터와 다중 벡터로 나눠 비교했습니다. 두 경우 모두 결합 방식이 기존 방식을 이기는 비율이 89%로 거의 같았습니다."
- "한 행에 벡터가 하나든 여럿이든, 효과가 흔들리지 않는다는 뜻입니다."

### slide 15 — 계층 수: 20개로 나눌 때가 가장 좋다

**화면**
- 상단 제목: "데이터를 20개 계층으로 나눌 때가 가장 좋다"
- 가운데 막대 그래프 세 개:
  - 10개 계층 → 83.3%
  - 20개 계층 → 89.6%
  - 30개 계층 → 85.4%
- 한 줄: 계층이 너무 적으면 분포를 충분히 나누지 못하고, 너무 많으면 계층마다 표본이 얇아진다
- v12·v13 같은 내부 버전 표현은 넣지 않는다

**발표 멘트**
- "데이터를 몇 개의 계층으로 나눌지도 실험했습니다. 열 개, 스무 개, 서른 개로 나눠 보니 스무 개일 때가 가장 좋았습니다."
- "계층이 너무 적으면 쏠린 분포를 충분히 나누지 못하고, 너무 많으면 계층마다 표본이 얇아져 불안정해집니다. 스무 개가 그 균형점이었고, 이는 논문이 기본값으로 쓴 값과도 일치합니다."

### slide 16 — 자원 효율: 정확도와 분포 파악 시간

**화면**
- 상단 제목: "정확도와 분포 파악 시간의 균형"
- 가운데 점 그래프 (figure F7 참조): 가로축 = 분포 파악에 걸리는 시간, 세로축 = 정확도 개선폭
  - 각 점에 방법 이름은 사람이 읽는 이름으로 (가중 표본 추출 · 희소 랜덤 투영 · Hilbert 곡선 · 가우시안 혼합 모델 등)
  - ★ 점 라벨이 축 눈금이나 다른 라벨과 겹치지 않도록 간격 확보
- 오른쪽에 짧게:
  - 가중 표본 추출 — 정확도와 속도의 균형점
  - 희소 랜덤 투영 — 분포 파악이 가장 빠름
  - Hilbert 곡선 — 정확도는 최고, 파악은 느림

**발표 멘트**
- "방법을 고를 때는 정확도뿐 아니라, 데이터가 들어올 때 분포를 파악하는 데 걸리는 시간도 봐야 합니다. 이 그래프는 두 축을 함께 보여 줍니다."
- "분포 파악이 빨라야 하면 희소 랜덤 투영, 정확도가 최우선이면 Hilbert 곡선, 둘의 균형이 필요하면 가중 표본 추출을 고르면 됩니다. 정확도가 낮은 방법은 대체로 속도도 느려서 쓸 이유가 없었습니다."

### slide 17 — 자동 선택: 데이터 유형을 보고 방법을 고른다

**화면**
- 상단 제목: "데이터 유형을 보고 표본 선택 방법을 자동으로 고른다"
- 가운데 단계 도식 (위에서 아래로):
  1. 데이터가 들어온다
  2. 데이터 유형을 판별한다 (크기·구조·차원)
  3. 그 유형에 맞는 표본 선택 방법을 자동으로 고른다
  4. 결합 방식으로 카디널리티를 추정한다
- 한 줄: 방법을 사람이 매번 고르지 않고, 데이터 유형에 따라 자동으로

**발표 멘트**
- "측정 결과를 종합해, 저희는 데이터 유형에 따라 표본 선택 방법을 자동으로 고르는 방식을 제안합니다."
- "데이터가 들어오면 크기와 구조, 차원을 보고 유형을 판별하고, 그 유형에 가장 잘 맞는 방법을 골라 결합 방식으로 추정합니다. 사람이 매번 방법을 고르지 않아도 되도록 한 것입니다."

### slide 18 — 결론

**화면**
- 상단 제목: "결론"
- 핵심 결과 네 가지를 큰 글씨로 간결하게:
  1. 분포를 반영한 표본 선택이 추정 오차를 89.1%에서 줄였다
  2. 통째 교체는 불안정 — 두 추정값의 결합이 답이다
  3. 선택도·데이터 구조·계층 수 모든 조건에서 일관되게 우월하다
  4. 데이터 유형에 따라 방법을 자동으로 고르는 방식을 제안한다
- 한 줄: 표본을 뽑는 방식을 바꾸는 것만으로 추정이 더 정확해진다

**발표 멘트**
- "정리하겠습니다. 첫째, 무작위 대신 분포를 반영해 표본을 뽑으면 카디널리티 추정이 89%에서 더 정확해졌습니다. 둘째, 통째 교체는 불안정하고 두 추정값을 결합하는 것이 답이었습니다."
- "셋째, 이 효과는 선택도, 데이터 구조, 계층 수 어느 조건에서도 일관됐습니다. 넷째, 데이터 유형에 따라 방법을 자동으로 고르는 방식을 제안했습니다. 추정 알고리즘은 그대로 두고, 표본을 뽑는 방식만 바꾼 결과입니다."

### slide 19 — 한계와 다음 단계

**화면**
