**화면**: Skew-Aware Stratified Sampling for Vector-Augmented Analytical Query

**풀어 말하면**:

- "Stratified Sampling" = 분포를 cluster (strata) 로 나누고 각 cluster 에서 sampling

**비유**: 시험 점수 조사할 때, "전체 학생 중 무작위로 100명" (random) 보다 "각 학년에서 25명씩" (stratified) 가 더 정확한 평균. 학년별 분포 차이 (skew) 를 알면 stratified 가 더 정확.

**결론**: 분포 정보 활용 = 정확도 ↑

## 🔍 Slide 3 (Problem) — 무엇이 문제인가

**화면**: pgvector 33.3% / VBASE 50% / DuckDB 100%

**풀어 말하면**:
- 기존 vector DB 들은 cardinality (= query 결과 row 수) 추정할 때 **고정 비율** 사용
- pgvector = "전체의 33%일 거야" 무조건 가정
- 그러나 실제 query 의 selectivity 는 **0.001%~90%** 까지 매우 다양
- 잘못된 가정 → 잘못된 plan (예: hash join vs nested loop) → 1000~10000× 느린 query

**비유**: 식당에서 "오늘 손님 100명" 라고 매일 똑같이 가정 → 실제 50명 와도, 200명 와도 다 잘못 준비. 적절한 손님 수 예측이 필수.

**결론**: 고정 비율 = "기술적으로 좋은 추정" 이지만 "실행 계획에 진짜 도움 되는 추정" 이 아님 → 그 간극을 메우는 게 본 연구.

## 📐 Slide 6 (RQ1) — 분포 차이가 정확도에 영향 주는가? → "그렇다"

**화면**: 12 cell × ρ < 0 100% 일관 (-0.366 ~ -0.609)

**풀어 말하면**:
- **12 cell** = 5 dataset (DEEP/SIFT/SSN/WIKI/YFCC) × 2 scale (sf1/sf10) × 1~2 method
- **ρ (Spearman rho)** = -1~+1 범위의 상관계수. selectivity 와 추정 오차의 단조 관계 강도
- **ρ < 0** = "selectivity 가 커질수록 추정 오차는 작아진다" (단조 감소)
- **100% 일관** = 12 cell 모두 ρ < 0 (예외 없음)
- **DEEP_sf1 KM20** 의 ρ = -0.680 [-0.800, -0.440] 95% 신뢰구간이 0 을 제외 → 통계적 유의

**비유**: 키 측정 정확도. 1000명 측정하면 평균 잘 맞고 (selectivity 큼 → 오차 작음), 10명만 측정하면 평균 부정확 (selectivity 작음 → 오차 큼). 표본 크기 효과의 단조 관계.

**결론**: 분포 차이 (selectivity 차이) 가 추정 오차에 일관되게 영향 → RQ1 답: "그렇다, 단조적으로"

## 🎲 Slide 7 (RQ2) — 분포 알 때 활용 효과? → "강력"

**화면**: 51/52 cells CI 0 제외 (sel=0.10) + σ-allocation 격차 < 1% (7/12 cell)

**풀어 말하면**:
- **51/52 cell** = 12 cell × 4 mode (BERN/proportional/Neyman/Anti-Neyman) - 1 outlier
- **CI 0 제외** = paired 통계로 "분포 활용 효과 ≠ 0" 통계적 유의 (즉 분포 활용 효과 99% 신뢰)
- **σ-allocation 격차 < 1%** = Neyman vs Anti-Neyman 의 차이가 1% 이내 (7/12 cell)
- **결론**: 분포 활용 효과는 강력하지만, σ 정확성 (Neyman) 보다 "분포 인지 자체" 가 결정적 — 단순 균등 stratification 으로 충분

**Anti-Neyman counterfactual**: "σ 를 *반대로* 쓰면 systematically 나빠짐" (DEEP +5.21%, SIFT +9.49% CI 0 제외) → σ 신호가 약하지만 *존재함* 을 정량 증명 (negative control)

**비유**: 인구 조사. 연령대별 sample size 를 정확하게 (Neyman) vs 균등 (proportional) → 결과 거의 같음. 그러나 정반대로 (Anti-Neyman) → 명확히 나빠짐 → "균등도 충분, 정확도는 marginal"

**결론**: 분포 활용 효과 강력. 단순 균등 stratification 충분. σ 정확성은 marginal.

## ⭐ Slide 9 (Hilbert + Tier 1 17종 spread)

**화면**: Tier 1 17 method spread 1.21%p (HDBSCAN −8.04 ~ kdtree −6.83)

**풀어 말하면**:
- 30 method 중 **17종이 "Tier 1"** (살아남는 method). 나머지 13종은 가지치기.
- Tier 1 17종의 평균 Δ% **차이 = 단 1.21%p** (HDBSCAN 1위 −8.04% ~ kdtree 17위 −6.83%)
- 즉 **"어느 분포 인지 method 든 Tier 1 이면 OK"** → method choice 부차

**핵심 결론**: **"method 선택보다 '분포 인지 vs 미인지' boundary 가 결정적"**

**비유**: 같은 학원 다닌 17명 학생들의 성적 차이가 단 1점 → 학원 자체가 좋은 거지 (분포 인지) 어느 선생님 만나도 별 차이 없음 (method 선택 부차).

**Hilbert 의 위치**: 4강 중 #3 = 학습 비용 0 + production sweet spot. 즉 "공짜로 90% 효과" 의 가치.
- inverse Manhattan distance 보존: Hilbert 1.000 vs Z-order 1.992 → 거리 보존이 정확히 2× 좋음 (locality preservation)

## 🚀 Slide 10 (MiniBatch K-means)

**화면**: 1,189× speedup + ARI 1.000 + CI ex 9/10

**풀어 말하면**:
- **MiniBatch K-means** = full K-means 의 빠른 버전 (mini-batch update 으로 incremental learning)
- **1,189× speedup** = full K-means 의 1/1189 시간에 학습 (분 → 초)
- **ARI 1.000** (Adjusted Rand Index) = clustering 결과 정확도 = full K-means 와 **완전 동일**
- **CI ex 9/10** = 4강 중 가장 강력한 statistical robustness

**특징**: `partial_fit` 가능 → streaming 환경에서 OLTP friendly. 즉 production 에서 새 데이터 들어올 때마다 cluster 갱신 가능 (online learning).

**비유**: "빠른 사진 vs 정밀 사진. 같은 사진을 1/1000 시간에 찍었는데 화질 동일 → production 에서는 빠른 사진 채택"

**결론**: MB_partial = "정확도 동일 + 1000× cheaper + OLTP-ready" → production 채택의 결정적 근거.

## 🎯 Slide 11 (Sweet Spot 정량 boundary)

**화면**: cluster_ratio > 1.4 + intrinsic_dim < 0.85 → SWEET / 반대 → CEILING

**풀어 말하면**:
- "분포가 어떻게 생긴 dataset 에서 본 method 가 강력한가" 의 **정량 정의**
- **cluster_ratio** = 가장 큰 cluster / 가장 작은 cluster 크기 비율 (1.0 = 완전 균등, > 1 = 불균형)
- **intrinsic_dim** = 데이터의 본질적 차원 (PCA 누적 분산 비율, 0.85 = 80% 정보 위해 차원의 85% 필요)

**SWEET 영역** (cluster_ratio > 1.4 + intrinsic_dim < 0.85):
- 분포 인지 효과 강력 = **−7%~−32%**
- 해당 dataset: SIFT (1.65 / 0.71), WIKI (1.84 / 0.81), YFCC (~1.5 / ~0.85)

**CEILING 영역** (cluster_ratio < 1.4 + intrinsic_dim > 0.85):
- 분포 균형 → BERN baseline 자체가 이미 ceiling → method 효과 약 (**+1~+2%**)
- 해당 dataset: SSN++ (1.29 / 0.88) — uniform-like distribution

**비유**: 길거리 sample. 강남 (분포 다양, ratio 큼) → 응답 결과 불균형 → sampling 으로 정확 측정. 시골 마을 (분포 균질, ratio 작음) → 어차피 다 비슷 → sampling 효과 작음.

**결론**: 두 metric 으로 distribution sweet spot 정량 경계 정의 → 적절한 분포에서만 분할이 효과 (Negative Control 본질).

## ⚠️ Slide 13 (Mechanism + Multi 25.2× shrinkage) — **가장 중요**

**화면**: 단일 17.13% → multi-vector 0.67% → multi-join 0.68% = **25.2× 약화**

**풀어 말하면**:
- **단일 sweet spot 4강 평균 |Δ%| = 17.13%** (SIFT_sf1 / WIKI_sf1 / YFCC_sf1)
- **multi-vector 4강 평균 |Δ%| = 0.67%** (deep_sift_10 + deep_wiki_10)
- **multi-table-join 4강 평균 |Δ%| = 0.68%** (partsupp_deep_10 ⨝ part_wiki_10, 8M JOIN, FK 4-to-1)
- **25.2× = 17.13 / 0.68** — magnitude 약화 비율, multi-vector 와 multi-join 거의 동일

**핵심 메시지**:
> 단일 정확성은 multi 정확성의 ***필요조건* 만 성립, *충분조건* 은 아님**

**직관적**: 단일 잘 ≠ multi 잘. 단일 못 → multi 도 못 가능. 단일 잘 → multi 약 가능. multi-vector 와 multi-table-join 의 magnitude 가 거의 동일 → **shrinkage 발생 지점 = "vector 수 증가" 단계**, table join 은 추가 약화 없음.

**multi cell 측정 결과 (sel=0.10)**:

| Cell | Type | 4강 paired Δ% (hdb / hil / hyb / mb_p) | 부호 |
|---|---|---|---|
| partsupp_deep_sift_10 (96+128 dim) | multi-vector | -1.02 / -0.48 / +0.31 / -1.30 | 3/4 negative |
| partsupp_deep_wiki_10 (96+768 dim) | multi-vector | +1.15 / +0.06 / +0.08 / +0.99 | 0/4 negative (boundary) |
| partsupp_deep_10⨝part_wiki_10 | multi-table join (8M JOIN) | +0.29 / -0.85 / -0.22 / +1.38 | 2/4 negative |

**해석**: multi 환경에서 4강 method 의 ranking 도 **노이즈 수준으로 와해** (\|Δ\| 모두 < 1.5%) → multi-relation 일반화는 **joint-aware clustering** 또는 **multi-vector decomposition** 별도 설계 필요 (future work). multi-join 의 ranking (hilbert > hybrid > hdbscan > mb_partial) 은 단일 (hdbscan > mb_partial > hilbert > hybrid) 과 거의 역순 — 4강 ranking 은 multi 환경에서 보존되지 않음.

**비유**: 한 사람 진료 (단일) 에 잘 맞는 약 → 환자 두 명 동시 진료 (multi) 에는 효과 25× 약. 병원 시스템 (multi) 은 다른 설계 필요.

**Mechanism (locality)**:
- Hilbert inverse Manhattan **1.000** vs Z-order **1.992** → Hilbert 가 거리 보존 정확히 2× 좋음
- stratum compactness gain: DEEP_1M **1.25×** / SIFT_1.5M **2.54×**

**결론**: 단일 → multi-vector → multi-join 25.2× shrinkage 가 본 연구의 **outer boundary** 정량화. multi-vector 와 multi-join 의 magnitude 가 거의 동일 → shrinkage 의 발생 지점은 join 자체가 아닌 vector 수 증가. multi-relation 일반화 future work.

## 🎯 Slide 14 (Effect Size Honesty)

**화면**: DEFF 0.338 / ESS 2,325 / 6× SRS effective sample + per-query routing ρ 0.78

**풀어 말하면**:
- **DEFF** (Design Effect) = 0.338 → SRS (단순 random sample) 대비 **1/0.338 = 3× 효율** (분산 절반 이하)
- **ESS** (Effective Sample Size) = 2,325 → 1만 샘플 중 효과적 정보 = 2,325 (SRS 대비 6×)
- **effect size d ≈ 0.3** = **practical small** (작은 효과)
- **per-query routing ρ = 0.78** → 어려운 query 에서 분포 활용 효과 **더 큼** (Q4_hard)

**Honest reporting**: 평균 effect 는 작지만, **어려운 query 에서 강력** (per-query routing 가치).

**SSN++ ceiling (boundary)**: 4강 모두 +1~+2% → 분포 균형 dataset 의 outer boundary 정의 (negative control 의 자연스러운 boundary).

**비유**: 약효. 평균적으로는 1% 효과 (작음) 지만 중증 환자 (어려운 query) 에는 강력 효과.

**결론**: effect size 작지만 (practical small), per-query routing 가치 있음. SSN++ ceiling = 본 연구의 outer boundary.

## ❓ 예상 질문 + 답변

### Q1: KM20 oracle 은 production 가능?
**A**: 아니다, oracle baseline. 그래서 4강 production-ready method 가 KM20 의 70~100% 회복. 특히 **MB_partial** = OLTP friendly (online learning).

### Q2: SSN++ 만 hurt direction (+1~+2%) 인 이유?
**A**: cluster_ratio 1.29 + intrinsic_dim 0.88 = **분포 균형** (uniform-like). BERN baseline 자체가 이미 낮음 (ceiling effect). 본 연구의 **outer boundary** 정의.

### Q3: PDX (SIGMOD 2025) 와 우리 연구의 관계?
**A**: **Complementary**. PDX = compute layer (data layout, fast similarity). 본 연구 = pre-process layer (sampling/clustering, accurate cardinality). 같은 thesis ("intrinsic_dim + skewness driven") 다른 layer.

### Q4: Tier 1 17종 spread 1.21%p 의 의미?
**A**: HDBSCAN (-8.04) ~ kdtree (-6.83) 까지 모든 Tier 1 method 가 작은 차이. 즉 **"method choice 부차, 분포 정보 인지 자체 결정적"**. 어느 method 든 Tier 1 이면 OK, 4강 = 대표.

### Q5: Multi 결과 25.4× shrinkage 는 부정적 결과 아닌가?
**A**: 아니다, **outer boundary 정량 입증** = honest finding. "단일 정확성 = multi 정확성 *필요조건* 만" → 본 연구 scope 명확화 + multi-relation 일반화 future work 정당화.

### Q6: sf100 (80M) 측정은?
**A**: 본 W4 sprint 미측정. 5/8 회의 후 자문 합의 → 5/15+ launch. DEEP/SIFT/SSN sf100 = 80M PG 적재 완료.

### Q7: 자문 메일 4 의제는?
**A**:
1. 4강 method 선정의 production cost 차별화 narrative validity
2. Distribution Sweet Spot 정량 boundary (cluster_ratio 1.4 / intrinsic 0.85) generalizability
3. Multi 일반화 검증 plan (joint-aware clustering)
4. Exqutor 통합 ensemble plan 타당성

## 📚 부록 — 자주 나오는 학술 용어 사전

| 용어 | 풀어 말하면 |
|---|---|
| **paired Δ%** | 같은 query 의 BERN 추정과 method 추정을 짝지어 비교한 % 차이. negative = improvement. |
| **CI 0 제외** | 95% 신뢰구간이 0을 포함하지 않음 = 통계적 유의 (효과 ≠ 0). |
| **Spearman ρ** | 두 변수의 단조 관계 강도 (-1~+1). negative = "더 큰 selectivity → 더 작은 오차". |
| **selectivity** | query 결과가 전체 row 의 몇 % 인가 (0.001~90%). |
| **stratified sampling** | 데이터를 cluster (strata) 로 나누고 각 cluster 에서 sampling. |
| **KM20** | K-means K=20 cluster 로 stratified (oracle baseline). |
| **BERN (bernoulli)** | 단순 random sampling baseline (각 row 독립 0/1 선택). |
| **Cohen's d** | 두 group 평균 차이의 표준화 효과 크기. \|d\|≥0.5 = medium, ≥0.8 = large. |
| **DEFF / ESS** | Design Effect / Effective Sample Size — sampling 효율 metric. |
| **HDBSCAN** | Hierarchical Density-Based Spatial Clustering of Applications with Noise. 노이즈 자동 분리 + 밀도 기반 cluster. |
| **MiniBatch K-means** | K-means 의 mini-batch update 버전. 1000× 빠름 + ARI 1.000 (full 과 동일). |
| **partial_fit** | sklearn 의 incremental learning API. streaming 환경에서 새 데이터 들어올 때마다 cluster 갱신. |
| **Hilbert curve** | space-filling curve. 다차원 공간을 1D 로 매핑하면서 locality 보존. |
| **cluster_ratio** | 가장 큰 cluster / 가장 작은 cluster 크기 비율 (1.0 = 균등, > 1 = 불균형). |
| **intrinsic_dim** | PCA 누적 분산 ratio. 0.85 = 80% 정보 위해 차원의 85% 필요. 큰 값 = 본질적으로 high-dimensional. |
