핵심 contribution 3종

★ 1. Hilbert Curve

Learning-free + 결정론 1순위

  • DEEP -1.78% / SIFT -2.47%
  • Cohen's d = -0.156
  • Mechanism: inverse Manhattan = 1.000 (Z-order 1.992)
  • Stratum compactness Z-order 대비 1.25-2.54×

★ 2. MiniBatch K-means

Production-Ready (OLTP)

  • DEEP -1.88% / SIFT -1.97%
  • KM20 vs MiniBatch: N=1M 1,189× speedup
  • partial_fit ARI = 1.000 (clustered)
  • 5/5 회의 OLTP 의문 정량 답변

★ 3. Cluster 분할 가치

Negative Control 정량 증명

  • Distance-Shell d = +0.49 (small-medium hurt)
  • Importance Sampling d = +0.5~+0.7 (medium hurt)
  • → "분할 자체가 stratification 핵심"
