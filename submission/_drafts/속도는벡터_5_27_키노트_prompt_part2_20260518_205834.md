## 슬라이드 상세 (slide 18~28)

### slide 18 — 핵심 결과

**화면**
- 제목: "결합 방식이 추정 오차를 89.1%에서 줄였다"
- 왼쪽: 거대 수치 "89.1%" + 그 아래 막대(89.1% 채워진 띠)로 비율을 한 번 더 시각화
- "결합 방식이 기존 방식보다 추정 오차를 줄인 비율 / 1508번 중 1344번 더 정확 · 추정 오차 중앙값 약 4.4% 감소"
- 오른쪽: 보조 지표 두 개를 막대로 — 통계적으로 의미 있는 개선 65% / 개선 폭이 큰 경우 72%

**발표 멘트**
- "핵심 결과입니다. 결합 방식은 1508번의 측정 중 1344번, 89.1%에서 기존 무작위 방식보다 추정 오차가 작았습니다. 줄어든 정도는 중앙값으로 약 4.4%입니다."
- "통계적으로 의미 있게 개선된 경우가 65%, 개선 폭이 뚜렷하게 큰 경우가 72%로 신호가 견고했습니다."

### slide 19 — 세 방식 비교: 완전 대체는 불안정, 결합이 답

**화면**
- 제목: "완전 대체는 불안정하다 — 결합이 답이다"
- 중앙에 **가로 막대 그래프 하나**로 두 수치를 표현한다 (★ 거대 수치 박스를 세로로 쌓지 말 것 — v14·v15에서 아래 박스가 슬라이드 밖으로 잘리는 문제가 반복됐다):
  - 막대 1 (위): 완전 대체 — 기존 방식보다 나은 경우 **35.2%** (짧은 막대)
  - 막대 2 (아래): 결합 — 기존 방식보다 나은 경우 **89.1%** (긴 막대, 강조 색)
  - 각 막대 끝에 수치 라벨
- 막대 그래프 전체가 슬라이드 세로 중앙 영역에 들어오게. 어떤 막대·라벨도 슬라이드 경계 밖으로 나가지 않게
- 두 막대 아래 작은 보조 수치 한 줄: "결합 vs 완전 대체 직접 비교 — 결합이 96.5%에서 우월" (막대를 키우지 않는 작은 텍스트, 슬라이드 안에 들어오게) ★★ 이 96.5% 한 줄을 누락하지 말 것
- 하단 한 줄: 표본을 통째로 바꾸면 우리 방법이 강할 때만 좋고 약할 때 크게 나빠진다 — 두 추정값을 결합하면 논문 방식이 안전망이 되어 안정적으로 개선

**발표 멘트**
- "무작위 표본을 우리 표본으로 통째 바꾸면 어떨까요? 그렇게 한 완전 대체는 기존 방식보다 나은 경우가 35%뿐이었습니다. 우리 방법이 강할 때는 좋지만 약할 때는 크게 나빠집니다."
- "반면 두 추정값을 결합하면 89%에서 개선됩니다. 그리고 결합 방식은 완전 대체와 직접 맞붙여 비교해도 96.5%에서 더 낫습니다. 논문 방식이 안전망 역할을 하기 때문입니다. 그래서 통째 교체가 아니라 결합이 답입니다."

### slide 20 — 방법별 정확도: 16가지 중 13가지 우월

**화면**
- 제목: "16가지 방법 중 13가지가 기존 방식을 안정적으로 이긴다"
- ★★★ 절대 "14가지"·"클러스터링 둘만 제외"로 쓰지 말 것 — 우월 13가지, 제외 3가지(가우시안 혼합 모델·미니배치 K-means·IVF 클러스터링). IVF 클러스터링은 막대가 음수(−2.7)여도 제외 3에 포함된다.
- 가운데~우측: 16가지 방법을 추정 오차 개선폭 순으로 **16개 모두 개별 가로 막대**로 표시 (묶지 않는다). 음수가 개선, 큰 개선이 위쪽:

  | 방법 | 개선폭 |
  |---|---|
  | 가중 표본 추출 | −6.2 |
  | Hilbert 곡선 | −5.9 |
  | 고차원 Hilbert 곡선 | −5.7 |
  | 독립성분 분석 | −5.7 |
  | 주성분 분석 | −5.6 |
  | Z-order 곡선 | −4.9 |
  | HyperLogLog | −4.6 |
  | 누적 제곱근 층화 | −4.5 |
  | Lavallée–Hidiroglou 층화 | −4.4 |
  | 희소 랜덤 투영 | −4.4 |
  | 랜덤 SVD | −4.1 |
  | 미니배치 K-means | −3.6 |
  | RaBitQ 양자화 | −3.6 |
  | 다차원 히스토그램 | −3.4 |
  | IVF 클러스터링 | −2.7 |
  | 가우시안 혼합 모델 | +2.7 |

  - 16개 막대 중 가우시안 혼합 모델·미니배치 K-means·IVF 클러스터링 세 가지는 권장 제외 대상이므로 나머지 13개와 다른 색으로 칠한다 — 가우시안 혼합 모델은 유일하게 양수(반대 방향), 미니배치 K-means(−3.6)·IVF 클러스터링(−2.7)은 음수 막대이지만 측정 안정성이 낮아 같은 제외 색으로 표시. 작은 범례로 "권장 13 / 제외 3"을 단다
- 좌측: "13 / 16" 큰 수치 + "공간 곡선·차원 축소·층화 계열이 견고하게 우월. 가우시안 혼합 모델·미니배치 K-means·IVF 클러스터링 세 가지는 측정에서 불안정해 권장에서 제외"

**발표 멘트**
- "열여섯 가지 방법을 정확도 순으로 줄 세운 결과입니다. 열세 가지는 거의 모든 측정 조건에서 안정적으로 기존 방식을 이겼습니다. 공간 곡선과 차원 축소 계열이 특히 좋았습니다."
- "권장에서 제외한 것은 세 가지입니다. 가우시안 혼합 모델은 기존 방식보다 정확도가 낮았고, 미니배치 K-means는 가장 큰 데이터에서 파탄났으며, IVF 클러스터링은 — 앞서 곡선 계열로 분류했지만 내부적으로 데이터를 군집으로 묶는 방식이라 — 기존 방식을 이기는 비율이 낮았습니다."

### slide 21 — 선택도: 높을수록 더 우월

**화면**
- 제목: "선택도가 높을수록 더 안정적으로 개선된다"
- 중앙에 막대 그래프 세 개 (우상향이 한눈에, 차트를 슬라이드 세로 중앙에 크게 — 상단에 빈 공간을 남기지 말 것):
  - 선택도 낮음(0.1%) → 83.3% / 선택도 중간(1%) → 87.6% / 선택도 높음(10%) → 97.5%
- 작은 라벨: 선택도 = 전체 데이터 중 조건을 만족하는 비율 / 조건에 맞는 데이터가 많을수록 분포 반영의 이점이 더 분명

**발표 멘트**
- "선택도는 전체 데이터 중 쿼리 조건을 만족하는 비율입니다. 선택도가 낮을 때, 중간일 때, 높을 때로 나눠 보면 결합 방식이 기존 방식을 이기는 비율이 83%, 88%, 98%로 꾸준히 올라갑니다."

### slide 22 — 데이터 구조: 단일·다중 모두 일관

**화면**
- 제목: "단일 벡터와 다중 벡터 모두에서 일관되게 우월"
- 중앙에 막대(또는 큰 수치) 두 개를 나란히 — 단일 벡터 89.1% / 다중 벡터 89.2%
- 두 막대 높이가 거의 같음을 한눈에 보이게
- 한 줄: 데이터 구조가 달라져도 우월 비율이 거의 같다

**발표 멘트**
- "데이터 구조를 단일 벡터와 다중 벡터로 나눠 비교했습니다. 두 경우 모두 결합 방식이 기존 방식을 이기는 비율이 89%로 거의 같았습니다. 한 행에 벡터가 하나든 여럿이든 효과가 흔들리지 않습니다."

### slide 23 — 계층 수: 20개가 최적

**화면**
- 제목: "데이터를 20개 계층으로 나눌 때가 가장 좋다"
- 중앙에 막대 그래프 세 개 (20개가 가장 높은 봉우리, 차트를 슬라이드 세로 중앙에 크게 — 상단 빈 공간 없게):
  - 10개 계층 → 83.6% / 20개 계층 → 89.8%(강조) / 30개 계층 → 85.9%
- 우측 짧은 설명: 계층이 너무 적으면 쏠린 분포를 충분히 못 나누고, 너무 많으면 계층마다 표본이 얇아진다 / 20개가 균형점, 논문 기본값과도 일치

**발표 멘트**
- "데이터를 몇 개의 계층으로 나눌지도 실험했습니다. 열 개, 스무 개, 서른 개로 나눠 보니 스무 개일 때가 가장 좋았습니다. 너무 적으면 쏠린 분포를 충분히 못 나누고, 너무 많으면 계층마다 표본이 얇아집니다. 스무 개가 균형점이고, 논문 기본값과도 일치합니다."

### slide 24 — 자원 효율: 정확도와 분포 파악 시간

**화면**
- 제목: "정확도와 분포 파악 시간의 균형"
- 중앙 점 그래프: 가로축 = 분포 파악 시간, 세로축 = 정확도 개선폭 (음수가 개선)
  - 점(시간 빠른 순): 희소 랜덤 투영(2.9초·−4.4%) · 가중 표본 추출(11초·−6.2%) · 주성분 분석(16초·−5.6%) · 가우시안 혼합 모델(30초·+2.7%) · Hilbert 곡선(41초·−5.9%) · HyperLogLog(53초·−4.6%)
  - 각 점 라벨이 축 눈금·다른 라벨과 겹치지 않게 배치
- 우측 짧게: 정확도 최고이면서 속도도 빠른 편 — 가중 표본 추출(11초·−6.2%) / 분포 파악 최단 — 희소 랜덤 투영(2.9초) / 느리고 부정확, 쓸 이유 없음 — 가우시안 혼합 모델

**발표 멘트**
- "방법을 고를 때는 정확도뿐 아니라 데이터가 들어올 때 분포를 파악하는 시간도 봐야 합니다. 분포 파악이 가장 빨라야 하는 상황이면 희소 랜덤 투영이 2.9초로 가장 짧습니다."
- "그 외에는 가중 표본 추출이 11초로 빠른 편이면서 정확도도 가장 높아 권장됩니다. 가우시안 혼합 모델은 느리고 부정확해 쓸 이유가 없습니다."

### slide 25 — 자동 선택: 데이터 유형을 보고 방법을 고른다

**화면**
- 제목: "데이터 유형을 보고 표본 선택 방법을 자동으로 고른다"

- 우측 한 줄: 사람이 매번 고르지 않고, 데이터 유형에 따라 자동으로 / 추정 알고리즘은 그대로

**발표 멘트**
- "측정 결과를 종합해, 데이터 유형에 따라 표본 선택 방법을 자동으로 고르는 방식을 제안합니다. 데이터가 들어오면 크기·구조·차원을 보고 유형을 판별하고, 그 유형에 맞는 방법을 골라 결합 방식으로 추정합니다."

### slide 26 — 결론

**화면**

**발표 멘트**
- "정리하겠습니다. 분포를 반영해 표본을 뽑으면 추정이 89%에서 더 정확해졌고, 통째 교체는 불안정하며 결합이 답이었습니다. 이 효과는 선택도·데이터 구조·계층 수 어느 조건에서도 일관됐고, 데이터 유형에 따라 방법을 자동으로 고르는 방식을 제안했습니다. 추정 알고리즘은 그대로 두고 표본 뽑는 방식만 바꾼 결과입니다."

## ★★ 생성 후 필수 자가 검증 절차

deck 28장을 생성한 뒤, **반드시 모든 슬라이드를 한 장씩 점검**하고 문제를 고친 다음 최종본을 낸다. 점검 항목:

1. **잘림** — 박스·그림·텍스트·수치·막대 등 어떤 요소도 슬라이드 경계(상·하·좌·우) 밖으로 잘려 나가지 않았는가. 특히 slide 19의 두 막대가 슬라이드 안에 완전히 들어왔는지 명시적으로 확인한다.
2. **겹침** — 텍스트끼리, 텍스트와 도형, 도형과 그림이 서로 겹쳐 읽기 어려운 곳이 없는가.
3. **위치·정렬** — 그림·도형·화살표의 위치가 어긋나거나, 정렬돼야 할 요소(카드·막대·단계 박스)가 어긋나 있지 않은가.
4. **빈 공간** — 슬라이드 상단·하단·좌우에 과도하게 빈 공간이 있어 내용이 한쪽으로 치우치지 않았는가. 차트·그림은 슬라이드 중앙 영역에 충분히 크게.
5. **시각 요소 유무** — 표지·마무리를 뺀 모든 슬라이드에 그림·그래프·다이어그램이 주인공으로 들어갔는가. 텍스트 박스만 나열된 슬라이드가 하나도 없는가.
6. **금지 사항** — B1·CaseA·CaseB 코드명, qe_trim·BH-FDR 등 용어, 페이지 번호, 영어 라벨, "★", "GMM" 약어 단독 사용, "직접 만들었다" 데이터셋 서사가 없는가.
7. **핵심 수치·framing 정확도 (★ 직전 deck가 실제로 틀렸던 지점 — 반드시 한 장씩 대조)** — slide 4에 "분포를 알 때/모를 때" 이분법이 없는가 · slide 7 데이터셋이 "9종 · 96~1024차원"인가 · slide 8에 다중 벡터 4번째 DEEP+CC3M(1024)이 있고 캡션 상한이 "1024차원"인가 · slide 10 접근 카드가 정확히 7개인가 · slide 19에 "결합이 96.5%에서 우월" 보조 수치 한 줄이 있는가 · slide 20이 "13가지 우월 · 3가지 제외"인가("14"·"둘만" 아님) · slide 23 계층 수치가 "83.6 / 89.8 / 85.9"인가.

→ 위 항목에서 문제가 발견되면 해당 슬라이드를 수정하고, 수정 후 다시 점검한다. 문제가 없을 때까지 반복한 뒤 최종본을 제시한다.
