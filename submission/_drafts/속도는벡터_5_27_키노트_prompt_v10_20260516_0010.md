## 2. method 알고리즘 slide 영역 — slide 9-15 자세히

### Slide 9 — P1 Cluster (3 method)
**Layout**: 3 column / 각 column 영역 method 알고리즘 다이어그램 + 한 줄 reference

**Method 1: minibatch_partial** (P1.3, Sculley 2010 partial fit)
- 알고리즘: MiniBatchKMeans + `partial_fit` (sub-batch 단계별 학습)
- 1차 mini-batch 학습 → cluster center 영역 → 2차 partial_fit (다른 batch) → cluster center update
- step diagram: input → batch 1 → partial_fit → centers → batch 2 → partial_fit → centers (update) → ...
- 시간 복잡도: O(batch_size × K × d) per batch

**Method 2: gmm** (P1.2, Dempster-Laird-Rubin 1977 EM)
- 알고리즘: Gaussian Mixture Model with EM (Expectation-Maximization)
- E-step: P(z=k | x) 계산 (cluster assignment 확률)
- M-step: μ_k, Σ_k, π_k update (cluster parameter update)
- iteration 반복 until convergence
- 본 측정 영역: `covariance_type='diag'` + `reg_covar=1e-2` (SIFT 128d / SSN 256d cholesky fail 회피)

**Method 3: faiss_ivf** (P2.6, Johnson-Douze-Jégou 2017)
- 알고리즘: IVF (Inverted File Index) — vector → cluster center 영역 nearest 매핑
- 1차 coarse quantizer 학습 (K-means K=20 영역) → vector 영역 cluster 매핑
- index 영역 stratum_id = cluster 매핑 결과
- 시간 복잡도: O(n × K × d) train + O(n × log K) assign

---

### Slide 10 — P2 Spatial (3 method)
**Method 1: hilbert_real** (P2.1, Faloutsos 1989 ★3 정정)
- 알고리즘: Hilbert curve indexing — high-D vector → 1D scalar 영역 매핑
- 1차 PCA → 2D / 3D projection
- 2차 Hilbert curve 영역 1D scalar value 계산
- 3차 scalar value 영역 K=20 quantile 분할 → stratum_id
- 본 측정 영역: 정정 후 raw Wikipedia Hilbert curve 표준 구현
- step diagram: vector → PCA 2D/3D → Hilbert curve → 1D scalar → quantile 분할 → sid

**Method 2: zorder_morton** (P2.3, Morton 1966)
- 알고리즘: Z-order space-filling curve — bit interleaving
- 1차 PCA → low-D projection
- 2차 각 dimension 별 binary 영역 bit interleaving
- 3차 interleaved bit 영역 quantile 분할 → stratum_id
- 시간 복잡도: O(n × d × log d) bit ops

**Method 3: skilling_hilbert** (P2.2, Skilling 2004)
- 알고리즘: state-machine algorithm — true high-D Hilbert curve
- AIP Conf Proc 2004; 707:381-387 verbatim
- 1차 vector 영역 unit cube 정규화
- 2차 state-machine 영역 high-D Hilbert curve scalar value 계산
- 3차 scalar value 영역 quantile 분할 → stratum_id

### Slide 11 — P3 Streaming (1 method, Pareto Top 5 ★)
**Method: chao_weighted** (P3.1, Chao 1982 *Biometrika*)
- 알고리즘: weighted reservoir sampling (priority queue base)
- 1차 vector 영역 weight 부여 (예: norm or anomaly score)
- 2차 priority queue 영역 weighted random sample
- 3차 sample 영역 K=20 stratum 영역 distribution-aware 부여
- 시간 복잡도: O(n × log K) priority queue insert/pop
- 메모리: O(K) priority queue
- **본 연구 Pareto Top 5 ★ (Type 1 best -14.11%)**

---

### Slide 12 — P4 DimReduction (4 method)
**Method 1: sparse_rp** (P4.1, Li-Hastie-Church 2006 ★4 정정)
- 알고리즘: Very Sparse Random Projection (Achlioptas 2003 → Li-Hastie-Church 2006 정정)
- 1차 sparse matrix 영역 random projection (density ~1/√d)
- 2차 projected vector 영역 quantile 분할 → stratum_id
- 시간 복잡도: O(n × k × d × density)
- 메모리: O(k × d × density) sparse matrix
- **본 연구 Pareto Top 5 ★ (fit_time 3.67s 최단)**

**Method 2: pca1d** (P4.3, Pearson 1901)
- 알고리즘: PCA → 1D 영역 projection
- 1차 covariance matrix SVD
- 2차 1st principal component 영역 vector projection (1D scalar)
- 3차 scalar value 영역 quantile 분할 → stratum_id
- 시간 복잡도: O(n × d²) covariance + O(d³) SVD
- **본 연구 Pareto Top 5 ★ (10/10 textbook audit pass)**

**Method 3: rsvd** (P4.4, Halko-Martinsson-Tropp 2011)
- 알고리즘: Randomized SVD — large-scale PCA 영역
- 1차 random sketch (Gaussian matrix) 영역 low-rank approximation
- 2차 power iteration 영역 stability 영역 향상
- 3차 truncated SVD 영역 1D projection
- 본 연구 영역: PCA1D 의 large-scale 영역 alternative

**Method 4: ica_fastica** (P4.5, Hyvärinen 1999)
- 알고리즘: FastICA — non-Gaussian independence 영역
- 1차 vector 영역 centering + whitening
- 2차 fixed-point iteration 영역 non-Gaussianity max
- 3차 independent component 영역 1D projection → stratum_id
- 시간 복잡도: O(n × d²) iteration

---

### Slide 13 — P5 QMC (2 method)
**Method 1: cum_sqrtf** (P5.6, Dalenius-Hodges 1959)
- 알고리즘: Minimum Variance Stratification (cum √f)
- 1차 vector 영역 1D projection (예: PCA 1st PC)
- 2차 영역 cumulative √frequency 영역 계산
- 3차 cumulative √f 영역 K=20 등간격 분할 → stratum_id
- 영역: classical stratification 정통 영역 (JASA 1959 verbatim)

**Method 2: lavallee_hidiroglou** (P5.7, Lavallée-Hidiroglou 1988)
- 알고리즘: take-all stratum + Neyman allocation
- 1차 vector 영역 magnitude 정렬 (descending)
- 2차 top-N take-all stratum (large value 전수 추출)
- 3차 나머지 영역 Neyman allocation 영역 stratum 분할
- 영역: skew long-tail dataset 영역 효과 (Survey Methodology 1988 verbatim)

---

### Slide 14 — P6 Quantization (2 method)
**Method 1: rabitq_strat** (P6.1, Gao-Lin 2024 VLDB)
- 알고리즘: RaBitQ — sign-based quantization
- 1차 vector 영역 random projection (Gaussian)
- 2차 각 dimension 영역 sign(>0) → 1 bit / sign(≤0) → 0 bit
- 3차 binary code 영역 K=20 영역 quantile 분할 → stratum_id
- 영역: 2024 VLDB Best Paper (paradigm 회복 anchor)

**Method 2: mhist2** (P6.2, Poosala 1997 VLDB)
- 알고리즘: MHIST — multi-dimensional histogram
- 1차 vector 영역 d-D 영역 multi-dim histogram bucket
- 2차 bucket 영역 영역 max variance 영역 split iteration
- 3차 bucket id 영역 stratum_id 매핑
- 영역: histogram-based real alternative

---

### Slide 15 — P9 InfoTheoretic (1 method, Pareto Top 5 ★)
**Method: hyperloglog** (P9.1, Flajolet-Fusy-Gandouet-Meunier 2007 AofA)
- 알고리즘: HyperLogLog — cardinality estimation 영역 sketch
- 1차 hash function 영역 vector → uniform random bit
- 2차 leading zero count 영역 register (m buckets) 영역 max update
- 3차 harmonic mean 영역 cardinality 추정 (bias correction 포함)
- 영역: sketch textbook anchor (AofA 2007 verbatim)
- 메모리: O(m × log log n) — 매우 compact
- **본 연구 Pareto Top 5 ★**

