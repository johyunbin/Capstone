## 1. RQ1 — 분포 인지 가치 + Selectivity Gradient 단조성 확정

**문제**: 기존 BERNOULLI sampling 이 skew 데이터에서 얼마나 부정확한가?

**핵심 결과**:
- **2x2 (Block vs Row × Normal vs Skew)** — 4 cell 모두 측정. SIFT(skew) 의 SYSTEM-BERN 격차가 모든 sel 에서 DEEP(normal) 격차 이상 (s=0.01 +5.61%p, s=0.05 +4.71%p, paired Wilcoxon p≤1e-49).
- **Selectivity Gradient** — KM20 의 BERN 대비 개선폭이 sel 낮을수록 큼:
  - DEEP s=0.500: +1.31% / s=0.300: +2.62% / s=0.100: +4.19% / s=0.050: +1.85% / s=0.010: +8.93%
- ★ **단조성 통계 확정** (W1 보강, Phase 6 SQL D 기준): DEEP-KM20 per-seed Spearman ρ=**−0.680**, **95% CI [−0.800, −0.440] (0 제외)**. DEEP-RAND 도 reverse-monotonic 확정 (ρ=+0.560 [+0.320, +0.840]).

> 📌 **5/7 W2 critical finding — 옵션 2 정직 reporting 채택** (5/8 회의 합의 안건, 본 자료는 회의 직전 ready 상태):
> - **Phase 6** (SQL D, vector.c hook, production-near): per-seed ρ = **−0.680** [−0.800, −0.440] **CI 0 제외, 단조 감소 확정** ← 5/27 발표 핵심 수치 인용 기준
> - **Phase 7** (numpy D, simulation): per-seed ρ = +0.240 [−0.061, +0.480] CI 0 포함, 단조성 약화 ← sub-contribution 으로 honest 별도 보고
> - **5-cell 격차** (s=0.01 Δ = −12.26%p, s=0.50 Δ = −9.44%p) 자체를 *measurement methodology robustness* sub-contribution 으로 격상
> - **본 연구 narrative**: gradient 19.6%p 핵심 수치는 Phase 6 production-near 기준 인용. Phase 7 결과와 격차의 origin (캐시 기반 numpy estimator vs vector.c hook) 은 Limitations + Q&A 대응
>
> 추가 W2 발견 (SIFT 단조성):
> - SIFT-KM20 5-cell ρ = −0.140 [−0.220, −0.100] **CI 0 제외** — DEEP-KM20 보다 약하나 통계 유의
> - SIFT-RAND 5-cell ρ = +0.380 [−0.140, +0.700] CI 0 포함 — 비-단조 패턴, mid-sel 음수 + 양 끝 양수

**Two-Level Decomposition**:
- Level 1 (proportional allocation, 보편): s=0.5 에서도 RAND +2.20%
- Level 2 (spatial awareness, sel-dependent): s=0.01 KM20 +8.93% vs RAND -10.67% (격차 19.6%p, CI 완전 분리)

## 2. RQ2 — Allocation 방식 ablation + KM20 robustness

**문제**: 분포 정보 알 때 어떤 allocation 이 최적?

**5-way 측정 결과** (DEEP/SIFT × 5 sel × 5 seed × 100 query, 25K rows):
- 모든 stratified > BERN: DEEP -1.3~-7.0%, SIFT -3.7~-10.5% (p≤1e-7~1e-50)
- **Neyman vs Equal**: SIFT × 좁은 sel (s=0.01) 에서만 유의 (-11.9%, p_BH=0.024). 나머지 case 에서는 σ_i 신호가 N_i 보다 약함.
- **Anti-Neyman vs Proportional**: 모든 case 통계 유의 X — 분산 신호의 allocation 효과 부정.

**Sample-size sensitivity** (실험 #4): KM20 의 4 ssize × 2 dataset × 5 sel × 5 seed × 100 query = 40K rows. **모든 40 cell 에서 KM20 > BERN 일관** (Δ% -1.09 ~ -13.50%).

**한계 → RQ3 동기**:
- σ 신호의 sel 의존성 → **B. KDE-pilot** (#10) 으로 query-adaptive σ
- KM oracle 의 production 학습 부담 → **F. MiniBatch K-means** (#8) 1% sample 학습

## 3. RQ3 — 7-way Distribution-Agnostic 비교

**문제**: 분포 모를 때 어떤 방식이 최적?

**측정 결과** (DEEP 1M + SIFT 1.5M × 5 sel × 5 seed × 100 query × 7 method):

| method | 패러다임 | DEEP | SIFT | 통계 유의 | 등급 |
|--------|----------|------|------|-----------|------|
| **MiniBatch K-means** | Offline 학습 1% | -1.88% | -1.97% | DEEP 3/5, SIFT 5/5 | ★★★ production solution |
| **Hilbert Curve** | 학습 X 결정론 | -1.78% | -2.47% | DEEP 2/5, SIFT 4/5 | ★★★ contribution 1순위 |
| KDE-pilot | Online | -0.40% | +0.27% | SIFT s=0.05 -3.28% only | ★ 부분 confirm |
| LSH | Offline 확률 | +4.91% | +7.07% | — | × hash 한계 |
| Random Projection | Offline 단순 | +5.77% | +12.78% | — | × negative control |
| Distance-Shell | Online 단순 | +9.74% | +12.13% | — | × cluster 정보 X 한계 |
| Importance Sampling | 비분할 | +52~+207% | +37~+135% | — | ×× 분할 X massive failure |

**RQ3 contribution 5종 확정** (5/7 NEW: HDBSCAN + hybrid 추가, 22 method 측정 완료):
1. **Hilbert curve = learning-free 1순위** (★예상 초과)
   - Mechanism (W1-C): inverse Manhattan = 1.000 (perfect 1D-2D continuity). Z-order 1.992 (50% jumps). Stratum compactness Z-order 대비 1.25−2.54× 우수 → HT estimator within-stratum variance 감소 직접 효과.
2. **MiniBatch K-means partial_fit = production-ready OLTP** (★H3-F confirm 강)
   - **partial_fit 4 cell paired CI 0 제외**. SIFT s=0.10 −2.36%, s=0.30 −1.47%, s=0.50 −1.08%, DEEP s=0.10 −2.07%. batch 동등 효과 통계 확정. ARI(batch, partial) = 1.000.
3. **HDBSCAN = SIFT mid-sel best** (5/7 NEW, ★ density-based 가치)
   - SIFT s=0.10 **−3.99%** [−5.34, −2.12] paired CI (모든 method 중 가장 큰 mid-sel 개선). SIFT 의 더 큰 skew + density-based clustering 의 가치 강화.
4. **Hybrid (KMeans + Hilbert) = SIFT rank 5.83** (5/7 NEW, ★ 양 paradigm 결합)
   - SIFT 평균 rank 5.83 (Hilbert 5.85 보다 약간 우수). DEEP s=0.05 −2.68% / SIFT s=0.10 −3.10% [−4.61, −1.19] paired CI 0 제외. Hilbert 의 learning-free + 결정론 우월성 narrative 는 보존.
5. **Distance-Shell + IS + PQ + Sobol = cluster 분할 결정적 가치 정량** (negative control 강화)
   - paired CI 0 제외 hurt direction. PQ DEEP s=0.01 +23.64% / Sobol SIFT s=0.01 +33.62% 등 명확한 실패 case.

**spectral 정정 (5/7 03:50 검증)**: recovery_summary -5.39% 는 mean-of-ratios 왜곡, paired CI 검증 시 +16.71% **hurt direction** → contribution 후보 제외.

**caveat (사전 등록 fall-back 활성)**: KM20-RANDOM20 격차 0.26~3.98% (분모 붕괴). primary metric → `method_minus_random_pct` 또는 `method_minus_bern_pct` 사용.
