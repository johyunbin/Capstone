## 단계 1 — 구조 변경 (삭제 · 통합 · 강화 · 복원)

claude.ai/design에 아래를 복붙.

```text
좋아, 이제 단계 1 — 구조를 변경하자. 아래 1~4를 모두 적용해줘.

1. [알고리즘 7장 삭제]
알고리즘 접근을 한 장씩 설명하는 7개 슬라이드 — 공간 곡선 / 차원 축소 / 통계적 층화 / 양자화 / 클러스터링 / 스트리밍 표본 추출 / 정보 이론 기반 — 을 삭제해줘. 이 알고리즘 상세 설명은 최종 보고서로 옮긴다.

2. ["16가지 방법, 7가지 접근" 슬라이드 강화]
이 슬라이드의 7개 접근 카드 각각에, 그 접근이 분포를 어떻게 반영하는지 한 줄 설명을 추가해줘:
- 공간 곡선 — 고차원을 한 줄로 펼쳐 균등 구간으로 자른다
- 차원 축소 — 정보가 가장 많은 축으로 압축해 구간을 나눈다
- 통계적 층화 — 각 구간에 데이터가 같은 양씩 담기게 자른다
- 양자화 — 짧은 코드로 바꿔 같은 코드끼리 묶는다
- 클러스터링 — 비슷한 것끼리 군집으로 묶는다
- 스트리밍 표본 추출 — 데이터를 한 번 훑으며 표본을 골라낸다
- 정보 이론 기반 — 해시로 데이터 분포를 적은 메모리에 요약한다
각 카드의 대표 방법 목록은 그대로 둔다. 슬라이드 하단 줄을 "일곱 가지 접근에서 대표 방법 16가지를 골라 모두 측정했다"로 바꾼다. 카드 7개 높이를 내용에 맞춰 하단 빈 공간을 없앤다.

3. [결과 3장을 1장으로 통합]
"선택도가 높을수록 더 안정적으로 개선된다" 슬라이드 + "단일 벡터와 다중 벡터 모두에서 일관되게 우월" 슬라이드 + "데이터를 20개 계층으로 나눌 때가 가장 좋다" 슬라이드 — 이 3장을 한 장으로 합쳐줘.
- 제목: "선택도·데이터 구조·계층 수 — 모든 조건에서 일관되게 우월"
- 가로로 미니 패널 3개:
  · 선택도: 막대 3개 — 낮음(0.1%) 83.3% / 중간(1%) 87.6% / 높음(10%) 97.5%. 한 줄 "선택도가 높을수록 더 우월"
  · 데이터 구조: 큰 수치 2개 — 단일 벡터 89.1% / 다중 벡터 89.2%. 한 줄 "단일·다중 거의 동일"
  · 계층 수: 막대 3개 — 10개 83.6% / 20개 89.8%(강조) / 30개 85.9%. 한 줄 "20개 계층이 최적"
- 세 패널 공통 캡션(하단): "결합 방식이 기존 방식을 이긴 비율"

4. ["다음 단계" 슬라이드를 "한계와 다음 단계"로 복원]
마지막 직전 슬라이드(현재 제목 "다음 단계", 산업 적용·논문 적용 두 박스가 있는 슬라이드):
- 제목을 "한계와 다음 단계"로 바꾼다.
- "산업 적용" 박스 안의 "현재 33%·100% 있은 고정값"을 "데이터와 무관한 33%·100% 고정값"으로 고친다. ('있은'은 오타다.)
- 슬라이드를 좌우로 나눈다. 왼쪽에 "정직하게 남기는 점" 박스를 새로 만들고 두 줄을 넣는다:
  ① 검증 중 비교 기준(기존 방식)의 측정에서 작은 결함을 발견해 바로잡았다 — 개선 수치는 더 보수적이지만 더 엄정한 기준 위의 값
  ② 가장 큰 규모의 다중 벡터 데이터는 일부 조합만 측정
- 오른쪽에는 기존 "산업 적용"·"논문 적용" 두 박스를 압축해 "다음 단계"로 둔다.

★ 수치는 위에 적은 값 그대로 — 한 자리도 바꾸지 마. 코드명·수식 쓰지 마.

다 끝나면 스스로 점검해줘: 슬라이드가 19장인가 / 알고리즘 7장이 삭제됐는가 / 어떤 박스·그림·막대·텍스트도 슬라이드 밖으로 잘리거나 겹치지 않았는가. 문제가 있으면 고치고 다시 점검해.
```

**단계 1 후 할 일** — claude.ai/design 작업이 끝나면 **PDF로 export** → Claude Code 세션에 "단계 1까지 적용한 deck야, 19장·삭제·통합·강화·복원 검증해줘" 요청. (handoff `새세션_복붙_프롬프트` 참조.) 통과하면 단계 2로.

## 단계 2 — 레이아웃 · 밀도 정리

claude.ai/design에 아래를 복붙.

```text
단계 2 — 레이아웃을 정리하자. 수치와 문구는 그대로 두고 배치만 손본다. 아래 슬라이드들이 여백이 많아 비어 보여 — 내용을 슬라이드 세로 중앙으로 모으고, 박스·패널 높이를 내용에 맞춰 줄여줘.

- "왜 카디널리티 추정이 중요한가" — 흐름도와 33%/100% 박스 사이 중앙 빈 공간이 크다. 세 요소를 세로 중앙으로 모아 간격을 고르게.
- "논문이 푼 것, 우리가 바꾼 것" — 파이프라인 도식과 하단 박스를 세로 중앙 정렬, 하단 빈 공간 축소.
- "연구가 걸어온 길" — 하단 띠의 긴 문장을 한 줄로 축약: "단계마다 측정 범위가 넓어지며, 초점이 '특정 방법'에서 '표본 선택 단계 개입의 효과'로 분명해졌다".
- "분포를 반영해 표본을 뽑는 세 단계" — 3개 박스가 길어 하단이 빈다. 박스 높이를 내용에 맞춰 줄이고 세로 중앙 정렬.
- "세 가지 방식을 같은 조건으로 비교했다" — 여백이 가장 심하다. 3개 카드가 슬라이드 하단까지 길어 아래 2/3가 빈다. 카드 높이를 절반 이하로 줄여 내용(도식+한 줄)이 카드를 채우게.
- "측정한 데이터셋" — 좌우 패널이 크고 막대 위아래 빈 공간이 많다. 패널 높이를 줄이고 막대 그룹을 패널 세로 중앙으로.
- "데이터가 쏠려 있을 때, 무작위는 쏠린 곳만 뽑는다" — 오른쪽 패널 안 라벨 "드문 영역도 표본에"가 동사 없이 잘려 보인다 → "드문 영역도 표본에 들어온다"로 완결.
- "핵심 결과" (거대 수치 89.1% 슬라이드) — 수치와 우측 보조 막대 아래 빈 공간이 크다. 두 블록을 슬라이드 세로 중앙으로 균형 있게.
- "완전 대체는 불안정 — 결합이 답" — 제목과 막대 사이 빈 공간이 있다. 두 막대·우측 수치·하단 보조 줄을 세로 중앙으로.
- "자원 효율" (점 그래프 슬라이드) — 그래프가 하단으로 치우쳐 상단이 빈다. 그래프와 우측 텍스트를 세로 중앙으로, 그래프를 약간 크게.

다 끝나면 스스로 점검: 어떤 요소도 슬라이드 밖으로 잘리거나 겹치지 않았는가 / 빈 공간이 과하지 않은가.
```

**단계 2 후 할 일** — (선택) PDF export해서 눈으로 확인. 바로 단계 3으로 가도 된다.

## 부록 A — 불변 수치 표 (한 자리도 바꾸지 말 것 · v13 측정 정본)

| 항목 | 값 |
|---|---|
| 결합이 기존 방식보다 정확한 비율 | 89.1% (1508번 중 1344번) |
| 추정 오차 중앙값 감소 | 약 4.4% |
| 통계적으로 의미 있는 개선 / 개선 폭 큰 경우 | 65% / 72% |
| 완전 대체가 기존보다 나은 비율 | 35.2% |
| 결합 vs 완전 대체 직접 비교 — 결합 우월 | 96.5% |
