## 0. 목적 · 사용법 · 불변 규칙

### 왜 슬리밍하나
캡스톤 공식 공지 — 최종 발표 **팀당 최대 10분, 10분 지나면 강제 중단**. 현행 deck는 28장이라 슬라이드당 21초밖에 안 돼 결과 슬라이드에 닿기 전 끊길 위험이 크다. 또 박세은 팀장 의견("내용 덜어내고 핵심만, 디테일은 보고서로")을 반영한다.

deck 자체는 이미 그림 중심이라 글이 빽빽하진 않다. **진짜 문제는 장수** — 그래서 슬리밍의 핵심은 ① 구조 압축(28→19장) ② 비어 보이는 슬라이드 레이아웃 정리다. 알고리즘 상세 7장은 6/11 최종 보고서로 이관한다.

### 사용법
1. claude.ai/design Capstone 프로젝트 **Keynote_Capstone**에서 현행 v16 deck을 연다.
2. 본 지침 **§2(구조 변경 4건) → §3(레이아웃 정리)** 순서로 적용한다. 각 항목의 `>` 블록은 claude.ai/design에 그대로 요청해도 되는 지시문이다.
3. 수정 후 claude.ai/design 자가 검증 절차(잘림·겹침·빈 공간·시각 요소)를 수행한다.
4. **§5 PPTX export 가이드**대로 Screenshot 기반 PPTX로 내보낸다 → `속도는벡터_최종발표_슬라이드.pptx`.
5. export한 .pptx를 repo `submission/_drafts/`에 두면 Claude Code가 §5 체크리스트로 최종 검증한다.

### 불변 규칙 (전 슬라이드 — v16과 동일, 슬리밍 중에도 유지)
- **수치는 §4 불변 수치 표 그대로.** 한 자리도 바꾸지 않는다.
- 코드명 금지 — B1·CaseA·CaseB·3-way·qe_trim·BH-FDR 등. "기존 방식 / 완전 대체 / 결합"으로만.
- "분포를 안다 / 모른다" 이분법 표현 금지.
- 수식·코드 용어 금지(estimate₁+estimate₂, h(x)→bits 등). 알고리즘은 풀어쓴 한국어 이름.
- 페이지 번호·영어 메타 라벨(BASE PAPER 등)·"★" 표기 없음.
- 흰 배경 + 남색(navy) 강조 단일 디자인 시스템 유지.

## 2. 구조 변경 4건

### 2-1. slide 11~17 삭제 (알고리즘 7접근 7장)

알고리즘 한 접근당 한 장(공간 곡선·차원 축소·통계적 층화·양자화·클러스터링·스트리밍 표본 추출·정보 이론 기반)은 **기존 알고리즘 설명**이라 우리 연구의 기여가 아니다. 10분 발표에서 가장 큰 시간 낭비 지점 — 7장을 통째로 삭제하고, 각 접근의 직관은 slide 10에 한 줄씩 흡수한다(§2-2). 상세 설명은 6/11 최종 보고서로 옮긴다.

> claude.ai/design 요청: "11번부터 17번까지 7개 슬라이드(공간 곡선·차원 축소·통계적 층화·양자화·클러스터링·스트리밍 표본 추출·정보 이론 기반)를 삭제해 줘. 이 알고리즘 상세 설명은 최종 보고서로 옮긴다."

부수 효과 — 삭제되는 slide 14·17의 코드성 표기("v = (3.2, −1.8, …)", "h(x) → bits")도 함께 사라진다(추가 조치 불필요).

### 2-2. slide 10 강화 — 알고리즘 단일 슬라이드化

11~17 삭제로 알고리즘 설명이 slide 10 하나로 모인다. 현재 7개 접근 카드는 **접근 이름 + 대표 방법**만 있고 카드 하단에 빈 공간이 많다. 각 카드에 **분포를 어떻게 반영하는지 한 줄 직관**을 추가하고 카드 높이를 내용에 맞춘다.

추가할 한 줄(카드별):

| 접근 | 추가할 한 줄 직관 |
|---|---|
| 공간 곡선 | 고차원을 한 줄로 펼쳐 균등 구간으로 자른다 |
| 차원 축소 | 정보가 가장 많은 축으로 압축해 구간을 나눈다 |
| 통계적 층화 | 각 구간에 데이터가 같은 양씩 담기게 자른다 |
| 양자화 | 짧은 코드로 바꿔 같은 코드끼리 묶는다 |
| 클러스터링 | 비슷한 것끼리 군집으로 묶는다 |
| 스트리밍 표본 추출 | 데이터를 한 번 훑으며 표본을 골라낸다 |
| 정보 이론 기반 | 해시로 데이터 분포를 적은 메모리에 요약한다 |

- 대표 방법 목록(현행)은 그대로 둔다.
- 하단 줄 "다음 일곱 장에서 각 접근이 어떻게 분포를 반영하는지 큰 개념 그림으로 본다" → **"일곱 가지 접근에서 대표 방법 16가지를 골라 모두 측정했다"** 로 교체(삭제된 7장을 가리키지 않도록).
- 카드 7개의 크기는 균일하게, 하단 빈 공간을 없애 내용에 맞춘다.

> claude.ai/design 요청: "10번 슬라이드의 7개 접근 카드 각각에 '분포를 어떻게 반영하는지' 한 줄 설명을 추가해 줘 — 공간 곡선:고차원을 한 줄로 펼쳐 균등 구간으로 / 차원 축소:정보가 가장 많은 축으로 압축해 구간을 / 통계적 층화:각 구간에 데이터가 같은 양씩 담기게 / 양자화:짧은 코드로 바꿔 같은 코드끼리 / 클러스터링:비슷한 것끼리 군집으로 / 스트리밍 표본 추출:데이터를 한 번 훑으며 골라낸다 / 정보 이론 기반:해시로 분포를 적은 메모리에 요약. 하단 줄은 '일곱 가지 접근에서 대표 방법 16가지를 골라 모두 측정했다'로 바꾸고, 카드 7개 높이를 내용에 맞춰 하단 빈 공간을 없애 줘."

### 2-3. slide 21·22·23 → 1장 통합 (new 14 "조건별 일관성")

현행 21(선택도)·22(데이터 구조)·23(계층 수)은 각각 한 장씩인데 모두 여백이 많다. 세 결과는 "조건이 달라져도 개선이 일관된다"는 한 메시지이므로 **한 장으로 통합**한다 — 시간 절약과 여백 해소를 동시에.

- 통합 슬라이드 제목: **"선택도·데이터 구조·계층 수 — 모든 조건에서 일관되게 우월"**
- 가로로 미니 패널 3개:

| 패널 | 내용 | 한 줄 |
|---|---|---|
| 선택도 | 막대 3개 — 낮음(0.1%) **83.3%** / 중간(1%) **87.6%** / 높음(10%) **97.5%** | 선택도가 높을수록 더 우월 |
| 데이터 구조 | 큰 수치 2개 — 단일 벡터 **89.1%** / 다중 벡터 **89.2%** | 단일·다중 거의 동일 |
| 계층 수 | 막대 3개 — 10개 **83.6%** / 20개 **89.8%**(강조) / 30개 **85.9%** | 20개 계층이 최적 |

- 세 패널 공통 캡션(하단): "결합 방식이 기존 방식을 이긴 비율"
- 21번 자리에 통합 슬라이드를 두고, 22·23번은 삭제.

> claude.ai/design 요청: "21·22·23번 슬라이드를 한 장으로 합쳐 줘. 제목 '선택도·데이터 구조·계층 수 — 모든 조건에서 일관되게 우월', 가로 미니 패널 3개 — ①선택도: 막대 3개 낮음(0.1%) 83.3% / 중간(1%) 87.6% / 높음(10%) 97.5%, '높을수록 우월' ②데이터 구조: 큰 수치 단일 벡터 89.1% / 다중 벡터 89.2%, '거의 동일' ③계층 수: 막대 3개 10개 83.6% / 20개 89.8%(강조) / 30개 85.9%, '20개가 최적'. 공통 캡션 '결합 방식이 기존 방식을 이긴 비율'. 22·23번 슬라이드는 삭제."

### 2-4. slide 27 한계 복원 (new 18 "한계와 다음 단계")

현행 slide 27은 hand-tuning 과정에서 제목이 '한계와 다음 단계'→'다음 단계'로 바뀌며 **정직한 한계 내용이 삭제**됐고, 본문에 오타가 있다. 학술 발표에서 정직한 한계 제시는 평가 가점 요소이고 narrative에도 한계가 정본으로 들어 있으므로 복원한다.

**(a) 제목 복원** — "다음 단계" → **"한계와 다음 단계"**

**(b) 오타 수정** — '산업 적용' 박스 안 "현재 33%·100% **있은** 고정값 → 데이터 분포 기반 추정으로" → **"데이터와 무관한 33%·100% 고정값 → 데이터 분포 기반 추정으로"** (slide 2와 같은 표현으로 통일)

**(c) 한계 섹션 복원** — 레이아웃을 좌(한계) + 우(다음 단계)로:
- 좌측 "정직하게 남기는 점" 박스 — 짧게 두 줄:
  1. 검증 중 비교 기준(기존 방식)의 측정에서 작은 결함을 발견해 바로잡았다 — 개선 수치는 더 보수적이지만 더 엄정한 기준 위의 값
  2. 가장 큰 규모의 다중 벡터 데이터는 일부 조합만 측정
- 우측 "다음 단계" — **현행 산업 적용·논문 적용 두 박스를 그대로 유지**(다른 데이터베이스 엔진 확장 / Exqutor 논문 프레임워크 통합). 우측 영역에 맞게 두 박스를 압축 배치.
- 코드명·수식 금지 규칙 유지. 텍스트는 각 항목 한 줄로 짧게.

> claude.ai/design 요청: "27번 슬라이드 제목을 '한계와 다음 단계'로 바꾸고, '산업 적용' 박스의 '현재 33%·100% 있은 고정값'을 '데이터와 무관한 33%·100% 고정값'으로 고쳐 줘. 그리고 슬라이드를 좌우로 나눠 — 왼쪽에 '정직하게 남기는 점' 박스를 새로 만들고 두 줄을 넣어: ①검증 중 비교 기준의 측정에서 작은 결함을 발견해 바로잡았다, 개선 수치는 더 보수적이지만 더 엄정한 기준 위의 값 ②가장 큰 규모의 다중 벡터 데이터는 일부 조합만 측정. 오른쪽에는 기존 '산업 적용'·'논문 적용' 두 박스를 압축해서 '다음 단계'로 둬."

## 3. 레이아웃 · 밀도 정리 (유지 슬라이드)

§2 구조 변경 후, 유지하는 슬라이드 중 **여백이 과해 비어 보이는** 것을 정리한다. 수치·문구·시각 요소는 그대로 두고 배치만 손본다. claude.ai/design 자가 검증 절차의 "빈 공간" 점검을 활용한다.

| new # | 슬라이드 | 정리 지침 |
|---:|---|---|
| 2 | 문제 제기 | 흐름도(쿼리→추정→실행 계획)와 "잘못 추정하면…" 캡션, 33%/100% 박스 사이 중앙 빈 공간이 크다. 세 요소를 슬라이드 세로 중앙으로 모아 간격을 고르게. |
| 3 | 논문 출발점 | 파이프라인 도식 + 하단 두 박스를 세로 중앙 정렬, 하단 빈 공간 축소. |
| 4 | 연구가 걸어온 길 | 하단 띠의 긴 문장("측정 범위가 단계마다 넓어지며, 초점이 '특정 방법이 우수하다'에서…")을 한 줄로 축약 → **"단계마다 측정 범위가 넓어지며, 초점이 '특정 방법'에서 '표본 선택 단계 개입의 효과'로 분명해졌다"**. 3단계 박스 라벨은 키워드만. |
| 5 | 우리 방법 3단계 | 3개 박스가 길어 하단이 빈다. 박스 높이를 내용(개념 그림+한 줄)에 맞춰 줄이고 세로 중앙 정렬. |
| 6 | 세 가지 방식 | **여백이 가장 심한 슬라이드** — 3개 카드가 슬라이드 하단까지 길어 아래 2/3가 빈다. 카드 높이를 절반 이하로 줄여 도식+한 줄이 카드를 채우게, 카드를 세로 중앙에. |
| 8 | 측정한 데이터셋 | 좌우 두 패널이 크고 막대 위아래로 빈 공간이 많다. 패널 높이를 줄이고 막대 그룹을 패널 세로 중앙으로. |
| 9 | 무작위 vs 분포 인지 | 우측 패널 안의 라벨 "드문 영역도 표본에"가 동사 없이 잘려 보인다 → **"드문 영역도 표본에 들어온다"**로 완결. 좌측 "드문 영역 — 표본 없음"은 그대로. |
