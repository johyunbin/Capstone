## 3. 알려진 문제 + 처리

### 3.1 Veo 영상 안 영문 단어 깨짐 (일부)

5+ 글자 단어 자모 깨짐 발견 (예: 1A "Sampling" → "Sampliing", "intervention" → "intervation"). 그러나 ★ **자막 SRT 한국어 narration carry** → 시각 텍스트 깨져도 메시지 전달 X 문제. **자막 burn-in 후에는 영상 안 영문 텍스트는 부가 정보 역할만**.

### 3.2 Flow Storyboard UI 자동화 어려움

새벽 진행 시 Storyboard 26 segment 추가는 매번 좌표 click 필요 + 라이브러리 정렬·검색 어려움 → 사용자 매뉴얼 진행 권장. 익숙한 사용자가 직접 더 빠름.

### 3.3 ffmpeg libass 미포함

`/opt/homebrew/Cellar/ffmpeg/8.1.1/bin/ffmpeg` 빌드 옵션에 libass 없음 → `subtitles=...` filter 미작동. 자막 stream embed (mov_text) 만 가능 (YouTube caption tab 표시).

**해결책** (사용자 선택):
- **DaVinci Resolve / HandBrake** (권장, GUI burn-in) — Step 3 carry
- **brew reinstall ffmpeg --with-libass** (시간 30분+, 빌드 from source)
- **subtitle stream만 사용** (자막 toggle 가능, burn-in 아님)
