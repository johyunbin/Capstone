## 1. 5/5 회의 이후 5/8 까지의 진행 사항

지난 5월 5일 비대면 회의에서 RQ 구조를 RQ1 (Normal vs Skew 정량 비교) / RQ2 (분포 인지 시 최적 방식) / RQ3 (분포 미인지 시 최적 방식) 의 3-tier 로 재정립한 이후, 5월 6일부터 5월 8일까지 사흘간 W1 sprint 를 진행하여 RQ1 보강·RQ2 ablation·RQ3 30 method 비교의 1차 측정을 모두 완료하였습니다. 총 측정 단위는 RQ1 13 cell, RQ2 60 measurement, RQ3 1500 measurement 이며, 5월 8일 17시 50분에 multi-vector / multi-table join 을 포함한 Stage 3 단일→멀티 일반화 측정까지 마감하였습니다. 본 확인서는 위 측정 결과 종합, 향후 일정, 검토 요청 사항을 보고드리는 자료입니다.

5월 8일 19시에 전원이 참가한 비대면 회의에서 박세은 팀장이 W1 sprint 결과를 정리하고, 다음 세 가지를 W2 (5/9~5/15) 방향으로 합의하였습니다 — (가) Exqutor 원논문의 Adaptive Sampling 과의 정면 비교 실험 추가, (나) 4강 method (HDBSCAN / MiniBatch_partial / Hilbert / Hybrid) 의 multi-table 적용 확장, (다) 자문 회신 후 5월 27일 최종 발표까지의 추가 실험 우선순위 확정. 본 확인서는 위 합의 사항에 대한 검토를 요청드리는 학술 자문 요청서를 겸합니다.

## 2. W1 sprint 결과 종합 (5/6~5/8)

### 2.1 RQ1 — Normal vs Skew 분포 직접 비교

5 dataset (DEEP 96d / SIFT 128d / SimSearchNet++ 256d / WIKI 768d / YFCC 192d) × 2 SF (SF1 = 800K / SF10 = 8M) = 10 single cell 에 multi-vector·multi-table 3 cell (partsupp_deep_sift_10 / partsupp_deep_wiki_10 / partsupp_deep_10 ⨝ part_wiki_10) 을 더한 총 13 cell 측정을 완료하였습니다. selectivity 5 구간 (s = 0.01, 0.05, 0.10, 0.30, 0.50) 에서 BERN 의 q-error 와 분포 skew 지표 (HHI / cluster_ratio / intrinsic_dim) 간의 단조 상관 (Spearman ρ) 을 측정한 결과, 13/13 cell 모두 ρ < 0 으로 sign 일관 100% 를 달성하였습니다. 대표 셀인 DEEP-KM20 의 ρ = -0.680 (95% CI [-0.800, -0.440], 0 제외) 으로 통계적 유의성도 확보되었으며, 이는 "selectivity 가 좁아질수록 BERN 부정확도가 단조 증가한다" 는 가설 H1 의 정량 증거입니다.

### 2.2 RQ2 — KM20 + 5-mode allocation ablation

12 single cell × 5 mode (BERN baseline / Proportional / Neyman / Anti-Neyman / Equal) × 5 selectivity = 60 measurement 를 완료하였습니다. selectivity 0.10 구간에서 paired bootstrap CI 가 0 을 제외하는 cell 이 51/52 (98.1%) 에 달하여 "분포를 알 때 KM20 stratification 이 BERN 대비 강건한 우위를 갖는다" 는 결론에 도달하였습니다. 한편 σ-allocation 5 mode 간 격차가 1%p 미만인 cell 이 7/12 (58.3%) 로, **mode 선택보다 분포 인지 자체가 결정적**이라는 부수 발견을 확보하였습니다. Neyman vs Anti-Neyman 비교에서도 Neyman 의 우위는 평균 0.7%p 수준으로 작아, σ 정보의 marginal contribution 은 K=20 기준에서 제한적임을 확인하였습니다.

### 2.3 RQ3 — 30 method 가지치기 + 4강 도출

10 cell × 30 method × 5 selectivity = 1500 measurement 를 통해 distribution-agnostic 후보군을 Tier 1 ~ Tier 4 로 분류하였습니다. Tier 1 17종은 평균 q-error 개선폭이 -8.04%p ~ -6.83%p 범위로 1.21%p spread 안에 밀집하여, "method 선택은 부차적이고 분포 인지 자체가 결정적" 이라는 RQ2 의 결론과 일치하는 신호가 RQ3 에서도 재현되었습니다. production criteria (학습 비용 / online 적응성 / 해석 가능성 / mechanism narrative) 를 적용하여 다음 4강을 선정하였습니다.

| 순위 | Method | 평균 개선폭 | 선정 근거 |
|---|---|---|---|
| ★1 | HDBSCAN | -8.04%p | Oracle 영역 best, 학습 비용 제외 시 |
| ★2 | MiniBatch_partial | -7.63%p | OLTP 친화 online learning 유일 후보 |
| ★3 | Hilbert | -7.54%p | Production sweet spot, 학습 비용 0 |
| ★4 | Hybrid | -7.13%p | Mechanism narrative + ablation 가치 |

### 2.4 단일 → 멀티 일반화 (Stage 3, 5/8 17:50 마감)

multi-vector (deep_sift_10 / deep_wiki_10) 와 multi-table join (deep_10 ⨝ part_wiki_10) 의 3 cell 에서 4강 method 를 측정한 결과, 단일 테이블 sweet spot 17.13%p 였던 개선폭이 multi 환경에서는 0.67%p 로 약 25배 약화되었습니다. 이로써 본 연구에서 정량화한 단일 테이블 정확성은 multi 정확성의 *필요조건*만 성립하며 *충분조건*은 아니라는 한계가 확인되었으며, 단일 → multi 일반화는 future work 로 명시할 근거를 갖추었습니다.

### 2.5 RQ3 30 method 분포·인덱스 leak audit

강재현 팀원이 제기한 "KM20 cluster id 또는 HNSW 인덱스 정보가 RQ3 method 에 누설되었을 가능성" 검증을 위해 30 method 코드를 일괄 audit 하였습니다. 23 method 는 raw vector 만을 입력으로 사용하여 누설이 확인되지 않은 clean 상태이며, KM20 baseline 1종은 의도된 oracle 입니다. kde_pilot 1종은 KM20 cluster 분할 단위를 stratification unit 으로 사용하여 weak leak 의 가능성이 있으나 Tier 2 boundary 에 위치하여 4강 selection 에는 영향을 주지 않습니다. halton / hammersley / reservoir / sf_importance 4종은 서버 코드 추가 검증이 필요하며 5월 9일 예정입니다.

## 4. 본 연구의 contribution (5/8 update)

(1) **RQ1 — Normal vs Skew × Block vs Row 정량 비교** (5/5 already): 5 dataset × 2 SF + multi 3 cell = 13 cell 의 sign 일관 100%, DEEP-KM20 ρ = -0.680 [-0.800, -0.440] 의 통계 유의 단조 신호.

(2) **Selectivity Gradient 분석** (5/5 already): 좁은 쿼리 (s=1%) 에서 KM20 vs RANDOM20 격차가 19.6%p 에 달하며, 이는 Exqutor 원논문이 다루지 않은 영역입니다.

(3) **Two-Level Decomposition**: Level 1 (Proportional, K 등분의 표본 안정화 효과) 과 Level 2 (Spatial, 공간 구조 인식 효과) 의 분해 framework. 5/8 sprint 결과 σ-allocation 5 mode 간 격차가 1%p 미만인 cell 이 58.3% 에 달하여, Level 1 이 본 연구의 핵심 메커니즘임이 추가 입증되었습니다.

(4) **Recovery Rate Framework (RQ3)**: 30 method × 10 cell × 5 selectivity = 1500 measurement 의 가지치기 결과, Tier 1 17종이 1.21%p spread 안에 밀집하는 "method choice 부차" 신호가 RQ2 와 RQ3 양쪽에서 재현되었습니다.

(5) **Distribution Sweet Spot 정량 boundary** (5/8 신규): cluster_ratio > 1.4 + intrinsic_dim < 0.85 영역에서 분포 인지 효과가 17%p 까지 확장되며, 그 외 영역에서는 1~3%p 수준으로 수렴합니다.

(6) **Multi 일반화 부분 입증 + future work positioning** (5/8 신규): multi-vector / multi-table join 3 cell 에서 단일 sweet spot 의 25배 약화를 정량화하여, 단일 정확성이 multi 의 필요조건이지 충분조건은 아님을 명시하였습니다.

(7) **PDX (SIGMOD 2025) 학술 confirmation** (5/8 신규): 본 thesis 의 핵심 framing 과 정확히 일치하는 후속 학회 논문이 발표되었음을 확인하여, 본 연구의 학술적 positioning 이 trend 와 일치함을 contribution narrative 에 통합하였습니다.

## 5. Limitation 자기 점검

본 연구의 한계와 향후 연구 방향을 다음과 같이 명시합니다.

(1) RQ2 의 KM20 + Neyman 은 **oracle benchmark** 이며 production 솔루션이 아닙니다. 실제 운영 솔루션은 RQ3 의 distribution-agnostic 4강이며, 본 연구의 가치는 분포 정보의 이론적 상한과 회수율을 정량화하는 데 있습니다.

(2) 사전 계산 비용은 **one-time cost** 이며, 이는 HNSW 인덱스 빌드와 같은 layer 입니다 (DEEP 1M K=20: 1.2초, 메모리 1/1000 of HNSW). 쿼리 응답 시점은 stratum_id lookup O(1) 입니다.

(3) **INSERT/UPDATE 빈번한 OLTP 환경**은 본 연구 범위 외이며, 본 연구는 analytical workload (bulk load + 다수 쿼리) 를 가정합니다. RQ3 의 MiniBatch_partial 가 이 부담을 1/20~1/100 수준으로 완화하나, 본격 OLTP 검증은 future work 입니다.

(4) **단일 → 멀티 테이블 일반화**는 future work 입니다. 5/8 Stage 3 측정에서 multi 환경의 sweet spot 약화 (25배) 가 정량 확인되어, 단일 정확성은 멀티 정확성의 *필요조건*이지 충분조건은 아님을 명시합니다.

(5) **kde_pilot 의 분류 ambiguity** (5/8 신규): RQ3 30 method 중 kde_pilot 1종이 KM20 cluster 분할 단위를 stratification unit 으로 사용하여 weak leak 의 가능성이 있습니다. Tier 2 boundary 에 위치하여 4강 selection 에는 영향을 주지 않으나, 본 보고에서는 honest disclosure 차원에서 명시합니다.

(6) **halton / hammersley / reservoir / sf_importance 의 서버 코드 검증 보류** (5/8 신규): 위 4종은 5월 9일 추가 검증 예정이며, 검증 결과에 따라 4강 selection 의 narrative 가 보강될 가능성이 있습니다.

## 6. 검토 요청 사항

채림 석사님 및 지도교수님께 다음 사항에 대한 검토 의견을 요청드립니다.

(1) RQ3 30 method 분포·인덱스 leak audit 결론에 대한 검토 — kde_pilot 1종을 Tier 분류에서 reclassify 할 것인지, 본 확인서와 같이 honest disclosure 로 명시할 것인지의 권장 방향.

(2) Exqutor 원논문의 Adaptive Sampling 과의 정면 비교 실험 설계의 적절성 — 동일 dataset / selectivity / sample_size 조건에서 KM20 4강 ensemble 과 Adaptive Sampling baseline 의 q-error 를 paired 비교하는 W2 실험안.

(3) multi-table 4강 generalization 의 narrative positioning — 단일 sweet spot 의 25배 약화를 "한계" 로 보고할지, "다음 연구 단계의 출발점" 으로 reframing 할지의 발표 톤 권장.

(4) SF100 (80M) 실험의 5월 27일 최종 발표 전 가용성에 대한 현실적 추정 — 단일 cell 12시간 이상 소요 시 W2~W4 일정 안에서 어느 dataset / selectivity 조합에 한정하여 측정하는 것이 적절한지의 권장.

(5) PDX (SIGMOD 2025) 학술 confirmation 의 본 연구 contribution narrative 에의 통합 방식 — 발표 슬라이드에서 어느 위치 (Motivation / Contribution / Discussion) 에 배치하는 것이 학술 기여 강조에 효과적인지의 권장.
