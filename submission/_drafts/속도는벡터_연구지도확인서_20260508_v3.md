## 2. W1 sprint 결과 종합 (5/6~5/8)

### 2.1 RQ1 — Normal vs Skew 분포 직접 비교 (SF1·SF10 측정 완료)

5 개 dataset (DEEP 96d / SIFT 128d / SimSearchNet++ 256d / WIKI 768d / YFCC 192d) 의 SF1 (800K) 와 SF10 (8M) 두 규모에 대하여 selectivity 5 구간 (s = 0.01, 0.05, 0.10, 0.30, 0.50) 에서 BERN 의 q-error 와 분포 skew 지표 (HHI / cluster_ratio / intrinsic_dim) 간의 단조 상관 (Spearman ρ) 을 측정하였습니다. 10 개 single cell 모두에서 ρ < 0 의 sign 일관성 100% 가 관찰되었으며, 대표 셀인 DEEP-KM20 의 ρ = -0.680 (95% CI [-0.800, -0.440], 0 제외) 으로 통계적 유의성도 확보되었습니다. 이는 "selectivity 가 좁아질수록 BERN 부정확도가 단조 증가하며, 이 경향이 skew 데이터에서 더 강하게 나타난다" 는 가설 H1 의 정량 증거입니다.

### 2.2 RQ2 — KM20 + Allocation Mode Ablation (SF1·SF10 측정 완료)

RQ1 과 동일한 5 dataset × 2 SF = 10 single cell 에 대하여 KM20 (K=20 cluster) 위에서 5 개의 sample allocation mode (BERN baseline / Proportional / Neyman / Anti-Neyman / Equal) 를 selectivity 5 구간에서 비교하였습니다. 분포를 알 때 stratification 의 효과를 확인한 결과 selectivity 0.10 구간에서 paired bootstrap 95% CI 가 0 을 제외하는 cell 비율이 매우 높게 (51/52 cell, 98.1%) 관찰되었으며, "분포를 알 때 KM20 기반 stratification 이 BERN 대비 강건한 우위를 갖는다" 는 RQ2 의 1차 결론에 도달하였습니다.

한편 5 개 mode 간의 q-error 격차가 1%p 미만인 cell 이 7/12 (58.3%) 에 달하여, **mode 선택보다 분포 인지 자체가 결정적**이라는 부수 발견을 확보하였습니다. Neyman vs Anti-Neyman 비교에서도 Neyman 의 우위는 평균 0.7%p 수준에 머물렀으며, 이로써 σ 정보의 marginal contribution 은 K=20 기준에서 제한적임을 확인하였습니다.

### 2.3 RQ3 — 실험 진행할 method 선정 단계 (paradigm framework 도출)

RQ3 는 본 측정에 앞서 학술 문헌 검토를 통해 분포 미인지 sampling method 의 후보군을 체계적으로 선정하는 단계를 거쳤습니다. 광범위한 후보 (~30 method) 를 검토한 후 inductive bias 의 학술적 근거에 따라 다음 5 개 paradigm 으로 분류하고, 각 paradigm 에서 1~3 개의 representative method 를 선정하였으며, 5/8 저녁 학술 정합성 심층 검증 (ACM Computing Surveys 2024 의 clustering taxonomy + Wu UWisconsin 의 sampling-based cardinality estimation survey 와 cross-check) 을 통해 paradigm naming 을 다음과 같이 확정하였습니다.

| Paradigm | Inductive bias | 학술 출처 | Representative |
|---|---|---|---|
| **P1. Density Clustering** | "유사 데이터는 군집을 이룬다" | MacQueen 1967 (KMeans) / Campello et al. 2013 (HDBSCAN) | HDBSCAN, MiniBatch K-means, GMM |
| **P2. Space-Filling Locality** | "고차원 → 1D mapping 후 quantile 분할" | Hilbert 1891 / Lawder-King 2001 (SIGMOD) / Faloutsos & Roseman 1989 | Hilbert curve, faiss IVF |
| **P3. Online Streaming** | "OLTP 환경 = partial fit / single-pass" | Sculley 2010 (WWW Web-scale K-means) / Vitter 1985 (TOMS Reservoir) | MiniBatch_partial, Reservoir |
| **P4. Linear Projection** | "고차원 핵심 정보는 저차원 투영 보존" | Johnson-Lindenstrauss 1984 / Achlioptas 2003 (PODS/JCSS) | sparse RP, PCA1D |
| **P5. Low-discrepancy / Quasi-random** | "결정론적 균등 sampling 으로 random variance 감소" | Sobol 1967 / Niederreiter 1992 / Halton 1960 | Sobol, Halton (baseline 검증용) |

본 paradigm framework 의 의도는 "분포 정보 없이도 어떤 inductive bias 로 stratification 학습이 가능한가" 의 학술적 답변을 5 paradigm × 11 representative method 의 비교 매트릭스로 정량화하는 것입니다. 본 측정은 W2 (5/9~5/15) 부터 launch 예정이며, 측정 후 paradigm 별 효과 + production 적합성 (학습 비용 / online 적응성 / 해석 가능성) 을 비교하여 4 위 안의 representative 를 5월 27일 발표의 핵심 contribution 으로 보고할 계획입니다. 현재 단일 SF1·SF10 측정 결과로 도출한 4강 후보는 **HDBSCAN (P1, density)**, **MiniBatch_partial (P3, online streaming)**, **Hilbert curve (P2, space-filling)**, **sparse RP (P4, data-independent linear projection — Achlioptas 2003)** 로 5 paradigm 중 4 paradigm 의 distinct representative 가 1위씩 차지하는 학술 narrative 가 형성되어 있습니다.

다만 2.2 의 RQ2 결과가 "mode 선택보다 분포 인지 자체가 결정적" 이라는 부수 발견을 확보하였으므로, RQ3 본 측정에서도 method 간 격차보다는 paradigm 간 narrative 가 핵심 결과가 될 것으로 예상하고 있으며, 이는 본 확인서의 검토 요청 사항 (1) 과 (2) 항에 반영하였습니다.

## 4. 본 연구의 contribution (5/8 update)

(1) **RQ1 — Normal vs Skew × Block vs Row 정량 비교**: 5 dataset × SF1·SF10 = 10 single cell 의 sign 일관 100%, DEEP-KM20 ρ = -0.680 [-0.800, -0.440] 의 통계 유의 단조 신호. 박세은 팀장이 제기한 연구 동기 ("normal 에서 잘되던 random 이 skew 에서는 안 나오더라") 의 정량 증거입니다.

(2) **Selectivity Gradient 분석**: 좁은 쿼리 (s=1%) 에서 KM20 vs RANDOM20 격차가 19.6%p 에 달하며, 이는 Exqutor 원논문이 다루지 않은 영역입니다.

(3) **Two-Level Decomposition**: Level 1 (Proportional, K 등분의 표본 안정화 효과) 과 Level 2 (Spatial, 공간 구조 인식 효과) 의 분해 framework. RQ2 의 5-mode ablation 에서 mode 간 격차가 1%p 미만인 cell 이 58.3% 에 달하여, **Level 1 이 본 연구의 핵심 메커니즘**임이 정량 입증되었습니다.

(4) **RQ3 Paradigm Framework**: 분포 미인지 sampling 의 학술 후보군을 5 paradigm (Density Clustering / Space-Filling Locality / Online Streaming / Linear Projection / Low-discrepancy Quasi-random) 으로 체계화하고 각 paradigm 의 inductive bias 와 학술 출처 (1891 ~ 2018) 를 정리. 본 framework 자체가 "분포 정보 없이 어떤 학습이 가능한가" 에 대한 본 연구의 답변이며, 5/8 학술 정합성 심층 검증을 통해 ACM Computing Surveys 2024 와 Wu UWisconsin 의 standard taxonomy 와 align 함을 확인하였습니다.

(5) **PDX (SIGMOD 2025) 학술 confirmation**: 본 thesis 의 핵심 framing — "intrinsic_dim + skewness 가 algorithm selection 을 결정한다" — 와 정확히 일치하는 후속 학회 논문이 발표되었음을 5월 8일 회의에서 확인하였습니다. PDX 는 compute layer (data layout for fast similarity), 본 연구는 pre-process layer (sampling 분배 전략) 로 complementary contribution 을 형성합니다.

## 5. Limitation 자기 점검

본 연구의 한계와 향후 연구 방향을 다음과 같이 명시합니다.

(1) RQ2 의 KM20 + Neyman 은 **oracle benchmark** 이며 production 솔루션이 아닙니다. 실제 운영 솔루션은 RQ3 의 distribution-agnostic method 이며, 본 연구의 가치는 분포 정보의 이론적 상한과 회수율을 정량화하는 데 있습니다.

(2) 사전 계산 비용은 **one-time cost** 이며, 이는 HNSW 인덱스 빌드와 같은 layer 입니다 (DEEP 1M K=20: 1.2초, 메모리는 HNSW 의 1/1000). 쿼리 응답 시점은 stratum_id lookup O(1) 입니다.

(3) **INSERT/UPDATE 빈번한 OLTP 환경**은 본 연구 범위 외이며, 본 연구는 analytical workload (bulk load + 다수 쿼리) 를 가정합니다. RQ3 의 P3 paradigm (Online Streaming, MiniBatch_partial 등) 이 이 부담을 1/20~1/100 수준으로 완화할 가능성이 있으나, 본격 OLTP 검증은 future work 입니다.

(4) **단일 → 멀티 테이블 일반화** 및 **RQ3 본 측정**은 W2 (5/9~5/15) 진행 예정이며, 본 확인서는 W1 sprint 의 RQ1/RQ2 finalize 와 RQ3 framework 도출까지의 결과를 보고드리는 자료입니다. 단일 테이블 정확성은 멀티 테이블 정확성의 *필요조건*이지 충분조건은 아니며, 멀티 테이블에서는 join key 분포·상관 등 추가 차원이 있어 별도 검증이 필요합니다.

(5) **누락 paradigm**: Sketch family (HyperLogLog Flajolet 2007 / Count-Min Cormode-Muthukrishnan 2005) 는 cardinality estimation literature 의 standard 한 축이나, 본 연구가 *stratum 학습* (sampling 위에 올리는 framework) 이지 distinct count 가 아니므로 architectural mismatch 로 별도 paradigm 으로 다루지 않았습니다. Graph-based ANN (HNSW Malkov 2018) 은 Exqutor 원논문이 ECQO 로 처리한 영역으로 본 연구의 인덱스 부재 scope 외이며, 두 영역 모두 future work 로 명시합니다.

(6) **누락 method**: P5 의 LSH (Indyk-Motwani 1998) 는 hashing-based ANN 의 representative 이나 본 연구 K=20 stratification 에 hyperparameter mismatch 로 Wave 0 측정에서 fail 하였으며, 이로써 P5 paradigm 은 "Low-discrepancy / Quasi-random" 단일 inductive bias 로 통일하였습니다 (LSH 는 future work 의 hyperparameter tuning 영역). Mean-Shift (Comaniciu-Meer 2002) 는 P1 density 의 또 다른 축이나 K-fixed 가정과 mismatch 하여 future work, R-tree (Guttman 1984) 는 bbox overlap 이 본 연구의 disjoint partition 과 mismatch 하여 kdtree 측정으로 tree-based 대표를 cover 하였고, MinHash (Broder 1997) 는 set similarity 용으로 vector data 와 architectural mismatch 입니다.

## 6. 검토 요청 사항

채림 석사님 및 지도교수님께 다음 사항에 대한 검토 의견을 요청드립니다.

(1) RQ3 의 5 paradigm framework (Density Clustering / Space-Filling Locality / Online Streaming / Linear Projection / Low-discrepancy Quasi-random) 의 학술적 유효성 — 분포 미인지 sampling 의 분류 체계로서 본 5 paradigm 이 적절한지, 누락된 paradigm 이 있는지의 검토. 특히 §5 의 (5) 항에서 limitation 으로 분류한 Sketch family 와 Graph-based ANN 의 처리 방식이 적절한지의 권장.

(2) 각 paradigm 의 representative method 선정의 이론적 정당성 — 11 개 representative method 가 paradigm 별 inductive bias 를 충실히 대표하는지, 또는 추가/대체 후보가 있는지의 권장. 특히 P4 의 ★4 후보로 sparse RP (Achlioptas 2003, data-independent) 와 PCA1D (Pearson 1901, data-dependent) 중 "분포 모를 때" 라는 RQ3 framing 에 sparse RP 가 더 적합하다는 본 팀의 판단에 대한 검토.

(3) Exqutor 원논문의 Adaptive Sampling 과의 정면 비교 실험 설계의 적절성 — 동일 dataset / selectivity / sample_size 조건에서 KM20 + RQ3 representative ensemble 과 Adaptive Sampling baseline 의 q-error 를 paired 비교하는 W2 실험안.

(4) **Adaptive×4강 Ensemble 의 5월 27일 발표 narrative 가치** — 5월 8일 22시에 launch 한 4강 stratification × Adaptive Sampling dynamic budget ensemble (10 cell × 4 base method × 5 sel × 5 seed × 100 query = 10,000 measurement, 1-2시간 내 완료 예정) 의 결과가 단순 4강 또는 단순 Adaptive 대비 paired-significant 우위를 보일 경우, 5월 27일 발표의 추가 contribution 으로 narrative 통합하는 것이 적절한지의 권장.

(5) PDX (SIGMOD 2025, CWI Amsterdam, arXiv:2503.04422) 학술 confirmation 의 본 연구 contribution narrative 통합 방식 — 발표 슬라이드에서 어느 위치 (Motivation / Contribution / Discussion) 에 배치하는 것이 학술 기여 강조에 효과적인지의 권장.
