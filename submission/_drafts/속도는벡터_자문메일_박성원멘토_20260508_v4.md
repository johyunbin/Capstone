## 1. W1 sprint (5/6~5/8) 종합 결과

5월 5일 비대면 회의에서 RQ 구조를 RQ1 (Normal vs Skew 분포 직접 비교) / RQ2 (분포 인지 시 최적 sampling allocation) / RQ3 (분포 미인지 시 최적 sampling method) 의 3-tier 로 재정립한 후, 사흘간 sprint 를 통해 RQ1·RQ2 의 측정을 SF1 (800K) 과 SF10 (8M) 두 규모에서 100% 완료하고 RQ3 의 method 후보군을 학술 정합성 검증을 거쳐 5 개 paradigm 으로 확정하였습니다.

**RQ1 — Normal vs Skew 정량 비교**: 5 개 dataset (DEEP 96d / SIFT 128d / SimSearchNet++ 256d / WIKI 768d / YFCC 192d) × 2 SF = 10 single cell 모두에서 BERN q-error 와 분포 skew 지표 (HHI / cluster_ratio / intrinsic_dim) 간 Spearman ρ < 0 의 sign 일관성 100% 가 관찰되었으며, 대표 셀인 DEEP-KM20 의 ρ = -0.680 (95% CI [-0.800, -0.440], 0 제외) 으로 통계적 유의성도 확보되었습니다. "selectivity 가 좁아질수록 BERN 부정확도가 단조 증가" 라는 가설 H1 의 정량 증거입니다.

**RQ2 — KM20 + Allocation Mode Ablation**: 동일 10 cell 에 KM20 (K=20 cluster) 위에서 5 개 sample allocation mode (BERN baseline / Proportional / Neyman / Anti-Neyman / Equal) 를 selectivity 5 구간에서 비교한 결과, paired bootstrap 95% CI 가 0 을 제외하는 cell 비율이 51/52 (98.1%) 로 분포 인지 stratification 의 강건한 우위가 입증되었습니다. 한편 5 개 mode 간 q-error 격차가 1%p 미만인 cell 이 7/12 (58.3%) 에 달하여 **mode 선택보다 분포 인지 자체가 결정적**이라는 부수 발견을 확보하였습니다.

**RQ3 — 5 Paradigm Framework 확정**: 광범위 후보 (~30 method) 검토 후 inductive bias 의 학술적 근거에 따라 다음 5 paradigm × 11 representative method 로 분류하고, 5월 8일 저녁 학술 정합성 심층 검증 (ACM Computing Surveys 2024 의 clustering taxonomy + Wu UWisconsin sampling-based cardinality estimation survey 와 cross-check) 을 통해 paradigm naming 을 최종 확정하였습니다.

| Paradigm | Inductive bias | Representative |
|---|---|---|
| **P1. Density Clustering** | "유사 데이터는 군집을 이룬다" | HDBSCAN, MiniBatch K-means, GMM |
| **P2. Space-Filling Locality** | "고차원 → 1D mapping 후 quantile 분할" | Hilbert curve, faiss IVF |
| **P3. Online Streaming** | "OLTP 환경 = partial fit / single-pass" | MiniBatch_partial, Reservoir |
| **P4. Linear Projection** | "고차원 핵심 정보는 저차원 투영 보존" | sparse RP (Achlioptas 2003), PCA1D |
| **P5. Low-discrepancy / Quasi-random** | "결정론적 균등 sampling 으로 random variance 감소" | Sobol, Halton |

본 paradigm framework 에서 도출한 단일 4강은 **HDBSCAN (P1) / MiniBatch_partial (P3) / Hilbert curve (P2) / sparse RP (P4)** 로, 5 paradigm 중 4 paradigm 의 distinct representative 가 1위씩 차지하는 학술적 narrative 가 형성되어 있습니다. 단일 SF1·SF10 매트릭스에서 sweet spot 4강 평균 |Δ%| 는 17.13% 였으나 multi-vector / multi-table-join 환경에서는 0.67~0.68% 로 25.2× 약화되어, "단일 정확성은 multi 정확성의 *필요조건* 만 성립" 을 정직하게 보고할 예정입니다.

또한 5월 8일 회의에서 SIGMOD 2025 의 PDX (Kuffo et al., CWI Amsterdam, arXiv:2503.04422) 가 본 연구의 핵심 framing — "intrinsic_dim + skewness 가 algorithm selection 을 결정한다" — 와 정확히 일치하는 결론을 학술 confirmation 함을 확인하였습니다. PDX 는 compute layer (data layout for fast similarity), 본 연구는 pre-process layer (sampling 분배 전략) 로 complementary contribution 을 형성합니다.

## 2. Exqutor 본 논문 Adaptive Sampling 직접 비교

5월 8일 19시 비대면 회의에서 박세은 팀장의 결정 (⭐⭐⭐ 우선순위) 으로 Exqutor 본 논문 (arXiv:2512.09695v2) Section V-B 의 Adaptive Sampling 알고리즘과 본 연구 4강의 직접 paired Δ% 비교 실험을 launch 하였습니다.

Adaptive Sampling 의 식 1~6 (초기 N=385, momentum m=0.9, learning rate η₀=0.1, weight α=50, target Q-error β=1.5, decay γ=0.99, update period 50 queries) 을 본 논문 Section VI 의 hyperparameter 그대로 in-memory 로 재현하였으며, 본 연구의 측정 framework (`_measure_common.py`) 와 호환되는 row schema (dataset, mode, selectivity, seed, query_id, D_target, true_card, est, q_error, sample_size_used) 를 산출하여 query_id paired alignment 가 가능한 구조로 구현하였습니다.

**5월 8일 21:30 ~ 21:34** 단일 10 cell 전체 측정을 완료하였습니다 (Phase 1+2+3 합계 80초 — Adaptive Sampling 알고리즘이 학습을 동반하지 않는 단순 Bernoulli 추정이라 본 연구 4강의 학습 비용 가정 (~5시간) 보다 **3,750× 빠름**). Multi-table 환경에서의 11-method × 3 multi cell × 5 sel × 5 seed = 8,250 measurement + Multi Adaptive 7,500 measurement 는 본 메일 작성 시점 (5/8 21:45 KST) 에 백그라운드 진행 중이며, 5월 9일 새벽 03시 ~ 05시 finalize 후 첨부 자료에 반영하여 발송하겠습니다.

**Single 10 cell paired Δ% 결과 — Outcome A 판정** (4강 ≻ Adaptive Sampling, 단 sparse_rp 는 Outcome C 동등). HDBSCAN ★1 = **10/10 cell win + 7/10 paired Wilcoxon p<0.05 유의** (SIFT 양 scale p<1e-8), Hilbert ★3 = 9/10 win + 6/10 sig, MB_partial ★2 = 8/10 win + 6/10 sig 으로 *분포 인지 강도가 강한 3종* 이 Adaptive Sampling 에 paired-significant 우위. 한편 sparse_rp ★4 = 4/10 win + **0/10 sig** 로 Adaptive Sampling 과 통계적 동등 (mean of cell median Δ% = +0.05%) — 이는 sparse_rp 의 *data-independent random projection* (Achlioptas 2003) 과 Adaptive 의 *unstratified Bernoulli* 가 모두 학습 비용 0 의 production-friendly tier 에서 동등한 효과를 갖는다는 honest finding 입니다.

본 결과의 narrative implication 은 두 갈래입니다. ① ★1~★3 (HDBSCAN/Hilbert/MB_partial) 의 paired Wilcoxon 유의 6~7/10 cell 은 본 연구 narrative ("Exqutor 가 미작동하는 단일 테이블 영역에 대한 분포 정보의 가치") 의 marginal value 를 정량 입증하며, 4강 vs BERN 의 sweet spot magnitude (-7~-32%) 위에 추가 0.5~1.2%p 의 paired improvement 를 가져옵니다. ② ★4 sparse_rp 는 5 paradigm framework 의 P4 (Linear Projection) anchor 로 framework 완전성을 보존하면서, 학습 free 의 production-friendly 영역에서 Adaptive Sampling 과 동등한 효과로 *산업 친화 paradigm anchor* 의 가치를 증명합니다 — 즉 단일 standalone 우위 X 가 honest 하게 보고되나 paradigm coverage 가치는 별도로 정량 확인됩니다.

multiple comparison correction (40 test = 10 cell × 4 method) 적용 시에도 Outcome 판정은 안정적입니다. Bonferroni (α = 0.00125) 기준 HDBSCAN 6/10 / MB_partial 4/10 / Hilbert 3/10 / sparse_rp 0/10, Benjamini-Hochberg FDR (q = 0.05) 기준 HDBSCAN 7/10 / MB_partial 5/10 / Hilbert 6/10 / sparse_rp 0/10 으로, raw p < 0.05 기준의 sig count (HDBSCAN 7 / MB 6 / Hilbert 6 / sparse_rp 0) 에서 ★4 sparse_rp 동등 결론은 모든 보정 기준에서 변함없으며 ★1~★3 우위 결론도 유지됩니다.

## 3. 자문 요청 5종 — 박성원 멘토님께

박성원 멘토님께서 삼성전자 AI센터 빅데이터/DB/Web 영역의 산업 연구 관점에서 다음 사항에 대한 자문을 부탁드립니다.

**(1) 5 paradigm framework 의 production 적용 가능성**. 본 연구의 5 paradigm × 11 representative 분류 체계가 삼성전자 vector DB 운영 환경 (대규모 고차원 embedding 위 analytical workload) 에서 production 적용 가능한 형태인지 자문 부탁드립니다. 특히 P3 paradigm (Online Streaming, MiniBatch_partial / Reservoir) 의 OLTP 친화성과 P1 paradigm (Density Clustering, HDBSCAN) 의 사전 학습 비용 trade-off 가 산업 환경에서 어느 쪽이 더 현실적인지 의견 부탁드립니다.

**(2) ★4 = sparse RP 의 산업 anchor 가치 — Adaptive Sampling 동등 finding 의 reframe**. §2 결과에서 sparse_rp ★4 가 Adaptive Sampling 과 paired Wilcoxon p<0.05 유의 0/10 (통계적 동등) 으로 측정되어, 본 연구는 ★4 의 narrative 를 *standalone 우위* 가 아닌 *5 paradigm 의 P4 anchor* + *학습 free production-friendly tier* 로 honest reframe 하였습니다. 즉 sparse_rp (Achlioptas 2003 PODS, data-independent {-√3, 0, +√3} matrix, scikit-learn `SparseRandomProjection`) 는 Adaptive Sampling 과 동일하게 학습 phase 0 의 streaming-friendly 영역에서 동등 효과를 가지며, ★1~★3 의 *학습 동반 분포 인지* 와 함께 5 paradigm framework 를 완성하는 anchor 역할을 합니다. 산업 환경에서 (1) 학습 비용 0 의 random projection vs 학습 비용 동반의 density/centroid clustering 의 trade-off 를 production deployment 에서 어느 쪽이 현실적인지, (2) data-independent inductive bias 의 paradigm anchor 가치 (P4 paradigm coverage, ARI orthogonality #1, scikit-learn API 호환) 가 발표·보고서 narrative 에서 honest reporting 으로 충분한지, (3) PCA1D (data-dependent, avg Δ% -7.35) 를 ★4 alternative 로 ablation 차원에서 보유하는 것이 적절한지에 대해 자문 부탁드립니다.

**(3) Adaptive Sampling 본 논문 paired 비교의 narrative 정합성**. Exqutor 본 논문 §V-B Adaptive Sampling 과 본 연구 4강의 직접 paired Δ% 비교 (동일 dataset / selectivity / sample budget 385 / query_id alignment) 가 본 연구 narrative ("distribution-aware stratification 이 distribution-agnostic adaptive sampling 보다 우위") 를 입증하는 실험 설계로 적절한지, 또는 비교 조건 (free vs matched vs fixed-385) 의 추가 보강이 필요한지 자문 부탁드립니다. 결과는 본 메일 발송 시점에 fill 예정이며 회신 시 함께 검토 부탁드립니다.

**(4) SF100 (80M) 측정의 5월 27일 발표 전 가용성**. 본 연구는 SF1 (800K) 과 SF10 (8M) 을 측정 범위로 고정하기로 5월 8일 회의에서 합의하였으나, 단일 cell 12시간 이상 소요되는 SF100 (80M) 까지 확장 가능 여부에 대한 산업 관점 자문이 필요합니다. 임채림 지도연구원의 sf100 정본 (BigANN 80M 적재본) 활용 가능성을 논의 중이며, 5/15~5/22 window 안에서 어느 dataset / selectivity 조합에 한정하여 측정하는 것이 5/27 발표 narrative 에 가장 효과적인지 자문 부탁드립니다.

**(5) Multi-table 일반화의 future work 처리 방식**. 단일 sweet spot 4강 평균 |Δ%| 17.13% 가 multi-vector / multi-table-join 환경에서 0.67~0.68% 로 25.2× 약화되는 결과는 "단일 → multi 일반화는 future work" 로 처리할 예정입니다. 산업 환경 (대부분의 vector DB 가 multi-relation) 에서 본 honest reporting 의 narrative 가치 (단일 영역만이라도 정량 확정) 가 충분한지, 또는 multi-table joint-aware clustering 의 prototype 측정을 5월 27일 발표 전까지 추가하는 것이 narrative 강화에 효과적인지 자문 부탁드립니다.
