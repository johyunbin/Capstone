# [속도는벡터] 연구 진행 경과 보고 및 3차 자문 요청

박성원 멘토님 안녕하십니까, 연세대학교 캡스톤 디자인 속도는벡터 팀 조현빈입니다.

4월 15일 2차 자문에서 단일 테이블 시나리오 좁힘과 Two-Level Decomposition에 대해 조언해주신 내용을 반영해 4월 28일 중간보고서와 4월 30일 중간발표를 잘 마쳤습니다. 이후 5월 27일 최종 발표를 위한 본선 실험을 모두 마무리하였고, 본 3차 자문을 부탁드립니다 (최종 보고서 제출(6월 11일) 전 4차 자문도 한 차례 더 부탁드릴 예정입니다).

본 연구는 단일 테이블 vector range query 영역 (Exqutor 본 논문이 hook 사각지대로 두는 영역) 에서 분포 정보 활용의 가치를 정량 측정하는 것이 목표이며, RQ1 (분포 차이가 추정 정확도에 영향을 주는가) → RQ2 (분포를 알 때 어떤 표집 방식이 최적인가) → RQ3 (분포를 모를 때 어떤 방식이 최적인가) 의 세 단계 구조로 진행했습니다. 5종 데이터셋 (DEEP / SIFT / SSN++ / WIKI / YFCC) × 두 규모 (sf1 = 80만 행, sf10 = 800만 행) 의 단일 10 cell + multi-vector / multi-table-join 6 cell = 총 16 cell 에서 100 query × 5 selectivity × 5 seed 측정을 마쳤습니다.

자문 받고 싶은 두 가지 사항입니다.

## 1. 데이터셋 분포를 *아는* 경우 (RQ2)

기존 분포 인지 표집 방식 (Bernoulli baseline 대비 KM20 + 비례 분배) 의 최대 성능은 **단일 sweet spot 평균 17%p Q-error 개선** 이었습니다. 한 단계 더 끌어올리기 위해 σ_i (cluster 별 표준편차) 정보를 활용하는 Neyman 분배를 도입했지만, **skew 데이터셋의 작은 selectivity 에서만 marginal 개선** (비례 분배 대비 +0.5%p) 으로 제한적이었습니다.

원인은 두 가지가 결합된 결과로 추정합니다 — (i) 다섯 분배 방식 (Bernoulli / 비례 / Neyman / Anti-Neyman / 균등) 사이의 격차가 12 cell 중 7 cell 에서 1%p 미만으로 작은 점, (ii) KM20 의 cluster 들 사이에서 σ_i 변별력이 충분하지 않은 점. (Anti-Neyman 만 systematic hurt 를 보여 σ_i 신호의 *존재* 자체는 확인했습니다.)

다음 탐색 방향을 어떻게 잡으면 좋을지 의견 부탁드립니다 — **(a) Neyman 분배를 변형** 하는 방향 (cluster-aware σ̂ 정밀화 / hierarchical Neyman 등) 또는 **(b) 아예 새로운 분배 방식** 을 찾는 방향. 산업 환경에서 어느 쪽이 더 현실적일지 듣고 싶습니다.

## 2. 데이터셋 분포를 *모르는* 경우 (RQ3)

분포 무인지 표집 method 후보를 inductive bias 기준으로 5가지 paradigm 으로 분류하고 각 paradigm 의 대표 method 11종을 비교했습니다.

| Paradigm | 대표 method |
|---|---|
| P1 Density Cluster | HDBSCAN, MiniBatch K-means, GMM |
| P2 Spatial Locality | Hilbert curve, faiss IVF |
| P3 Online Streaming | MiniBatch_partial, Reservoir |
| P4 Linear Projection | sparse Random Projection, PCA1D |
| P5 Quasi-random | Sobol, LSH |

자문 부탁드립니다 — **(a) 5 paradigm 정도의 개수를 유지** 하는 것이 좋은지 (4개로 축소 또는 6~7개로 확장), **(b) inductive bias 기준으로 분류해서 비교** 하는 방식이 학술적으로 타당한지. 본 분류는 ACM Computing Surveys 2024 의 clustering taxonomy + UWisconsin Wu et al. 의 sampling-based cardinality estimation survey 와 cross-check 하였습니다.
