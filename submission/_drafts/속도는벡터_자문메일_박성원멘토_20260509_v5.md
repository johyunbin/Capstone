# [속도는벡터] 연구 진행 경과 보고 및 3차 자문 요청

박성원 멘토님 안녕하십니까, 연세대학교 캡스톤 디자인 속도는벡터 팀 조현빈입니다.

4월 15일 2차 자문에서 단일 테이블 시나리오 좁힘과 Two-Level Decomposition에 대해 조언해주신 내용을 4월 28일 중간보고서와 4월 30일 중간발표에 잘 반영하였습니다. 이후 5월 27일 최종 발표를 위한 본선 실험을 모두 마무리하였고, 이번 3차 자문을 부탁드립니다.

본선 실험은 2차 자문 때 보고드린 5종 데이터셋 (DEEP / SIFT / SSN++ / WIKI / YFCC) 을 두 가지 규모 (sf1 = 80만 행, sf10 = 800만 행) 로 측정하여 마쳤고, 자문 받고 싶은 두 가지 사항이 있습니다.

## 1. 데이터셋 분포를 *아는* 경우 (RQ2)

기존 분포 인지 표집 방식 (k-means K=20 + 비례 분배) 의 최대 성능은 **단일 sweet spot 평균 17%p Q-error 개선** 이었습니다. 한 단계 더 끌어올리기 위해 cluster 별 표준편차 정보를 추가로 활용하는 **Neyman 분배** (분산이 큰 cluster 에 더 많이 표집하는 방식) 를 도입했지만, **skew 데이터셋의 작은 selectivity 에서만 marginal 개선** (비례 분배 대비 +0.5%p) 으로 제한적이었습니다.

원인은 k-means K=20 의 cluster 들 사이에서 표준편차 차이가 크지 않아 Neyman 의 변별력이 약했던 것으로 추정합니다. 다만 분산이 작은 cluster 에 일부러 더 표집하는 Anti-Neyman 분배에서는 체계적으로 정확도가 악화되어, 표준편차 신호 자체는 의미가 있음을 확인했습니다.

다음 탐색 방향을 어떻게 잡으면 좋을지 의견 부탁드립니다 — **(a) Neyman 분배를 변형** 하는 방향 (예컨대 cluster 별 표준편차 추정을 정밀화하거나 계층적으로 나누는 방식) 또는 **(b) 아예 새로운 분배 방식** 을 찾는 방향. 산업 환경에서 어느 쪽이 더 현실적일지 듣고 싶습니다.

## 2. 데이터셋 분포를 *모르는* 경우 (RQ3)

분포 무인지 표집 method 후보를 작동 원리 기준으로 5가지로 분류하고 각 분류의 대표 method 11종을 비교했습니다.

| 분류 | 대표 method |
|---|---|
| 밀도 기반 cluster | HDBSCAN, MiniBatch K-means, GMM |
| 공간 국소성 (1D 매핑) | Hilbert curve, faiss IVF |
| 온라인 streaming | MiniBatch_partial, Reservoir |
| 선형 투영 (random projection) | sparse Random Projection, PCA1D |
| 저편차 표집 | Sobol, LSH |

자문 부탁드립니다 — **(a) 5가지 정도의 개수를 유지** 하는 것이 좋은지 (4가지로 축소 또는 6~7가지로 확장), **(b) 이렇게 작동 원리 기준으로 분류해서 비교** 하는 방식이 학술적으로 타당한지.
