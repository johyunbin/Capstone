## 2. Mechanism 정량 분석 (W1-C)

Hilbert 의 강한 결과의 origin 을 (a) PCA 효과 vs (b) curve 자체의 locality 효과 로 분리 검증하기 위해 **Z-order curve** (PCA+quantile 동일, curve 만 다른 ablation) 와 **PCA-1D quantile** (curve X) 를 추가 구현하였습니다.

Synthetic data 에서 두 metric 직접 측정:

1. **Inverse Manhattan distance** (1D 인접 → 2D Manhattan distance):
   - Hilbert: 1.000 (perfect 1D-2D continuity)
   - Z-order: 1.992, fraction (Manhattan > 1) = 0.500

2. **Stratum compactness** (각 stratum 내 좌표 std):
   - Hilbert: SIFT-like skew 데이터에서 4.77
   - Z-order: 12.12 (**2.54× 더 흩어짐**)

3. **ARI redundancy** (Adjusted Rand Index, 정보 동의도):
   - Hilbert ↔ Z-order = 0.479 (50% information overlap)
   - Hilbert ↔ PCA-1D = 0.297 (2D + curve 가 1D 대비 정보 추가)

## 3. 자문 요청 사항

본 mechanism 분석의 학술적 robust 성에 대해 다음 의견을 듣고 싶습니다:

**(가) Inverse Manhattan metric 의 적절성**: Hilbert curve 의 locality 의 표준 측정이 본 metric (1D 인접 → 2D Manhattan) 인지, 또는 추가 metric (correlation between 1D distance and 2D Euclidean, etc.) 가 더 적절한지?

**(나) Stratum compactness 와 HT estimator variance 의 직접 연결**: 본 연구는 \"Hilbert 의 stratum compactness 가 HT estimator within-stratum variance 감소로 직접 효과\" 라 narrative 하나, stratum compactness 와 estimator variance 의 정량 관계 (변환식 또는 bound) 가 학술적으로 알려진 결과가 있다면?

**(다) Hilbert 의 PCA dependence 한계**: Hilbert 의 fit 이 학습 sample 의 PCA basis 에 의존하므로, distribution shift (production 의 INSERT 패턴 변화) 에 적응 X. 본 한계의 상대적 심각성 — KM20 oracle 의 사전 학습 부담 vs Hilbert 의 PCA basis 고정 — 에 대한 평가?

**(라) 본 narrative 의 공헌 수준**: \"learning-free + 결정론 stratification\" 이 Vector DB 분야에서 새 contribution 인지, 또는 기존 IVF / PQ / HNSW 등에 비해 어떤 위치에 있는지 ?
