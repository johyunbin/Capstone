## 2. RQ3 Hilbert Mechanism 정량 분석 (W1-C)

Hilbert 의 강한 결과의 origin 을 (a) PCA 효과 vs (b) curve 자체의 locality 효과로 분리 검증하기 위해 **Z-order curve** (PCA+quantile 동일, curve 만 다름) 와 **PCA-1D quantile** (curve X) 를 추가 구현.

1. **Inverse Manhattan distance** (1D 인접 → 2D Manhattan distance):
   - Hilbert: 1.000 (perfect 1D-2D continuity)
   - Z-order: 1.992, fraction (Manhattan > 1) = 0.500

2. **Stratum compactness** (각 stratum 내 좌표 std):
   - Hilbert: SIFT-like skew 데이터에서 4.77
   - Z-order: 12.12 (**2.54× 더 흩어짐**)

3. **ARI redundancy** (Adjusted Rand Index, 정보 동의도):
   - Hilbert ↔ Z-order = 0.479 (50% information overlap)
   - Hilbert ↔ PCA-1D = 0.297 (2D + curve 가 1D 대비 정보 추가)

**5/7 추가 — Method orthogonality ranking** (5 ARI CSV 통합 분석):
- 직교성 ranking (avg ARI): sparse_rp 1위 (0.122) → pca1d (0.277) → curve sibling Hilbert/Z-order (0.31) → tree (0.331) → cluster method 4종 (0.55+)
- 7-way 비교 (KM20 / sparse_rp / pca1d / Hilbert / cluster / tree / online weight) 가 정보 직교성 5 region 모두 cover → "정보적으로 직교한 7-way ablation" 정량 입증

## 3. 자문 요청 사항 (5종, 5/8 회의 합의 후 발송)

**(가) Inverse Manhattan metric 의 적절성**: Hilbert curve locality 의 표준 측정이 본 metric (1D 인접 → 2D Manhattan) 인지, 또는 추가 metric (correlation between 1D distance and 2D Euclidean, Lebesgue measure 보존도 등) 가 더 적절한지?

**(나) Stratum compactness 와 HT estimator variance 의 직접 연결**: "Hilbert 의 stratum compactness 가 HT estimator within-stratum variance 감소로 직접 효과" 라는 narrative 의 학술 정량 관계 (변환식 또는 bound) 가 stratified sampling 문헌에 있는지?

**(다) Hilbert 의 PCA dependence 한계**: Hilbert 의 fit 이 학습 sample 의 PCA basis 에 의존 → distribution shift (production INSERT 패턴 변화) 에 적응 X. KM20 oracle 의 사전 학습 부담 vs Hilbert 의 PCA basis 고정의 상대 심각성 평가?

**(라) "learning-free + 결정론 stratification" framing 의 Vector DB 분야 contribution 위치**: IVF / PQ / HNSW 등 기존 indexing 과의 차별점이 어디에 있다고 보시는지? Hilbert 가 query-time stratification 의 새 paradigm 인지, 또는 prior work (Z-order based vector indexing 등) 의 한 variant 인지?

**(마) RQ1 Phase 6/7 5-cell 단조성 격차의 origin 학술 분리** (5/7 W2 NEW): numpy estimator 의 sampling-population scope (≤10K row 캐시에서 추출 + HT weight 만 N=1M 적용) vs vector.c hook 의 production env 측정 path 차이 — 둘의 정량 분리가 가능한 학술 framework 또는 prior work? 본 5-cell 격차 자체를 measurement methodology robustness sub-contribution 으로 격상하는 framing 의 학술 가치?
