## 1. 본 연구 한 줄 요약

본 논문 (Exqutor) 의 §V-B 적응적 샘플링 영역에서, 본 논문 베르누이 추정값과 우리의 분포 인지 계층적 표집 추정값을 산술 평균으로 합치면 (`est_final = (est_bernoulli + est_method) / 2.0`) 짝지어 비교한 측정의 92.5% (455/492) 에서 베르누이 단일 baseline 보다 더 정확하다 (p < 10⁻⁴⁵). 우리 측정은 산술 평균에 한정되었고, 가중치 평균이나 기하 평균, 분산 기반 결합 같은 다른 결합 방식과의 비교는 future work 다.

## 2. 측정 portfolio — 분포 인지 방법 56 의 폐기 분류

본 연구의 RQ3 는 분포 정보를 얻으려는 후보 method 56 개를 8 패러다임 (클러스터링, 공간 분할, 스트리밍, 차원 축소, 정보 이론, 양자화, 준 무작위, 밀도 추정) 으로 모아 9 cell 매트릭스에서 측정한 결과다. 측정을 진행하면서 일부 method 는 그대로 둘 수 없어서 폐기했어. 폐기 사유를 측정 과정 그대로 정리하면 이렇다.

**자원 한계로 실행이 어려운 method (6 종)**

- **birch**: 작은 데이터셋에서도 50 ~ 200GB 메모리를 사용해서 측정 서버에서 실행이 불가능했음.
- **agglomerative**: SimSearchNet++ 256 차원에서 nearest-centroid 계산이 메모리 부족으로 실행 실패.
- **hdbscan**: 데이터셋 일부에서 KMeans 로 fallback 되어 본질적으로 KMeans 와 동등한 결과.
- **kde_parzen**: 한 cell 측정에 4 시간 이상 timeout 이 필요해서 전체 portfolio 9 cells × 56 method 완성이 어려웠음.
- **dirichlet, kernelpca, neuocard**: 자원이나 구현 안정성 문제로 9 cells 전부 완료 못함.

**알고리즘 정독 검토 (5월 10일 8-agent code audit) 에서 paper 의도와 다른 것이 발견된 method (23 종)**

- **kdtree**: 알고리즘 구현 코드를 보면 leaf 인덱스가 random hash (`idx % n_strata`) 로 처리되어 있어서 무작위 표집과 거의 동등 — paper 가 의도한 kdtree 효과가 아님.
- **vinecopula**: 코드 구현이 rank + PCA 1 차원 정렬의 별칭으로 되어 있어서 Bedford-Cooke 1986 의 진짜 vine copula 가 아님.
- **neuram**: 코드 한 줄씩 검토한 결과 PCA1D 와 100% 동일.
- **ams_count_sketch**: lsh 와 코드가 한 줄씩 동일.
- 그 외 약 20 종도 같은 방식으로 reference 위반이 발견되어 폐기.

**큰 데이터셋에서 추정값이 극단으로 튀는 method (정합성 위반 9 종)**

halton, sobol, lhs, hammersley, dense_rp, random_projection, dbscan, ccsketch, lsh, ams_count_sketch — 측정 결과가 SSN sf=100 같은 큰 dataset 에서 +145,483%, +213,065% 등의 외곽 값으로 나타나서 paper N=385 sample budget 안에서 estimator 정합성을 보장하지 못함.

폐기를 거치고 남은 측정 가능 method 는 약 43 개. 이들이 비교 실험군이고 9 cells × 2 modes 가 모두 완료된 method 로 한정. 본 연구 비교 실험군 file 은 약 750-800 개. paper 재현 정합성도 네 축에서 검증한 결과 (절사 평균 Q-error 1.618 vs paper 1.69, -4.3% 차이) 논문 리뷰 수준.

## 3. 핵심 결과 — 7 단계 순차 흐름

### 3.1 단독 대체 가능성 분석 (단계 3)

남은 43 method 의 추정값을 본 논문의 베르누이 대신 그대로 갈아 끼우는 단독 대체 모드 (CaseA) 의 결과를 정직하게 풀면:

- **평균 우위 약 40%**: 56 방법 중 약 40% 가 평균적으로는 베르누이 기준선보다 정확.
- **통계 일관 우위 7.6% (15/197)**: BH-FDR 보정 + paired Wilcoxon p<0.05 로 cell 전반에서 안정적으로 베르누이를 우위로 누른 method 는 7.6% 정도.
- **15 method 의 평균 개선폭 -5 ~ -12%**: 단독 대체로 통계 일관 우위인 15 method 의 평균 개선폭은 -5 ~ -12% 다. 이는 paper 자체 재현 시 발생하는 측정 변동 (-4.3%) 보다 1.2 ~ 3 배 큰 의미 있는 개선이다 (즉 단독 대체로도 noise floor 를 넘는 실제 개선이 가능한 method 가 존재).
- **selectivity / dataset 별 편차**: 같은 method 라도 cell 마다 효과가 다름.

즉 단독 대체로도 일부 method 와 일부 cell 에서는 가능하지만, 56 방법 전체에 걸쳐 산업 적용 보장할 만한 압도적 우위는 아니다. 이 안정성 부족이 결합 framework 검토 (CaseB) 의 motivation.

### 3.2 결합 framework — 산술 평균 (단계 4)

베르누이 추정값과 우리 method 의 추정값을 산술 평균하면 (`est_final = (est_bernoulli + est_method) / 2.0`), 492 짝지어 비교한 측정 중 455 개 (92.5%) 가 베르누이 baseline 보다 더 정확. paired Wilcoxon p < 10⁻⁴⁵, Cliff's δ large better 63.0%, Hedges' g large 55.7%.

베르누이의 편향 0 / 분산 큰 특성과 계층적 표집의 분산 작은 / 편향 가능 특성을 산술 평균으로 결합하면 한 쪽이 실패해도 다른 쪽이 보완해 주는 안정적인 구조. 산술 평균이 가장 좋은 결합 방식인지는 모르며 (가중치 평균 / 기하 평균 / 분산 기반 결합 비교는 future work).

### 3.3 자원 효율 분석 (단계 5) — Centroid tuple cheap 근사

재현이가 5/13 0:20 + 14:27 카톡으로 제기한 후속 가설 두 가지 — multi-table 재계층화의 정확도 영향과 저비용 근사 가능성 — 를 정량 검증한 결과.

multi-table cell 에서 계층적 표집을 어떻게 할지의 두 후보 — 비싼 multi-join 재학습 (864 차원 concat 후 KM20 재학습) vs cheap 근사 (Centroid tuple, 두 single-table 클러스터 결과의 (s_A, s_B) tuple folding, 학습 비용 0 추가, 강재현 5/13 14:27 카톡 제시 방향). 8 measurement 결과: CaseB 산술 평균 모드에서 4 method 모두에서 cheap 근사가 비싼 재학습보다 평균 -0.84%p 추가 정확도. **"더 싸고 더 좋은"** best of both worlds 결과로 multi-table 영역 확장의 cheap 근사 가능성.

또한 multi-join 재학습 자체 결과 (재현이 5/13 0:20 카톡 제시 방향): CaseA 단독 대체 모드에서 sparse_rp 와 chao_weighted 는 -2.6 ~ -3.5%p 추가 개선, Hilbert curve 와 HyperLogLog 는 거의 차이 없음. CaseB 산술 평균 모드에서는 4 method 모두 차이 없음 (평균 -0.12%p) — **우리 핵심 기여인 산술 평균은 학습 방식 변경에 안정적** 이라는 분명한 증거.

## 4. paradigm 별 결과 (보조 표)

8 패러다임 중 다섯 개가 평균적으로 의미 있는 우위.

| paradigm | 평균 Δ% (CaseB) | 대표 anchor method |
|---|---:|---|
| 밀도 추정 | -11.93% (n=1 caveat) | KDE Parzen |
| 정보 이론 | -7.60% (n=9) | HyperLogLog |
| 스트리밍 | -6.63% | Chao 1982 weighted reservoir |
| 차원 축소 | -6.03% | Sparse Random Projection |
| 공간 분할 | -5.57% | Hilbert curve, Z-order |

[5/13 1:00 재현이 지적 반영] — paradigm 평균만으로는 paradigm 우위를 단정 짓기 어렵다. paradigm 안의 일부 method 가 극단값 (outlier) 으로 평균을 끌어 올리거나 끌어 내릴 수 있음 (예: wavelet_hist +68%, lp_bound +16%). 우리는 paradigm 평균과 함께 12 anchor method 의 일관성 (-9 ~ -10% × std 2 ~ 3) 을 학술 도메인 자문 영역 (박광현 교수님 / 임채림 박사님) 으로 묶어서 별도 부록으로 다룰 예정.

또한 3-axis sensitivity 분석 결과 (2 axis 일치 + 1 axis 다른 분류):

| Method | K granularity sensitivity | Multi-jn sensitivity | Cheap 근사 친화도 |
|---|---|---|---|
| sparse_rp | K-sensitive (U-shape) | sensitive (-3.55p) | Indifferent |
| chao_weighted | K=20 sweet | sensitive (-2.63p) | **Friendly** |
| hilbert_real | K-robust | robust | Hostile (CaseA harmful) |
| hyperloglog | K-robust | robust | **Friendly** |

K granularity 와 multi-table 재계층화 두 axis 는 method 별 민감도 분류가 일치 (sparse_rp + chao_weighted sensitive vs hilbert_real + hyperloglog robust). 그러나 저비용 근사 친화도는 다른 분류 (Friendly: hyperloglog + chao_weighted). 즉 method 의 내부 메커니즘이 측정 영역에 따라 다른 영향을 미친다. 2 axis 일치는 method-level consistency 의 evidence 이지만, 1 axis 다른 분류는 단순 sensitivity 분류로 환원되지 않는 점을 정직하게 표기.

## 5. 한계 및 정직하게 짚어 둘 부분

5월 측정 portfolio 의 미커버 영역을 9 카테고리로 분류했다. 그리고 method 단위로 정직하게 짚어 둘 부분이 두 가지:

첫째, hilbert method 가 코드에서 PCA 2D 정렬로 구현되어 있어서 진짜 Hilbert curve 효과가 아니라 PCA 대용 (proxy) 효과를 측정한 거였다. 별칭으로 `pca2d_lex` 라고 명명하고, 진짜 Hilbert curve (hilbert_real, Wikipedia xy2d 표준) 를 별도 9 cells × 2 modes 로 따로 측정해서 paradigm 대표 방법으로 추가.

둘째, RQ2 의 Neyman 할당이 비례 할당보다 약간 부정확한 역설 (paradox) 이 발견됐는데, 이는 PartSupp PK 의 KM20 클러스터 균등 분포 (CV=0) 와 클러스터 내 분산 범위 1.3 ~ 1.6 배의 좁은 특성 때문에 σ-가중 Neyman 이 proportional 과 통계적으로 동등이 되는 자연 결과.

## 6. 본 연구 권장 design 과 산업 적용 영역 (단계 6)

5월 측정 결과를 종합하면 본 연구가 권장하는 design 은 다음 세 가지 원칙의 조합.

1. **산술 평균 결합** — 본 논문 베르누이 추정량과 분포 인지 계층적 추정량을 산술 평균으로 합쳐서 한 쪽 추정량의 실패를 다른 쪽이 보완하는 안정적인 구조.
2. **cheap 근사 사용** — multi-table cell 에서는 비싼 864 차원 재학습 대신 두 single-table 클러스터 결과의 (s_A, s_B) tuple folding 으로 0 학습 비용에 더 좋은 정확도.
3. **method-aware 적용** — 12 anchor method 중 cell 별 K-민감도와 quality-민감도 패턴이 다르므로 sparse_rp 와 chao_weighted 에는 정밀 처리, Hilbert curve 와 HyperLogLog 에는 단순 처리.

산업 적용 영역은 두 가지. (1) PostgreSQL pgvector 의 default sampling 메커니즘에 우리 method 의 stratified estimator 를 산술 평균으로 추가. (2) Exqutor 의 §V-B 모듈에 우리 안 (산술 평균 + cheap 근사 + method-aware) 을 통합.

## 7. 향후 연구 방향

본 연구는 산술 평균이라는 가장 단순한 결합 방식부터 측정을 시작해서 결합 framework 자체의 효과를 baseline 수준에서 입증한 거야. 실제 산업 적용을 위해서는 데이터셋의 분포 특성, 차원, 질의 선택도에 따라 결합 방식이 동적으로 결정되는 data-aware ensemble framework 가 필요하고, 우리 산술 평균 결과는 그 framework 의 출발점이야.

### 7.1 Data-aware ensemble framework — 핵심 5 영역

1. **Distribution-aware ensemble** — skew / dense 데이터셋에 따라 결합 가중치 동적 결정
2. **Dimensionality-aware ensemble** — 차원 별 결합 방식 선택 (예: 차원 큰 → PCA preprocessing 결합)
3. **Estimator-confidence-aware (BLUE)** — 각 estimator 의 분산 추정 기반 분산 최소화 가중치 (Best Linear Unbiased Estimator 이론)
4. **Query-aware ensemble** — selectivity 별 결합 방식 변경
5. **Meta-learning adaptive ensemble** — 측정 환경 feature → ML 모델로 결합 가중치 학습 (우리 측정 portfolio 가 training set 으로 활용 가능)

### 7.2 일반 확장 6 영역

1. **다른 데이터셋 일반화** — YFCC, GLOVE 등에서 동일 패턴 검증
2. **논문 동적 framework 와의 완전 정합** — Q-error 신호 source 명시
3. **이론적 분산 분해** — Cochran 1977 §11.10 composite estimator 적용
4. **다른 결합 방식 비교** — 가중치 / 기하 / 분산 기반 (7.1 의 baseline 비교)
5. **다른 cheap 근사 후보** — PCA / Iterative refinement / Hash bucketing
6. **실제 시스템 적용** — pgvector 또는 Exqutor prototype 통합
