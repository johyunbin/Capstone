## 1. 30 초 요약

벡터 데이터베이스 옵티마이저가 거리 조건의 *결과 행 개수* 를 더 정확히 추정하도록, 코드 *세 줄* 을 손봤다. 단일 테이블 검색에서 보완이 켜지도록 진입 조건을 풀었고, 표본 추출 단위를 행 단위로 바꿨고, 데이터의 공간 구조를 활용한 층화 표본 분기를 새로 추가했다. 결과적으로 selectivity 0.5 구간에서 9.6 % 의 정확도 개선과, 그 위에 1.6 ~ 4.4 % 의 추가 개선을 통계적으로 확인했다. 분포를 사전에 모르는 환경으로의 확장은 5 월에 비교 실험한다.

### 2.2 핵심 용어 — 5 분이면 익힌다

| 용어 | 풀이 |
|---|---|
| 카디널리티 | 쿼리 결과로 나오는 행의 개수. 옵티마이저가 미리 짐작하는 값. |
| 임베딩 | 의미 거리가 보존되는 숫자 벡터로 데이터를 변환하는 절차. |
| Adaptive Sampling | Exqutor 가 인덱스 없을 때 쓰는 추산 방식. 표본을 늘려 가며 비율로 추정. |
| 베르누이 추출 | 각 행을 동전 던지듯 독립으로 뽑는 방식. 블록 단위 편향이 없다. |
| 층화 표본 | 데이터를 K 개 영역으로 나눠 각 영역에서 균등 추출 후 가중 합산. |
| Q-error | 추정값과 실제 값의 비율. 1 에 가까울수록 정확. |
| 회복률(Recovery Rate) | 분포를 모르는 방법이 분포를 알 때의 효과를 어디까지 회복하는지. |

### 2.3 우리 보고서의 4 가지 산출물 — 한 줄씩

1. **단일 테이블 사각지대 확인** (RQ1) — Exqutor 보완은 우리가 다루는 시나리오에서 동작하지 않는다. 코드를 읽어 확인했다.
2. **베르누이 추출의 효과** (RQ2-1) — 코드 한 줄 교체로 selectivity 0.5 에서 +9.6 % 중앙값 개선, p < 0.001.
3. **공간 인식 층화 표본의 효과** (RQ2-2) — 베르누이 위에서 1.6 ~ 4.4 % 의 추가 개선. 5-seed 95 % 신뢰구간 양수 확정.
4. **인과 관계 입증** (Two-Level 분해, HHI/CV) — 데이터의 쏠림이 클수록 공간 인식의 가치가 크다는 가설이 데이터에서 그대로 나타났다.
