## 1. 연구 주제

본 연구는 벡터 데이터베이스의 카디널리티 추정 정확도 문제를 해결한 Exqutor (arXiv:2512.09695v2) 의 Adaptive Sampling 이 가진 두 단계 한계 — 단일 테이블 vector range query 사각지대 (motivation finding) 와 naive uniform sampling 의 정확도 손실 (개입 측정) — 를 정량 드러내고, `vector.c` 한 줄 교체 (Pivot A) 와 data-side k-means K=20 기반 stratified sampling 의 native 구현 (Pivot C) 으로 두 sanitize 를 직교 ablation matrix 로 분리 측정한다. 본 보고서는 4 월 14 일~17 일 사이에 수행한 RQ1 Motivation + RQ2 본선 (Phase 1~7 및 4/16~4/17 보강 측정) 의 결과를 정리하고, 6 월 11 일 최종보고서까지의 RQ3 Distribution-Agnostic 확장 로드맵을 함께 제시한다.

본 v2 는 4 월 15 일자 초안 이후 확보된 세 가지 보강을 반영한다. 첫째, 5-seed 반복 측정과 95% 신뢰구간 산출로 Phase 6 Step 4 의 단일 seed 수치가 확률적 우연이 아님을 확인하였다. 둘째, D_target 을 각 데이터셋별로 재계산하여 SIFT 1.5M 과 DEEP 8M 에서의 외적 타당성을 정상 selectivity 영역에서 재확인하였다. 셋째, KM20 개선분을 Level 1 (비례 배분) 과 Level 2 (공간 인식) 로 분해하여 쏠림 기여를 정량화하고, 클러스터 분포의 HHI/CV 지표로 데이터셋 간 쏠림 격차가 KM20 효과 격차의 직접 원인임을 인과적으로 규명하였다.

## 2. 연구의 필요성

### 2.1 벡터 카디널리티 추정 문제

벡터 데이터베이스에서 *주어진 query 벡터와 유사도가 임계값 이상인 행의 개수* 를 추정하는 문제는 옵티마이저의 실행 계획 선택에 직접 영향을 미치는 핵심 작업이다. pgvector 는 벡터 조건의 선택도를 33.3% 로 고정 추정하고, VBASE 는 50%, DuckDB 는 100% 로 추정한다. 그러나 실제 선택도는 query 에 따라 0.001% 부터 90% 까지 매우 넓은 범위를 가지며, 고정 비율 추정으로는 옵티마이저가 nested loop join 과 hash join 사이, 또는 vector index 사용 여부 사이에서 잘못된 선택을 내리는 사례가 빈번하다. Exqutor 는 이 문제에 두 가지 해법을 제시했다. **ECQO** 는 HNSW 인덱스가 있을 때 range query 를 직접 실행해 1~2 ms 안에 정확한 카디널리티를 획득하는 방식이며, **Adaptive Sampling** 은 인덱스가 없을 때 모멘텀 기반 동적 샘플링으로 카디널리티를 근사한다. 두 방법으로 Exqutor 는 pgvector 에서 최대 1000 배, VBASE 에서 10000 배, DuckDB 에서 1.5~37 배 성능 향상을 보고했다.

### 2.2 Exqutor Adaptive Sampling 의 잠재적 약점

본 팀의 출발 가설은 4 월 3 일 교수님 미팅에서 합의된 명제로 정리된다. *Exqutor 의 Adaptive Sampling 은 무작위 샘플이 전체 데이터의 거리 분포를 대표한다는 암묵적 가정 위에 동작하며, 거리 분포가 한쪽으로 치우친 (skewed) 환경에서는 무작위 샘플이 밀도가 높은 영역에 편중되어 카디널리티 추정 정확도가 떨어진다.* 본 가설을 데이터로 확인하고, distribution-aware sampling (분포를 알 때) 과 distribution-agnostic sampling (분포를 모를 때) 두 노선에서 정확도 개선을 정량 측정하는 것이 본 연구의 큰 골격이었다.

본 가설을 4 월 14 일에 직접 검증하는 과정에서 본 팀은 두 가지 발견에 도달했다. 첫째, 4 월 3 일 합의의 핵심 명제 — *글로벌 skewness 지표 (Fisher γ 등) 가 클수록 Q-error 도 크다* — 는 96 차원 DEEP 벡터의 1M subset 100 query × 6 selectivity × 5 seed × 2 mode = 6000 측정에서 강하게 기각되었다. 둘째, 같은 데이터에서 Exqutor 가 사용하는 `TABLESAMPLE SYSTEM` 의 block sampling bias 와 `vector.c` 의 hook trigger 조건 (`table_count > 2`) 이 만드는 단일 테이블 vector range query 사각지대 등 다섯 가지 design constraint (본문 4 + 부록 1) 를 발견했다. 본 두 발견은 4 월 3 일 합의의 큰 골격을 유지한 채, 측정 정의와 본선 시나리오를 정교화한 결과 (이하 v4 수정 설계안) 로 이어졌다. 본 보고서의 §4 는 이 정교화의 모든 단계를 정량 결과와 함께 정리한다.

## 3. 연구 질문

본 연구는 4 월 3 일 합의의 RQ1/RQ2/RQ3 세 단계 구조를 그대로 유지하며, 각 RQ 의 측정 정의를 4 월 14 일~17 일의 정량 결과 위에서 정교화한다.

**RQ1 — Motivation 검증 (단일 테이블 사각지대 + 구조적 finding)**. Exqutor 의 Adaptive Sampling 은 단일 테이블 vector range query 시나리오에서 어떤 구조적 한계를 가지며, 그 한계는 어디에서 측정 가능한가? 본 RQ 는 (i) Hook trigger 사각지대, (ii) plan replacement 부작용, (iii) `TABLESAMPLE SYSTEM` block bias, (iv) query feature 사전 식별 불가능성의 네 finding 을 직접 소스 검증과 EXPLAIN ANALYZE 로 정량 드러낸다.

**RQ2 — Distribution-Aware (Pivot A + Pivot C 병합)**. 분포를 알 때 (또는 데이터 자체의 partition 을 사전 학습할 수 있을 때), 두 단계 sanitize — `vector.c` L889 한 줄 교체로 block sampling bias 제거 (Pivot A) + data-side k-means K=20 기반 stratified sampling 의 native 구현 (Pivot C) — 가 카디널리티 추정 정확도를 얼마나 개선하는가? 본 RQ 는 BERN/STRAT × dataset × selectivity 의 직교 ablation matrix 로 두 sanitize 의 효과를 분리 측정하며, 개선분을 Level 1 (비례 배분) 과 Level 2 (공간 인식) 로 분해하여 쏠림 기여를 수리적으로 분리한다.

**RQ3 — Distribution-Agnostic (Recovery Rate 프레임워크 7-way 비교)**. 분포를 모르는 상황에서, 사전 학습 없이 KM20 의 공간 인식 효과를 얼마나 회수할 수 있는가? 본 RQ 는 세 가지 패러다임 (Offline Partition / Online Query-Adaptive / Weight-based) 에 속하는 7 가지 방법을 Recovery Rate = (방법X − RANDOM20) / (KM20 − RANDOM20) 프레임워크로 비교하며, 본 중간 보고서 시점 (4/28) 에서는 설계만 확정하고 실험은 최종 보고서 (6/11) 국면 (W7, 5/12~5/18) 에서 수행한다. 상세 설계는 §6 과 `plans/RQ3 설계안.md` 에 정리되어 있다.

## 4. 연구 내용 — 4월 14일 ~ 17일의 측정 결과

### 4.1 출발점 — 4월 3일 교수님 합의

4 월 3 일 미팅에서 본 팀은 Exqutor 의 Adaptive Sampling 정확도 개선을 본선 주제로 확정하고, 두 트랙 — 분포 인지 / 분포 무인지 — 의 3 단계 실험 구조 (베이스라인 → 트랙 A → 트랙 B) 를 합의했다. 본선 시나리오는 **multi-table join with vector range filter** 로 가정되었고, 첫 단계의 판단 기준은 *Fisher 의 skewness γ 큰 그룹의 Q-error 가 작은 그룹 대비 2 배 이상* 이었다. 본 합의의 자세한 narrative 는 `plans/archive/연구설계안_20260403_162818.md` (v3) 에 정리되어 있으며, 본 보고서의 모든 정교화는 v3 의 큰 골격을 유지한 채 측정 정의만 4/14~17 데이터 위에서 단단하게 만든 결과다. v4 수정 설계안 (`plans/연구재설계안_20260415.md`) 이 두 버전의 차이를 표로 정리한다.

### 4.2 RQ1 1차 실험 — 가설 H1 기각과 Phase 5 8지표 전수 검증

본 팀은 4 월 14 일 오전에 연세대학교 BDAI Lab 서버 (`capstone2026@165.132.140.240`) 에 vanilla PG 16.9 + pgvector 0.7.1 환경을 구축하고, `partsupp_deep_10` (TPC-H sf10 + 96 차원 DEEP 벡터, 8M 행) 의 1M 결정론적 서브셋 위에서 RQ1 1차 실험을 5 단계 (Stage 1~5) 로 수행했다. 100 query 를 무작위 추출하고, 각 query 에 대해 6 개 선택도 구간 (0.001 / 0.010 / 0.050 / 0.100 / 0.300 / 0.500) 의 D_target 을 사전 계산한 뒤, Adaptive Sampling 을 Python 으로 재구현해 5 seed × 2 mode (`bernoulli`, `block_system`) × 100 query × 6 selectivity = 6000 측정의 q-error 를 산출했다. 본 실험의 자세한 절차와 산출물은 `experiments/results/rq1_motivation/summary.md §I~II` 에 정리되어 있다.

검증 결과는 가설 H1 을 강하게 기각했다. 4 가지 글로벌 skew 지표 (Fisher γ, log-Fisher γ, tail ratio P99/P50, Bowley skew) 와 query 별 median Q-error 의 Spearman 상관은 모든 24 개 조합 (4 지표 × 6 선택도) 에서 절대값이 0.2 미만이었으며, `|γ| > 1` 그룹과 `|γ| < 0.5` 그룹의 median Q-error 비율도 12 개 조합 모두에서 1.00 근처였다. 100 query 가 모두 Fisher γ < 0 (left-skewed) 이며 tail ratio P99/P50 도 1.07~1.17 의 좁은 범위에 모여 있어, 96 차원 벡터의 *고차원 거리 집중 (distance concentration)* 현상이 글로벌 skewness 지표의 변별력을 평탄화시켰다는 것이 1 차 진단이었다.

본 진단을 보강하기 위해 4 월 14 일 저녁 (Phase 5) 에 **로컬 4 지표** — k-NN distance entropy, k-NN PCA EVR1, KDE modality count, NN clustering coefficient — 를 numpy + scipy 만으로 직접 구현해 같은 100 query 에 적용했다. 결과는 24 개 조합 (4 지표 × 6 선택도) 모두에서 |Spearman ρ| < 0.2 였다. 글로벌 4 + 로컬 4 = **8 지표 전수 검증 후 query-conditional layer 정의가 사전 식별 불가능** 함이 확정되었다. 이는 본 연구의 중요한 negative result 이며, RQ1 motivation 의 한 축으로 직접 편입되어 *query feature 가 아닌 data-side 에서 layer 를 가져와야 한다* 는 Pivot C 의 정당화로 사용되었다.

### 4.3 Exqutor Design Constraint 발견 — 새 motivation 첫 줄

H1 기각의 정량 결과 위에서 본 팀은 Python 재구현이 Exqutor 네이티브와 정확히 일치하는지 확인하기 위한 옵션 A (Phase 3 native bitwise 검증) 를 같은 날 오후에 시도했다. 그 시도는 두 가지 강력한 finding 으로 이어졌으며, 본 두 finding 은 본 연구 motivation 의 새 첫 줄로 격상되었다.

**첫째 — Hook trigger 사각지대**. Exqutor 의 `pgvector_set_baserel_rows_estimate_hook` 은 `vector.c` line 243 의 `if (table_count > 2)` 조건을 통과해야만 활성화된다. 본 팀의 검증 query 인 `SELECT count(*) FROM partsupp_deep_10_subset_1m WHERE (ps_embedding <-> q) < D` 는 단일 테이블이므로 `table_count = 1` 이고, 따라서 hook 이 우회되어 PostgreSQL default selectivity 1/3 으로 fall-through 된다. 즉 단일 테이블 vector range query 는 Exqutor 의 Adaptive Sampling 함수 자체에 도달하지 못하는 사각지대다. 이는 Exqutor 원논문 본문에 명시되지 않은 design constraint 이며, 본 팀의 직접 소스 검증으로 처음 정량 확인되었다. 이미지 검색, 추천 시스템, RAG 의 retrieval 단계가 모두 단일 테이블 vector range query 의 전형이라는 실무적 관찰은 본 사각지대를 본 연구가 채울 수 있는 학술적 빈자리로 격상시킨다.

**둘째 — Plan replacement 부작용**. 위 hook 을 `if (table_count >= 1)` 로 한 줄 우회하면, outer query 의 base relation 노드 자체가 PostgreSQL 의 `Sample Scan` 으로 plan-tree 가 교체된다 (`Sampling Method: system, Sampling Parameters: ['0.0385'::real]`). 단일 테이블 시나리오에서는 outer query 결과 자체가 sample 안 부분 카운트로 격하되어 (예: true=100,000 query 에서 `SELECT count(*)` 가 32 반환), outer query 의 정확성이 깨진다. multi-table join 에서는 base table sample scan 으로의 교체가 join 결과의 부분 영향만 주지만, 단일 테이블에서는 outer query 의 의미를 잃게 만드는 design constraint 다.

본 두 finding 외에도 옵션 A 시도 중 (iii) q-error inf 발산, (iv) sample_size NaN 발산, (v) Adaptive update path SIGSEGV 의 세 가지 추가 design constraint 가 발견되었다. 본 세 finding 은 Adaptive Sampling 의 update path 가 multi-table only design intent 를 가정하고 만들어진 결과이며, 본 연구의 측정 단계에서는 `vector.update_sample_size = off` GUC 로 update 경로를 차단하고 sampling method 자체의 효과만 분리 측정하는 방식으로 회피했다. 자세한 narrative 는 `experiments/results/rq1_motivation/direction_pivot_rationale.md` 에 187 줄로 정리되어 있다.

### 4.4 Pivot A + Pivot C 병합 노선 확정 (4월 14일 17:35 KST)

위 finding 들을 근거로 본 팀은 4 월 14 일 17:35 KST 에 **Pivot A + Pivot C 병합 노선** 을 확정했다. 4 월 3 일 합의의 큰 골격은 그대로 유지되며, 다음 두 차원에서 정교화가 일어났다.

**시나리오 좁힘**. 본선 시나리오를 multi-table join with vector range filter 에서 단일 테이블 vector range query 사각지대로 좁힌다. 좁힘의 비용은 multi-table 벤치마크와의 직접 비교 불가능이며, 대응은 (i) 본 연구 motivation 자체가 사각지대를 드러내는 것이므로 multi-table 비교가 필요 없고, (ii) 단일 테이블 시나리오의 실무적 중요성이 본 연구의 외적 타당성을 강화한다는 것이다.

**측정 도구의 교체**. Layer 정의를 query-side feature 에서 data-side partition 으로 이전한다. Phase 5 의 8 지표 negative result 가 query-side feature 의 사전 식별 불가능성을 보였으므로, 본 팀은 데이터 자체에 대한 numpy mini-batch k-means K=20 (seed=42) 학습으로 stratum 을 정의하고 각 행에 `stratum_id smallint` 컬럼을 사전 부여해 query 시점의 overhead 를 0 으로 만든다.

본 두 정교화 위에서 두 sanitize 가 정의된다. **Pivot A** 는 `vector.c` L889 의 `TABLESAMPLE SYSTEM(%f)` 을 `TABLESAMPLE BERNOULLI(%f)` 로 한 줄 교체하는 단순 변경이며, Exqutor 가 사용하는 block sampling 의 row-correlation bias 를 제거하는 *fair baseline* 도구다. **Pivot C** 는 `vector.c` 에 +228 줄의 stratified sampling 분기를 추가하여 GUC `vector.sampling_method = 'stratified'` 활성화 시 per-stratum `ORDER BY random() LIMIT sample_size/K` 형태의 SPI SQL 로 층별 균등 sample 을 추출하고 Horvitz-Thompson 가중 카디널리티 추정식 `est = Σ (n_i × cnt_i / s_i)` 을 native 에서 계산하는 본 연구의 핵심 본선 구현이다. 두 Pivot 은 직교적이므로 SYSTEM/BERNOULLI/STRATIFIED × dataset × selectivity 의 ablation matrix 로 각 개선의 기여를 분리 측정할 수 있다.

### 4.5 Phase 4 — Pivot A Native 검증 (4월 14일 19:30~19:40 KST)

### 4.7 Phase 7 — 외적 타당성 확장 시도와 측정 artifact (4월 15일 08:31 KST)

Phase 6 Step 4 직후의 결과는 *1M subset × 96d DEEP 단일 dataset × 100 query × 1 seed* 라는 좁은 조건에 한정되어 있어 외적 타당성이 부족했다. 본 팀은 4 월 15 일 오전에 두 가지 외적 타당성 확장을 시도했다. **Phase 7-1 sf10 8M 재현** (`partsupp_deep_10_phase7_8m_subset`) 에서는 원본 `partsupp_deep_10` 8M 행을 별도 테이블로 COPY 후 (보존) numpy mini-batch k-means K=20 (seed=42) 으로 8M 전체에 stratum_id 를 학습·UPDATE 하고 인덱스 + VACUUM ANALYZE 를 적용했다. setup 17 분 + measurement 23 분, 100 query × s=0.500 D_target × 2 mode = 200 query 측정. **Phase 7-2 sift 128d 확장** (`customer_sift_10_phase7_noidx_subset`) 에서는 vanilla PG 55435 의 `customer_sift_10` (1.5M, 128d, HNSW 있음) 에서 c_custkey + c_embedding 만 Exqutor PG 55436 으로 minimal transfer 한 후 (838 MB, 2 분 33 초), HNSW 없이 별도 테이블에 KM20 stratum_id 를 부여했다. setup 3 분 + measurement 7 분, 100 query × s=0.500 D_target × 2 mode = 200 query 측정.

본 두 실험에서 의도한 selectivity 0.500 은 1M subset 에서 derive 된 D_target 을 8M / 128d 에 그대로 적용했기 때문에 actual selectivity 가 약 0.0001 영역으로 이동했다 (1M 과 8M, 96d 와 128d 의 거리 분포 차이). 이 극극소 selectivity 영역에서 BERN 의 `cnt=0 → 1` clamp fallback 과 STRAT 의 stratum 균등 추출이 모두 fallback 경로로 진입한다.

**초기 분석의 오류와 artifact 발견**. 본 팀은 최초에 EXPLAIN ANALYZE plan tree 의 `plan_rows` 값을 q-error 산출에 사용했으며, 이로부터 BERN median q-error 20810 vs STRAT 9.60 (8M, ratio 2168×) 및 BERN 3875 vs STRAT 9.48 (sift, ratio 409×) 이라는 극단적 개선율을 산출했다. 그러나 심층 검증 결과, STRAT 측의 `plan_rows` 가 100/100 row 에서 **정확히 20** (min=max=20, std=0) 으로 고정되어 있음이 확인되었다. 이 값은 stratified estimator 의 추정 출력이 아니라 plan tree `Aggregate → Append → [Subquery Scan × 20]` 구조에서 `find_scan_node` 가 반환한 **stratum LIMIT 상수** 였다. q-error 9.60 은 true_card 193 / plan_rows 20 = 9.65 의 산술적 결과일 뿐이다. Phase 6 Step 4 에서 확립한 측정 원칙 — `find_scan_node` 가 첫 Subquery Scan 의 plan_rows 를 반환하면 garbage 이므로 hook 이 `elog` 로 서버 로그에 기록한 `hook_est` 를 authoritative metric 으로 사용한다 — 에 따라 `hook_est` 기반으로 재분석한 결과는 완전히 반전되었다 (8M: STRAT −26.5%, sift: STRAT −325%). 두 데이터셋의 plan_rows 기반 paired Wilcoxon p 가 정확히 `1.948279922547955e-18` 로 identical 한 것도 scipy `wilcoxon` 의 `w_stat=0` saturation floor 에 의한 artifact 임이 확인되었다.

**Phase 7 의 재framing — boundary condition 과 후속 해소**. 본 결과는 Phase 4 의 s=0.001 tie 패턴 (sample 안 매칭 0~1 개로 두 모드 동치) 및 Phase 6 Step 4 의 s=0.001 동률 (median 2.5806) 과 일관된다. 극극소 selectivity 영역 (actual ≈ 0.0001) 에서는 어떤 stratification 전략도 cnt-clamp fallback 을 벗어나지 못하며, KM20 의 stratum 균등 추출이 오히려 BERN 대비 불리한 분배를 만든다. 이는 Pivot C 의 효과가 **정상 selectivity 영역에 한정**된다는 경계 조건을 정량적으로 확인한 결과이다. 본 팀은 이후 D_target 을 각 데이터셋별로 재계산하여 actual selectivity ≈ 0.5 로 재진입한 뒤 SIFT 1.5M 과 DEEP 8M 에서 Pivot C 효과를 재측정하였으며, 그 결과는 §4.8 에 상세 서술된다. Phase 7 의 외적 타당성 결손이 해소되는 동시에, 층화 샘플링의 효과가 안정적으로 발현되는 selectivity 하한 (s ≥ 0.050) 이 정량적으로 확정되었다. 상세한 검증 과정과 증거는 `experiments/results/rq1_motivation/phase7_artifact_verification_20260415.md` 에 공식 기록되어 있다.

### 4.9 클러스터 쏠림 정량화 — HHI 와 CV 지표로 본 데이터셋 간 격차

SIFT 의 KM20 효과가 DEEP 의 약 2 배에 달하는 이유를 인과적으로 설명하기 위해, 본 팀은 각 데이터셋의 K-means K=20 클러스터 크기 분포를 HHI (Herfindahl-Hirschman Index) 와 CV (변동계수) 로 정량화하였다. HHI 는 각 클러스터가 차지하는 비율의 제곱합으로 균일할 때 1/K = 0.05 이며 한 클러스터에 집중될수록 1.0 에 접근한다. CV 는 표준편차를 평균으로 나눈 값으로 균일할 때 0 이며 쏠릴수록 증가한다.

| 지표 | DEEP 1M (96d) | SIFT 1.5M (128d) | 균일 기준 |
|------|---------------|-------------------|----------|
| K | 20 | 20 | 20 |
| 최소 클러스터 크기 | 26,343 | 33,330 | 50,000 / 75,000 |
| 최대 클러스터 크기 | 81,233 | 148,202 | 50,000 / 75,000 |
| 최대/최소 비율 | 3.08배 | **4.45배** | 1.00 |
| HHI | 0.05274 | **0.05776** | 0.05000 |
| CV (변동계수) | 0.234 | **0.394** | 0.000 |

SIFT 의 CV (0.394) 는 DEEP (0.234) 대비 **68% 높다**. 특히 SIFT 의 최대 클러스터는 기대값 (7.5 만) 의 약 2 배인 14.8 만에 달하며, 상위 두 클러스터 (14.8 만 + 14.0 만) 가 전체의 약 19% 를 차지하여 균일 가정의 10% 대비 거의 2 배에 이른다. 이 쏠림의 정량 차이가 §4.8 에서 확인된 KM20 효과의 2 배 격차의 직접 원인이다. 즉 "데이터가 쏠려 있을수록 공간 인식 샘플링의 이점이 더 크다" 는 연구 가설이 HHI/CV 의 정량 지표와 Q-error 개선폭의 정량 차이 사이에 일관된 단조 관계로 뒷받침된다.

### 4.10 Two-Level Decomposition, Gradient 해석, Anomaly

§4.8 의 KM20 vs RANDOM20 대조는 "공간 인식" 의 기여를 식별할 수 있게 해준다. 본 팀은 개선분을 두 층으로 수리적으로 분해한다. **Level 1 (비례 배분)** 은 RANDOM20 의 개선분이며 파티션의 공간 품질과 무관하게 "나누는 것 자체" 가 제공하는 표본 크기 안정화 효과이다. **Level 2 (공간 인식)** 는 KM20 개선분에서 RANDOM20 개선분을 뺀 것이며, 공간 구조를 반영한 파티션만이 제공하는 추가 이점이다. 두 층의 합은 정의상 KM20 개선분과 같다.

| selectivity | Level 1 (비례 배분) | Level 2 (공간 인식) | Total (KM20) |
|-------------|--------------------|--------------------|-------------|
| 50% | +2.20% | −0.56% | +1.64% |
| 30% | +0.26% | +2.36% | +2.62% |
| 10% | +1.74% | +2.45% | +4.19% |
| 5% | +0.79% | +1.06% | +1.85% |
| 1% | −10.67% | **+19.60%** | +8.93% |

DEEP 1M 의 분해 결과는 selectivity 가 줄수록 Level 2 의 기여가 급격히 증가한다는 것을 보여준다. s=0.500 에서는 Level 1 이 지배적이고 Level 2 는 거의 0 이며, 쿼리 범위가 넓을 때는 파티션 품질과 무관하게 비례 배분의 안정화 효과만으로 충분함을 의미한다. 그러나 s=0.010 에서는 Level 2 가 단독으로 +19.60%p 를 기여하며 전체 개선의 원동력이 된다. 이는 좁은 범위 쿼리에서 결과 행이 소수 클러스터에 집중되므로 해당 클러스터를 정확히 아는 파티션 (KM20) 만이 올바른 표본을 추출할 수 있기 때문이다. SIFT 1.5M 에서는 쏠림이 더 크므로 s=0.500 부터 이미 Level 2 가 +2.06% 로 유의하며, s=0.050 에서는 +4.44%p 로 DEEP 1M 대비 더 이른 selectivity 에서 Level 2 가 지배적이 된다.

![Figure 9 — Two-Level Decomposition: KM20 개선을 비례 배분(L1)과 공간 인식(L2)으로 분해](/Users/hyunbin/Capstone/experiments/figures/rq2_aware/figure_9_two_level_decomposition.png)

#### Gradient 비단조성의 방법론적 배경

DEEP 1M 의 KM20 gradient 에서 s=0.100 (+4.19%) → s=0.050 (+1.85%) 의 비단조적 하락이 관찰된다. 이 비단조성의 일부는 D_target 계산 방식 차이에서 기인한다. s=0.050 실험은 초기 Phase 6 에서 SQL 기반 이진 탐색으로 D_target 을 산출하였으며, s=0.100 과 s=0.300 은 최종 실험 일괄 수행 (Phase 7) 에서 numpy 기반 D_target 계산으로 전환된 후 측정되었다. 두 방식은 부동소수점 정밀도와 실제 selectivity 달성 정도에 미세한 차이를 유발할 수 있으며, 이것이 인접 구간의 부분적 불연속에 기여한 것으로 판단된다. 전체적 상승 추세 (s=0.500 → s=0.010) 는 이 방법론적 차이와 무관하게 견고하며, SIFT mid-selectivity 보충 실험이 완료되면 교차 검증될 예정이다.

#### Anomaly 3건의 구조적 해석

선택도 구간별 세부 결과에서 세 가지 일관된 anomaly 가 관찰되는데, 이는 모두 같은 구조적 원인 — sample_size=385 의 절대적 부족 — 에서 기인한다.

- **Anomaly 1 (DEEP 1M s=0.500 에서 RANDOM20 > KM20)**: 이 영역에서 BERNOULLI 의 Q-error 가 이미 1.04~1.07 로 낮아 어떤 파티션이든 소폭 개선만 발생한다. KM20 과 RANDOM20 의 차이 0.56%p 는 seed 간 분산 (~0.5~1% std) 안에 있어 비유의적이며, Level 1 효과만 작동하고 Level 2 가 불필요함을 확인시킨다.
- **Anomaly 2 (DEEP 8M s=0.010 에서 KM20 이 −0.71%)**: 8M 에서 s=0.010 이면 true_card 는 약 8 만이지만 sample_size=385 가 추출하는 표본은 전체의 0.005% 에 불과하다. 이 극소 표본으로 8 만 건을 추정하면 Q-error 가 6~8 배까지 치솟으며 95% CI 가 [−21.13, +19.70] 으로 0 을 포함한다. 어떤 샘플링 방식이든 정확한 추정이 불가한 영역이다.
- **Anomaly 3 (SIFT 1.5M s=0.010 에서 KM20 이 −0.53%)**: 5 seed 모두 BERNOULLI median Q-error 가 1.4435 로 동일하다. 이는 hook estimation 이 같은 값을 반환하는 양자화 현상이며, 방향 자체가 불안정하다. KM20 이 방어 역할은 하지만 (RANDOM20 의 −12.11% 악화를 방지), 적극적 개선은 표본 부족으로 불가능하다.

세 anomaly 를 종합하면 **층화 샘플링의 효과가 안정적으로 발현되는 selectivity 하한은 s ≥ 0.050** 이라는 실험적 경계 조건이 확정된다. 이 범위에서 KM20 은 DEEP 1M/8M 에서 +1.6~1.9%, SIFT 1.5M 에서 +3.1~4.4% 의 일관된 개선을 보이며, Phase 7 에서 관찰된 극극소 selectivity 의 negative finding 과 상호 보완된다. 세부 분석은 `experiments/results/rq2_aware/anomaly_analysis.md` 와 통합본 §Anomaly 설명 절에 정리되어 있다.

### 5.2 본 시점의 한계 (honest report)

본 중간 보고서 시점의 RQ1/RQ2 결과는 다음 네 가지 한계를 인지하고 기록한다.

**(a) 단일 dataset family 에 대한 제한된 외적 타당성**. 4/16~17 보강 측정으로 deep 96d (1M, 8M) + sift 128d (1.5M) 의 두 데이터셋 family 에서 KM20 효과가 재현되었으나, 차원 96~128 의 좁은 영역에 한정된다. 768 차원 wiki 데이터셋 (`part_wiki_10`) 은 최종발표 W5 에 검증한다.

**(b) Mid-selectivity 의 5-seed CI 보충 결손**. DEEP 1M 은 5 selectivity 중 50%/30%/10% 에서 5-seed CI 를 확보하였으나, 5% 와 1% 는 단일 seed 측정에 그쳐 CI 가 없다. SIFT 1.5M 도 50%/5%/1% 의 3 구간만 5-seed 로 측정되었고 10% 와 30% 의 mid-selectivity 는 서버의 D_target 재계산 경로에서 `unrecognized node type` 오류가 발생하여 미측정 상태이다. 본 오류는 Adaptive Sampling 의 내부 노드 식별 자료구조와 보조 스크립트의 인터페이스 불일치로 보이며, 최종발표 W5 의 per-stratum BERNOULLI 최적화 작업에 부수하여 해소할 예정이다. 본 결손이 §4.10 의 gradient 비단조성 해석에 불확실성을 남긴다는 점은 명시한다.

**(c) Phase 7 의 경계 조건 명시**. Phase 7 의 8M / sift 128d 확장에서 D_target 을 재계산하지 않아 actual selectivity 가 약 0.0001 로 이동했으며, 초기 plan_rows 기반 q-error (2168× / 409×) 는 stratum LIMIT 상수 artifact 로 확정되어 철회되었다. 이후 D_target 을 각 데이터셋별로 재계산한 §4.8 의 재측정에서 DEEP 8M 은 1M 과 CONSISTENT, SIFT 는 DEEP 대비 2 배 효과로 정상 selectivity 영역에서의 외적 타당성이 회복되었다. 남는 한계는 s ≥ 0.050 에서만 층화 샘플링 효과가 안정적으로 발현되며, 그 이하 selectivity 는 Exqutor 기본 sample_size=385 의 구조적 하한에 의해 boundary condition 으로 분류된다는 점이다. 최종발표 W5 에서 per-stratum BERNOULLI 최적화 + sample_size 조정 sensitivity 실험으로 하한 완화 여지를 탐색한다.

**(d) `vector.c` 의 단일 테이블 hook 우회 수정의 reviewer 관점 위험**. 본 팀의 측정은 `vector.c` line 243 의 `if (table_count > 2)` 를 `if (table_count >= 1)` 로 한 줄 수정한 상태에서 수행되었으며, 변경된 binary 와 원본 백업을 모두 보존해 검증 가능하게 만들어두었다. 그러나 이 변경 자체가 Exqutor 의 design intent 를 임의로 patch 한 것으로 보일 위험이 있어, 본 팀은 멘토 자문 이메일에서 이를 직접 질의하고 narrative 톤 조정 권고를 요청했다 (회신 수령 후 §2~§4 서술에 반영 예정).

본 네 가지 한계 외에 본 연구의 측정 자체가 가진 정량적 약점은 §4 의 각 절에서 honest 하게 기록되었으며, Phase 5 의 8 지표 negative result 는 부정 결과로서 motivation 의 한 축으로 직접 편입되었다.

## 6. 남은 작업 — 최종발표 (5/27) + 최종보고서 (6/11) 까지

본 팀은 4 월 28 일 중간발표 직후부터 6 월 11 일 최종보고서 제출까지의 4 주를 W5~W8 로 분할해 다음과 같이 수행한다. 자세한 세부 작업과 리스크 대응은 `plans/연구재설계안_20260415.md §VI` 과 `plans/RQ3 설계안.md` 에 정리되어 있다.

**W5 (4/28~5/4) — 최적화 + Layer sweep + wiki 768d 검증**. 첫째, 현재 STRAT 의 `ORDER BY random() LIMIT` 의 BERN 대비 11 배 비용을 per-stratum `TABLESAMPLE BERNOULLI` 로 교체하여 2 배 이내로 줄인다. 둘째, Layer 후보 4 종 (KM30/40/50, random projection, multi-layer PCA, k-means on float16) 의 selectivity 3 구간 비교로 KM20 유지 또는 전환을 결정한다. 셋째, `part_wiki_10` (768d) 에서 KM20 학습이 empty cluster 없이 동작하는지 사전 검증하고, 실패 시 PCA 96d 축소 또는 100K subset 으로 fall-back 한다. 넷째, SIFT 1.5M 의 mid-selectivity (s=0.100, 0.300) 와 sample_size sensitivity 실험으로 §5.2(b) 의 결손을 해소하고 s≥0.050 boundary 의 완화 여지를 탐색한다.

**W6 (5/5~5/11) — 3 dataset × 3 mode × 6 sel × 10 seed × 500 query 전면 ablation**. 본 주차의 핵심 결과는 최종보고서의 main result table 이 된다. 예산 계산은 270,000 측정 × query 당 1~2 초 = 75~150 시간 으로, W5 의 per-stratum BERN 최적화 적용 시 약 25 시간으로 단축되어 주말 + 주중 야간 분할 수용이 가능하다. 결과 분석과 시각화 1 차도 본 주차 말에 착수한다.

**W7 (5/12~5/18) — RQ3 Distribution-Agnostic 7-way 비교**. 분포 무인지 상황에서 사전 학습 없이 공간 인식 효과의 몇 % 를 회수할 수 있는지를 측정하는 Recovery Rate 지표 — `recovery = (방법X − RANDOM20) / (KM20 − RANDOM20)` — 를 도입하고, 세 가지 패러다임의 7 가지 방법을 체계적으로 비교한다. **Offline Partition** 패러다임은 데이터 로드 시 1 회 계산하는 경량 사전 처리로 A(LSH 랜덤 하이퍼플레인), C(Random Projection · Johnson-Lindenstrauss lemma), E(Hilbert Curve · 공간 DB 의 space-filling 기법을 벡터 카디널리티 추정에 최초 적용), F(Mini-batch K-means · 1~5% 데이터만으로 근사 학습) 의 4 종을 포함한다. **Online Query-Adaptive** 패러다임은 쿼리 시점에 pilot sample 로 동적 적응하는 방식으로 G(Distance-Shell · 쿼리 벡터 중심 동심원), B(KDE-pilot · Neyman 최적 배분) 의 2 종을 포함하며, **Weight-based** 패러다임은 파티션 없이 가중치로 분산을 감소시키는 H(Importance Sampling) 의 1 종을 포함한다.

| 방법 | 패러다임 | 기대 Recovery | 사전 학습 | 구현 난이도 |
|------|---------|---------------|----------|-----------|
| C. Random Projection | Offline | 10~40% | 사영 1회 | 하 |
| A. LSH | Offline | 30~60% | 해시 1회 | 중 |
| E. Hilbert Curve | Offline | 20~60% | index 1회 | 중 |
| F. Mini-batch K-means | Offline | 75~95% | 1~5% 데이터 | 하 |
| G. Distance-Shell | Online | 25~50% | 불필요 | 중 |
| B. KDE-pilot | Online | 50~80% | 불필요 | 상 |
| H. Importance Sampling | Weight-based | 30~70% | 불필요 | 상 |

7 가지 방법의 차이는 stratum_id 할당 방식뿐이며, 측정 파이프라인 (multiseed_paired, hook_est 파싱, paired Wilcoxon) 은 RQ2 에서 완성된 것을 재활용한다 (H 만 hook_est 반환 공식을 가중 평균으로 수정). 핵심 회피 경로는 **Hilbert Curve 의 공간 DB 기법 최초 적용** 으로, 실패하더라도 negative finding 자체가 고차원 벡터에서 space-filling locality 가 붕괴하는 경계를 정량 확인하는 기여를 가진다. RQ3 의 구현 계획, 맹점 점검, 탈락 후보 상세는 `plans/RQ3 설계안.md` 에 12 개 대안의 탈락 근거까지 정리되어 있다.

**W8 (5/19~5/25) — 최종보고서 + 포스터 + 전시회 데모**. 본 중간보고서를 확장 + Phase 7 후속 결과 + RQ3 결과 반영하고, 포스터 제작 (Phase 6 Step 4 의 s=0.500 + 5-seed CI 를 hero figure 로 배치, Two-Level 분해와 Recovery Rate 결과 병기), 전시회 데모 스크립트 (Exqutor 기본 vs Pivot A vs Pivot C 세 경로 실시간 시연), 팀 내부 리허설 2 회를 완료한다.

본 4 주 로드맵의 세 가지 리스크 — (R1) 측정 시간 폭발, (R2) wiki 768d k-means 재학습 실패, (R3) RQ3 고차원 locality 붕괴 — 각각에 대한 fall-back 경로는 v4 수정 설계안과 RQ3 설계안에 정리되어 있다.

## 8. 결론

본 중간보고서는 4 월 14 일 ~ 17 일의 RQ1 Motivation + RQ2 본선 (Phase 1~7 및 4/16~17 보강 측정) 의 정량 결과를 종합한다. 4 월 3 일 합의의 큰 골격 (Exqutor Adaptive Sampling 의 정확도 한계를 데이터로 드러내고 두 트랙으로 sanitize 한다) 은 그대로 유지된 채, RQ1 의 측정 정의가 8 지표 negative result + 5 design constraint finding 으로 정교화되었고, RQ2 의 본선이 Pivot A (BERNOULLI 한 줄 교체) + Pivot C (data-side KM20 stratified native 구현) 의 직교 병합 노선으로 재정의되었다.

RQ2 본선의 유효 anchor 는 단일 Phase 6 Step 4 의 s=0.500 +1.81% p=4.01e-05 에서 **5-seed CI 로 확정된 3 데이터셋 결과 집합** 으로 승격되었다. 구체적으로 (i) DEEP 1M 에서 s=0.500/0.300/0.100 세 구간이 모두 95% 신뢰구간 하한이 양수 [+1.11, +1.45, +0.72] 로 확정되었고, (ii) DEEP 8M 에서 s=0.500 CI [+0.65, +2.86] 이 1M 의 [+1.11, +2.18] 과 겹쳐 규모 불변성이 확인되었으며, (iii) SIFT 1.5M 에서 s=0.500 CI [+2.66, +3.48] 이 DEEP 과 겹치지 않아 더 쏠린 분포에서 효과가 2 배로 정량 확대됨이 확인되었다. 추가로 Two-Level Decomposition 분석에서 KM20 개선분을 비례 배분 (Level 1) 과 공간 인식 (Level 2) 으로 분해하였으며, DEEP 1M s=0.010 에서 Level 2 가 단독으로 +19.60%p 를 기여함을 확인하여 본 연구의 핵심 가설 — "데이터의 쏠림이 클수록 공간 인식 샘플링의 가치가 크다" — 가 인과적으로 뒷받침되었다. 클러스터 분포의 HHI/CV 정량화는 SIFT 의 CV 가 DEEP 대비 68% 높다는 사실이 KM20 효과의 2 배 격차의 직접 원인임을 데이터로 확증한다.

Phase 7 의 초기 외적 확장 시도에서 발견된 plan tree artifact 는 철회되었으며, D_target 재계산 후의 정상 selectivity 재측정으로 외적 타당성이 회복되었다. 남는 경계 조건은 s ≥ 0.050 에서만 층화 샘플링 효과가 안정적으로 발현된다는 것이며, 이는 Exqutor 기본 sample_size=385 의 구조적 하한의 결과로 최종발표 W5 의 sample_size sensitivity 실험에서 완화 여지를 탐색한다. 본 중간보고서 시점의 네 가지 한계 — 단일 dataset family / mid-selectivity CI 결손 / selectivity 하한 / `vector.c` 우회 수정의 reviewer 관점 위험 — 는 W5~W8 로드맵에서 체계적으로 해소되며, RQ3 의 Recovery Rate 7-way 비교는 Pivot C 의 자연스러운 확장 경로로 W7 에 합류한다.

본 연구의 학술적 명제는 다음과 같이 좁고 정확하다.

> 본 연구는 Exqutor 가 자신의 multi-table only design intent 로 배제한 단일 테이블 vector range query 사각지대를 두 단계로 분석하고 개선한다. 첫째 단계는 finding 제시 (Hook trigger 사각지대 + plan replacement 부작용 + query feature 사전 식별 불가능성) 이며, 둘째 단계는 개입 측정 (`TABLESAMPLE SYSTEM` 의 block bias 를 BERNOULLI 한 줄 교체로 sanitize, naive uniform sampling 을 data-side k-means K=20 stratified 로 sanitize) 이다. 두 sanitize 의 정확도 이득은 직교 ablation 으로 분리 측정되며, 본 중간 보고서 시점에서 Phase 4 (4 구간 p<0.001) + Phase 6 Step 4 의 5-seed CI (3 데이터셋 / 3 selectivity 구간) + Two-Level 분해 (Level 2 단독 +19.60%p) 의 복수 유효 anchor 를 확보했다. 더 쏠린 SIFT 1.5M 에서 KM20 효과가 DEEP 의 2 배로 확대됨을 HHI/CV 정량 지표로 인과적으로 설명하였으며, Phase 7 의 boundary 조건 (s ≥ 0.050) 은 Pivot C 의 효과 범위를 정량적으로 확정하는 학술적 기여를 가진다. 최종 보고서 단계의 RQ3 Recovery Rate 프레임워크는 분포 무인지 상황에서 공간 인식 효과의 회수율을 7 가지 방법으로 체계적으로 비교한다.
